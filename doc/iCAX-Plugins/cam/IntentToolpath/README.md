# IntentToolpath：通用可编辑刀路组件

本设计于 2026-10-25 整理，2026-10-26 补充图层及右侧图层栏。核心要求是：绘制、导入、打断、合并以及工艺产生的刀路，均为具有稳定身份、可以继续选择和编辑的同一种刀路对象。

- [方案文档](IntentToolpath方案文档.md)：独立模块、组件组合、操作输入输出、注册接口、增量计算、持久化及完整交付条件。

## 核心模型

刀路具有稳定身份、精确几何和可继续编辑的能力。工艺与基础编辑统一记录为操作，输入明确、输出可关联；来源与当前加工结果分别解析。

```text
A → 微联 M → B
           → C → 加引线 → C 的当前结果
```

此时加工 B 与 C 的当前结果，A 和 C 的旧结果保留为来源。B/C 均可继续打断、合并、编辑或加工艺。删除 B 只排除该支路；取消 M 才可能恢复 A。上游变化时依靠精确映射保留下游编辑，歧义必须显式处理。

刀路支持单条/批量设置图层。场景右侧竖排显示图层色块，初始 8 层；选中刀路后点色块即换层并显示该层颜色，支持自定义新增、删除、命名及配色。归属、继承/覆盖、配色与默认层随工程保存并可撤销；拆分默认继承、重算保留手工换层、跨层合并明确目标。加工图层的工艺绑定与显示层颜色分别管理，右侧换色不暗中更换工艺，隐藏不等于停用加工。

核心提供统一对象、命令、操作图、有效输出、保存撤销和增量计算；工艺算法通过注册接入，产品通过适配器提供来源、上下文与业务流程。核心不依赖具体产品、机床或界面。

## 范围与状态

该能力以现有独立插件 `IntentToolpath` 为承载，供平面切割、管材切割、三维五轴切割等产品复用。实现时扩充这一公共组件，避免在各产品中复制刀路内核。

基础数据结构一次完整到位，统一完成身份、几何、图层及归属、编辑/工艺操作、来源映射、有效输出、异步增量、原生事务、保存和撤销。全部验收条件共同成立后统一接入产品；不交付缺功能的中间模型，不保留同步降级或双模型运行路线。后续新增工艺通过已定义的注册接口接入。

本文规定完整目标契约。源码已加入统一编辑操作图、方案/端口、持久排除、工艺注册和异步派生发布，FiveAxisCAM 已使用该操作图；具体 API、已验证范围及产品验收边界见[源码状态](../../../../src/iCAX-Plugins/cam/IntentToolpath/README.md)。不包含旧工程兼容迁移；这些原生能力的验证不代替真实产品工作流和界面验收，全部门槛仍须共同满足。

历史 Laser3DCAM 的刀路衍生设计可作为来源说明；涉及对象身份、删除、有效输出、存储和模块边界时，以本目录的共享设计为准。
