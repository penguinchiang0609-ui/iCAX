# iPlaneCAM 基础能力与界面交互

本轮将二维编辑抽到 `SDK/Cad`，由底图刀路与零件/板材草图共同使用。草图有独立 EC 身份和所属对象，进入编辑后复用当前视口，完成时校验材料并更新原零件或板材，取消则恢复原曲线；底图无需完成草图便能独立成立。

本轮验收及交付入口见 [开发验收版](README.md)。文内 r3/r4/r5/r6 测试数字为历史基线；复用r8已验原生672次调用基线，覆盖共享服务、草图、图层、后台任务、旧工程兼容及保存重开，通过日志见 [native-test.log](../../output/tests/iplane-cam-layers/native-test.log)。真实浏览器及包内回归另行记录，不能由原生结果替代。
## 1. 四个核心对象

**底图是正式二维工作台面。** 目标能力是直接导入、绘制、编辑和保存底图，以后也可以在底图上直接开展加工。它不是参数草图，不通过“确认草图”才能成立；底图与下料输入分别管理，使用底图不以排样为前提。

| 对象 | 内容与身份 | 对几何的要求 | 与其他对象的关系 |
|---|---|---|---|
| 底图 | 文档、图层、曲线/文字等图形对象、稳定对象 ID、几何版本、来源和单位 | 开放线、开放曲线和闭合区域都合法；导入对象有问题时可以定位、编辑 | 可以独立使用，未来可直接作为加工输入；下料另行导入零件与板材 |
| 零件 | 零件定义 ID、几何版本、外形与内孔、需求数量、允许的角度/镜像 | 作为排样材料时必须形成明确有效的材料区域 | 同一个零件定义可以有多件需求；每件排样实例另有身份 |
| 板材 | 板材定义、物理库存板 ID、外形、板孔/禁排区、边距及库存数量 | 作为排样输入时须具有有效材料外边界；板孔与禁排区不得被当作可用材料 | 相同规格可以归组，但物理板的身份、缺陷和使用状态必须保留 |
| 排样结果 | 任务 ID、输入版本快照、实际消耗板、具体件的变换、未排件、校验和报告 | 使用原始材料边界验收；结果完整性与几何合法性分别记录 | 引用输入快照；移动排样实例不会修改底图或零件原始几何 |

以上是领域对象划分。顶层界面只有“底图”和“下料”两页：底图承载正式二维绘制与编辑；下料在同一工作台内管理零件、板材库存和布局结果。零件、库存、布局各自保留独立身份，不另开顶层页面。

下料的零件通过“导入零件”取得，板材通过“导入板材”或“矩形板材”取得。底图与这些独立输入各自保存几何、稳定身份和版本，底图编辑不静默覆盖下料输入，布局也不回写底图或零件源几何。这些入口已注册真实 Scene SDO，限定类型导入和删除源文件副本后的保存重开已通过；手动布局调整尚未提供。

闭合检查发生在**零件/板材导入和排样输入验收**时；矩形板材设置也要校验有效尺寸与库存。不能因为底图有开放线，就阻止保存底图或继续绘制。导入文件内存在多个分离外轮廓时，必须明确它表示多个零件，还是尚未支持的固定组合；不能把它们的包围盒替代真实材料。

## 2. 真实现状与复用矩阵

下列路径均相对于仓库根目录。当前原生产品位于 `src/iCAX-Plugins/product/iPlaneCAM`；能力开放以 `PlaneScene.ReadState` 返回的 capabilities 为准。

| --- | --- | --- |
| 中性 DXF 读取 | `PlaneCAM.cpp::ImportObject` 通过 `ICadDocumentImportService::Load` 复用 `cad/OpenCascadeResourceImport`，嵌入原始源文件载荷 | 已验 7 份外部文件、unitless 明确选择、拒绝导入不增加对象/资源及删除源文件副本后重开；不等于完整 DXF 支持 |

| 原生绘制 | `PlaneDrawing.Create` 接入五类形状；完整轮廓预览、逐点/拖画、右栏数值输入和可读名称；绘制右键“闭合 / 取消 / 结束”，右栏无结束类按钮 | r3 包内菜单14/14、绘图15/15通过；临时点不提交 ECS，椭圆/样条未接 |

| 图层 | `PlaneLayer` SDO、视口右侧竖向色层栏及共享SDK管理界面；初始8色，支持创建、改名、配色、显隐/锁定、当前层、批量归层及迁移删除 | Color/Order/LayerID是typed EC；ICRM为派生显示材质。锁源/锁目标都校验，迁移含草图备份并可Undo；线型及原DXF层映射尚未提供 |
| ECS 业务权威 | `CPlaneProjectComponent` 保存 typed 参数；对象、任务、TaskInput、结果汇总、结果板、具体件、未排件分别为实体与 typed 组件 | 数量、版本、输入引用、任务参数及结果关系已通过保存重开；不使用全工程 JSON、Parameters blob 或 ResultRef 承载业务 |
| Undo/Redo 与保存 | `PlaneCAM.cpp::Mutate` 复用 Repository 撤销作用域/事务，AppShell 管理项目保存与原生历史，产品清单声明 `.ipcam` | 已验编辑撤销/重做、Undo 后分支版本冲突、无源文件保存重开、无效导入原子性和历史结果过期恢复 |
| 视口与工作台 | AppShell、`createWorkbench`、SDK 正交视口；两页共用画布，左零件、底部板材/结果、右当前对象参数 | 真实原生浏览器 10/10 已验多图形显示、结果板、资源及重开后二维 GeometryKind；界面专项 18/18 另验一板一显示、页面/参数联动与异步交互保护 |
| 中性排样服务 | `geometry/PlaneNestingServices` 注册 `IPlaneNestingService`，包装既有 C ABI；12/12 原生测试覆盖真板形、孔、数量、旋转/镜像、间距、预算与物理板身份 | 验证范围为给定多边形材料。产品记录解析近似误差并加入实际计算间距；服务不读写 ECS，不发布结果 |
| 原生任务与结果 | `PlaneCAM.cpp` 使用框架 Task 和取消令牌处理中性输入；`PlaneSceneBehaviour.cpp` 在所属 Scene 检查版本/取消后事务提交 typed 结果及子实体 | 已验真实排样、任务参数与输入快照、输入改变使结果过期。当前产品使用离散角步进；连续区间仅服务层支持。手动布局、余料和完整紧凑度指标未接 |

共享工作台的隔离约定见 `src/apps/_shared/workbench/README.md`。产品不直接导入 TubeDesigner 目录，也不复制其产品域；中性 reader、服务、视口、事务和资源机制沿框架组合。原始文件、几何及显示可使用版本化资源，业务属性与关系属于 ECS。
## 3. 统一工作台布局

界面参照 TubeDesigner 的现有工作台组织：顶部 Ribbon、左侧对象列表、中央共享视口、底部板材与结果停靠区、右侧参数栏，沿用 AppShell 的主题、按钮、图标与分隔条交互。参考 [TubeDesigner Ribbon](../../src/apps/tube-designer/webpage/ribbonDefinition.mjs)、[TubeDesigner 排样停靠区](../../src/apps/tube-designer/webpage/nestingDock.mjs) 与 [共享工作台主题](../../src/iCAX-UI/SDK/AppShell/theme/workbench.css)。界面组织通过共享工作台组合，管材模板、管型展开或草图模态流程不属于 iPlaneCAM 的底图或下料语义。

顶层只提供 `drawing`（底图）与 `nesting`（下料）两个页面。底图用于导入、直接绘制与图形编辑，未来可直接进入加工扩展。下料把零件需求、板材库存、排样参数与布局结果组织在同一工作台内；选择零件、板材或结果只更新当前对象、必要显示和右侧参数，不切换为新的顶层页面。

```text
AppShell：应用入口 / 项目切换 / 保存 / 撤销重做 / 窗口控制
产品 Ribbon：底图 | 下料；按页面组织绘制、编辑、零件、板材与排样命令组
下料工作台：
┌────────────────┬─────────────────────────────┬──────────────────┐
│ 左侧零件列表    │ 中央共享正交视口             │ 右侧参数          │
│ 零件定义/需求   │ 当前板边界、孔与布局          │ 当前对象/命令参数  │
│ 数量/未排件     │ 零件选择、姿态与操作预览      │ 来源、数量、设置   │
│                ├─────────────────────────────┤ 结果指标与问题    │
│                │ 底部停靠区：板材 | 结果       │                  │
│                │ 库存板/实际用板/结果选择      │                  │
├────────────────┴─────────────────────────────┴──────────────────┤
│ 中央画布下方状态栏：单位、当前工具、捕捉、正交、网格              │
├─────────────────────────────────────────────────────────────────┤
│ AppShell 底部：命令 | 日志，选项卡切换，共用可调高度面板          │
└─────────────────────────────────────────────────────────────────┘
```

底图页仍使用相同的工作台、视口和右侧参数机制；左侧显示文档、图层与图形，命令提示和坐标用于直接绘制。板材与结果停靠区属于下料页的业务区域，和 AppShell 的应用日志区分别组织，不用日志面板承载板材或结果。普通保存、改名等成功反馈写日志，不增加常驻“成功”横条。诊断详情可以展开，不挤占日常视口。

命令与日志在AppShell底部以选项卡切换，默认命令页。日志追加不会切换页签或抢焦点，日志节点和滚动保留；命令页保留原始文本、光标和选区。单位、当前工具以及捕捉/正交/网格开关位于中央场景的状态栏，在画布下方、底部辅助面板上方，右侧不再提供重复的交互设置卡片。切换辅助页、调整高度或异步更新不终止正在绘制的命令。

文件与项目动作直接使用 [AppShell 现有实现](../../src/iCAX-UI/SDK/AppShell/app/bootstrap.mjs)：左上角应用入口进入项目中心，标题栏提供保存和撤销重做、项目页签与窗口控制。产品 Ribbon 不再增加“文件”页签，也不重复实现新建、打开和保存。界面编排通过 `src/apps/iplane-cam/webpage/entry.mjs` 接入 `createWorkbench`，不是另做一套 HTML 外壳。

| 顶层页面 | 左侧 | 中央共享视口 | 底部业务区域 | 右侧参数与主要操作 |
|---|---|---|---|---|
| 底图 `drawing` | 文档、图层、图形/组；可定位导入问题 | 直接绘制与编辑；开放线合法 | 当前绘制命令提示与坐标输入 | 当前图形、文档与命令参数；底图导入、绘制、编辑和图层 |
| 下料 `nesting` | 零件定义与需求列表、数量和未排情况 | 当前板边界、板孔、具体件和布局；可查看来源与姿态 | 板材与结果停靠区：可用库存、实际用板与布局结果选择 | 随当前零件、板材、实例或任务显示参数；导入零件、导入板材、矩形板材设置、排样、结果检查与报告 |

下料页的对象选择和参数联动如下：

| 选择入口 | 当前对象 | 中央显示与右栏联动 |
|---|---|---|
| 左侧零件列表 | 零件定义或具体需求 | 可查看材料轮廓和孔，右栏显示编号/名称、需求、材料分组、角度/镜像及来源；保持在下料页 |
| 底部“板材”区域 | 库存板定义或具体物理板 | 显示真实板形、板孔/禁排区和可用区域，右栏显示规格、库存、物理板 ID、材料和边距；不新建板材页面 |
| 底部“结果”区域 | 某次任务结果及实际用板 | 中央显示所选板的布局，右栏显示输入版本、校验、完成情况与报告；在当前布局中选择具体件时改为实例身份与实际姿态 |
| 下料设置命令 | 当前排样任务 | 右栏编辑需求、库存选择及求解参数；列表与已有布局继续可见，未产生结果时明确显示空态 |

底图与下料页使用同一项目和正式 Scene。页面切换以及下料页内的对象选择均须保留各自合理的视图范围、选择和列表状态；普通参数刷新不重新创建编辑器。底部停靠区的折叠、大小及列表滚动与左右栏一起保护，不在每次选择对象时恢复成默认布局。无效命令不给误导性的可执行入口；不出现工艺/NC 的空页或占位按钮。

## 4. 底图与 CAD 命令交互

本节是完整 CAD 交互的设计要求，已实现范围以第 2 节为准。窗口/交叉选择、节点增删/拖动、完整图层样式及尚未接通的命令不能因列在本节而视为已交付。

### 4.1 选择和图层

- 普通单击选择图形；Shift/Ctrl 增减选择；空白处单击清除。树、视口和右栏使用同一对象 ID 选择集。
- 从左向右的窗口选择只选完全落入窗口的对象；从右向左的交叉选择包含与窗口相交的对象。预览线型区分两种方式。
- 图形、路径段和节点是不同选择层级；进入节点编辑须有明确状态，不能一次点击随机切换语义。
- 锁定层可显示和查看属性，但不参加普通编辑；隐藏层不参加视口拾取。图层显示/锁定不等于从已有零件需求或排样任务中删除几何。
- 列表或问题项定位对象时只调整必要的视口范围；不能顺带更换图层、改动几何或清空其他选择。

### 4.2 绘制、数值输入与取消

当前直线、折线、矩形、圆和圆弧使用统一的输入流程，鼠标、原位标注、右栏及底部命令输入共享同一份草稿。r5圆弧标注明确区分半径R、起始角α与扫过角θ；椭圆和样条尚未接通。

| 图形 | 当前操作与预览 | 完成方式 |
| --- | --- | --- |
| 直线 | 点击起点再点击终点，或拖动后松开；预览线段 | 第二点或有效拖动结束后一次提交 |
| 矩形 | 点击两个对角点，或拖画；预览完整四边 | 第二点或有效拖动结束后一次提交 |
| 圆 | 点击圆心再点击半径点，或从圆心拖画；预览完整圆 | 第二点/拖动结束，或右栏输入正半径 |
| 圆弧 | 保留圆心、起点、终点的鼠标路径；R/α/θ数值与角标注 | R→α→θ，最后一次Create |
| 折线 | 逐点添加顶点，预览已接受折线与当前候选段 | 三点起可右键“闭合”、C 或回点首点；两点起可右键“结束”或 Enter 开放提交，成功后退出工具 |

坐标接受绝对 `X,Y`、相对 `@dX,dY` 和极坐标 `@长度<角度`。r5圆弧数值标注用α给出起始方向、θ给出逆时针扫过量；鼠标仍可逐点指定起点和终点。右栏只有步骤、数值和“确定输入”，不提供闭合、结束或取消绘图按钮；底部命令输入仍可直接创建完整图形。

绘制中右键在光标处弹出且只弹出“闭合 / 取消 / 结束”三项。不适用或点数不足时禁用对应项：折线闭合需至少三个点，开放结束需至少两个点；取消丢弃未提交点并回到选择工具。已完成直线/矩形/圆的连续绘图工具可用结束退出，不产生多余实体。菜单打开时 Esc 先只关闭菜单，再次 Esc 取消未完成交互；失焦、切页和工具切换也清理菜单。

已有开放折线在画布选择后右键“闭合轮廓”，或选中后按 C，调用原生 `PlaneDrawing.Edit(operation=close)`。同一实体发布新的几何和显示引用，GeometryVersion 递增；Undo/Redo 恢复对应版本，保存重开仍保持闭合。`ReadState` 从当前几何派生 `isPolyline`、`closed`、`canClosePolyline` 决定可用性；无效/不适用输入明确拒绝，不增加对象或资源。

预览沿用既有 SDK 视口并复用共享曲线采样，只保留前端临时显示，不发布正式资源或 ECS。中间点不产生撤销记录，完整提交才使用“直线 1”“矩形 1”“圆 1”等名称创建正式图形。闭合沿用r3已验收语义，尺寸描述和事务编辑自r4接通。

#### r4 绘制、编辑与查看尺寸标注

绘制草稿通过 SDK 尺寸线显示R、W/H及当前直线/折线段L等辅助尺寸，标签采用TubeDesigner共用样式并贴合尺寸线。圆心或矩形起点后可在标签原位输入，不抢焦点、不要求移鼠标去侧栏；画布数字键、Tab及标签可进入尺寸编辑。

| 输入阶段 | 行为 |
| --- | --- |
| 圆 R | 输入正的有限半径，Enter 后一次创建圆 |
| 矩形 W | Enter 锁定宽度并转入 H；尚不创建图形 |
| 矩形 H | Enter 后用完整宽高创建矩形 |
| Tab | W/H 间切换，保留草稿，不创建实体 |
| 锁宽后移动鼠标 | 宽度保持，鼠标确定高度；按当前方向保留四象限 |
| 编辑过程中 | 活动标签位置和输入节点保持；鼠标移动、异步刷新不改输入字符串、选区和光标 |
| 失焦 | 不提交；只有明确完成操作才生成正式图形 |

绘制尺寸属于临时草稿，宽高和半径均须为正有限数；完整确认才Create。纯鼠标/拖画、右键三项、C/Enter折线与Esc保持。查看时，在选择工具下选中一个可见底图图形，即读取原生派生尺寸：

| 图形 | 可编辑尺寸 | 查看边界 |
| --- | --- | --- |
| 单一圆 | R | 半径取自解析曲线 |
| 单一圆弧 | R、α、θ | 角度单位°，真实角弧/射线 |
| 单一直线、两点开放折线 | L | 不是任意多段折线总长编辑 |
| 正交矩形，允许整体旋转 | 局部W/H | 基于矩形局部边方向，不取世界包围盒当宽高 |
| 复杂、复合或不满足矩形判定的图形 | 无 | 只读外形W/H，不冒充矩形 |

双击可编辑标签，Tab切换W/H保留同一草稿且不提交；Enter一次提交修改，Esc丢弃，失焦不提交。尺寸修改通过 `PlaneDrawing.Edit(operation=dimensions)`，携带原 `expectedGeometryRef`；原生核对资源URL/版本、适用图形和数值后，以一次正式事务修改同实体几何/显示引用及版本。查询 `dimensions` 无写入，显示尺寸不是第二份业务状态。原生及包内真实浏览器已覆盖这些行为、异步保护、Undo/Redo和保存重开。

#### r5 圆弧R/α/θ

α为相对+X方向的逆时针起始角，可输入负数或0，规范显示为`[0,360)`；θ从该方向逆时针扫过，范围`0<θ<=360`。α/θ使用°，R使用mm，不能把角弧当成弦长或线段长度。

数值绘制R Enter后转α、α Enter后转θ，前两阶段不生成实体，θ完成时一次Create；鼠标圆心/起点/终点保留。选中圆弧后双击标签可编辑，Tab在字段间切换并保留同一事务草稿；α改变保持θ，θ改变保持起方向，单改R保留原始角数值。Esc、无blur提交、异步所有权及节点/焦点/选区/滚动保护沿用尺寸编辑机制。

SDK `setDimensionAnnotations`的`kind=angle`用圆心、半径和角度范围绘制角弧及射线，α放内圈、θ放外圈。标签保留原几何锚点，使用现有相机缩放查看，编辑输入仍固定并保留引线。θ=360沿用同起终角表示整周；极小θ若不能可靠表示则拒绝，不转成整周。非法扫过角返回`PLANE_INVALID_ARC_SWEEP`，不会以无效输入修改原图形。原生历史基线及r9包内圆弧专项均已通过。

| 输入/动作 | 设计行为 |
|---|---|
| 工具启动 | 提示下一步所需输入，显示可用选项；不弹出管材截面或草图确认对话框 |
| 鼠标移动 | 只更新临时预览；不产生场景版本和撤销记录 |
| 坐标输入 | 明确支持绝对 `X,Y`、相对 `@dX,dY`、极坐标 `@长度<角度`；按命令接受半径、距离或角度。单位统一显示，语法错误不提交 |
| Enter | 接受当前有效输入，或结束允许结束的连续命令；提交后形成一个有名称的撤销步骤 |
| Esc，有活动命令 | 取消未完成输入、手势和预览；保留之前完成的对象。已经发出的原生提交不由 Esc 撤回，其晚到响应不得抢回新选择、工具或输入 |
| Esc，无活动命令 | 清除当前选择或退出节点编辑，回到选择工具；不回退项目、不关闭底图 |
| Ctrl+Z，有活动多点命令 | 撤回本命令最后一个输入点；无活动命令时使用正式场景历史。文本输入框有焦点时，优先保留正常文本撤销行为 |
| 拖动编辑 | 拖动过程是预览，完成时一次提交；Esc 恢复拖动前状态，不产生半个几何修改 |

命令不能依靠当前屏幕缩放来决定数值输入是否闭合。明确输入的坐标须按工程单位解析；吸附半径只影响鼠标候选，不改变用户已经输入的精确尺寸。

创建等待期间改选对象，返回结果不覆盖后来的对象选择；取消、切换工具/页签或项目后，不恢复旧预览和旧输入。无效终点保留已接受前缀供修正；更新后的吸附候选随正式对象/几何版本刷新，旧查询响应不能混入当前绘制。

### 4.3 吸附

底部统一提供捕捉开关及类型选择，至少覆盖端点、中点、圆心、象限、交点和最近点；正交单独控制。采用既有候选高亮和名称提示，不把吸附点直接写入 CAD，直到用户接受本次输入。

屏幕像素半径用于选择附近候选；精确点由原始曲线及参数计算。显示折线、网格和预览采样不成为新的几何事实。相同位置有多个对象时，候选需可轮换并显示所属对象，不因重合而丢失源对象的可达性。

当前二维交点捕捉仅有有限附近线段逻辑，通用曲线交点、切点/垂足、稠密大图索引等属于需补齐并单独验收的能力；不能把三维 BRep 吸附和二维曲线吸附直接视为同一份现成实现。

### 4.4 编辑与历史

移动、复制、旋转、镜像、缩放、打断、合并、修剪、延伸、偏移、圆角、倒角、阵列和修图共享选择、预览、参数检查、提交、取消流程。涉及几何改变的命令通过场景事务发布新的几何资源版本；一条命令是一个原子历史步骤。

修图应列明去重、补断口、精简、裁剪自交等选项并预览结果。删除短线不得默认开启；修图容差不能被排样算法暗中调用。结果报告可以追溯哪些源对象被删除、替换或拆成多个对象。

## 5. DXF 导入、角色与单位公差

### 5.1 底图与下料分别导入

底图页的“导入 DXF”将文件导入正式底图文档。下料页提供独立的“导入零件”和“导入板材”入口，并显示目标零件集合或库存分组；“矩形板材”通过尺寸和库存参数设置板材。每个入口的业务角色明确，不能把底图中的现有图形自动纳入下料输入。

底图导入保持全部来源对象和图层关系。下料导入则检查材料区域，明确外轮廓、内孔、分离区域、需求或库存数量；单个文件不天然等于单个零件，一条闭合曲线也不天然等于板孔。检查失败必须定位到导入文件的来源图形，不能自动改成包围盒或静默删掉无法解释的线。

### 5.2 通用基础 DXF 的验收范围

设计要求覆盖 LINE、ARC、CIRCLE、ELLIPSE、LWPOLYLINE/POLYLINE（含 bulge）、SPLINE、BLOCK/INSERT 及阵列变换，保持图层、编码、单位、模型空间/图纸空间与可见性信息。文字、标注及填充对象应保留其来源和语义，不能因不参加排样就从底图无提示丢弃。

当前 iPlaneCAM mapper 仅接通 LINE、ARC、CIRCLE、LWPOLYLINE（含 bulge），检查 XY 平面、挤出方向及有限坐标；未支持的实体明确拒绝，底图也不静默跳过文字、填充或标注。ELLIPSE、SPLINE、旧 POLYLINE、BLOCK/INSERT、文字/标注/填充及原 DXF 图层映射均属于缺口，不能用“已导入文件”代替几何完整性验收。

同一图块的多次插入应保留各自实例路径；不能按几何完全相同就删除重复实例。原 DXF handle、图块引用路径、来源文件摘要与导入后稳定对象 ID 的映射，应成为来源记录的一部分。中性读取服务本身不分配零件、板材或排样身份。

### 5.3 单位和公差

当前内部工程长度和显示均使用 mm，对象保存来源单位与来源类型，原文件嵌入工程。已知 `$INSUNITS` 使用英寸、毫米、厘米或米换算；缺失、unitless 或未识别时要求明确 `units`，前端在右栏提供明确选择后重新提交，未确认前不创建对象。任意文档显示单位切换尚未提供。

以下数值用途独立：

| 数值 | 作用 | 不得混用为 |
|---|---|---|
| 鼠标吸附半径 | 屏幕附近候选选择 | 修图或闭合公差 |
| 连接/修图容差 | 明确接受的断口连接、几何修复 | 自动隐藏导入错误的阈值 |
| 曲线近似误差 | 为排样生成有误差界的计算表示 | CAD 保存精度或屏幕细分数量 |
| 零件间距/板边距/孔边距 | 排样约束 | 曲线误差或允许重叠量 |
| 求解与结果验收精度 | 当前后端的几何数值条件 | 用户可以任意放大的“通过开关” |

权威底图保持精确曲线；算法输入可以是单独生成的计算表示，但必须记录其来源版本和误差界。当前 iPlaneNesting 材料内核（`src/iCAX-Engine/foundation/iPlaneNesting/src/material/polygon_geometry.cpp:15`）有固定 `1e-6` 线性/面积验收规则及量化条件，公开 ABI 也未提供任意 CAD 公差设置；适配层不能承诺一个未接通的统一容差滑块。

当前支持的解析边界复用 OCCT 检查相交/重叠。计算离散采用不超过 0.05 mm 的圆弧弦高界并计入端点连接误差，计算 PartGap 加 `2 × 最大零件误差 + 1.1e-6`，StockMargin 加 `最大零件误差 + 最大板材误差 + 1.1e-6`，板外边与板孔统一受该边距约束。用户参数、误差界和实际计算间距分别保存；报告仍标明 `PolygonMaterial`，不声称任意原曲线已精确验收。

### 5.4 错误信息

错误显示“对象 + 原因 + 可执行修正”，并支持在树和视口定位。例如：

- 底图导入：来源实体不支持、单位未确定、图块引用丢失、非平面对象或坐标无效。
- 导入零件：开放轮廓、分叉、自交、孔与外轮廓相交、分离区域含义不明确。
- 导入或设置板材：尺寸/库存无效、孔越界、孔间相交/包含/接触、边距用尽可用区域。
- 排样：具体未排件、库存不足或求解达到时间/复杂度限制，分别说明；限时未找到位置不能写成“已证明放不下”。

错误不覆盖尚未提交的命令输入。下料导入或板材设置失败不得留下部分零件/库存，也不能自动改为底图导入；底图文档及其未提交编辑保持独立。

## 6. iPlaneNesting 适配边界

### 6.1 身份和生命周期

通用领域层持有文档/几何版本、零件定义、具体需求实例、板材定义、物理库存板和任务结果的稳定 ID。算法适配器只为一次任务创建 PN2 会话，并维护领域 ID 与 PN2 Shape/Part/Sheet 句柄的映射；这些指针不进入项目文件，也不作为界面对象 ID。

一份几何定义可对应多件具体需求；不能以轮廓数组下标或显示名称代替实例身份。排样结果必须守恒：每个需求实例只在某张结果板上出现一次，或者在未排清单中出现一次；使用数量不能超过快照库存。

当前 `PN2_GetResult` 返回板材定义句柄，同一板材类型多库存的物理序号未通过公开 ABI 返回。如果必须区分每块实际库存板，应一块物理板对应一个 Sheet 句柄、数量为 1；等价库存归组时也必须由领域层明确分配物理板身份。带不同缺陷的物理板不得混成一份板孔定义。

### 6.2 几何、坐标和板孔

- 零件内孔属于零件材料几何；板孔/缺陷属于板材可用材料定义；两者不是同一种对象身份，也不能因为画面上的包含关系就自动互换。
- 板孔可以使用现有 `PN2_SheetAddDefectWithOffset`；外边距和每个孔的间距分别传入，不能重复相加。保留同一套原始材料验收，不用矩形包围盒或凸包代替凹轮廓。
- SDK 异形板要求其包围盒原点为 `(0,0)`，见 `src/iCAX-Engine/foundation/iPlaneNesting/src/api_material.inl:36`。适配应显式保存源坐标到板局部坐标的变换，并在显示、导出和回查时恢复，不能更改底图坐标来满足算法入口。
- SDK 支持圆弧轮廓入口，但并不意味着 CAD 的所有 NURBS/图块/材料语义已经接通；精确源几何与计算几何分开保存。
- 两套现有排样变换约定不同：`SheetNesting.h:14` 是先局部镜像后旋转；`iPlaneNesting/src/geometry.cpp:48` 是先减 pivot、旋转，再沿 Y 镜像。适配必须转换完整变换；不能直接复用旧 Pose 的角度和镜像字段。

### 6.3 后端能力声明

当前材料域有 500 个具体件、100 类/张物理板、64 个姿态约束、单环 8192 顶点等限制；材料保护偏置、L-offcut、多头组合及部分后处理入口明确不支持。见 `include/iPlaneNesting.h:95`、`src/iCAX-Engine/foundation/iPlaneNesting/src/api_material.inl:68`。

这些是后端当前能力，不是底图的文档限制。底图可以保存超过一次求解上限的几何；创建排样任务时应检查并解释限制，不能截断图形或悄悄分批后声称是同一个全局解。

排样读取输入快照，在后台运行并返回中性结果；项目/SDO 决定是否提交和如何持久化。用户取消或输入版本改变后，晚到结果不能覆盖当前工作。现公开 ABI 没有任意时刻中断求解的接口，后续任务适配必须明确取消行为，不能在求解途中删除会话或强杀应用来冒充取消。

## 7. 排样结果的手动编辑与验收

本节为后续设计要求。当前提供布局查看、板选择及报告，尚未接通手动移动、旋转、镜像或其提交验收入口。

在下料页底部选择布局结果与实际用板后，可在中央视口选择具体件并移动、旋转或在允许时镜像。拖动只预览候选，不修改零件源几何。右栏显示具体件 ID、来源零件/版本、所在物理板和实际姿态，底部结果选择与左侧零件列表保持联动。

提交一次手动编辑前，对新结果执行真实几何验收：

1. 具体实例、物理库存和输入版本仍有效，无丢件、重复件或库存超用。
2. 变换满足原零件角度/镜像许可；连续角保留实际求得值。
3. 所有材料位于真板形内，不穿入板孔/禁排区，并满足外边距和逐孔间距。
4. 零件材料不重叠且间距满足要求；零件放入另一零件内孔时按真实材料判断。
5. 记录验收版本和诊断。失败的拖动候选不得变成“已验证结果”，也不得改变之前保存的有效布局。

结果若需要保留尚未通过的编辑，应明确标识为待验草稿，与正式有效结果区分；任何正式布局报告不得隐去该状态。一次有效手动编辑对应一个正式撤销步骤，撤销/重做仍核对原输入版本。

界面报告分别显示：几何是否合法、需求是否全部完成、实际用板数和未排件；固定板材净面积利用率；占用包络与排布紧凑程度。可用余料只有在独立几何计算证明后才能给出尺寸，不能把所有空白面积直接称作可复用余料。

## 8. 项目保存、重开与刷新保护

项目的权威业务保存于 MainScene Repository：typed 参数、图层、对象/需求数量、任务、结果汇总、物理结果板、placement 姿态及 unplaced 原因使用实体字段与 ID 关系。`PlaneComponents.h` 是当前字段契约；资源仅保存原始文件、版本化几何和显示载荷，不能用全工程 JSON 或布局/报告资源代替 ECS。

重开项目应从 ECS 恢复业务实体、typed 参数和结果关系，从嵌入资源恢复其引用的源文件与几何；不依赖原始文件仍在原目录或旧 PN2 会话仍在内存。报告按结果实体查询生成，不依靠另存的 JSON 报告 blob。

上述正式数据恢复已由原生产品、外部 DXF 和真实原生浏览器流程验证：测试只删除专门准备的源文件副本，用户下载文件保持原样。LoadBaseline 不触发 Awake，产品在 OnStart、启用和必要的首次更新重建非持久运行态及二维显示类型；未完成任务恢复为 Interrupted，查询本身不初始化或提交任务。

视口显示、几何版本和界面会话状态分开。当前已验正式对象、布局资源和二维显示恢复；跨重开的活动页面、选择、视图范围及临时草稿恢复需单独确认，不包含在业务数据保存通过的结论中。不保存尚未提交的一半命令为正式几何。

异步导入、排样和参数响应必须遵守：

- 优先局部更新；不替换仍在使用的画布、输入框和事件监听器。
- 确需替换 DOM 时，在实际替换前捕获最新焦点、文本光标/选区及左右栏、底部停靠区和嵌套容器滚动；不能使用请求发出时的旧位置。
- 恢复焦点使用 `preventScroll`，然后恢复滚动；对象/字段已删除时不把焦点给其他对象的同名字段。
- 旧项目、旧页面或旧选择对象的响应不能抢回当前焦点、相机、选择和滚动，也不能覆盖用户后续输入。
