# Products

本目录放置基于 iCAX Engine 设计的具体产品文档。

## 目录结构

- `Laser3DCAM/`：已撤下独立产品的三维线条切割 CAM 设计参考，共享能力仍保留。
- `TubeDesigner/`：管材产品参数化设计、装配预览、制造拆单与 STEP 输出；[中性管材 CAD 表达与编辑器接入](TubeDesigner/04-中性管材CAD表达与编辑器接入.md) 说明下料编辑的共享几何定义。
- `TubeOne/`：已撤下独立产品的管材 CAM 与 CSG 原语模型设计参考。
- `TubeCAM/`：TubeDesigner 管材 CAM 的[详细规格](TubeCAM/01-管材CAM详细规格说明书.md)与[实施方案](TubeCAM/02-管材CAM详细技术实施方案.md)，设计、下料、加工统一到 TubeDesigner。
- `FlatLaserCAM/`：历史平面激光 CAM 方案文档，仅作参考，不对应当前 `src/apps` 落地产品。
