# TubeDesigner P0 产品与架构设计

## 1. 产品定位

TubeDesigner 是 iCAX 上的管材产品参数化设计与制造拆单产品。它承接旧 StepModelGenerator 中已经验证的防盗窗参数与拆单规则，但不把旧程序的界面、文件耦合和一次性流程原样搬入新框架。

产品边界如下：

| 产品 | 负责的问题 | 主要产物 |
| --- | --- | --- |
| TubeDesigner | 产品是什么、怎样装配、拆成哪些制造零件 | 产品实例、装配构件、连接意图、制造零件、STEP |
| TubeOne | 制造零件怎样排样、编程和加工 | 工艺、刀路、仿真与机床输出 |

TubeDesigner 可以在后续阶段把制造零件交给 TubeOne，但两者保持独立工程与独立产品清单。

## 2. P0 目标

P0 只做一条完整、可验证的纵向链路：

1. 用户新建 .tubedesigner 工程。
2. 选择“防盗窗 1 号”模板并输入尺寸、数量、截面与预留。
3. 系统生成产品装配预览。
4. 系统同时生成制造零件与显式连接意图。
5. 用户检查零件编号、角色、长度和数量。
6. 用户把每个制造零件导出为独立 STEP 文件。

默认参数生成两根外框、一根中间竖管和四根横管，共 7 个制造零件、12 个连接意图。

P0 暂不包含 Excel 批量订单、防盗窗 2/3 号、圆管、安装孔、吊装孔、公母口、V 槽折弯和 TubeOne 一键交接。

## 3. 领域模型

### 3.1 ProductTemplate

模板是有版本的纯规则。当前模板标识为 security-window-1@1.0.0。输入参数相同且模板版本相同时，应生成稳定的零件顺序、编号和连接关系。

### 3.2 ProductInstance

CProductInstanceComponent 保存产品编号、模板标识、模板版本和参数快照，并指向当前生成批次。修改参数并重新生成时，新结果替换当前设计，但仍以一次撤销命令提交。

### 3.3 AssemblyMember

CAssemblyMemberComponent 表示产品中的装配构件，保存角色、截面、壁厚、中心线端点、长度和预览几何。它只回答“成品装起来是什么样”。

### 3.4 JointIntent

CJointIntentComponent 显式保存被加工的目标构件、插入构件、连接模式、装配间隙和交点。P0 的连接模式为 through。

不能在几何生成阶段重新猜测连接主从关系；模板求值时一旦确定，后续制造几何、清单和工艺交接都应读取同一份意图。

### 3.5 ManufacturingPart

CManufacturingPartComponent 表示实际下料和导出的制造对象，保存来源构件、零件号、数量、长度、制造几何与文件名。

装配构件与制造零件是不同实体，P0 虽然是一一对应，模型仍不把这种关系固化。后续 V 槽折弯、拼焊或合并下料可以形成一对多、多对一关系。

### 3.6 GenerationRun

CGenerationRunComponent 记录模板版本、生成状态、零件数和问题数，使模板升级、结果追踪和后续批量订单具备稳定落点。

## 4. 参数与拆单规则

防盗窗 1 号使用矩形空心管，参数包括：

- 产品编号、高度和宽度；
- 横管数量、中间竖管数量；
- 首横管距顶部、末横管距底部；
- 外框管、中间竖管、横管的截面宽度、深度和壁厚；
- 横支管和竖支管的安装预留；
- 开孔装配间隙。

预留为 -1 时，使用外框管宽度的一半。零件编号按模板稳定顺序生成：

1. 左外框；
2. 右外框；
3. 中间竖管，从左到右；
4. 横管，从上到下。

编号格式为“产品编号-三位序号”，例如 TD-001-007。

连接处选择截面较大的管材作为开孔目标构件，截面较小的管材作为插入构件。P0 用插入构件外包络加装配间隙切割目标构件。

## 5. 几何与资源

TubeDesigner 为每个零件生成两份独立 BRep 资源：

- preview：完整矩形空心管，用于装配预览；
- manufacturing：应用全部连接开孔后的实际制造几何，用于 STEP 输出。

两份资源使用稳定命名 URL，并作为工程内嵌资源保存。逻辑构件实体 ID 和 ResourceID 不随重新生成而变化；内容更新通过同一 ResourceID 下的新 version 表达。装配构件、制造零件和渲染实例都保存自己实际引用的资源版本。

重新生成时，资源池先写入同一 ID 的新版本，再由一次数据库事务把组件引用切换到新 version。撤销/重做只恢复组件上的版本号。后端 View 将组件中的 ResourceID 与 version 原样投影，前端据此读取精确历史版本，不把“资源池当前版本”误当成实体引用版本。

预览 BRep 通过现有 RenderInteraction 能力发布成前端 Mesh；制造 BRep 由 TubeDesigner 注册的 OpenCascade STEP 导出器按组件记录的精确版本写出。

这一区分是产品模型的硬边界：未来 V 槽折弯的预览可能是折弯后的成品形态，而制造几何仍是展开或带槽的单根管材。

## 6. 后端命令

| SDO | 输入 | 返回 |
| --- | --- | --- |
| TubeDesigner.List | 空对象 | 模板、当前产品、构件、零件、连接与生成批次 |
| TubeDesigner.Generate | 模板参数 | 更新后的完整 TubeDesigner 快照 |
| TubeDesigner.ExportAll | targetDirectory | 已导出的文件路径和数量 |

前端只通过这三个命令访问领域状态，不直接拼装 Entity 或 BRep。

## 7. 前端工作区

工作区复用 iCAX 已有三维视口、相机、渲染发布和工程状态设施：

- 左侧为参数表单与生成入口；
- 中央为产品装配预览；
- 右侧为制造零件清单和 STEP 输出；
- Ribbon 提供生成、恢复默认值和导出命令；
- Excel 导入与“送入 TubeOne”以禁用入口表达后续方向。

## 8. 验收基线

P0 完成的最低标准：

- TubeDesigner.dll 可在 Debug x64 构建；
- 产品清单可被 iCAX 发现并创建 .tubedesigner 工程；
- 默认参数稳定生成 7 个零件和 12 个连接；
- 默认外框长度为 1800 mm，中间竖管长度为 1750 mm，横管长度为 1150 mm；
- 装配预览使用未开孔几何，STEP 使用开孔后的制造几何；
- 7 个零件可按稳定文件名分别导出 STEP；
- 核心模板规则有独立自动化测试。

## 9. 后续阶段

建议按以下顺序继续：

1. 在防盗窗 1 号上补安装孔、吊装孔和端部连接规则；
2. 引入防盗窗 2/3 号，共享参数协议并保持模板版本隔离；
3. 加入圆管和型材库；
4. 建立 V 槽折弯的“一根制造零件、多个装配段”模型；
5. 增加 Excel 批量订单和批量输出；
6. 定义 TubeDesigner 到 TubeOne 的制造零件交接协议。
