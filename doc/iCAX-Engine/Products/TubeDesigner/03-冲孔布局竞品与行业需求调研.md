# 冲孔布局：竞品与行业需求调研

调研日期：2026-09-08。范围：管材冲孔的孔位分布规则、尺寸含义、变更联动及表格交互；不是切割路径排序，也不涉及坡口工艺实现。

## 1. 结论与证据边界

现有向导的四种轴向排布只是基础，不能据此认定已经达到“不弱于维宏”的目标。需要把“孔的形状”和“孔的位置规则”分开：管型库支管、参数化刀具（包括 V 槽）、本地 DXF 轮廓应共用布局能力，而不是分别只有少量排列功能。

用户明确提出的三项——两端固定后按数量均分、从一端按步长排列、从中心向两端扩散——应成为首批验收主线。调研还发现，真正容易形成差距的是：不等距、自动孔数、分区与孔组、逐孔例外、跨面对齐，以及修改管长后仍保持原来的尺寸意图。

证据分为三类：

- **官方功能证据**：产品手册和功能帮助。只证明文档所述版本/入口的能力，不替代安装软件后的实测。
- **实际需求证据**：用户原帖、制造商产品和订货说明。证明需求存在，不足以量化市场频率或占比。
- **本项目建议**：由上述证据及用户明确要求推导的规则、优先级和验收案例，不冒充竞品已经实现的功能。

本轮没有安装、操作竞品，也没有修改产品代码。部分官方页未标版本；部分论坛原页跳转登录，采用搜索索引可读的原帖正文，阅读可复现性弱于直接可访问的手册。公开资料没找到某项功能，统一记为“未证实”，不写成“不支持”。

### 值得借鉴、但不是切管竞品的成熟交互

Fusion 官方阵列帮助明确区分“总跨度均分”和“固定步距”，提供双向对称及逐实例抑制。SOLIDWORKS 的表格驱动阵列则允许正负坐标、坐标表保存/加载、指定定位参考点。这两项分别支持我们采用“明确布局意图”和“表格输入任意位置”的设计判断，但不能算成国内切管向导的已实现功能。[Fusion 阵列][c11]、[SOLIDWORKS 表格阵列][c12]

另需区分两种 Excel 能力：柏楚的“脚本 Excel 导入”可以通过定制脚本和参数表生成带孔零件；“通过 Excel 表格批量导入零件”则是读取已有文件路径、名称、数量。后者不能证明支持孔位置表，前者也不是已公开统一字段的任意孔坐标导入。[脚本 Excel][c14]、[批量文件导入][c15]

### 两个不能混为一谈的尺寸

1. **孔中心距与孔边净距**不是同一数值。制造商 EE Ingleton 也把 pitch 与 bridge 分别用于中心间距和孔间实体宽度；只写“孔距”会产生实际歧义。[制造商尺寸说明][u10]
2. **V 槽中心距与折弯制品内空**也不是同一尺寸。超控专门提供内空输入，并解释不同 V 槽端距基准的区别。这说明 V 槽虽然属于刀具，仍可能需要自己的尺寸换算，不能一律套圆孔中心距。[超控 V 槽][c13]

以下“产品含义”是本项目的推导，不是用户原话。没有把国外通用 CAD 用户帖子当成中国切管工厂的需求频率统计。

| 诉求 | 可追溯的实际证据 | 对本产品的含义 |

| 管长改变后，固定步距、自动增减孔 | Onshape 原帖的 2018 年跟帖直接描述方管一面的一排孔，要求参考另一端并按间距自动决定数量。[方管用户原帖][u01] | “数量固定”和“按区间自动数量”必须分开 |

## 4. 建议建立的布局规则体系

以下是本项目规格建议，不是竞品功能清单。优先级表示实现先后，P0 不代表完成全部竞争力目标。

### 4.1 轴向布局

| 编号 / 优先级 | 用户看到的方式 | 用户固定什么 | 自动计算或必须说明什么 |
| --- | --- | --- | --- |
| L01 / P0 | 从首端／尾端按步长 | 首孔位置、步距、总孔数 | 尾端剩余距离；可反向，不能靠输入负孔数表达 |
| L02 / P0 | 两端留距，中间均分 | 首端距、尾端距、总孔数 | 实际步距；两端距可以不同 |
| L03 / P0 | 固定步距，整体居中 | 总孔数、步距 | 首尾余量；奇数中心有孔、偶数中心为空档 |
| L04 / P0 | 从中心向两端扩散 | 中心位置、步距、中心有孔／中心留空、总数或对数 | 对称位置；中心有孔要求奇数总数；中心留空可设置首对孔偏移 |
| L05 / P0 | 固定步距，按可用区间排满 | 可用区间、步距、对齐方式 | 孔数和余量；余量留首端、留尾端或平分，三者明确可选 |
| L06 / P0 | 不等孔距 | 首孔位置、后续间距序列 | 累加位置、总孔数、末端余量；序列可粘贴，重复次数显式填写 |
| L07 / P1 | 最大间距，自动均分 | 区间端点、最大中心距或最大净空 | 满足上限的整数孔数及实际距离，不把近似目标间距当硬上限 |
| L08 / P1 | 分区布孔 | 每段起止、各段布局规则 | 段界去重、区间冲突及总数；支持局部留白 |
| L09 / P1 | 孔组重复／交替孔型 | 组内孔位置及孔型、组间规则 | 总组数、每组孔数、实际总孔数分别显示 |
| L10 / P1 | 自定义位置表 | 各孔的轴向位置和横向位置／角度 | 检查单位、重复、越界；支持表格粘贴及保存复用 |

“从中心扩散”的位置集合与加工先后顺序要分开。如果用户还需要中心先切、再向两端交替切，这是另一个工艺排序需求，不能由布孔方式自动决定。

### 4.2 可以组合的横向、周向和例外规则

- **跨面布局**：当前面、指定面组合；同轴向坐标同步或各面独立。相邻面孔可轴向错位，对面孔可对齐。布局位置与当前面/反向面/双面/贯穿的切除方式是两类属性。
- **圆管布局**：固定角度步长、整圈指定排数、局部角区、指定角度列表；整圈不能把 0° 和 360°算成两个位置。
- **错列**：相邻排偏移半步或指定距离；不能只有轴向数乘周向数的矩形乘积。
- **孔组镜像**：镜像整组；区别“位置镜像”和“刀具姿态也镜像”，尤其适用于非对称 DXF。
- **例外孔**：跳过单个实例、改变个别实例属性、禁孔区及与已有孔的净距检查。跳过后默认不重新压缩剩余孔；重新均分必须由用户显式选择。
- **重复规则复用**：保存的是排布规则，不仅是生成后的坐标；换主管长度、支管尺寸或 DXF 后重新计算，并保留可追溯的例外孔标识。

横向/周向基础阵列和跨面共同基准应随 P0 一并核对；分区、孔组、错列和位置表属于 P1 的主要竞争力。渐变间距、螺旋、目标开孔率反求等先放 P2，待目标客户样件验证。

## 5. 尺寸与计算契约

### 5.1 坐标和计数先统一

- 主管中心保持在场景原点，轴向范围可表示为 `[-L/2, +L/2]`。从首端标注的工艺距离 `s` 转成场景坐标 `x = s - L/2`；场景居中不应取消首尾端定位。
- 界面“数量”统一为**这一排的总孔数，包含首孔和末孔**。周向排数、孔组数、刀具体数量、实际形成的切口数分别统计。
- “两端各放一个，再在中间增加 N 个”若作为快捷输入，必须写明是中间新增数量，总数为 `N+2`。
- 对倾斜/异形端面，区分共同主管基准与各面有效区间；各面均分与跨面对齐可能不能同时成立，不能暗中切换。

### 5.2 常用公式和例子

以下是自行定义的验收数学模型：平直管、单排、同向且同尺寸孔，先按中心位置计算。`L` 为选定布局区间的主管长度，`a/b` 为首末孔中心到两端的距离，`N` 为总孔数。

| 模式 | 位置公式 / 条件 |
| --- | --- |
| 首端固定步距 | `s_i = a + i·p`，`i=0…N-1` |
| 尾端固定步距 | `s_i = L-b-i·p` |
| 两端固定、数量均分 | `p=(L-a-b)/(N-1)`，要求 `N≥2`；位置 `a+i·p` |
| 固定数量和步距，整体居中 | `s_i=L/2+(i-(N-1)/2)·p` |
| 区间内固定步距，自动孔数 | 区间 `[A,B]`，`N=floor((B-A)/p)+1`；只适用 `B≥A,p>0`；余量 `r=B-A-(N-1)p` |
| 最大中心距、端点固定 | `N=ceil((B-A)/p_max)+1`，再按 `N-1` 段均分；`A=B` 单独处理 |
| 指定间距序列 | `s_0=a`，`s_i=s_(i-1)+d_i`；不把每个 `d_i` 当绝对坐标 |

以 `L=1000` 为例：

- 两端中心距各 100，总数 5：`100,300,500,700,900`。
- 首端距 100、步距 150、总数 5：`100,250,400,550,700`。
- 中心有孔、步距 100、总数 5：`300,400,500,600,700`；场景 X 坐标为 `-200,-100,0,100,200`。
- 中心留空、步距 100、总数 6：`250,350,450,550,650,750`；场景 X 为 `-250,-150,-50,50,150,250`。

中心扩散的“首对孔偏移”可以不是半步：中心为 500、首对偏移 100、外扩步长 150、每侧 3 孔，结果为 `100,250,400,600,750,900`。它与普通居中等距阵列不同，应保留为独立布局意图。

### 5.3 净距不能靠改标签实现

对沿轴向投影宽度为 `w` 的相同、对称、未旋转孔：中心距 `p=净距g+w`；首端孔边留距 `h` 对应首孔中心 `a=h+w/2`。两端和孔间全部要求同一净距时，`g=(L-Nw)/(N+1)`，不是 `L/(N+1)`。

例如长 1000、5 个轴向宽度 20 的孔，所有孔间和端部净距相等，应为净距 150，中心位置 `160,330,500,670,840`。直接按 `L/(N+1)` 给中心定位会得到另一种结果。

这些公式不能直接扩展到任意相贯孔、异形端面和旋转 DXF：必须使用实际轮廓的轴向前后范围，并把“沿排列方向的投影净距”“外接框净距”“三维轮廓最短距离”区分清楚。支管名义直径不一定等于其在主管上形成的孔宽。无法可靠计算的距离应禁用并说明原因，不显示假精确值。

### 5.4 冲突和特殊情况

- 任意长度下，首端距、尾端距、整数孔数和固定步距不能全部任意指定。选择布局模式就是明确哪项由系统计算。
- `N=1` 时不能默默忽略其中一端约束：两端要求落在同一点才成立，否则应提示冲突或由用户换成单孔定位。
- 空白主管、零条孔记录仍允许保存；它不同于一条开启的阵列记录输入非法数量。
- 越界时给出哪一个孔及超出多少。默认保留完整孔；需要端部开口时由明确的开口意图控制，不能悄悄裁成半孔。
- 跳孔后显示“候选位置数/已跳过数/实际孔数”，不强制补齐到原数量；补齐属于另一种求解策略。
- 单位明确为 mm 或 inch，内部不提前舍入；显示精度不决定模型精度。

## 6. 对当前实现的只读核查

本节来自当前工作区代码，不是本轮运行测试。工作区已有大量未提交更改，本轮全部保留。

| 检查点 | 当前情况 | 与目标的差距 |
| --- | --- | --- |
| 轴向排布入口 | `punchWizard.mjs:365` 的四个模式覆盖固定步距、端部均分和两端留距 | 没有规则化的自动孔数、间距序列、分区和位置表 |
| “距中心” | 界面有中心参考，但底层仍按 `station + i·pitch` 单向展开 | 不能当作独立的中心向两端扩散；`middle-fixed` 能得到部分对称结果，但未表达中心孔/首对偏移意图 |
| 均分含义 | `punchWizard.mjs:58` 的 `equal` 直接使用 `L/(N+1)`，没有使用孔形尺寸 | 实际是端部到中心与中心步距相等，不能称孔边净距均分 |
| 单孔与两端约束 | `end-margins` 在数量为 1 时取首端距、步距为 0 | 未按两个端距是否指向同一点处理冲突 |
| 端面变更后的基准 | 侧面刀具采用端面 datum；支管脚本按基础主管边界计算位置 | 同一输入在不同来源下存在基准不一致风险，需三类来源交叉实测，不能仅看预览居中 |
| 周向阵列入口 | 原生代码有周向旋转；界面中 `toolTarget=part` 的定位区域隐藏了阵列面选择 | 不能仅凭底层能力声称支管/DXF 的表格已完整暴露周向控制 |
| 例外位置 | 可停用一整条记录 | 缺少阵列内部跳过一个孔的稳定标识和交互 |
| 大批量预览 | 前端当前限制单零件 1000 个展开刀具；原生路径逐实例处理 | 密集穿孔场景需性能基准；本轮没有测量帧率和计算耗时，不擅自承诺支持规模 |

## 7. 交互落点：继续使用场景下方的表格

不新增一整页大参数表单。保留用户已经明确的场景、ViewCube、母材中心原点及场景下方记录表。

1. **每行是一条孔型/孔组及其布局规则**。基础列为来源、孔型与尺寸、加工面、布局方式、定位基准、固定参数、计算结果、例外数量。
2. 切换布局后只显示该模式所需的可编辑单元格；计算值只读。例如两端固定时能填首距/尾距/总数，步距作为结果显示。
3. 不等距、分段、孔组内部和自定义位置表在当前行内展开子表；支持复制粘贴、增删行、键盘移动和撤销。不是把每个普通孔都强制展开成主表一行。
4. 场景选择一组时高亮整组；选择单孔时定位到该组的例外记录。显示当前选择的端距、孔距和首末孔编号，不依赖状态栏文字猜效果。
5. 提供简洁的一维尺寸预览，和三维刀具拉伸体/最终切孔同步；三者使用同一份求解结果。拖动或改数时显示实际数量、实际间距、剩余长度和冲突。
6. 更换支管、刀具或 DXF 只改变形状来源；布局规则保持。若新轮廓导致越界/干涉，应准确标出失效位置，不静默缩小或重新排孔。

建议实现顺序：先统一距离、数量、基准与规则存储，再完成 P0 布局及共享求解，最后扩展孔组/分区/例外和性能。不要先添加下拉菜单，再分别在预览与生成端补不同的坐标算法。

## 9. 下一阶段的验证边界

这份报告已足以确定布局功能结构和现有缺口，但不能据此宣布全面超越任何竞品。还需要以同一组真实样件，在维宏、小步、柏楚与本产品上记录完成步骤、所需输入、错误提示、修改后行为及预览一致性。方菱通用向导尚缺细节资料，应继续索取对应版本教程或实际试用证据。

优先收集的样件：两端不等留距的护栏横杆；中部有孔/无孔两种中心阵列；分区孔距健身架立柱；每组两个孔的安装管；已有大孔的减重管；错列金属穿孔管；带斜端面的跨面对齐件；相同布局换三种孔型来源的零件。

可以作出的阶段结论是：**“丰富布局”应落实为统一规则、清楚的尺寸语义、变更联动和实例例外，而不是仅增加几个排布名称。当前实现尚未覆盖完整目标。**
