# 三维五轴 CAM 产品规格说明书

版本：规格基线 1.2。日期：2026 年 10 月 13 日。

配套文档：[三维五轴 CAM 技术方案设计书](D:/penguinchinage0609/iCAX/doc/3DCAm/02-三维五轴CAM技术方案设计书.md)。

本产品基于 iCAX 框架，为三维工件提供从 CAD 准备、切割定义、工艺编程、五轴运动规划到仿真与加工程序交付的完整工作流程。FACAM 是功能和操作流程参考，工程格式、加工程序、机床接口与产品交互由我们独立设计。本规格定义完整产品应做什么及如何验收，技术设计书定义实现方式。

以下需求均为待实现和验收的产品要求，不代表当前代码已具备相应能力。M01—M10 为功能模块编号，Mxx-Rxx 为可追踪需求编号。没有标注可选的条款均属于完整产品范围。

## 1 产品目标和使用范围

### 1.1 产品目标

用户导入工件后，可以定义加工面和轮廓、设置工艺及姿态、选定机床与装夹，生成完整的切割和空移运动。通过仿真发现并定位问题，修改后重新验证，最终生成与所选设备配置一致的加工程序。工程保留每一层的可编辑输入，支持后续尺寸、工艺、机床或装夹变化后的重算。

适用工件包括曲面薄壁件、汽车覆盖件、弯管和变截面梁等具有三维修边、切孔需求的工件。不同工件族分别声明可用的识别和加工策略，并分别验收。主要工艺为激光切割，包括连续姿态轮廓、固定摆轴标准孔和具有明确截面要求的倾斜/坡口切割。

工件准备接入 iCAX 的 CAD 几何能力，承担导入、检查、定位和必要的加工几何处理。完整参数化 CAD 产品设计、平面材料排样优化、控制器伺服闭环不属于本 CAM 的功能模块；产品通过明确接口消费 CAD 结果并交付设备程序。

### 1.2 使用角色

| 角色 | 主要工作 | 必须得到的结果 |
| --- | --- | --- |
| 编程人员 | 准备工件、定义切割线、设工艺、调姿态与顺序 | 可编辑、可重算、问题可定位的加工工程 |
| 工艺人员 | 管理材料/厚度条件、工艺参数和可用范围 | 可复用且版本明确的工艺配置 |
| 设备配置人员 | 配置机床运动链、工具、标定、限位和输出能力 | 与实际设备一致的机床配置 |
| 操作与验证人员 | 核对装夹、定位、程序及验证报告 | 可核对来源和适用条件的加工交付包 |

角色用于说明流程责任，不要求首版实现复杂的组织权限系统。同一用户可承担多个角色。

### 2.1 模块责任与用户菜单

2026-10-13 最终布局为 **工件、CAD、CAM、仿真、帮助**。M01—M10 仍是领域责任划分，不等于顶部页面数。工程新建、打开、保存和另存为复用 iCAX 统一文件入口，产品不再自建文件页。

| 顶部页面 | 用户主要操作 | 责任模块 |
| --- | --- | --- |
| 工件 | 导入模型；粗/精定位与装夹；生成板式夹具、拆单、平面下料及编号拼焊资料导出 | M02 M03；M01提供公共工程能力 |
| CAD | 几何检查、修复、测量；可选三维零件编辑与 CSG 开孔 | M02；三维编辑可不提供，不是加工前置 |
| CAM | 自动提取、手动选面、草图投影；单一切割定义的孔/姿态/起点；工艺、生成调整、排序、头部轨迹仿真、现场定位和输出；设备与规划设置 | M04 M05 M06 M07 M08 M09 M10；M03提供定位计划 |
| 仿真 | 真实机型、完整机床结构、运动链、行程、工具标定与装夹的数字孪生；问题定位及整机报告 | M06 M08 |
| 帮助 | 说明、诊断、日志、关于和重置布局 | M10 |

导入加工为主流程，CAD 辅助编辑不构成进入 CAM 的强制阶段。夹具制造流程为“按工件形面生成支撑/底板 → 确认避让和装配 → 板件拆单编号 → 平面切割图、板件清单与编号拼焊资料”。板件来源必须是实际可制造的平面几何，不是三维外观的任意投影；夹具下料交付与工件五轴程序分开。

CAM 轨迹仿真只显示工件、切割头与切割/空移路径，用于检查顺序和头部姿态。独立仿真页驱动真实机型的完整机床，形成与机型、装夹和计划版本绑定的整机结论。缺少实机配置时显示待配置；头部轨迹播放、通用示意机床或无问题列表都不能替代整机通过结论。

跨页保留统一加工任务树、对象选择和仍有效草稿；切割定义与生成运动分别显示。孔形与加工姿态分别表达，不因识别为圆孔就自动决定固定摆轴。起点和孔属性各维护一份来源。关键点编辑针对局部姿态，刀路调整针对整体方向，空移调整针对工序连接。

粗定位建立编程坐标；精定位配对实测 XYZ 并校准；CAM 三点定位准备供现场测量的模型点计划。未实测不能标记已定位，已有有效精定位时不得重复叠加同一变换。

草图投影从 CAM 发起：建立工作平面 → 绘制并标注尺寸/孔距 → 选择目标面与投影方向 → 核对并确认切割线。保留草图、约束、工作平面、目标面和设计轴向；投影不改变实体。CAD CSG 开孔改变零件实体，两者用途和数据归属不同。

M05—M07 仍由一个“生成刀路”入口协调。上述为功能设计基线；当前页面仅连接部分共享原生通道，夹具、投影、完整规划、仿真与输出等未接入能力不能假成功。配套三级功能表见 `output/pdf/三维五轴CAM-三级功能规格表.pdf`。

### 2.2 全面对标的范围

对标基准是本地《FACAM三维五轴套料软件用户手册（汽车覆盖件版）》V1.1.0，软件版本10.2504.2.0，共37个PDF页面。功能和操作效果按第19章逐项对应；手册没有披露的算法和内部数据不能据此推定相同。本文“覆盖”均表示规格覆盖，功能实现、效果对比和设备验收另记状态。

自主工程与程序格式保持不变，不承诺读取FACAM工程、生成柏楚私有`.stepnc`或直接被FACut-C执行。三维工件编程的功能对标与第三方文件互操作是不同范围，后者仅在另有明确设备适配需求和接口依据时建立。FACut-C的实时控制、示教、PLC和硬件接线不作为本次FACAM对标的漏项。弯管、变截面梁仍属本产品完整范围，但本手册只作为其流程参考，不能替代各工件族的独立验收。

## 3 标准工作流程

1. 创建工程，按需追加导入多个加工工件，分别确认单位及几何检查结果。一个项目文件保存完整工件列表，一次只显示和加工当前选中工件；各工件独立摆放、装夹、建立切割定义、生成刀路和仿真，切换工件保留其他工件的数据。
2. 选择机床与工具，建立编程坐标系，摆放工件和夹具；已有实测点时完成定位，否则保存待执行的定位计划。
3. 自动提取切割候选，手动补充或修正加工面、边界、分段、起点和类别。
4. 分配工艺，设置补偿、引线、过切、穿孔、姿态模式及局部关键点。
5. 生成工艺路径、轴运动、加工次序和空移；失败项定位到具体对象并允许修改。
6. 仿真完整程序，核对切割、空移、机床运动和过程事件，修正碰撞或超限并重新验证。
7. 选择输出配置，生成程序，读取实际输出重放检查；通过后形成加工交付包。
8. 保存工程。以后修改几何、工艺、机床或定位时，系统标记受影响结果并按依赖重算。

用户可以在流程中返回任何已建立的编辑对象；修改输入不能丢失其他仍然有效的编辑。只有具备所需输入和有效验证结果时，相关生成或输出操作才可执行。

### 3.1 自动生成与人工修正

“生成刀路”以活动装夹为范围，处理其中全部启用的切割定义，一次协调工艺路径、姿态、机床运动、排序、空移和程序入口/结束运动。用户可以在计算前查看参与对象、固定配置和将保留的人工约束；未启用对象不参与，其他装夹不被混入。生成成功仍须经过仿真验证才能输出。

初次使用装夹时固定一份规划配置：普通轮廓默认按板面法向初始化；孔几何类别与姿态策略分别设置，固定摆轴还须通过设计轴向、机床和工艺校验；默认内部特征先于失去支撑的外轮廓，再在合法顺序内优化空移时间；空移自动尝试可验证的直接连接、抬升连接及绕障。工艺配置或必需装夹信息缺失时要求补齐，不猜测激光功率、厚度、机床标定等输入。默认值来自所选固定版本配置，库更新不静默影响工程。

| 用户修正 | 保留内容 | 应重新计算或检查 |
| --- | --- | --- |
| 改起点、反向、分割、转换标准孔 | 明确可追踪的工艺覆盖、其他对象和人工顺序 | 来源映射、当前路径、轴运动、相邻空移、验证与输出；无法重映射的关键点明确待处理 |
| 改引线、补偿、过切、整体姿态或关键点 | 原切割定义、未修改工艺、人工锁定 | 当前工艺路径及受影响的运动与连接 |
| 改手动顺序、锁定前缀 | 切割线、工艺与姿态输入 | 受影响空移、端点动态和完整时间线 |
| 改单段空移方式、间隙或必经点 | 其他连接覆盖、切割定义与人工约束 | 该连接及相邻动态边界、完整计划验证 |
| 改机床、工具、定位或夹具 | 机床无关的几何及工艺意图 | 可达性、轴锁定、运动、碰撞及输出资格 |

选中对象可以预览局部修正，但“当前装夹生成完成”必须拥有完整且版本一致的加工计划。自动重算保留人工关键点、排序锁定和空移覆盖；遇到冲突先定位问题，不通过静默删除人工输入完成生成。用户主动选择“恢复自动”时显示本次移除的覆盖类别与对象，一次应用可一次撤销；普通“重新生成”不等于“全部恢复默认”。

## 4 核心对象和状态

| 对象 | 用户可编辑的内容 | 与下一层的关系 |
| --- | --- | --- |
| 工件 | 几何准备、加工对象、坐标关系、厚度信息 | 为切割定义提供精确几何来源 |
| 切割定义 | 加工面/边、区间、起点、方向、类别、留料侧 | 与工艺共同生成实际切割路径 |
| 工艺路径 | 工艺输入、姿态关键点、引线与补偿设置 | 结合机床和装夹生成轴运动 |
| 机床轨迹 | 通过约束和规划输入调整；不以随意改点替代重算 | 为仿真和程序输出提供同一运动依据 |
| 验证与输出 | 检查配置、目标设备、输出选项 | 固定记录被验证和输出的版本 |

结果状态分为未生成、有效、已过期和无效。计算任务分为排队、运行、成功、失败、取消和被新请求替代。任务成功与结果仍然有效分别判断：输入随后变化时，成功生成的旧结果也必须变为已过期。

过期结果允许以明确标识继续显示供比较，但不能被当作当前有效结果输出。取消或失败不破坏已保存的输入和历史结果。每个问题至少给出对象、位置、原因和可执行的修正入口。

模块范围包括工程生命周期、统一对象树、视图与属性联动以及编辑状态保护。工程必须独立于导入文件和开发机器的目录结构。

| 需求 | 功能与业务规则 | 失败行为和验收标准 |
| --- | --- | --- |
| M01-R01 | 新建、打开、保存、另存为工程；一个工程可包含多个加工工件及其装夹 | 保存重开后对象、编辑输入和固定资源版本一致；保存失败保留上次文件 |
| M01-R02 | 工程收集所需几何、工艺、机床及依赖资源，记录来源 | 移到另一台具备对应产品能力的机器后可打开；不能依靠原电脑绝对路径 |
| M01-R03 | 对象树与三维视图双向选择；支持多选、显示隐藏、重命名和分组 | 选择身份一致；隐藏对象是否参与加工/碰撞由独立属性决定 |
| M01-R04 | 支持旋转、缩放、平移、标准视角、适合窗口和聚焦选择 | 调整视图不改变工件坐标；切换显示方式不改变加工结果 |
| M01-R05 | 输入编辑、删除和批量修改支持撤销/重做；一次用户动作形成一个步骤 | 撤销恢复参数、关联关系和资源版本；重做后与原提交一致 |
| M01-R06 | 长任务显示阶段、进度或正在计算状态，允许取消 | 取消立即撤销结果发布资格；旧任务晚到不能覆盖新输入 |
| M01-R07 | 修改参数和异步刷新保留左右栏及嵌套滚动、焦点、光标和选区 | 真实浏览器测试继续输入/滚动后接收响应仍保持最新状态；常规刷新不替换输入节点和监听 |
| M01-R08 | 提供恢复记录和未保存提示；关闭/切换工程结束其预览和任务发布资格 | 异常退出可选择恢复；损坏包报告缺失项，不以空工程伪装成功 |
| M01-R09 | 独立开关支撑面法向、切割方向、加工序号、定位点、机床行程范围和原定义/生成路径对比；图例区分切割线、切割、空移、选中与问题段 | 标号来自当前计划，法向来自明确支撑面；过期结果有标识；显示开关不改变输入及碰撞角色 |

## 6 M02 工件几何与加工准备

主要输入为 STEP/STP 的实体、曲面及装配数据。导入结果需要足够的精确几何和拓扑信息，显示出来并不等于已具备加工条件。

| 需求 | 功能与业务规则 | 失败行为和验收标准 |
| --- | --- | --- |
| M02-R01 | 导入 STEP/STP，保留装配层级、对象名称、来源和单位 | 单位不明确时要求用户指定；用已知尺寸样本核对缩放及装配位置 |
| M02-R02 | 显示实体、曲面、边界、线框及加工线，可单独控制可见性 | 显示网格精度变化不改变精确加工定义 |
| M02-R03 | 检查破损面、开壳、重复几何、退化边、异常法向和非流形连接 | 问题可定位；影响所选加工区域时阻止对应生成，不能吞掉错误 |
| M02-R04 | 提供受控几何修复；可选提供变换、CSG、修剪/局部编辑，保留原始来源；三维编辑不作为加工前置 | 修复结果形成新版本并可撤销；不能无提示改变成品尺寸 |
| M02-R05 | 指定本次加工工件、支撑面、材料厚度或表面表示方式 | 厚度未知但相关坡口/工艺需要厚度时，要求补齐而非使用隐含默认值 |
| M02-R06 | 几何更新后检查切割线来源及人工参数的适用性 | 唯一可追踪来源自动重绑定；分裂或歧义来源标记待重选，不绑到相邻边 |
| M02-R07 | 曲面薄壁件、弯管、变截面梁使用适用的识别策略 | 每种工件族有独立样本；不支持的几何组合明确报告 |

### 9.1 刀路调整的产品语义

姿态面板分为“目标方向”“允许调整”“人工关键点”三组。目标方向含法向/明确面内方向、前倾和侧倾目标角；允许调整含前倾允许误差、侧倾允许误差、总姿态上限和台阶法向偏好；关键点含位置、工具方向或指定机床轴锁定、相邻过渡方式。选中路径后可沿路径移动检查位置，联动显示切割头和轴值；人工点可增加、修改、删除，系统起终点保留。多选对象显示混合值，应用只修改明确输入的字段。

本产品以前倾/侧倾的有符号方向偏差角表达允许误差，角度单位在面板集中显示；台阶法向偏好为0—1无量纲权重。它们对标FACAM的调姿能力，不宣称与竞品同名参数存在数值换算。参数的局部参考系、约束优先级和默认配置由技术方案第6.4节定义。

“清除”按类别去除引入、引出、过切、割缝补偿、局部参数覆盖或穿孔覆盖；必要基础切割参数继续来自所选工艺版本。清除引线得到无引线，清除过切得到零过切，清除补偿得到零几何补偿；清除局部参数或穿孔覆盖恢复库继承。清除后的策略若不满足当前工艺条件则阻止生成，不能生成不可用路径。“恢复继承”显式恢复所选类别的库值，可能重新启用引线/补偿，不与“清除”混用。姿态和顺序的恢复使用各自明确入口。

### 11.1 空移策略与调整入口

选中空移段后进入该段调整，显示前后工序、路径、当前策略、基础间隙及附加间隙。用户可切换直接连接、抬升连接、自动绕障，并设置单段覆盖；不改其他连接。基础间隙来自固定碰撞配置，附加间隙非负，二者与模型不确定性共同参与检查。

| 策略 | 本产品行为 | 与FACAM对标关系 |
| --- | --- | --- |
| 直接连接 | 在端点姿态与动态约束下尝试不经过强制安全平面的短连接，全段关光并检测 | 对应其“飞切”空移使用场景；不表示连续开光跨越工序，也不宣称算法相同 |
| 抬升连接 | 按明确方向和安全平面退出、跨越、再进入，检查全部姿态转换 | 对应其“蛙跳”空移调整需求；不能仅因抬高就视为无碰撞 |
| 自动绕障 | 在限定预算内搜索、平滑并验证完整连接，可约束必经点 | 对应其“快速规划算法”的自动连接需求，不承诺相同搜索实现 |

默认“自动选择”可依次尝试这些策略，并显示实际采用的策略和原因。用户明确指定直接/抬升策略时，失败返回该策略问题，不静默换成另一策略；改为自动选择由用户主动执行。

## 15 通用质量要求

### 15.1 准确性与一致性

| 编号 | 要求 | 验收方法 |
| --- | --- | --- |
| Q01 | 长度、角度、时间、坐标方向和工具参考点有明确约定 | 已知尺寸和姿态样本跨导入、计算、显示、输出核对 |
| Q02 | 几何、姿态、定位、离散和输出误差分别配置，并形成总误差预算 | 各阶段记录实际误差；超预算阻断，不把软件阈值当机床精度承诺 |
| Q03 | 同一用户操作原子改变关联对象，失败保留已提交状态 | 注入资源发布、事务提交和保存失败，核对引用完整性 |
| Q04 | 异步任务只发布与当前请求和输入版本匹配的结果 | A先发后回、B后发先回，切页、关闭及撤销场景下不出现旧结果覆盖 |
| Q05 | 编辑定义、用户关键点和人工顺序在重算及重开后保留 | 进行工艺/几何修改再重算，核对所有仍适用的人工输入 |
| Q06 | 工程及输出可追溯至固定版本的几何、机床、工艺和算法 | 从输出记录反查完整依赖；依赖缺失明确失败 |

### 15.2 交互与性能目标

性能验收使用固定基准机器并记录具体 CPU、内存、GPU、驱动、磁盘和构建版本。建议基准配置为 8 核 CPU、32 GB 内存、独立 GPU 和 SSD；它是测试环境约定，不代表所有满足最低配置的机器性能完全一致。

样本 B1 包含约 1,000 个面、100 道工序和 100,000 个轨迹采样点；B2 包含约 10,000 个面、1,000 道工序和 1,000,000 个轨迹采样点。记录精确边数、网格规模、障碍物数量与公差，冻结实际样本后使用相同输入比较。

以下为首轮设计目标，首套基准测量后可通过规格变更调整，不能无记录地降低：

| 编号 | 指标 | 目标与测量边界 |
| --- | --- | --- |
| Q07 | 常规选择、树操作、字段输入 | B1下用户输入到可见反馈的95分位不超过100毫秒，不计后台完整规划 |
| Q08 | 任务受理和取消反馈 | 95分位不超过500毫秒；取消立即撤销发布资格，计算安全终止单独记录 |
| Q09 | 三维浏览与模拟播放 | 基准视图B1平均不少于30帧/秒，B2不少于15帧/秒；记录分辨率和显示项 |
| Q10 | 长计算可观测性 | 不阻塞输入；运行阶段至少每秒检查是否需要更新进度或取消状态；不可细分内核调用显示其阶段与超时状态 |
| Q11 | 增量更新 | 单条工艺修改不重新导入工件，不重建整个工作台；以阶段日志与浏览器节点身份验证 |
| Q12 | 重复使用与资源释放 | 连续打开/关闭10轮同一B1工程后，活动对象和任务数回到基线；内存达到稳定平台，无持续递增趋势 |

完整规划耗时随几何、障碍物和精度变化，应在基准上分别报告导入、识别、工艺、逆解、连接和验证耗时以及优化预算。自动优化到达预算时，只能返回完整有效方案或明确终止状态，不能以未完成结果满足耗时目标。

### 15.3 界面一致性

视图操作、选择、多选、应用、取消和撤销使用统一语义。正在输入的草稿不能被后台消息覆盖；条件字段消失时不把焦点误给其他字段。普通操作不显示常驻状态条，生成任务和可执行问题有专门呈现区域。

单位集中清晰显示，参数标签简短。机床和工艺库的全部管理字段不应自动铺满加工对象属性区。帮助说明给出参数的加工含义、适用条件和修改后需要重算的范围。

## 16 端到端验收场景

| 场景 | 操作流程 | 最终验收结果 |
| --- | --- | --- |
| A01 曲面件完整编程 | 导入覆盖件、建立装夹、提取孔与外轮廓、设工艺、规划、仿真、输出 | 工程可重开；全部工序连接完整；程序重放通过 |
| A02 固定摆轴孔 | 识别标准孔、指定孔方向、生成，再改变装夹 | 原计划实际摆轴固定；装夹变化后旧结果失效，新解符合几何要求 |
| A03 连续姿态修边 | 跨曲面接缝及角度周期，添加关键点、修改起点并反向 | 姿态和逆解连续；保留侧及尺寸不变；人工关键点可追踪 |
| A04 复杂夹具避碰 | 自动排序、加入挡住直接空移的夹具、规划绕障、调整必经点 | 检查整个头部和运动中间段；无解时明确阻挡对象 |
| A05 几何变更 | 保存工程、替换局部几何、产生拓扑分裂，再恢复引用 | 不误绑定；有效工艺保留；失效定义可以重新选择和生成 |
| A06 三点定位 | 正常点组、共线点组、错序点组、有噪声点组分别应用 | 正确结果为刚体变换；退化或超残差被拒绝；更新后重验运动 |
| A07 工艺异常 | 窄孔大补偿、无效引线、冲突姿态、最低速度冲突 | 每种情况准确失败；不产生可执行错误路径；编辑可继续 |
| A08 异步编辑 | 连续修改、双侧滚动、移动光标、取消，再切换工程 | 最新交互不丢；旧响应不覆盖、不抢焦点、不进入新工程 |
| A09 保存与输出失败 | 注入写入失败、资源缺失、后处理不支持、输出量化超差 | 保留上次有效文件；问题清楚；不发布半成品或过期程序 |
| A10 安装与实机 | 干净机器安装、导入工程、核对配置、空走、加工样件 | 安装内容合规；实际坐标、运动、事件、样件尺寸满足选定配置标准 |
| A11 自动编程与修正闭环 | 按默认配置一键生成，逐次修改关键点、手动排序和单段空移，再生成、撤销、保存重开 | 完整计划包含入口/出口；人工输入和未修改对象保留，恢复自动仅影响所选类别 |
| A12 姿态调整对比 | 同一曲面/台阶样本分别改变目标角、两个允许误差、台阶法向偏好和过渡方式 | 参数效果相互可区分；硬约束始终满足；固定摆轴不被连续姿态设置改变；自动简化保留关键边界 |
| A13 阴阳切与工艺清除 | 对闭合孔、外轮廓和开放线修改留料侧，再反向、批量清除及恢复继承 | 保留区域与引线/补偿一致；起点、方向和人工约束不被误清；失败批量编辑不部分提交 |
| A14 辅助显示与捕捉 | 切换法向/刀序/行程显示，捕捉端点、中点、圆心后定位和测量，后台同时生成 | 数值与精确几何一致；无效捕捉明确拒绝；显示不改加工输入，交互状态保持 |
| A15 支持组合与帮助 | 切换工件族、机床/工具/输出组合，尝试缺项配置，离线打开帮助、查看日志 | 不支持的组合被明确拒绝；只有具备完整证据的组合允许声明设备支持 |

每个验收场景保存输入、配置、操作步骤、实际结果和证据。几何算法测试、原生业务链、真实浏览器交互与设备测试分别完成；任何单一层面通过都不能自动替代其他层。

## 17 交付和变更管理

完整产品交付包括可安装程序、系统内置机床/工具/工艺资源、工程与加工程序定义、已验收的设备输出配置、用户操作说明、诊断能力、需求追踪表和验证证据。

任何范围、误差预算、设备能力或验收目标变更，记录变更原因、影响需求ID、设计章节和需要重跑的验收。新增加工策略必须补齐输入条件、失败行为及对应样本，不能只增加一个界面按钮。

规格覆盖92条模块需求和12条通用质量要求，包含15个端到端验收场景。需求编号用于设计、开发和测试追踪；实现不得用竞品功能名称或界面外观替代本规格中的具体行为。基线1.1补充自动生成与人工修正、姿态调整、辅助操作、对标附录和支持矩阵；2026-10-13菜单修订见第2.1节，不改变M01—M10责任边界。
