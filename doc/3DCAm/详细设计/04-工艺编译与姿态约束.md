# 04 工艺编译与姿态约束

版本 1.0 · 2026-10-13。覆盖 F18—F28、F35 的工艺/姿态部分，领域 M04/M05。完整生成的运动、顺序和空移见 05。

当前实现状态：工艺/连续姿态资源准备、读取、分配、批量修改、清除和固定库继承恢复已通过原生验证；引线、补偿、过切和连续姿态的单定义编辑已有真实原生浏览器证据。中性 ProcessPlanning 已实现空间任意平面内、法向圆形边界的局部精确补偿、引线、过切和事件；这只是受限特例，**不是一般三维空间曲线刀补**。用户于 2026-10-13 决定暂缓刀补，优先完成其他功能；第 4.4 节保留为未来恢复实施的要求，不得用平面圆孔测试抵扣。连续方向场、曲面约束及完整计划仍未实现。自定义工艺未提供设备资格证据，只能标 Incomplete 或 Unqualified。

新增的资源准备消息为场景 `CamProcess.Prepare {commandId, expected, setupId, placementId, library, assignment, pose}`，返回固定 `process/pose` 引用和缺项状态；不产生 Repository 写入或 Undo，资源在 `CamCut.Create` 成功后进入保存闭包。`CamProcess.Read {expected,intentIds}` 返回各对象引用、工艺库、分配、姿态及缺项状态。`CamScene.QueryCommand {epoch,commandId}` 支持确认回执丢失后的核对；未知命令返回 NotFound，不能当作成功。

当前 `cam.process-library` 自定义值使用固定数值 schema：feedMmPerSecond、laserPowerW、gasPressureBar、standOffMm、focusOffsetMm、pierceTimeSeconds、pierceFootprintRadiusMm，分别采用 mm/s、W、bar、mm、mm、s、mm；可留空但不猜值。库保存材料、厚度、气体及 Kerf/LeadIn/LeadOut/Overcut 默认值。覆盖仅接受已声明字段、正确数值类型及有限值；生产资格不能由请求自报。固定摆轴、关键点、独立穿孔资源和设备资格接入仍待实现。

`CamProcess.Compile {commandId,expected,intentId}` 从已保存固定资源创建异步任务；`CamPlan.QueryStatus/CancelTask` 查询/取消，`CamProcess.QueryCompiled {epoch,taskId}` 读取当前结果。路径、事件和摘要仅为 RuntimeOnly，不写 Repository 或 Undo；编辑、Undo/Redo、更新编译任务或重开均阻止旧结果复用。当前结果为 LocalCircularBoundary/NotPlanned，仍缺邻近几何、工具包络、机床可达性和设备工艺验证。原生及真实浏览器均已验证该限定范围。

## 1 工艺编译器的责任

输入为固定版本的切割 Intent、材料厚度/表面表示、工艺库、局部覆盖、姿态要求及机床能力约束；输出为机器无关的精确过程路径、事件和允许姿态集合，并保留每段的来源映射。它不直接写 Repository，也不把 UI 草稿当输入。

编译顺序必须固定：来源有效性 → 几何/材料侧 → 起点与遍历 → 工艺继承 → 补偿/成品边界求解 → 引线/过切/穿孔 → 姿态约束 → 过程事件 → 误差和完整性检查。倾斜切割时补偿与方向存在耦合，不能机械地一次线性计算，见第 4 节。

编译失败定位到 Intent 和原曲线区间，保留输入及上次成功结果。一次完整 Plan 中任一启用工序失败都不能伪装成完整成功。

## 2 工艺继承与批量修改

工艺库是固定版本资源，按材料、厚度区间、工具/喷嘴和支持范围提供参数。`ProcessAssignment` 保存库引用与显式覆盖；生成时解析为 `ResolvedProcess`，逐字段保留来源 `Library/Override/Derived`。库更新不静默改变工程。

参数“缺失”“显式清空”“数值为零”有不同含义。批量 patch 缺省字段是不改，null 仅用于允许清除的可选字段，0 是有效的关闭量或非法值，按字段契约判断。混合值只供 UI 显示，不写成空字符串。

`Clear(Leads)` 明确把引入/引出置 None；`RestoreInherited(Leads)` 恢复各自固定库版本。清除补偿/过切不清除材料侧、起点、方向、孔形、关键点、排序与来源。禁用引线后前端保存的旧长度不进入有效编译输入。

已知基础工艺缺失时返回 `PROCESS_PROFILE_INCOMPLETE`，不猜激光功率、气压或穿孔时间。本设计不把未经设备试切验证的材料表写成生产默认值。

## 3 几何类型、设计轴与机床姿态

| 概念 | 表达 | 决定什么 |
| --- | --- | --- |
| geometryKind | Contour/Circle/Slot/… | 形状、中心和尺寸意义 |
| designAxis | 带 frame 的单位向量 | 孔/特征的功能安装方向 |
| CamPosePolicy.mode | Continuous/FixedToolDirection/FixedRotary | 允许工具如何运动；UI rotaryStrategy 为其投影 |
| axisLock | 明确机型、轴 ID、数值/分支 | 实际机床轴限制 |

上级基线中的 FixedRotary 不等同于固定工具方向：转台机型中旋转轴固定与工件坐标下方向固定的关系取决于运动链。UI 的“固定方向”先形成方向要求；只有执行配置支持并求解验证后，才可转成具体旋转轴锁定。不能把圆孔识别结果直接写成 B/C 角常量。

对功能孔，若 designAxis 为硬约束，允许角域必须包含该轴；法向跟随与功能轴冲突应明确报冲突，不能为了避碰自动沿曲面法向切割。对一般修边则可把法向作为优选方向并给出允许偏差。

识别的形状/测量截面/通道证据由 [11](11-加工特征识别算法与数据契约.md) 定义。局部贯通不表示远侧管壁安全，标准形状也不自动构造 FixedRotary。工艺编译必须检查识别来源、测量合同、方向及 passage 的适用性；只允许在显式姿态策略和真实机型能力下求轴锁。

## 4 材料侧和补偿模型

### 4.1 在承载几何上解释留料区

闭合轮廓保存保留区域的拓扑意义；开放轮廓保存沿承载面明确的有向侧或指定区域。曲线反向后可通过调整相对符号保持同一物理材料区。不得因顺逆时针变化把内孔变成外轮廓。

局部曲线切向 t、有效面法向 n 建立横向 `b=normalize(n×t)`。n 需要经过有向面/加工侧一致化；反向时 t 改变，而保留材料区域的空间意义不变，因此侧符号必须对应调整。

### 4.2 法向切割与曲面偏移

对平面轮廓和法向光束，可将名义轮廓按切缝半宽向废料侧偏移；曲面上不能直接套全局 XY 二维 offset。必须在所声明的测量面或承载面上满足成品边界条件，区分曲面距离和投影尺寸。

曲率半径接近补偿量时会产生偏移尖点、自交或局部消失。先检测拓扑变化，再按角点策略构造连接，检查材料区域差；不能用任意圆角掩盖小孔消失。无法保持要求尺寸返回 `OFFSET_TOPOLOGY_CHANGED`，给出限制区间。

### 4.3 倾斜切割和厚度

倾斜光束在参考面上的切缝截面通常不再是简单等宽条带。`kerfWidth` 必须说明测量截面、材料/工艺条件和模型适用范围。不能直接把常规二维 kerf/2 偏移用于所有姿态，也不能把厚度乘 tan(角度) 当作任何曲面上都成立的补偿公式。

工艺结果需声明尺寸控制在入口面、出口面、中心面还是独立测量平面。根据工具方向与厚度模型求束线和对应参考面交点，再求满足成品边界约束的中心轨迹。方向改变会改变补偿；运动规划若在允许域内调姿，必须回到此阶段重新核验/修正边界，不能只旋转头部而保持旧 TCP 线。

采用有界迭代：工艺给出初始轨迹和允许姿态 → 运动选择方向 → 工艺重算参考截面误差 → 在同一意图容差内修正 → 达到预算或拒绝。每轮用完整依赖摘要，最大迭代/时间来自规划配置；不收敛返回 `PROCESS_POSE_COUPLING_FAILED`，不放松设计尺寸。

首个可交付能力可限定为经验证的法向/固定方向薄壁切割组合，复杂曲面倾斜补偿由支持矩阵逐项开放；完整范围仍保留，不以近似计算冒充全部支持。

### 4.4 三维空间曲线刀补的实现合同

输入不是二维投影多段线，而是保留原生参数的空间边界 `P(s)`、实际切割方向场 `d(s)`、承载面及其使用方向、物理留料区和测量截面。空间曲线本身不能唯一决定偏移方向。法向跟随时 d 由承载面局部法向确定；倾斜切割时 d 来自姿态要求与运动求解，不能继续以面法向替代。

对于已声明为“光束法截面半径 r、局部圆柱束”的工艺模型，令 `t(s)` 为源曲线单位切向，`b(s)=normalize(d(s)×t(s))`。按物理废料侧取符号 σ，构造局部切向接触的束轴线：

```text
L(s,λ) = P(s) + σ r b(s) + λ d(s)
```

它定义的是束轴线，不等同于已经得到承载面上的轨迹或切割头 TCP。该构造满足名义点到束轴线的距离为 r，且径向接触向量垂直源曲线切向。d 与 t 平行或近退化时不能构造；不得以任意备用轴掩盖退化。切割方向随 s 改变时偏移方向也随之改变。曲线反向同时翻转 t 和相对侧符号，保留同一物理束轴线。

随后沿同一束轴线与声明的控制表面求交，追踪同一承载面分支，确定参考点；按实际随动/工具定义另算 TCP，不能将焦点偏置、板厚补偿与切缝偏移混成一个距离。多交点、切触、无交点、面域外、跨接缝及法向不连续必须有明确结果。不能把 `P+σrb` 简单正投影到承载面，因为那通常会改变束轴线和成品尺寸。若控制表面为加工边界的延续面，必须显式声明允许的延续域，不能假定孔内仍存在原实体的裁剪面。

上述 r 只适用于已声明的光束法截面模型。现有 Surface 测量宽度不能在倾斜切割中不经转换直接设为 r 的两倍；不同测量截面和板厚要求由工艺模型计算。入口和出口有独立尺寸要求时检查完整板厚束扫掠，不以入口处相切证明全壁满足。

局部接触方程也不证明全局有效：还需检查偏移奇异、自交、邻近成品过切、角点接续、闭合接缝、引线与过切的全区间关系。曲线拟合/离散必须提供区间误差界和来源映射；只检查若干采样点通过不标为完整验证。每条路径绑定生成时使用的方向场；运动规划调姿后重新补偿或重新证明尺寸，不允许旋转切割头后直接沿用旧位置。

实现边界：几何服务返回曲线/表面求值、微分、求交与区间证据；CAM 工艺服务负责切缝模型、留料语义、方向耦合和结果；产品 SDO 负责固定版本、事务和失效。Open CASCADE 的 [Geom_OffsetCurve](https://occt3d.com/dev/doc/refman/html/class_geom___offset_curve.html) 使用固定参考方向，且不自动消除自交，因此不能单独承担变方向五轴刀补。

2026-10-13 基础能力扩展：已新增独立 `geometry/OpenCascadeGeometryServices` 插件，以框架 `ICurveOffset3DService : IService` 提供三维曲线固定/变方向偏移求值，公共数据在 `foundation/GeometryData`；不放在 FiveAxisCAM 或 ProcessPlanning 内。原生 15 项测试通过，包含真正非共面曲线；结果仅 `RequestedParametersOnly`，尚缺全区间证明、曲面求交/裁剪及工艺编译接入，不能据此提高本章开头的产品支持范围。选型与服务合同见 [三维曲线偏移服务与开源库选型](../../iCAX-Engine/Foundation/三维曲线偏移服务与开源库选型.md)。

必测样本包括非共面圆柱曲面曲线、球面/自由曲面曲线、变方向与前侧倾、曲面接缝、两次反向、近退化方向、小曲率半径、自交、入口/出口不同尺寸及调姿后重算。平移或旋转一个平面圆仍是平面特例，不能充当三维空间曲线验收。

## 5 起点、引线、过切与事件

起点锚定原曲线，编译器生成遍历映射 `sourceSpan → processSpan`。闭合线改起点是环形区间重排；人工关键点跟着源位置迁移，而不是维持原采样序号。反向不改变成品材料侧。

引线从废料区进入。候选直线/圆弧依据可用废料区域、穿孔半径及工具姿态构造，整个引线和穿孔过程都要检查邻近成品、夹具及可达性。开放修边的板外引线必须证实起始点在允许区域，不能仅放到 BBox 外。

过切是沿闭合轮廓越过起点的追加弧长；源位置重复但过程时间不同，因此 source parameter 不是事件的唯一键。结果段必须有独立 segmentId/occurrenceId。没有明确配置时不能自动把过切复制到新打断的开放段。

事件不是一串自由字符串。使用受控事件联合体：ProcessSelect、GasOn、HeightFollow、Pierce、Dwell、CutOn、CutOff、GasOff 等，参数由工艺 schema 校验，未知类型返回 Unsupported。每个事件锚定过程段位置或时域边界，具有确定的同位置顺序。

同一时刻的基本约束：运动准备完成 → 选择工艺/气体 → 穿孔及等待 → CutOn → 切割段 → CutOff → 空移。具体气体延时和随动策略由配置决定。未经解析的 RawNC 无法参加完整语义重放，只能在后处理明确声明受控扩展且有解释器时允许交付。

## 6 姿态场的几何定义

路径位置由精确曲线求值；pose field 保存工具轴向和必要的前进方向，不重复存一套可漂移的位置。参数锚点复用 ProcessPath 的 SegmentIndex/SegmentParameter，但正式结果需增加稳定 segmentId 和源映射。

局部姿态参考框架优先用经过一致化的面法向 n 和切向 t，构造正交基。面接缝法向不连续处必须区分真实折角与参数缝。真实折角需工艺分段或明确的过渡区，不能平滑后越出成品角度容差。

当 `n×t` 退化或曲线导数接近零时，采用邻域连续框架/平行运输作为候选，并报告参考退化；无法唯一解释时要求分段。不得任意切换欧拉角轴序。前倾/侧倾的旋转顺序和正方向固定在 schema 中，显示单位度，计算单位弧度。

目标方向是优选项，允许偏差是约束。每个路径位置形成可行方向集合 `D(s)`：设计轴约束 ∩ 工艺角域 ∩ 局部关键点要求。机床和碰撞由 05 再筛选。方向从 d 到 -d 不是等价，不能用四元数表示符号连续性掩盖光束翻转。

## 7 关键点与过渡

`PoseKeypoint` 字段：id、sourceAnchor、constraintKind、targetDirection 或 axisLocks、tolerance、hardness、transitionMode、influenceSpan、creator。系统起终点与用户点分开，系统点不可删除但可在允许范围编辑约束。

硬约束必须满足；软目标只参与成本。两个硬约束在同一位置不相容时立即给出 conflict set，不能取后输入覆盖前输入。实际轴锁定还绑定机型配置版本，更换机型时 NeedsReview，不把 B 轴数值直接改名为 A 轴值。

按弧长过渡和按方向变化过渡只是姿态目标插值规则，不直接保证机床轴连续或动态可行。插值后重新计算允许域、位置误差和轴解。方向插值可用球面插值/单位向量轨迹，近反向情况须有明确过渡平面或拒绝；不对归一化后近零的线性向量继续计算。

## 8 工艺结果资源束

```text
CompiledOperation {
  operationId: UUID, intentId: UUID, sourceRefs: ResourceRef[],
  curveRef: ResourceRef, poseDomainRef: ResourceRef,
  eventsRef: ResourceRef, sourceMapRef: ResourceRef,
  resolvedProcessRef: ResourceRef,
  measurementContractRef: ResourceRef,
  entryState: ProcessBoundaryState, exitState: ProcessBoundaryState,
  mandatoryBreaks: PathLocation[],
  validation: {coverage, maxPositionError, maxDirectionError},
  inputDigest: Digest, compilerVersion: string
}
```

`ProcessBoundaryState` 包含光/气/随动状态、姿态要求和速度连续性要求，空移不能只读取几何起终点。结果只在全部参数满足后标记 Compiled，尚不意味着 machine axes ready。几何/工艺/运动阶段状态独立显示。

## 9 消息流与重算范围

工艺编辑走基线 `CamProcess.Assign/Update/Clear/RestoreInherited/UpdatePose/SetKeypoint`；起点、反向、材料侧走 `CamCut.*`。每次命令验证全部选中对象，失败原子拒绝；用户可主动重新提交有效子集，后端不静默跳过失败项。

局部工艺变化通常只需重编译关联 Operation，但端点方向/速度变化会使相邻空移失效；支撑关系变化可能影响后续顺序，不能只更新当前刀。每个结果声明 inputDependencies，Plan 汇总依赖闭包；初期不能证明局部重算完整时，保守重算整个 Setup。

## 10 必测不变量

F18：识别圆孔后切换连续/固定策略，几何尺寸不变。F19/F24：闭合线起点重排、反向后同一物理关键点和材料侧保持。F20—F23：引线在废料侧、开放过切拒绝、小孔偏移拓扑变化拒绝、倾斜姿态变化触发尺寸重验。F25：清除和恢复继承不同，其他人工输入保持。F27/F28：相反方向、法向退化、冲突硬锁、换机型轴锁全部有可定位结果。

测试以原成品尺寸/材料区域和独立事件解释器作为判据，不只比较编译器自己产生的“成功”标志。
