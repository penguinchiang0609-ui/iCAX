# 02 工件定位与夹具制造

版本 1.0 · 2026-10-13。覆盖 F01—F09，领域 M02/M03。重点是从精确工件走到可重新生成、可开料、可装配的夹具，而不是做一组看起来像夹具的网格。

## 1 领域决策

导入零件、工件实例、装夹摆放是三件事。源 CAD 和原始几何保留在 Workpiece；同一项目文件可保存多个加工工件，每次导入建立独立的 Workpiece、Placement 和 Setup。工件列表切换当前工件，视图区一次只显示该工件及其工装；切割定义、刀路编号、生成结果和仿真按工件隔离。当前选择随项目保存，切换不修改加工输入，也不清空撤销/重做记录。编程/实测坐标变化只改变该工件的装夹关系。夹具设计属于当前 Setup，来源是其 Placement 的固定版本及支撑区域。

夹具形状依赖工件，刀路避碰又依赖夹具，存在循环。采用两阶段：先按工件与人工禁布区生成设计候选；有刀路后检查加工可达、光路和落料，产生夹具冲突建议。不能让规划器静默移动夹具并继续沿用旧夹具下料图。用户接受夹具修改后新建装配版本，Plan 和下料包一起失效。

板式支撑不是完整夹紧系统。生成器输出支撑板、底板及可制造连接，不假装自动证明工件不会滑移、变形或因焊接热变形失准。夹紧点、基准块、固定件和实际工装确认是明确输入/检查项；本轮不新建力学 FEA 模块。

## 2 模型导入

### 2.1 外部导入流程

正式产品域以 `CamWorkpiece.Import` 调用中性 CAD 导入服务，由 Scene 协调资源发布和唯一工件的创建。文件选择由宿主提供文件读取授权；后端不得只相信网页路径指向的任意文件。`sourcePath` 是基线业务字段，必须与当前宿主授予的读取范围核验，不另设同义的导入命令。

1. 导入器返回原文、BRep、拓扑与显示资源及诊断；记录格式、单位、缩放来源和装配层级。单位不明进入 NeedsUnit，不隐含毫米。
2. 实体/面片集合中保留对象身份；没有可用精确几何时只能显示，不授予加工定义资格。
3. 为源装配节点生成稳定 importNodeId。默认选择加工子件，不把夹具/参考件的所有边一并当切割线。
4. 新导入命令仅在工程没有工件时接受；任务发布前再次校验。在 Scene 事务中一次创建 Workpiece、Placement 与渲染切面；失败不留下半个工件。重复同 commandId 返回原任务回执，不重复创建。`CamScene.ReadState.workpiece` 为单个工件快照，未导入时为空对象；不维护工件列表或活动工件选择。
5. 自动分析是只读候选，不因成功显示而自动创建全部加工 Intent。

原文与生成资源采用可保存依赖闭包，断开原 CAD 文件后工程仍能重开。重新导入是新的来源版本，并触发 03 的拓扑重绑定，不能逐索引覆盖旧面 ID。

### 2.2 内置模型范围调整

2026-10-13 按用户要求，内置／参数化模型移出当前产品范围。删除工件页菜单、模型管理和装夹环境中的相关入口、参数面板及会话草稿。当前通过外部模型导入准备工件。

## 3 坐标定义与定位求解

统一使用列向量，`T_A_B` 将 B 坐标映射到 A。模型点 `p_W` 经 `T_S_W` 到 Setup；机床世界中的定位为 `T_M_W = T_M_S · T_S_W`。资源曲线必须标注自己的 frame；API 不接收无法解释 frame 的裸 XYZ。

粗定位用三个不退化方向构建正交基。点法：原点 O，X 方向点 P，平面点 Q；`x=normalize(P-O)`，`z=normalize(x×(Q-O))`，`y=z×x`。拒绝近共线或尺度不足，检查 det(R)=+1。线/面法先明确法向正负和 OX 朝向，预览可翻转；不得按屏幕朝向猜手性。

精定位对成对点求解 `min Σ w_i ||R p_i + t - m_i||²`，约束 `RᵀR=I, det(R)=1`。采用中心化 SVD 的正刚体解，反射分支显式修正；不引入缩放。三点要求不近共线，多点显示每点残差、RMS、最大残差及几何条件性。仅有低 RMS 不足以判定长条分布点组稳定，点组空间分布必须参与资格检查。

测量权重来源需记录；没有测量不确定度时等权，不凭残差自动删除“离群点”。可提出剔除候选，但由用户明确确认并保存原因。应用后的变换、原点组、残差和阈值同属一个定位结果资源。

精定位与现场三点计划通过 `applicationMode=AppliedInCAM/ApplyAtExecution/Pending` 互斥。输出端根据执行配置决定是否已烘焙变换；必须记录变换摘要，见 06，防止同一校准执行两次。

2026-10-14 实现闭环：`CamPlacement.ReadRegistration(expected,setupId,placementId)` 返回固定定位资源引用与完整报告（含输入点组、权重、方向、每点残差）。读取验证当前工件几何与摆放，没有定位记录时返回空报告。编辑器按定位资源版本恢复输入；未应用草稿与读取期间的新输入保留，不跨页面回填。`ApplyRegistration` 的回执未知时，通过 `CamScene.QueryCommand` 核对；重试沿用原 commandId 和原提交输入。计算不改动工程，应用才替换当前摆放并使下游过期，支持撤销、重做与工程保存重开。

2026-10-14 界面按 FACAM 手册第 3 章修正：点法按 O、OX 点、OXY 点选取；线法按 OX 直线、平面内非平行直线、O 选取；面法按平面、O、OX 点选取。前端选择结果自动推进，原生端始终重新解析固定几何版本的引用。面法传入 `xPoint`，原点引用也解析完毕后派生 `xDirection=xPoint-origin`，避免将模型点误当绝对方向。“确定”内部求解合格后才应用，取消或计算期间的新编辑禁止应用旧结果。界面精定位固定为三点，底层中性服务的多点和权重能力不直接铺成产品表单。

## 4 夹具设计输入与结果契约

以下字段补充上级基线的 `CCamFixtureComponent`，不让该实例组件塞进整个设计过程。

```text
FixtureRecipe {
  id: UUID, revision: u64, setupId: UUID,
  sourcePlacementId: UUID, sourceGeometry: ResourceRef,
  placementRevision: u64,
  supportFaces: TopologyRef[], forbiddenRegions: RegionRef[],
  supportSide: ExplicitNormalSide,
  plateFamily: ParallelX | ParallelY | CrossRibs,
  stations: {stationId: UUID, coordinateMm: f64, enabled: bool}[],
  thicknessMm: f64, materialRef: ResourceRef,
  basePlane: RigidFrame, baseHeightMm: f64,
  contactGapMm: f64, minimumWebMm: f64, minimumFeatureMm: f64,
  joint: TabSlot | LocateAndWeld,
  assemblyClearanceMm: f64, locatorRecipe: ResourceRef?,
  machiningExclusions: RegionRef[],
  toleranceProfile: ResourceRef
}
FixtureAssembly {
  recipe: ResourceRef, inputDigest: Digest,
  parts: {partId: UUID, role, solidRef, blankRef, T_Setup_Part}[],
  joints: {jointId, partA, partB, locatorRef, insertionDirection}[],
  contactEvidence: ResourceRef, issueSet: ResourceRef,
  confirmation: Draft | GeometryChecked | AssemblyConfirmed
}
```

stationId 和 partId 由设计语义创建并持久，不由数组序号、形状哈希或当前名称生成。调整间距保留存活 station 的 ID；合并/删除的板件明确失效，不能静默把原编号绑定给另一块板。形状等价的零件可分组下料，但每个装配 occurrence 仍保留单独身份。

## 5 板式夹具生成算法

### 5.1 建立支撑截面

每个 station 定义垂直板平面 Πᵢ 和板局部正交基。用精确工件与 Πᵢ 求交，取得曲线和来源面。内核 Section 返回交线/顶点，不保证它们已经是可制造的封闭板轮廓；业务层仍需排序、连通性与区域解释。

同一平面可能穿过外皮、内壁和多个零件。选择支撑面集合与 supportSide 确定接触分支；不能取最低 Z 或第一条 wire。无法唯一选择时给出分支候选，暂停该板生成。

### 5.2 从接触曲线到有厚度板件

中心截面曲线只定义名义接触。真实板有厚度 `t`，曲面沿厚度方向变化时，中心曲线外挤会顶入工件。必须针对整个板厚带验证实体间隙：构造板实体后与工件求距离/干涉，必要时按厚度带的保守包络修剪顶缘，再验证。

间隙以接触面的空间距离或明确法向间隙定义，不能简单把整条曲线沿全局 Z 下移 contactGap。在陡壁或反折面上两者不同。实现可采用工作包络与板实体相交/差，但只有能给出误差界与有效实体时才发布；网格近似包络必须带保守误差，不把采样无干涉当精确证明。

从接触区域向底板建立材料区域，包含必要侧边与脚部。检查最小连桥、孤岛、尖角、小孔槽和材料连通性。可建议调整站位、扩大支撑脚或删除无效板，不在未确认时自动填平重要避让孔。

### 5.3 插槽与交叉板架

交叉板以实体交集确定槽位置；槽宽使用被插入板厚 `t_mate + assemblyClearance`，制造切缝补偿留给下游开料，不再次把 kerf 加到设计槽宽。槽深/开口方向要允许装配，不能每个交叉点都独立选“最短槽”而制造无法装入的闭环。

将连接构成装配依赖图，检查插入方向与顺序。出现环时给出拆分、分体板或连接形式调整候选，不能只通过静态相交检查就标记可装配。定位榫与焊缝间隙分别记录，圆角/释放槽是制造细节，不应改变基准面。

### 5.4 加工可用性检查

检查支撑板与零件、切割头外形、光束通路、预定落料区以及夹紧件。没有实际刀路时只能核对已知禁布区和粗略工具包络，状态为 GeometryChecked；有 Plan 后再做加工验证。零件是否稳定、工装实际能否夹紧由装夹确认项明确，不拿几何碰撞通过替代。

将诊断定位到 stationId、partId、sourceFace 和冲突区域。单块板失败时可以展示其他候选，但整个 assembly 不标记成功；允许用户明确禁用该 station 后重新计算。

## 6 拆单是制造几何提取

1. 验证板实体确实由一个平面材料区域沿常厚度外挤组成，检查两主平面、平行侧边和恒厚。仅有两个大平面不足以证明中间没有变厚、斜孔或沉孔。
2. 建立 `T_Setup_Part` 与板局部 XY，提取实际材料区域的外环、内孔、槽及需要区分的标记。非垂直孔或多层加工特征返回 `REQUIRES_SECONDARY_OPERATION`，不能投影后当作普通平面切割。
3. 根据制造目的判定合并：材料、名义厚度、公差等级、正反面标记、孔槽/倒角及允许翻面状态都一致才合并。仅比较外轮廓哈希不足够。
4. 保留 assemblyPartId → blankId → occurrenceNumber 的映射。编号放在余料/指定打标区，不能侵入插槽或夹持基准。镜像板默认分别编号，除非制造和装配语义确认可以翻面互用。
5. 保留真实几何，不在本模块执行排样。下游平面开料负责材料排样、切缝补偿和其设备程序。

`FlatBlank` 至少包含 `blankId, sourcePartIds[], frame, region2DRef, materialRef, thicknessMm, quantity, sidePolicy, markingRef, secondaryOps[], dimensionalToleranceRef`。2D 外环/孔方向是文件约定，材料区域拓扑是权威，不能仅以顺逆时针确定孔。

## 7 交付包与文件校验

夹具交付包括：1:1 毫米 DXF、按材料/厚度分组的 CSV 清单、编号装配图/拼焊示意 PDF，以及记录装配/拆单版本与文件摘要的 manifest。文件名来自稳定编号的安全编码，不使用用户路径片段直接拼接。

DXF 层至少区分 CUT_OUTER、CUT_INNER、MARK_ID、REFERENCE；参考层不能被默认当切割层。圆弧可精确输出则保留，离散化只在目标格式限制下按误差预算执行。导出后独立回读核对单位、闭合性、自交、数量、外环/孔拓扑、尺寸误差、编号一致性和镜像朝向。

拼焊资料给出基准板、装配坐标、编号视图、插接方向和装配先后，焊接符号只在确有工艺数据时输出；没有焊接工艺时写“拼装示意/待工艺确认”，不编造焊脚尺寸、焊序或热变形保证。

通过临时目录生成完整包，全部校验后以受控发布动作交付；目录存在时先按用户选择处理，不逐文件覆盖导致新旧混包。包的版本/hash 与装配结果关联，后续修改后显示历史，不宣称仍适用。

## 8 业务方法和消息流

新增方法均是 Scene SDO，按 01 的 commandId/expected/TaskAccepted 协议执行。

| 方法 | 载荷核心 | 返回 | 原子修改范围 |
| --- | --- | --- | --- |
| `CamModel.Create` | templateRef、parameters、role | TaskAccepted → workpiece/fixture ID | 模型及显示切面 |
| `CamFixture.SetRecipe` | setupId、recipePatch | recipeRef、revision | 输入、受影响状态 |
| `CamFixture.Generate` | setupId、recipeRef | TaskAccepted → candidateAssemblyRef | 仅候选，不替换确认版本 |
| `CamFixture.Confirm` | candidateRef、acceptedChecks | assemblyRef、fixture IDs | 装配、碰撞实例、失效状态 |
| `CamFixture.Breakdown` | assemblyRef | TaskAccepted → partListRef | 拆单结果引用 |
| `CamFixture.Export` | assemblyRef、partListRef、destination | TaskAccepted → deliveryRef | 发布记录，不改工件几何 |

```text
用户调整板片间距
 → SetRecipe：确认输入版本，一次 Undo 提交新配方，旧装配标记 Stale
 → Generate：冻结工件、Placement、支撑区域和配方
 → worker：截面/包络/板实体/连接/制造检查
 → 返回候选及问题，视图只加载候选资源
 → Confirm：再次核对来源与用户确认项
 → 事务替换夹具实例和碰撞配置，旧 Plan/报告/拆单失效
 → Breakdown：按确认装配计算平面板件
 → Export：回读文件校验后发布下料包
```

## 9 必测边界

薄曲面厚度未知、双层皮导致两个接触分支、曲面沿板厚方向急变、交叉板插接环、孤立材料岛、非平面板、斜孔、镜像件、源工件重导入、布局改动后旧拆单返回、导出中断和单位错误均必须有测试。每个失败都保留旧确认装配，不能把“生成了部分图形”作为完成。

几何内核依据：仓库 OCCT 8.0.0-p1 的 BRepAlgoAPI_Section、BRepCheck_Analyzer、BRepTools_History；算法适配仍需中性接口。官方说明确认 Section 的结果为交线/顶点，制造轮廓重建为本设计责任：[OCCT Section](https://dev.opencascade.org/doc/refman/html/class_b_rep_algo_a_p_i___section.html)。
