## 1. 主要判断

现有“基础形状／互补组合 → 包络规划 → 真实几何补隙 → 独立job比较”的路线可以继续。新增图片带来的主要改进方向是：**把重复单元批量排放、补隙时机和有限前瞻分开控制**，减少大数量任务中的重复单件试放。

必须继续保留混规格能力。整批同规格阵列只是候选之一，不能因为批量速度快，就固定先排完一种再排下一种。

| 借鉴点 | 照片 | 当前实现与实际缺口 |
| --- | --- | --- |
| 同一阵列池，比较不同选件规则和补隙时机 | 14、15 | `RunRules`已有组合、空位适配及补隙；尚未形成“相同批量阵列池，只改变补隙节奏”的严格对照 |
| 互补小组作为重复单元，再排多行多列 | 14、18 | `Pattern`保留成员姿态和库存消耗，已有互补、角链、混合单元；需要研究压缩的批量描述，避免重复计算同类候选 |
| 纵横分区、矩形件绕圈，补足单向阵列 | 15、18 | 已有行列、MaxRects和小范围矩形搜索；没有专用的大数量绕圈阵列生成器，不能把圆形件混排当成此能力 |
| 多个剩余矩形、多种单元间做有限前瞻 | 16 | `rect.lookahead`限20件、8个活跃规格、单张兼容板；不能称为大数量组合单元前瞻 |
| 同一位置服务支持左底、贴靠、阵列和压紧 | 17～19 | 公共实际几何验证已有；通用NFP、扫描线放件和压紧尚未接入 |
| 解释实际执行路径及未执行原因 | 24～39 | 注册ID、job结果、阶段计时、文字诊断已有；统一的适用性原因、实际后端和停止原因记录还不完整 |

## 2. 重复单元与批量阵列

照片14、18的有用结构是两级规划：先得到单件或互补小组，再枚举单元的行列排法。小组可以包含不同规格，保存原ID、成员局部姿态和需求向量。

对轴向保守包络宽高 `w,h`、可用矩形宽高 `W,H`、单元间距 `g`，候选满足：

`nx*w + (nx-1)*g <= W`，`ny*h + (ny-1)*g <= H`。

若单元消耗规格i的数量为 `ci`，重复次数还不得超过 `min(floor(remaining[i]/ci))`。共享原件的不同组合共用数量账，不能各自重复消耗。不足整行的需求保留为短行、其他组合或原件，不能丢弃。

批量描述可压缩为“单元、周期、行列数”，输出仍恢复每个原始实例。提交前检查真实成员、方向、板界和间距，再由中心验证器从原问题复核。小组内部间距已计入成员位置时，不能再次把每个成员重复外扩。

平行四边形／交错单元可以有斜向周期；轴向矩形包络只是保守候选，应与周期向量铺排比较。单元内部空洞不等于占用材料，补隙仍查询真实成员。

## 3. 补隙时机需要独立对照

照片14、15区分两种节奏：

1. 主体单元先形成整板骨架，再统一填内部孔、组间缝和板边余隙。
2. 每放一批单元，立即补局部空隙，再决定下一批主体。

第一种减少小件提前占据大件所需位置的风险；第二种可能及时利用局部空隙，但也可能消耗下一组所需的互补成员。不能预先宣布哪一种更好。

对照使用相同原问题、单元池、选件规则及总预算，只改变补隙时机，记录补隙实际消耗的规格。保留一个不做中途补隙的候选；恢复原件后，以“完整性 → 板数 → 最终板规整余料”统一选优。

当前孔槽局部填充已有增量能力，但不等于完成上述整套节奏对照。照片中的NFP填充也不能在我们的当前能力中标成已实现。

## 4. 有限前瞻与混合单元

照片16的价值是多保留几条不同排放路径，不在于具体的10／5／3等分支数。可围绕当前空位保留少量候选：大件／稀缺件、适配空位的组合、不同规格的行模式，以及保留规整余料的条带。

每个分支独立保存剩余需求、板材占用和成员映射，选择“单元＋重复次数＋方向＋空位”，向前试少量步骤后淘汰较差路径。不同基础形状的单件和组合共同参加选择，避免先按形状全部分开排完。

这是有限候选构造搜索，不使用蚁群或退火决定零件顺序。深度、候选数和状态量受job预算约束，各分支不能重复领取完整时间。相同包围盒不代表相同真实占用或孔隙，不能仅凭包围盒去重。

中间状态的已排面积、空位适配和接触程度可以作启发式，完整结果必须用公共评价。当前已排面积更大不证明订单更省板，当前保留的余料也不保证后续仍能保留。

## 5. 正交分区和矩形件绕圈

照片15的横／纵分区和照片18的 `CIRCLE_ARRAY` 可作为矩形单元的布局模式。**这里的CIRCLE_ARRAY描述矩形件沿四边绕圈，不是圆形零件排样。**

例如1000×1000局部区域，600×400矩形全部同向做规则行列只能放2件；四件按下表交替横竖放置，可以容纳4件，中央留下200×200空口：

| 件 | x | y | 宽 | 高 |
| --- | ---: | ---: | ---: | ---: |
| A | 0 | 0 | 600 | 400 |
| B | 600 | 0 | 400 | 600 |
| C | 400 | 600 | 600 | 400 |
| D | 0 | 400 | 400 | 600 |

这是允许90°转向、零间距的局部几何示例，不是2240×6000订单的性能结果，也不证明我们的现有组合／小范围搜索找不到它。带间距、固定角或数量不足时须重新计算。

将分区、绕圈作为同一阵列生成器的少量模式即可，不再复制库存、多板、验证和调度框架。绕圈更密也不能一律采用：中央孔可能形成难回收碎料，仍按板数和规整余料选优。

## 6. NFP、扫描线和位置服务

照片17～19支持将位置生成与决策分开。同一固定实际角度的几何服务，未来可供左底、贴靠、互补配对、补隙和局部压紧调用，各策略独立决定零件、角度和位置。

图中的轨迹／滑动法是参考路线，不能仅凭函数列表替换现实施方案中的分解／配置空间路线。先比较凹件、孔洞、接触退化和成本证据，再选择具体方法；内外NFP与板内可行域不能只凭名称混用。

- 缓存区分真实几何、实际姿态、间距、容差／误差和算法版本，不能只用ID或取整角度作键。
- 空间索引只筛掉确定无关的障碍，最终仍调用原实际材料谓词。
- 照片17的重叠／越界面积阈值描述不能成为我们的合法性条件；贴靠评分不能覆盖碰撞、间距或越界错误。
- 有限扫描线或有限NFP接触点未找到位置，只说明本轮没找到，不能宣称无解。
- NFP不独自决定零件顺序。空间浪费要定位到候选、角度、顺序或评价规则，不能归结为NFP必然如此。

## 7. 框架上吸收什么，避免什么

照片24～39展示用户选项、上层任务和底层实际执行之间可能发生错位。保留现有 `StrategyRegistry → Job → IStrategy／Pipeline → AssessCandidate → Quality` 的职责划分。

后续确需选择器时，先输出可检查的任务计划：输入特征、构造器／顺序／补隙模式、预算和选择原因；执行后记录实际后端、停止原因及各阶段成本。当前没有产品UI和行业分流，不为参照截图而提前增加这一层。

显式请求不适用的算法，明确说明原因。自动模式可另建已声明候选job，不能悄悄替换显式请求，也不能把某阶段没生成候选写成原问题无解。诊断应区分不适用、未实现、预算耗尽、取消、候选检查失败、需求未完成和正常完成；当前状态枚举与文字诊断不等于这些原因已全部结构化。

不照搬100／200／500种、每种不超过5件等门槛：它们是特定实现的分流条件，不是几何定理。用我们自己的少种多件、多种少件、多种多件、密集小件数据检验。研究模式保留全策略结果；以后自动选择器必须经过相同总预算和未见数据验证，不能只挑已获胜任务证明自己。

照片21的“必须邻近”是工艺约束，与主动寻找互补组合不同。当前 `Placement.Group`只是可拆规划标签，不是刚体或强制相邻约束。共边、门业、一刀切、异形板和卷料本轮不扩范围；MaxRects空闲区分裂也不自动产生可执行的一刀切顺序。

照片37的先消化余料、再排新板可作为未来独立候选，不能在全局省板目标下无条件锁死早期选择。混合策略必须说明比较整订单还是逐板结果，逐板最佳不保证订单最佳。

## 8. 后续优先次序及本轮交付范围

同步的大数量实测支持先解决完成度和重复工作：2240×6000主矩阵32例、每例34个job，每job构造0.5秒／10万次尝试，最好结果23例完整。随后6例、7种策略、2秒／200万次尝试的试验中，3200件两例完整，6400件四例仍有未排需求；其中两例是没有同输入低预算对照的密集小件。独立审计未发现数量、几何或余料证书错误，原始浮点尾差另记，均按既有容差判定。这些是合成数据观察，不是生产验收，也不能把缺件方案的较少板数解释成省板。

四个重合输入只比较相同的七种策略，28个配对中24改善、4相同；时间与尝试上限同时增加，不能单独归因。详见[大数量筛查审计](../../output/research/plane-nesting/20261027/large-sheet-2240x6000/audit/spatial-screen-01-independent-review/summary.json)和[增加预算试验](../../output/research/plane-nesting/20261027/large-sheet-2240x6000/runs/deep-tier-02/RESULT.md)。压力集另有输入见证核验，尚未运行求解器，不能计作求解通过。

1. 继续核对2240×6000多规格／多数量结果，区分预算不足与策略能力，保留原件数量和独立几何复核。
2. 以相同组合池对照补隙节奏，再研究批量阵列、短行余数、正交分区和绕圈，记录质量与真实耗时。
3. 将有限前瞻从小型纯矩形扩展到批量混合单元，先做隔离试验，按实际需要共用助手。
4. 沿原定顺序接入扫描线、NFP位置服务，复用组合／混排／补隙层，通过独立job比较。

本轮完成图片阅读、源码对照和设计记录，没有因截图直接增加默认策略，或把未完成能力标成实现。

## 10. 后续实现进展

同日先以可选 `MakeBatchRuleFactory` 实现重复单元行列铺排、末行余空、两种补隙节奏及原件恢复，复用原组合池和调度／验评。经过后续固定大数量对照及完整34策略补测，OnStall现已追加默认表，总35个job，原34项顺序前缀不变；AfterBatch仍可选。大数量混合单元的多步前瞻、正交分区／绕圈、斜周期及通用NFP／扫描线仍未实现。具体边界见[模块说明](../../src/iCAX-Engine/foundation/SheetNesting/README.md)。

首轮大数量对照保留了负结果：新增两策略在32个短预算案例中只提供一个同板数余料改善，在6个较高预算案例中只提供一个6400件完成度改善；其余最佳批量候选多数弱于原控制，没有两个完整结果之间的省板证据。数量、实际几何和余料证书经过独立核验，不能把少排的件当成省板。见[首轮证据](../../output/research/plane-nesting/20261027/large-sheet-2240x6000/runs/batch-array-01/EVIDENCE.md)和[完整数量图文对照](../../output/research/plane-nesting/20261027/large-sheet-2240x6000/runs/batch-array-01/visual-review/index.html)。
