# 33 锯切分组与铣削余区混排

先组织满足锯切要求的矩形组，再在明确剩余区域中安排铣削件。业务路由、首件约束、两类间距和区域更新必须显式表达。

类型：业务复合策略。当前实现状态：**已实现显式分类、切分构造与专用验证**。核对日期：2026-11-07。

## 代码实现与调用

入口：`RunPlaneManufacturingTask(SawMill)`。实现位置：[NestingPlaneManufacturing.cpp](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingPlaneManufacturing.cpp:328>)。

加工分类有三个明确入口，不能混用：保留旧 `SawPartIDs` 契约（其余原件为 Mill）；也可提供完整的 `ProcessAssignments`，用 `PlanePartProcess::Saw/Mill` 逐原件分类，遗漏、重复或未知原件均拒绝；或者显式选择 `ProcessClassification=RectanglesSawPolygonsMill`，按真实矩形类别分流。实现不看零件名称猜加工方式。被声明为 Saw、但无合法轴向矩形姿态的原件不会偷偷改成 Mill。

锯件在真实剩余矩形叶子上比较同高行和同宽列，按逐规格余量进行有限数量回溯，再生成有序横切／竖切与锯缝记录。铣件只放在切分后的真实叶子内；Saw–Saw 使用 `max(PartGap, SawGap)`，含 Mill 的原件对使用 `max(PartGap, MillGap)`，每个叶子最多一件 Saw，所有原件都不能跨实际切线。

工艺整板复用已接入：专用验证源布局后，在私有草稿中复制整板原件、新实例、独立组号及该板全部 `Cuts`；切分记录的 `StockInstance` 随新板更新。复制草稿再次通过专用验证才原子发布，剩余数量不足一整板时继续处理尾数；构造、复制共享时间、尝试和取消预算。

专用优化入口 `OptimizePlaneManufacturingLayout` 保留原 `Cuts`，每次平移／旋转后重新检查加工间距、叶子归属及切线；仅接受完整工艺合法且公共质量改善的结果，失败或取消保留历史最好合法方案。调用者传入后处理剩余预算。

## 原资料的方法与实际分支

原文 WoodHybridNest 是业务入口，CWoodHybridStrategy 只是其中一条：移板/桥切转一刀切，全异形调用次级矩形板竞赛，有矩形才进入具体混排。具体流程先尝试大件首件启发式，锯片栈按组处理，扣出铣刀余区后再填充。

三种间距 nPartDistance、nWoodRectDistance、nWoodSawDistance 不可合并。铣刀候选表与真实分支不同，实际只有左底、ARRAY_4 和可选随机阵列等有效路径。旧 EvaluateResult 的“更多件，否则 IsBetterThan”不是严格件数字典序，可能依遍历顺序变化。

## 面向 iCAX 的独立策略步骤

1. 宿主声明每个原件的加工类别、各类间距、组约束和首件条件；纯几何模块不猜测刀具类型。
2. 业务入口先判定纯锯切、纯铣削或混合，并选择真实已注册的子构造。
3. 锯切分支生成带原成员和切分证据的矩形组；用明确距离转换建立铣削禁放区。
4. 将剩余实际可用域提供给铣削构造，所有子策略面对相同需求快照独立试排。
5. 以统一字典序验评选择一份候选，再原子提交需求与组状态。
6. 首件未成功时返回明确状态；大件尺寸启发式不作为吸附或防跑板证明。
7. 后处理只能在保留工艺约束与距离转换的条件下移动组或原件。

## 当前适用边界

分类规则必须由调用者显式选择；尚未接入生产业务的自动路由、桥切／移板分流及首件业务规则。行列组合、铣件落点及后处理均为有限搜索，不保证全局最优或所有可行加工方案均能找到。`Cuts` 是可复核的矩形叶子切分证据，不是 CAM 刀路、完整修边工序或机床程序。
