### 全部适用初解的并行构造与回调

基础27个候选加一个条件原向order，对应30个注册入口去除完整优化工作流 `plane.nfp-all` 和调度入口 `plane.initial` 自身。普通构造注册与候选生成共用 `InitialConstructors` 描述表，多排序包装通过同一候选生成路径接入，避免两套名单漂移。

| 构造方向 | 参加初解的入口（均带 `plane.` 前缀） |
| --- | --- |
| 保守包络天际线 | `envelope-initial`，原件需求与孔保留；包络只用于构造，每次落位及最终结果仍按真实材料复核 |
| 数量/密度/原式与补隙 | `array-1`、`array-2`、`array-4`、`array-5`、`array-2-source`、`array-5-source` |
| 首项与递归 | `array-first`、`array-search-first`、`array-search-multi`、`array-reduce`、`rect-block-search` |
| 逐件NFP | `nfp-initial`、`nfp-closest`、`nfp-directional`、`nfp-strip` |
| 阵列与绕圈 | `nfp-array`、`nfp-multi-array`、`four-block` |
| 矩形专用 | `rect-contact`、`single-product`、`single-column` |
| 扫描与组合调度 | `scanline`、`array-3`、`mix`、`array-random`、`order-ultra` |

全部正需求原件都是无孔真实矩形时，27项均准入；有正需求非矩形或孔时，按描述表跳过 `rect-contact`、`single-column`、`single-product`、`rect-block-search`、`four-block` 五项，保留22项并逐项说明原因。零需求件不影响资格。准入不代表各策略一定完成，内部数量/姿态、几何与有限搜索条件仍生效；`nfp-strip` 是有限板内条带，不能误当暂缓的卷料。

每条路线独立构造完整任务，用原问题验证与 `Options.Ranking` 择优。`Workers=0` 自动选择 `max(1,min(硬件并发数,4))`，也可显式配置1～32；有限线程从同一启动门释放，完成一条即可领取下一条，没有阶段屏障。通用并行工厂默认 `FairScheduling=false`，保持原固定尝试份额及全局剩余时间行为；`plane.initial` 强制开启公平调度，调用方不能将它退回旧模式。

公平模式启动路线时，以 `remainingTime/ceil(unfinishedRoutes/W)` 分配局部时间，并受同一全局截止点限制。尝试租借池初始为 `available=globalCap,unleased=N`；启动时预留 `ceil(available/unleased)`，结束按真实消耗退还未用部分，失败或超报保守计满本次份额。排队路线可共享归还余量；配额暂被活动路线占满时等待归还，不能提前当作永久耗尽。总实际/保守计费不超过全局上限，租借的累计发出份额可因归还再利用而大于该上限。局部时间到期不等于用户取消。

每次初解执行新建一份有界 `NfpCache`，只在本任务适用候选及其内部有限构造之间共享源几何分解和不可变NFP。需求、库存、布局、随机状态、世界姿态几何和件对判定均留在各自构造器；不跨任务缓存布局。缓存的互斥与并发构建等待只保护几何，不把某条路线的取消或失败写成永久失败缓存。

纯构造准入由 `IsPureConstruction()` 声明，预算/生命周期所有权由 `OwnsRefinementLifecycle()` 声明，不能互相替代。Order、PlaneInitial和通用纯构造组合都可同时为真；`plane.nfp-all` 的完整优化不属于纯构造。source43与密度入口、即时与延后补隙、逐板与整单竞赛都有不同选择语义，不能因共享模板或Kind而去重为别名。

通用并行工厂也可接调用方选定的纯构造器列表。工厂调用、原始 `Cancel` 轮询及两个可选回调均在 `Run` 调用线程串行执行：`OnImprovement` 只发布经原问题验证、完整且公共质量严格改善的best；`StopWhen` 在同样的完整改善边界判断目标。回调参数引用只在调用期间有效，异步消费须自行复制。两个可选回调异常各自停用；原始取消已确认或其轮询异常后不再通知，但仍可保存迟到的已验收更佳候选用于最终返回。工作线程全部回收后结束。

```cpp
ParallelConstructionSettings parallel;
parallel.Workers = 4;
parallel.OnImprovement = [&](const JobResult& best) {
    // 在当前调用线程取得已完整验评的改善；需保留时复制 best.Output。
};
// 未设置StopWhen：默认继续比较完整质量，板数下界不提前结束候选竞赛。
// 验证全部方法执行时，可设置始终返回false的StopWhen并给足预算。
// MakePlaneInitialFactory内部强制FairScheduling=true。
registry.Register("example.parallel", MakePlaneInitialFactory(parallel));
auto initial = RunJob({"example", "example.parallel", problem, options}, registry);
```

当前默认不安装 `StopWhen`。完整一板和名义材料板数下界都不代表余料、紧凑度、板型配比等完整质量已最优，不能提前取消其他适用路线；调用方仍可显式提供成功停止条件。默认在共同预算内比较候选，时间截止、尝试预算和真实取消仍生效。下方 G025 的下界提前停止计时保留历史快照语义，不能当作当前默认调度的耗时结论。

成功停止与时间截止均保留历史最好合法完整/部分结果；只有原始 `Cancel` 确认才使整体状态为 `Cancelled`。工作线程仅读取内部停止标记，不并发调用原始取消回调。时间截止是协作式，单次几何操作、回调及最终验评可能越过名义时点。总耗时使用实际 wall time，诊断另记 `first-complete-wall-s`、`last-improvement-wall-s`；不得把并行路线耗时或相互包含的阶段耗时相加当总时间。

自定义配置通过 `MakePlaneStrategyFactory(settings)`。配置包含 `Kind`、`XFirst`、毫米 `ScanStep` / `ContactBand`、候选数、分支宽度、分叉深度、节点数、随机重启数、阵列轴上限，以及 `EnableHoleNesting`、`EnableIndependentPairArrays`、整板复用及构造内整理开关。非法枚举和限额抛出 `std::invalid_argument`；运行时非法问题或预算返回 `InvalidInput`。有限搜索失败保留未排需求，不作为不可行证明。

逐件 NFP、阵列组合和固定补隙支持正间距。共享内部服务 [NestingClearancePlacement.h](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingClearancePlacement.h:15>) 为固定件建立私有避让轮廓，候选返回前按原件和名义间距严格复核。正间距生产规格限额扩至每种兼容材料 512；私有场景含外扩副本、域障碍在内仍受总轮廓准入约束。`NfpPlacementLimits.MaxFixedPlacements` 默认 4096，可由内部调用显式限制；更多规格不等于更复杂几何必然可准备。

圆与孔的支持位于私有提案及原件验收层：圆可用外接多边形，带孔移动件可填实孔提案；原始 NFP core 仍采用无孔多边形、零间距场景，不能据此宣称孔或圆的全部 NFP 接触/周期组合都已原生支持。一般孔内候选由 [NestingPlaneHoles.cpp](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingPlaneHoles.cpp>) 按实际孔域生成，包络仅作必要尺寸和邻近剪枝。保守提案、外扩失败、候选与场景限额仍可能漏掉可行解，保留未排需求和合法基准。

周期模板按原间距验证远邻与对角；独立 pair 展开后对全部实际成员验真，不能只凭相邻周期放行。主尾与孔内展开仍按各原件完整用量向量扣数，孔容量排序不增加材料面积。

`plane.nfp-all` 是完整算法工作流：先以剩余时间的75%及按75%取整的尝试数份额运行全部适用初解的公平竞赛，再用实际剩余预算对完整单板或多板执行轴向压紧、跨板回填及持续优化；尝试份额至少为1，只有剩余总额仅1次时无法另留迭代次数。初解提前达到板数下界只结束构造竞赛，未用预算留给后续优化。工作流拥有生命周期，但声明非纯构造，不会在 `RunJob` 外层重复整理，也不会被纯构造竞赛误收。

`plane.nfp-initial` 保留独立 NFP 路线，关闭完整布局的压紧与跨板回填，对应 `EnableLayoutRefinement=false`。该路线内部按靠接、增量包络空耗、大件优先和有限束搜索作有界评分/轴向 trials；`NfpTrials` 为 1～6，有限 trials 仍在本路线内按剩余预算执行，不是另开六份任务预算。首件按实材量、低位位置和实际材料质心选择。隔离单路线纯构造测试时还应设置 `Options.EnableBasicCompaction=false`。阵列递归先保留贪心基准，再按剩余面积板数分配每板时间、尝试数和节点；叶子按真实材料面积优先比较。

初解负责短时间内形成完整、有竞争力的排样；明显可下落、可在允许角度内转向贴合的零件属于初解职责，不能留给长时间迭代补救。多规格递归阵列及两个 NFP 阵列入口默认启用 `EnableContourSettling`、`EnableAllowedAngleSettling`：每板先沿原轮廓向下/左落位，再有界尝试有限允许角度并下落。原件身份、板分配、组号及补隙来源保留；旋转后严格验证名义间距，天际线及右界不增加。默认不在该小步骤搜索自由连续角。

构造内收尾独立于外层 `EnableBasicCompaction`，共用初解总时间、尝试及取消预算；不是将旧布局送入额外任务求解。用户选择利用率优先时，再从初解调用适用的重组、缩域、跨板回填或约束邻域等迭代算子，始终保留历史最好完整结果。单板固定集合与多板减板/回填接口的作用域保持区分。

补充 44 的整板复用已接通。`EnableSheetTemplateReuse=true` 时，首张布局正式提交后按全部原件的用量向量计算额外可复制次数，并受同板型剩余库存限制；副本保留几何坐标和角度，重新分配物理板及原件实例、正组号。复制逐板原子提交，尾量继续正常构造。`MinimumSheetReuseUtilization` 默认 0，与原机制不强加密度门槛一致；可显式设置质量门槛。重复订单的代表板先取得有界启动预算，再按实际配方的可复制收益加权搜索，不按大量物理板数将首板预算摊薄。

`PlaneDomainTask` 同样默认复用同一 `StockID`、同一真实边界/孔/障碍的布局，复制前重新核对真实可用域；不同板型只因外接宽高相同不能混用。异形域的可选密度门槛按真实可用净面积归一。源机制的折叠 `nRepeat` 表示没有加入当前 `Result`，副本展开为独立物理板，不代表重新进行了几何求解。详见 [44](<D:/penguinchinage0609/iCAX/doc/Plane/策略/44-单板布局批量复用.md>)。

配对、共边、锯切与锯铣专用任务也已接入整板复用：副本及对应切分 `Cuts` 一起在私有草稿中展开，恢复新物理板和原件身份后由 `ValidatePlaneManufacturingLayout` 检查工艺、组关系及实际叶子切分，验收通过才发布。跨任务缓存和折叠 `nRepeat` 输出仍未增加。

整板复用本身选定一份配方后计算可复制次数；不同配方的整数份数组合由可选 `OptimizePlaneSheetMix / MakePlaneSheetMixStage` 处理。配方只能来自本任务现有结果或本任务原输入的新构造，不载入以前任务布局。其配方数、搜索节点、构造探针和尾排次数均有界，不能把一次整数配比找到的结果说成全局最优。

现有 [MakeNfpRefillStage](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingNfpRefill.cpp:17>) 也接入相同正间距服务。跨板转移保留原实例，只有完整原件验评改善才提交；取消、预算耗尽或无法清空尾板时保留完整的最好布局。

可选约束后端的 `MakeSheetCountStrategy` 现在默认由当前原始输入生成一次原件 NFP 初解，再以软提示搜索更少板数；位置、角度和板归属均不锁定。`SheetCountSettings.EnableNfpInitializer` 控制该步骤，关闭时仍走原有冷搜索。初解失败继续固定板数搜索；已得完整初解在后续求解失败、取消或预算结束时保留。源代码在 [NestingSheetCount.cpp](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingSheetCount.cpp>)。

整数求解结果默认仍遵循原问题的几何容差。需要额外消除输出位姿舍入误差时，可启用 `EnableRoundoffRefinement`；其通用微量平移服务现支持正间距和多张物理板，并严格复核接受的名义间距。完全紧配等情况下修复不可行时保留原验证政策，不据此伪报几何不可行。

## 固定布局与专用任务

```cpp
#include "SheetNestingPlaneCompaction.h"
#include "SheetNestingPlaneDomains.h"
#include "SheetNestingPlaneManufacturing.h"
#include "SheetNestingPlaneSheetMix.h"

// 对已有板补入尚缺实例，固定已有姿态；fixed 可以有稀疏的 Instance 编号。
auto filled = MakePlaneNfpFillStage().Factory()->Run(problem, fixed, options);

// 只重排最后一板，保留之前所有板；complete 必须是完整合法结果。
auto shrunk = MakePlaneShrinkStage(MakePlaneStrategyFactory()).Factory()
    ->Run(problem, complete, options);

// 此函数优化完整、非空、单张物理板的固定原实例集合。
PlaneCompactionSettings compact;
compact.TargetUtilization = .85;
compact.StableIterations = 16;
compact.EnablePerturbation = true; // 只扰动私有 current，发布的 best 不退
auto optimized = OptimizePlaneLayout(problem, singleSheet, options, compact);

// 完整多板任务：逐板固定集合优化、相同配方优化复用与全局 checkpoint；
// RefillAcrossSheets / MixSheetRecipes 可分别关闭跨板回填和整数配比。
auto optimizedJob = MakePlaneOptimizationStage(compact, MakePlaneStrategyFactory())
    .Factory()->Run(problem, complete, options);

// 也可只单独比较不同单板布局的整数张数与准确尾量。
auto mixed = OptimizePlaneSheetMix(problem, complete, options, MakePlaneStrategyFactory());

PlaneDomainTask domain;
domain.Input = problem;
domain.Domains = domains; // 每项含 StockID、真实 Boundary、Obstacles、可选 InnerRectangles
domain.UseInnerRectangle = true;
domain.CombineInnerRectangles = true;
domain.EnableInnerPrefill = true;
domain.InnerShrinkProbes = 2; // 本板只压缩选中的主排，预算不超过剩余 1/8
domain.MaxRigidShift = 0; // 从当前真实域与成员包络推导有限范围
auto domainResult = RunPlaneDomainTask(domain, options);
auto domainCheck = ValidatePlaneDomainLayout(domain, domainResult);
auto domainOptimized = OptimizePlaneDomainLayout(domain, domainResult, options);
auto domainOptimizedCheck = ValidatePlaneDomainLayout(domain, domainOptimized);

PlaneManufacturingTask process;
process.Input = problem;
process.Mode = PlaneManufacturingMode::SawMill;
// 调用者明确选择这个规则；也可以改用完整 ProcessAssignments 表。
process.ProcessClassification = PlaneSawMillClassification::RectanglesSawPolygonsMill;
process.SawGap = .5;
auto processResult = RunPlaneManufacturingTask(process, options);
auto processCheck = ValidatePlaneManufacturingLayout(process, processResult);
auto processOptimized = OptimizePlaneManufacturingLayout(process, processResult, options);
auto processOptimizedCheck = ValidatePlaneManufacturingLayout(process, processOptimized);

PlaneLabelRequest label; // 填入宿主、标签、目标中心等
auto labelResult = LocatePlaneLabel(label, options);
```

以上片段展示可选接口结构，`problem`、`fixed`、`complete`、`singleSheet`、`domains` 由调用方提供真实数据。实际流程选择所需入口并传入剩余预算，不应把每个示例都各给完整预算串跑。完整可执行用例见下方测试源码。

异形板的真实边界、障碍，以及配对、共边组、锯铣切分规则属于专用任务。后续编辑必须再次执行 `ValidatePlaneDomainLayout` 或 `ValidatePlaneManufacturingLayout`。普通 `Validate(problem, result)` 只认识原 Problem，不能替代这些额外规则；当前没有把专用结果自动送入普通优化器。

持续优化的时间与尝试数始终生效；目标和稳定条件可以关闭。停止原因优先顺序是取消、目标、时间、尝试数、稳定。单板有限扰动允许私有 current 在配置的包络增长范围内临时恶化，所有发布结果只更新历史最好完整解；多板每张完成的合法改进经共享质量全局 checkpoint 验收后保留，后续中断不会抹掉已经验收的改进。时间检查是协作式的，单次几何调用或最终验证可能越过名义时间点。
