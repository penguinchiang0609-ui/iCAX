# 38 多阵列块的有界递归组合

以阵列块为决策单元，递归尝试多个块在余矩形中的组合。适合作为小规模对照或有界组合构造器，不直接恢复为默认算法。

类型：历史构造参考。当前实现状态：**已实现受限适配**。核对日期：2026-11-07。

## 原资料的方法与实际分支

旧 CRectNestStrategy 与当前旧库 ITER_RECT 的 CRectangularStrategy 不是同一类。源码、编译项和包装仍在，但顶层 DoNestRect 调用已注释。按材料输入顺序消费，每块余区选择最大矩形，实际只调用 X 向阵列生成器。

候选逐个 nX 求 nY，达到或刷新最大数量就追加而不删除先前较小记录；约五次累计成功后停止规格扫描。递归暂扣数量、复制余区、移除块、返回恢复；每层最多进入前 21 个下标，结果数大于 100000 才在入口截断。完整方案按真实面积排序，无明确同分 U 规则。末张非重复板另作最多八次竖直缩高，仍仅按面积不减接受。

## 面向 iCAX 的独立策略步骤

1. 用现有 Pattern 保存阵列块的原成员、角度、节距与需求向量，避免仅 nX/nY 丢失模板语义。
2. 在有序余区上生成多规格块候选，显式排序后保留前 K 项，区分候选数量与成功计数。
3. 每分支保存私有需求、空域和原件姿态，提交前验证块内部及对固定布局的真实几何。
4. 用显式栈或有界递归探索，节点、深度、时间、尝试和内存均纳入预算。
5. 保留有限最好叶子，不积累十万级全部方案；可用剩余材料上界作安全剪枝，启发式剪枝另标记。
6. 全部候选用统一质量比较，胜者首板唯一展开并提交；再按实际用量向量与剩余库存复制额外物理板，重映射实例和组号，尾单保留准确余量。
7. 末板缩域另用固定实例后处理，不将面积相等当身份保持。
