# 初解策略及共享算法

更新：2026-11-12。本文描述本次源码结构，验收结果另见本次输出记录；旧文中的数量评分、重复路线数及旧案例成绩不作为当前实现证据。

## 职责

- `NestingPlaneStrategies.cpp`：注册、历史名称兼容、逐板竞争、随机重启、完整任务并行调度和公共终局选优。
- `NestingPlaneConstructors.cpp`：各策略的单板执行顺序、补空时机、条带范围、有限搜索状态。
- `NestingPlaneConstruction.h/.cpp`：原件库存、许可姿态、NFP查询、自组合及阵列候选、轮廓硬检查、利用率/接触/当前剩余空间评分、提交、缓存和观察。
- 既有公共几何服务仍分别在 `NestingNfp*`、`NestingPlaneEvaluation*`、`NestingSheetTemplateReuse*`，没有复制成每路专用版本。

策略可以共用候选生成器和循环模板。策略区别必须来自选件范围、候选类型、评分或状态推进规则，不能只换名称或日志。

## 默认参赛策略

| 入口 | 实际构造规则 |
| --- | --- |
| `plane.envelope-initial` | 保守包络天际线/空腔基线，最终检查原轮廓 |
| `plane.array-layered` | 大同型组合阵列；当前高度内先组合补空再单件补空；再继续主阵列 |
| `plane.array-deferred` | 主阵列连续构造，主排停止后统一补空；主排本身可自然占用凹槽 |
| `plane.array-immediate` | 每批主阵列后，在该批实际范围内组合及单件补空，再继续主阵列 |
| `plane.array-random` | 每次真实抽选候选；各次独立重启，由完整方案质量择优 |
| `plane.scanline` | 按扫描步距生成格点并检查原件，扫描方向由设置控制 |
| `plane.nfp-initial` | 所有可用规格的单件NFP候选比较；只构造一次，不隐含重复试次 |
| `plane.nfp-closest` | 首可行规格；同利用率/净料后比较实际靠接面积 |
| `plane.nfp-directional` | 首可行规格；同主键后比较主轴位置及实际靠接半周长 |
| `plane.nfp-strip` | 首件确定临时条带宽度或高度，后续在该范围内逐件放置；原板尺寸保持权威 |
| `plane.nfp-array` | 首规格的单件、自组合和轮廓阵列候选竞争 |
| `plane.nfp-multi-array` | 多规格的单件、自组合和轮廓阵列候选共同竞争 |
| `plane.array-search-multi` | 贪心可行单板保底，再进行有界多规格分支；保留已认证方案 |
| `plane.mix` | 各板用不同子策略构造完整单板候选，选择后扣实际库存 |
| `plane.rect-contact` | 矩形接触阵列，多规格候选比较 |
| `plane.single-product` | 单一产品规格阵列，产品状态限制后续选择 |
| `plane.single-column` | 固定列宽/列顶推进的矩形构造 |
| `plane.rect-block-search` | 矩形区块的有界搜索 |
| `plane.four-block` | 四块矩形模板、有界分支及实际中心区域填充 |

最后五项仅适用于全部需求为无孔矩形。默认清单有19项，异形任务适用14项。此数是调度项数，包含复合策略及共享候选算法的不同构造规则，不等于19种不同几何内核。

## 历史入口

`array-1`指向分层构造；`array-2`及`array-2-source`指向延后补空；`array-4/5/5-source`指向即时补空。source仅保留来源诊断，件数不是评分目标。`array-first`为最大规划余矩形参数变体；`array-search-first/reduce`为显式搜索参数变体；`array-3`为两路单板竞赛。它们仍可单独调用，不重复加入默认竞赛。

`order-array/order-ultra`是排序包装，仍可显式调用；默认不与对应基础策略重复参赛。`plane.initial`为总调度，`plane.nfp-all`为显式含后整理的工作流，均不冒充新增初解算法。

## 公共约束及评价

所有方案各自从原需求构造，不共享可变库存、布局或姿态选择；只共享不可变几何缓存。旋转和镜像属于每步候选，不作为整批翻转的伪策略。

候选先核原件、板边、间距、共边许可和剩余数量。局部排序首先比较真实净用料/整板宽度所耗长度，再比较净用料；接触、当前剩余空间和稳定位置项仅用于主键平局。空间评价不试排后续原件。最终方案经统一验证及利用率评价，未排齐结果不能作为完整成功。

普通分层/填空及单件NFP使用当前原轮廓空间评价。评分异常或预算终止时保留已认证候选，不能凭不完整几何分数换掉更优利用率。

分层路线在调用方关闭组合或补空阶段时，回退为普通向前阵列。该回退保留既有的单个下一主阵列认证见证，用实际原轮廓保护其位置；不穷举后续零件排列。

默认初解关闭尾部重排、转角整理和压紧。显式开启这些设置会声明为带后整理工作流；原始构造与后整理快照分别记录。
