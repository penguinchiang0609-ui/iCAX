# 28 剩余矩形上的接触评分构造

用可重叠的空闲矩形描述候选位置，在已考察的规格和方向之间选择接触分最高者。该算法不提供一刀切顺序，也不连续移动已排件。

类型：独立构造策略。当前实现状态：**已实现受限适配**。核对日期：2026-11-07。

## 代码实现与调用

入口：`plane.rect-contact`。实现位置：[NestingPlaneStrategies.cpp](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingPlaneStrategies.cpp:925>)

在 MaxRects 剩余矩形候选处按外扩接触材料与候选余区边界评分，提交真实矩形原件。

## 原资料的方法与实际分支

CRectangularStrategy、CRectNestAlgo 和 CRealRectList 组成原矩形主算法。普通自动准入要求激光规则、矩形库存、无特殊共边数量/同边约束；通常至少 200 种零件，每种无孔矩形且总数量不超过 5。邻近规则有另一路由。以上是旧系统业务门槛，不是 iCAX 的准入规则。

候选 P 左下角对齐当前空闲矩形 R。令 E(P) 为四边外扩 d=50 的矩形，评分为 Σ Area(E(P)∩Nᵢ)+Area(E(P))−Area(E(P)∩R)，取大者。R 是当前空闲矩形而非整板，d 是源坐标常数而非已证实的 50 mm。提交后将全部相交空区拆成最多四块并作包含过滤；空区允许重叠，面积不能直接相加。默认适配候选预算 6000，随大订单下降，并有约预算/20 的局部限制，属于软循环截断。

## 面向 iCAX 的独立策略步骤

1. 通过真实矩形识别与合法角度准备占位包络，正间距和板边距仍由统一几何契约处理。
2. 初始化 MaxRects 空域，枚举空区、剩余规格和允许方向的左下角候选。
3. 将源式接触分作为独立 RectScore 扩展，显式配置物理外扩尺度；保留按空区边和按物理板边两种不同版本。
4. 分项计算邻件外扩交面积与边界项，不把代理分记成真实共享边长或 U。
5. 按明确预算及稳定平局顺序选候选，原件验证后提交并扣数。
6. 分裂全部相交空区、删除被包含区，继续直到无候选、预算耗尽或取消。
7. 最终重算真实材料、原件包络与统一质量，另行评价是否值得进入后续压紧。

## 实现后的验收条件

以下保留原资料导出的完整验收目标，不表示每项已通过。当前已执行的测试与未覆盖范围见“实现状态”，尤其保留上述适配差异。

- 正间距原件校验有效。
