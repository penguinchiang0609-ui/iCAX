# 32 同宽单列续排

沿一个方向排列首个规格，再以同宽规格延续当前列。适用同宽加工约束；它不自动填满旁侧余区，也不应与多列矩形混排混称。

类型：工艺约束构造策略。当前实现状态：**已实现受限适配**。核对日期：2026-11-07。

## 代码实现与调用

入口：`plane.single-column`。实现位置：[NestingPlaneStrategies.cpp](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingPlaneStrategies.cpp:902>)

锁定首列宽度，只向上续排同宽合法矩形方向；不在列旁补隙。

范围与差异：同宽以实际几何和输入容差比较；已接入同任务展开式整板复用，按整列布局实际用量和剩余同型库存计算额外副本。每张副本独立输出，不提供源库折叠 `nRepeat` 结构或跨任务布局缓存。详见 [44 单板布局批量复用](<D:/penguinchinage0609/iCAX/doc/Plane/策略/44-单板布局批量复用.md>)。

## 原资料的方法与实际分支

`CVerticalAndFillStrategy` 只从矩形集合取件。首列强制横向重复数为 1，纵向受需求和板高限制；续排只看已排包络上方，并找与末件同宽的第一个合法角度。角度/节距内部比较 ArrayEvaluation，跨规格比较占位矩形面积。

首张内部已扣需求，重复数代表额外张数，输出需加 1。候选截断按成功次数累计，不是固定 20 次所有尝试。材料按输入顺序消费，没有跨材料利用率竞赛。

## 面向 iCAX 的独立策略步骤

1. 准入只接受实际满矩形、材料兼容及明确方向许可；其他需求保留未排。
2. 为各合法角度建立真实宽高，首列固定横向数量 1，以可用高度和库存求纵向重复。
3. 以实际放入净材料、占用面积及稳定顺序挑首列，并记录与源评分的差异。
4. 从当前列顶部生成上方剩余区，查找与列宽相等的候选规格和合法角度。
5. 追加同宽段直到没有候选；旁侧空白不擅自放件。
6. 首张提交后按完整用量向量及剩余同型板库存求额外复制次数；副本重分配原件、板材和正组号实例，余量继续构造尾列，不重复扣首张。
7. 同时报净材料/包络比和净材料/板面积，防止窄列 100% 紧凑掩盖大量耗板。
