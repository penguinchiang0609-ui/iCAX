# 03 阵列减行减列的有限回溯

在贪心阵列的前几次决策中，主动少放一行或一列，为后续件留出空间；用完整路径质量决定是否值得让位。

## 原资料的方法与实际分支

`CDfsArrayStrategy` 是 NFP_ARRAY 的辅助搜索，不是 ARRAY_1～5 的通用递归。旧入口同时受编译宏、非检查距离、利用率优先及已有基准解限制。每层只取父类候选首项，生成原阵列、减行、减列；`path.size()<=5` 允许前六次决策分叉，之后仍递归，只是不再分叉。

配对阵列先比较两个成员最远端，再减伸出者并重算包络。叶子先按真实面积、再按旧 IsBetterThan 比较，只给选中叶子补填；父层只接受真实面积严格增加，因此同件集更紧的结果可能被挡住。

## 面向 iCAX 的独立策略步骤

1. 保存基准布局，将阵列模板、余区、原实例消耗放入每个搜索状态。
2. 从可行基准阵列提出原案、减一行和减一列，按配对成员的实际边界重算所有姿态。
3. 用明确 `MaxBranchDecisions` 控制分叉，节点、候选和保存状态另设上限；不用含混的递归深度代替。
4. 每条边事务式提交数量和余区，返回时完整恢复；深订单使用显式栈。
5. 在叶子或截断点保留合法部分解，按共同质量形成有限候选集。
6. 给保留叶子分配相同补隙份额后再比较，避免只填一个叶子的偏差；这是相对原文的改进。
7. 与原基准用同一个 Quality 比较，不再由父层另加“面积必须增加”门槛。
