已在排样库实现 **28 个显式入口**。`plane.initial` 现按同一构造描述表调度全部适用的 **26 个初解候选**，覆盖43原式评分、即时/延后补隙、扫描线、NFP、递归、逐板 mix、随机和多排序；全部正需求为无孔矩形时准入26项，存在正需求非矩形或孔时跳过五项矩形专用入口，保留21项。完整优化入口 `plane.nfp-all` 及 `plane.initial` 自身不在默认候选内。`plane.nfp-all` 先取得初解，再用剩余预算优化完整布局；固定补隙、异形板、工艺和标签等另有专用接口。[实现状态与调用示例](<D:/penguinchinage0609/iCAX/doc/Plane/策略/实现状态.md>) 说明边界。**卷料36、39暂不实现。本轮83个程序回归通过，G025三次独立零容差审计通过；全量批测仍执行中。**

## 本轮算法补齐范围

| 方向 | 当前代码行为 |
| --- | --- |
| 并行强初解 | 从同一描述表选择26/21项适用初解，有限线程按剩余路线数分局部时间、按尚未领取路线数租借尝试配额并归还未用部分；共用全局截止点和总尝试上限。只共享本任务不可变NFP几何，调用线程发布完整改善；达到名义材料板数下界可提前成功，无需全跑完。 |
| 孔内联合 | 按真实孔域补入原件并进入有限搜索；宿主容量参与候选排序，最终材料量仍按原件计算。初解已经排齐需求时停止无收益分支。 |
| 多规格候选前沿 | 保留原排序首选，交错数量主序（孔模式保留宿主容量）、实材及实际 AABB 节省序列；先覆盖不同需求向量，再补充同需求的几何变体，生成途中与最终裁剪共用同一选择器。 |
| 认证与重复计算 | NFP 组合仅在规范化前后原件索引及姿态逐位不变时沿用完整认证，发布已认证坐标；同任务内按完整世界姿态复用有界几何及件对计算，不改变名义间距与最终验证。 |
| pair 与尾区 | 同规格两组分别使用独立行列数，支持奇数和三件时的周期候选；右/上不重叠双尾区按不同顺序联合试排。四块绕圈阵列可在开启补隙时补中心空区。 |
| NFP 提案与规模 | 正间距每兼容材料至多512生产规格，仍受含外扩副本/障碍的私有场景总限额约束；固定轮廓查询默认4096。圈/孔采用私有保守提案，原始几何与名义间距最终验真。 |
| 异形板 | 多内矩形独立/联合、小区预填、实材刚体对齐、一次有界主排压缩、正间距外围补排和同型复制；后续优化保留真实域上下文。 |
| 制造工艺 | 实际多边形配对/共边，显式工艺表或调用方选定的分类规则；整板与Cuts一起复制，优化后仍复核配对、共边和切分叶子。 |
| 持续优化 | 单板current可以有界扰动，发布历史best不退；多板复用相同代表板的优化，每张完成的合法改进作全局checkpoint，再按配置回填。 |
| 多布局配比 | 从本任务布局及本任务原输入新构造的布局建立配方库，有界选择不同配方的整数份数，并对准确余量重新排尾板。 |

## 当前代码的共同边界

- 原始输入见 [SheetNesting.h](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/SheetNesting.h:21>)。几何单位为毫米，零件支持单外环与合法孔或解析圆；普通库存 `Stock` 仍为矩形；异形板、标签、锯铣和硬配对已由本轮专用任务类型表达，调用者须保留这些约束上下文。卷料尚未实现。
- 原实例由 `PartID` 与 `Instance` 标识。普通 `Placement.Group` 是可拆的规划标签；在 PlaneManufacturingTask 内由专用验证器赋予容量、连通、间距等工艺规则，普通后处理不自动继承这些规则。
- NFP缓存与放置域已有实现；正间距、圆和带孔件的扩展位于私有提案及真实孔域服务，原始NFP core仍使用无孔多边形和零间距场景。正间距每材料512生产规格与私有场景总轮廓限额共同生效，查询默认4096固定轮廓；这不表示所有孔/圆组合、周期或其他搜索器均已全面支持。保守提案与有限候选仍可能漏解。
- [15 多规格搜索](<D:/penguinchinage0609/iCAX/doc/Plane/策略/15-多规格递归阵列与孔内联合构造.md>) 按需求向量保留候选差异，不把同需求的不同姿态直接去重。任务内件对缓存固定 16384 槽，仅在支持的浮点环境按调用方向、原件索引和完整世界姿态二进制值精确匹配；碰撞仅丢弃旧缓存，`Uncertain` 仍拒绝。相对平移、交换次序或跨任务不能复用这项认证，数量、角度、板边、停止状态及预算继续单独检查。
- 默认 [Quality](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingRanking.cpp:89>) 先比较缺件、板数等，再处理经验证的规整余料和材料集中。固定单板实例的 `U=净材料面积/实际包络面积` 是另一个明确目标，不能据原资料自行替换默认排名。
- [DefaultStrategies](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingStrategies.cpp:264>) 是当前默认注册依据。接口存在、可选工厂存在和默认启用是不同状态。`RunJob` 默认有基础轴向整理，不代表旋转、NFP 重组等可选阶段都默认启用。
- [构造竞赛接口](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/SheetNestingPipeline.h>) 中，串行工厂按剩余候选分配预算；通用并行工厂的 `FairScheduling=false` 保留固定份额和剩余全局时间模式。`plane.initial` 强制开启公平模式，以 `remaining/ceil(unfinished/W)` 分局部时间、以 `ceil(available/unleased)` 预留尝试数并归还未用部分，有限线程无阶段屏障。两模式都守同一截止点与全局尝试上限。`RunPortfolio` 仍为每job单独预算，性能比较采用实际总耗时。
- `IsPureConstruction()` 与 `OwnsRefinementLifecycle()` 分别表达纯构造角色和预算/生命周期所有权；Order、PlaneInitial和通用纯构造组合可同时为真，不能用后者误判是否做了布局优化。26候选共用注册描述表，没有把共用模板或同Kind的不同评分入口当别名删除。矩形专用五项为 `rect-contact`、`single-column`、`single-product`、`rect-block-search`、`four-block`；零需求件不影响资格。
- 并行工厂与原始取消回调在调用线程执行；`OnImprovement`、`StopWhen` 仅对合法完整且质量严格改善的方案串行调用，回调异常单独停用。成功停止与截止保留最好结果，只有原始取消确认才返回整体取消。`plane.initial` 默认的原始名义材料面积下界仅证明板数；达到后无需等26项全跑完，验收全部方法执行须关闭成功停止并给足预算。它不证明余料、紧凑度、板型配比或容差验收下全局最优；非四分之一圈多边形姿态及算术不确定时不凭此提前停止。
- `plane.nfp-all` 将剩余时间的 75% 和按 75% 取整、至少 1 次的尝试份额交给并行初解，再在实际剩余预算内优化完整单/多板；初解未用预算保留。单独 `plane.initial` 与 `plane.nfp-initial` 不执行完整布局持续迭代，后者的有限评分/轴向 trials 仍在本路线内运行。
- `OptimizePlaneLayout`面向完整单板固定集合；完整多板使用`MakePlaneOptimizationStage`，可选跨板回填与整数配比。异形域和工艺结果分别使用`OptimizePlaneDomainLayout`、`OptimizePlaneManufacturingLayout`并保留专用验证器，普通矩形质量改善不能代替额外约束验收。整数配比、扰动和有界搜索均不证明全局最优。

## 代码接入边界

1. 普通构造通过 `RegisterPlaneStrategies` 显式注册，使用 `RunJob` 或工厂执行；`plane.initial` 与注册共用描述表，覆盖26项适用初解；`DefaultStrategies()` 未因此自动替换。
2. 固定补隙和末板缩域作为后处理；持续压紧使用独立控制器，固定原实例并比较实际包络 U。
3. 异形板和工艺任务必须调用对应专用验证器。后续移动、压紧、重排不能只依赖普通 `Validate` 判定这些额外约束。
4. 当前26候选、角色准入与公平租借已通过83个程序回归；新G025通过独立零容差审计，全量批测继续执行。旧三路83个程序和旧02阶段结果单列历史。产品界面尚未接入新增流程，CAM工艺输出不在本次验证范围内。
