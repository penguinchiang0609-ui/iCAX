# 25 异形库存外部障碍化构造

把矩形工作域中不属于板材的部分表示为禁放障碍，在保留真实板边和板孔约束的前提下复用 NFP 放置服务。

类型：独立构造策略。当前实现状态：**已实现受限适配**。核对日期：2026-11-07。

## 代码实现与调用

入口：`RunPlaneDomainTask(UseInnerRectangle=false)`。实现位置：[NestingPlaneDomains.cpp](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingPlaneDomains.cpp:386>)

多边形库存含孔及固定障碍先求真实可用域；域外竖直梯形作为私有 NFP 障碍，输出只包含生产原件。外围 NFP 已支持正间距：生产原件的固定提案轮廓承载零件间距，域外障碍只表达已经扣除板边距的真实禁入区，不再重复加上零件间距。每个落点再以原始轮廓、名义间距和真实可用域验收。

范围与差异：普通 `Stock` 仍给出物理板外接矩形；真实板形、孔和固定缺陷由 `PlaneDomainTask` 保存，任何后续修改仍须调用 `ValidatePlaneDomainLayout`。带孔生产件和解析圆可使用保守 NFP 提案，最终验收保留原始材料；这不表示候选已覆盖所有孔内可嵌套位置。候选与私有场景规模受限，不支持的候选准备不会抹掉已提交的合法板。

同一任务中已验证的整板可按 [44](<D:/penguinchinage0609/iCAX/doc/Plane/策略/44-单板布局批量复用.md>) 批量复用，数量受完整原件用量向量和同板型剩余库存共同限制；每个副本重新分配物理板、原件实例及正组号，尾量继续构造。只有同一 `StockID` 的相同真实域可以沿用原坐标，相同外接宽高不能证明两块异形材料等价。

完整调用示例、注册清单及测试范围见 [实现状态](<D:/penguinchinage0609/iCAX/doc/Plane/策略/实现状态.md>)。

## 原资料的方法与实际分支

旧异形 ARRAY_1 实际使用 CIrregularNestStrategy。SplitAdobe 从外包矩形 Inflate(10) 后生成左右矩形并减去材料外轮廓，得到板外障碍，不是把板切成两张材料。板孔也转成障碍；负 ID 区分障碍身份，复杂凹障碍可能取凸包而保守损失空间。

区域按包络面积排序，INNER 排除最大区域，OUTER 只取最大区域，ALL 先其他再最大。MergeSamePolyID 统一等价障碍标识，不等于合并可用区域。各区域用相同库存试左底、非检查距离靠接及适用时阵列，只提交胜者；ALL 末尾可扫描补漏。

## 面向 iCAX 的独立策略步骤

1. 为 Stock 增加真实外边界、孔、材料坐标和固定禁放区；障碍独立于生产订单，不占零件需求。
2. 构造有界工作矩形，求矩形减真实板材的外部禁放域，再加入板孔及工艺禁放区。
3. 为障碍保存来源和保守近似标识；负 ID 只可作为内部实现，不能与生产实例混用。
4. 将 INNER/OUTER 解释成明确的候选区域集合，保留原域到真实板材的关系。
5. 各区域候选从同一剩余需求快照独立构造，NFP/扫描/阵列各守自己的准入约束。
6. 提交前逐件验证在真实材料域内、避孔和避禁区，不能只检查障碍近似。
7. 保存剩余需求、实际利用空间、保守近似损失及不支持原因。

## 当前适用边界

板材外环、板孔及固定缺陷使用板材局部坐标下的合法多边形。`EdgeMargin` 约束真实材料边界与缺陷，`PartGap` 约束生产原件之间的距离；两者不相互替代。私有域外障碍不消耗订单、不进入材料面积或生产结果。正间距、圆或带孔生产件不再被统一拒绝，但圆外接多边形、填实移动件孔等保守提案可能错过实际可行落点；最终几何仍使用原件。

该入口采用有界候选及现有 NFP 场景、已排件和几何准备限额，没有复刻原库全部区域排序、扫描捡漏及任意近似损失量化。默认整板复用不设置密度门槛；显式门槛按真实可用净面积归一。时间或次数耗尽保留已提交的整板与准确剩余需求，只有实际用户取消才标为取消。

## 保留真实域的布局优化

`OptimizePlaneDomainLayout(task, initial, options, settings)` 对已有合法布局执行有界事件压紧与可选固定集合重构。它按每张物理板保留当前原件集合、原 `Instance`、`StockInstance`、Group 和 GapFiller，逐次使用原件及真实外环、孔、缺陷验收，只接受该板包络与靠边排序改善的完整替换。预算或取消结束时保留最好合法布局。

该入口没有把异形板转成普通矩形后直接调用通用优化器；跨板移动、减板或新件补入也不属于这个固定集合优化接口。调用者必须继续保存 typed task，不能只保留矩形 `Problem`。实现见 [typed 优化入口](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingPlaneDomains.cpp:459>)。

已运行的 [PlaneDomainAdvancedTests.cpp](<D:/penguinchinage0609/iCAX/src/tests/icax-engine/foundation/SheetNesting/PlaneDomainAdvancedTests.cpp>) 覆盖正间距与边距分离、同外接矩形不同真实板域、孔与固定缺陷、库存尾量、整板复制、固定实例优化、统一预算及取消。原有同型域复用回归另见 [PlaneDomainReuseTests.cpp](<D:/penguinchinage0609/iCAX/src/tests/icax-engine/foundation/SheetNesting/PlaneDomainReuseTests.cpp>)。
