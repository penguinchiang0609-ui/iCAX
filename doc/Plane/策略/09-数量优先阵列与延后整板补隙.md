# 09 数量优先阵列与延后整板补隙

优先铺设重复单元，普通凹隙留到阵列阶段结束再补。适用于重复需求，选择规则以当前候选件数为主。

类型：独立构造策略。当前实现状态：**已实现受限适配**。核对日期：2026-11-07。

## 原资料的方法与实际分支

ARRAY_1 先按余矩形与仓库顺序找到首个可行件型，再比较其单件/配对模板：件数更多、占用包络面积更小，容差平局还可能按角度替换。并非所有规格同时比较实材面积。

阵列循环中可填孔；“延后填充”只指普通间隙。一个余矩形失败会删除并继续其他区域。此分支没有调用同文件的 FindBetterArray，不能凭函数存在添加两区前瞻。

## 面向 iCAX 的独立策略步骤

1. 建立带原成员姿态和数量向量的模板，单件方向不受额外组合上限裁掉。
2. 按配置选择余矩形，查首个可行规格，并枚举行列与节距。
3. 按总原件数、真实展开包络面积、合法角度稳定序选择。
4. 提交原件并更新余区；配对两成员可能具有不同重复数，不能一律以 2xy 计数。
5. 孔内填充作为可选动作独立扣数；普通间隙不在每批后抢先消费小件。
6. 全部主阵列停滞后面对真实几何做整板补隙，再恢复完整 Result。
7. 只在公共验评中判定任务完整性与胜负，局部最多件不保证最少板。

## 当前适用边界

`EnableHoleNesting` 默认开启，宿主提交后可在真实孔域放入多边形、带孔原件及解析圆；原始轮廓保持不变。保守候选可能漏掉极窄接触可行点，失败仅保留未排需求。
