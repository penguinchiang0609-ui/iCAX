# 阵列原式评价与容器权重

来源：`doc/Plane/43` 的 10 张补充照片。此前缺失的公式和变量定义已经补齐。

2026-11-08用户明确以利用率为唯一目标后，以下原式作为来源研究和独立计算API保留，当前生产初构不再用K/P、总件数或绝对容差赢家覆盖利用率排序。组合自身按净料／组合包络评紧密度；落到固定板宽后按净料／整板宽占用段评价，侧向及下方空白计入分母。历史 `-source` 注册名不表示当前生产评分仍使用原公式。

当前评价矩形宽高为 `W,H`，实际阵列包络为 `X,Y`，原件件数为 `N`。令 `R=W/(W+H)`，则原式为：

```text
E = N / ((X + (W-X)^(0.5*(1-R))) * (Y + (H-Y)^(0.5*R)))
F(a,b) = a*b + 0.25*(a*a+b*b)
Qi = F(Li,Bi)
Ti = F(tx_i_last,ty_i_last)
Ai = Qi*(Qi+Ti)
P = K*E
```

`K` 按模板容器顺序计算：初值 `DBL_MAX`，跳过无候选节距模板，只读各模板候选列表末项；仅当 `Ai < K-1e-4` 时更新。它不是所有节距的最小乘积，也不是本次选中节距的即时权重。单件容器和同规格成对容器分开计算；角度子容器复用父容器缓存。

`W,H` 来自当前参与评价的余矩形，不必是整张板；`N` 是实际原件数，成对补行补列后不能固定写成 `2*nx*ny`。`E`、`P` 都不是利用率。原式受模型单位影响，也不保证包络略小的候选一定得分更高。

内核服务为 `ComputePlaneArrayAkward`、`EvaluatePlaneArray`，声明见 `SheetNestingPlaneEvaluation.h`。iCAX 对非有限值、零域、越域及溢出明确拒绝，几何可行性由原件校验器另外保证。

历史显式入口 `plane.array-2-source`、`plane.array-5-source` 保留延后、即时补隙调用位置，当前同样按统一利用率排序。来源原式的容器K、候选P和绝对容差更新仍由上述独立API验证，不再决定生产候选胜负。模板生成仍是iCAX当前内核，不声称复刻旧扫描线生成器。

异规格及三四成员组合的 K 在原资料中没有定义；它们继续使用明确的密度/数量构造入口，不外推这个权重。NFP 多阵列最终仍按自己的数量和尺寸规则比较，也不将 P 替换为全局板数或真实材料目标。

手算回归包括 `K=17672`、`E=0.014776548935583802`、`P=261.13117278963693`，并覆盖候选末项、顺序容差、奇数实际件数和计算域边界。
