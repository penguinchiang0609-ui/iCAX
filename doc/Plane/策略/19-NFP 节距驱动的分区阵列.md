# 19 NFP 节距驱动的分区阵列

先由原轮廓的接触关系计算重复单元和节距，再把单元铺入剩余矩形。它保留阵列速度，同时允许相邻原件的包络相交而实材不相交。

类型：独立构造策略。当前实现状态：**已实现受限适配**。核对日期：2026-11-08。

## 原资料的方法与实际分支

CNfpArrayStrategy 使用 NFP 单件/配对模板及临界节距，不是直接以原件 AABB 宽高重复。角度间寻找 180°伙伴；矩形或近矩形会关闭部分配对，单角列表在特定分支可同角配对。按方向选择最大余矩形，先成功的规格进入件数和移除框面积比较，并尝试右上补阵列、减行减列。

展开后扣数、移除 rcRemove、可选填孔。末端可回收最多六件，换方向或调用 NFP Fill。只剩一个规格且非检查距离时，恢复数量后再试 NfpMultiArray；DFS 还受宏与配置限制。RenestFinalParts 的返回表达式是 PartResults.empty()，不能按名字理解为 true 就成功。

## 面向 iCAX 的独立策略步骤

1. 规范化原件和合法角度，以 NfpCache 产生单件重复及双件相邻接触候选。
2. 模板保存成员原身份、相对姿态、X/Y 节距及计数规则；检查相邻周期和对角周期，不能仅验证单元内部。
3. 在当前余矩形枚举容量与需求允许的行列，保留原文首可行规格模式作为独立配置。
4. 按展开后原件净面积／整板宽占用段评价落位利用率，组合自身另按净料／其包络比较紧密度，主阵列、右上补阵列和减行列候选分别保留来源；件数用于需求扣量及容量统计，不作为质量奖励。
5. 提交原件并唯一扣数，规划移除框与实际实材分开；孔内填充受独立几何支持范围约束。
6. 从同一末端快照执行最多 K 件回收重排或主尾联合替代，只提交统一验评胜者。
7. 输出模板生成失败、尺寸不合、需求不足、有限搜索耗尽及取消等不同原因。

## 当前适用边界

正间距每兼容材料至多 512 规格，默认最多 4096 个已排原件参与查询；周期提案检查每轴至多 8，展开后仍检查全部实际成员。圆／带孔件可用保守单件候选及孔域套排，复杂组合和周期模板仍保留各自几何准入。尾部回收保留全部旧实例后，只有新增材料才提交。
