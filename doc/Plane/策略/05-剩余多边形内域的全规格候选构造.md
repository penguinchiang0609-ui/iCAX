# 05 剩余多边形内域的全规格候选构造

对每块剩余多边形、每种原件和每个允许方向生成可行落点，再跨全部组合择优。它与“首个可放规格就提交”是不同的搜索策略。

类型：独立构造策略。当前实现状态：**已实现受限适配**。核对日期：2026-11-07。

## 代码实现与调用

入口：`plane.nfp-all`。实现位置：[NestingPlaneStrategies.cpp](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingPlaneStrategies.cpp:988>)

对所有有余量规格、合法角度和 NFP 候选择优，支持正间距；共享预算内比较多种评分与有限束搜索，完整初解之后继续轴向压紧和跨板回填。该入口拥有完整改进流程。

范围与差异：普通矩形库存上的有限 NFP 候选；通用异形域使用 PlaneDomainTask。正间距通过固定件私有避让轮廓生成候选，再严格复核原件间距和板边；支持每种兼容材料最多 512 个规格。圆、带孔件可用保守私有外轮廓提案，真实孔域由独立孔套排补充；不代表原始 NFP 核心已支持任意带孔配置空间。

完整调用示例、注册清单及测试范围见 [实现状态](<D:/penguinchinage0609/iCAX/doc/Plane/策略/实现状态.md>)。

## 原资料的方法与实际分支

旧 NFP_BOTTOM_LEFT 是 CBottomLeftNFPStrategy，不等于共享 NFP 的 ST_BOTTOMLEFT 模式。它直接向剩余物理区域求内接 NFP；Facade 函数指针加载被注释，可能只由顶点邻边方向匹配的单点回退产生位置。

每个区域/规格/角度只评估按 Y 排序的前十点，最终按外扩 1.0 轮廓落在剩余区外的面积 nCloseArea 降序。虽然计算合并包络面积，排序并未使用；不能照类名解释成全局左底或最小包络。

## 面向 iCAX 的独立策略步骤

1. 从原板减去固定真实材料形成剩余域，保留多个连通区域及孔边界。
2. 对每个原规格和合法角度生成该件专属的内域，区分物理剩余区与参考点域。
3. 汇总各区域的有限接触候选，使用明确的候选配额；不因第一种可放就结束规格扫描。
4. 内域不可用时可尝试原顶点对齐，但须标记有限回退，不能以其失败证明无位置。
5. 以指定接触分或低左分排序，显式添加稳定平局项；最终仍按真实原件校验。
6. 提交一件、扣数量、更新真实剩余域，再开始下一轮。
7. 独立记录全规格模式相对首可行模式的候选数和耗时，按同预算比较。

## 当前适用边界

普通矩形库存上的有限 NFP 候选已支持正间距；私有圆／孔提案与真实材料严格验真分离。默认查询上限为 4096 个已排原件，可显式收紧；复杂轮廓、保守提案和候选上限仍可能漏掉可行点，不证明不可行。
