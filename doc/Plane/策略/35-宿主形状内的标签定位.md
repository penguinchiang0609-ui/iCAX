# 35 宿主形状内的标签定位

为每个宿主零件或板材寻找对应标签的合法位置，以靠近指定点和可贴放性为目标。它不参与生产件省板排名。

类型：独立定位策略。当前实现状态：**已实现受限适配**。核对日期：2026-11-07。

## 代码实现与调用

入口：`LocatePlaneLabel`。实现位置：[NestingPlaneDomains.cpp](<D:/penguinchinage0609/iCAX/src/iCAX-Engine/foundation/SheetNesting/NestingPlaneDomains.cpp:560>)

专用宿主/标签输入，以目标中心为起点逐圈扩散候选，检查真实宿主材料、孔、障碍和边距；圆标签采用解析包含检查。

范围与差异：单对调用，由调用方逐对处理；只返回有界首次可行解，不是全局最近位置。宿主和障碍当前要求多边形。

完整调用示例、注册清单及测试范围见 [实现状态](<D:/penguinchinage0609/iCAX/doc/Plane/策略/实现状态.md>)。

宿主与标签一一绑定；每个姿态必须在真实宿主材料域内。配对失败独立返回，不用普通省板排名代替贴标评价。

## 原资料的方法与实际分支

原文 CWoodLabelCalStrategy 一标签对应一宿主，中心/边中点使用有限窗口扩散，其余方位调用左底。初始窗口用第一个可容纳角度的标签框，按整数扫描单位外扩 10，再居中或对齐指定点；最多 100 轮，首次可行即接受。

64 配对一批及缓存清理是旧内存控制。上层无效配对也可能返回 NEST_SUCCESS，必须检查实际落点。首次可行不是离中心欧氏距离全局最小；单个矩形标签 U 始终可能为 100%，不能用 U 区分位置。

## 面向 iCAX 的独立策略步骤

1. 建立独立 LabelRequest：宿主材料域、孔/禁入区、标签形状、角度、目标点、边距及配对 ID。
2. 对每配对单独运行，失败保留原因；去重只复用形状计算，不混淆宿主实例。
3. 将目标方位转换到统一局部坐标，初始窗口和扩散步长明确采用物理单位。
4. 在窗口内生成合法位置，精确验证标签全部在宿主允许域内且避孔。
5. 快速模式取首次可行；精修模式再比较目标距离、方向与贴标可达性，二者分开声明。
6. 返回每个配对的成功状态、姿态和偏差，不以批处理成功代替全部标签成功。
