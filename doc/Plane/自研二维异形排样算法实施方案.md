# 自研二维异形排样算法实施方案

更新日期：2026-10-27。状态：规则/组合/补隙与独立策略 job 的原生模块已实现，三种基础形状均增加不同规格混排；通用异形搜索与生产性能仍为后续工作。当前接口和验收范围见 [SheetNesting](../../src/iCAX-Engine/foundation/SheetNesting/README.md)。

## 1. 采用的总体路线

实现独立 C++ 二维排样引擎，首先完成：**规则识别 → 规则图形密排 → 少量零件组合成类简单图形 → 包络规划 → 真实材料余隙补小件 → 统一验证与选优**。

每种策略通过独立接口注册。每个 job 拥有独立问题快照、策略实例、库存、布局、预算和停止状态；调度器运行各 job、保留全部结果并统一比较，不共享可变布局或数量账。当前默认注册35个策略，包含 MaxRects、异规格行/列背包、规则组合、混半径圆、平行四边形接触/同行组合、跨形状接触、角口袋递归组合、方阵孔混圆、圆外接方形行候选、矩形孔局部填充、优先匹配空位的两个组合分支、小库存优先闭合分支、保留规整直条余料的重排、小范围矩形合并/前瞻、混合基础单元及新增的组合单元批量构造。原34项顺序保持；不同参数分支也有独立ID，注册数量不代表独立几何引擎数量。

基础铺排能力优先收敛到矩形、平行四边形与圆。三角形、梯形保留形状识别与专门的组合生成规则，先不各自建立整套排样策略：允许相应旋转时，全等三角形或梯形可以两两组成平行四边形，直角三角形还可组成矩形。两个到四个原件可以组成重复单元，并保存每个原件的局部姿态与数量。等圆比较方阵/错列与方向，组合比较边接触与半转配对。数量余单、角度限制及低效配对返回单件排放/补隙路径，不能强制全部配对。有限板材、间距及混合数量仍须实际比较候选，规则铺排公式不自动证明整个混排任务最优。

形状分类、组合产生器与完整排样策略分开。每个 job 独立运行仍是调度原则；组合优先、单件优先及不同铺排参数可以形成不同 job，但不按输入形状重复建设库存、多板和补隙框架。

矩形、平行四边形与圆均按多规格需求建模：矩形混合不同长宽和允许转向；平行四边形通过边接触与基底延续混合不同底边、高度和剪切量；圆通过不同半径之间的解析相切位置混排，小圆可使用大圆之间的空间。同规格重复模板是其中的快速候选，不能替代异规格混排。基础混排不依赖最后的可选补隙。

组合上限只约束额外组合候选，基础规格和各自允许方向不能因排在输入数组后面被裁掉。所有专用策略仍为有限候选启发式，不宣称多规格有限板材混排已达到数学最优。

扫描线、NFP 左底贪心和后续顺序/实数角度搜索，在规则排样闭环之后作为新增策略接入。几何合法性服务与调度/比较器由各策略复用。

当前版本以矩形板材、多边形零件与解析圆为范围，覆盖凹轮廓、孔洞、数量、间距、板边距、有限库存和固定允许角集合。原始 CAD 曲线适配、连续角度搜索、异形板与共边仍待接入。当前结果为容差内验证的启发式可行解，不声明全局最优。

## 2. 输入、输出与目标

输入将几何与需求分开：

- `ShapeDefinition`：精确 `GeometryData::Region2`、外环/孔洞拓扑、几何指纹。
- `PartDemand`：形状引用、数量、材质/厚度兼容组、允许角度区间或固定角集合、镜像许可。
- `SheetStock`：可用区域、板材数量、材质/厚度、成本与板边距。
- `FixedPlacement`：确实要求固定的已有实例及其板号、位置和姿态。
- `SolveOptions`：时间预算、随机种子、线程数、曲线误差与几何容差。

同一几何的不同订单实例可以共享几何缓存；只有几何与约束完全等价的实例才能视为可交换，不能把不同订单身份或锁定状态丢失。

输出每件的 `(instanceId, sheetId, x, y, angle, mirrored)`，以及未排需求、已用库存、材料成本、余料指标、耗时和验证结果。单独保存构造顺序；它既不是几何身份，也不是加工切割顺序。

目标按层次比较：先完成必需需求并通过实际材料验证，再减少用板数，板数相同时最大化最终板可保留的大块规整余料。成本、占用包络和低左位置保留为辅助报告或显式对照策略，不能抵消多用一张板。库存或几何条件不足时返回明确的未完成状态；漏排件的高利用率不算成功。

当前可执行的规整余料基准，是剩余真实材料中一个完整、满足间距和板边要求的轴向矩形。返回明确矩形及面积下界、乐观上界；不把碎缝面积相加，不以空白区域的 AABB/OBB 代替可保留材料。测量使用保守网格和真实几何扩张，默认 64，可加密至 256；返回下界不等同于求得严格最大矩形。若两方案区间重叠，应保留各档已验证的更大矩形再加密，不能将测量误差写成确定省料收益。

同材料兼容组的板可调整逻辑加工次序：从实际已用板中选一张具有最大规整余料的板作为最终板，不依赖数组末项；不同材料组分别选一张汇总。空闲未用板不获得余料分数。兼容组、加工次序和库存身份保持明确，不合并不同材料需求。

最小可回库尺寸与后续零件规格由实际业务给定，不先给长条设置任意惩罚。面积相同的 50×200 与 100×100 余料能接不同订单；当前输出保留长宽。旋转矩形等更广的规则余料先保留独立研究证据，公共评分当前仍限轴向矩形。

## 3. 几何内核：先确定哪里可以放

### 3.1 原始曲线与搜索多边形

复用已有 `Region2/Loop2/Curve2` 保存 CAD 权威几何。搜索层另建材料多边形，记录曲线逼近、坐标量化与变换的误差上界。外包材料时外边界外扩、孔洞收缩，使可行结果保持保守。

首批曲线适配实现直线和圆弧的误差界；样条只有在适配器能给出可靠误差界时才接入。自交、开口、不明确的孔洞归属或不支持的几何类型返回诊断，不自动把坏轮廓变成实体。

间距与板边距分别计算。若要求两件实际材料之间至少相距 `g`，配置空间只计入这一次 `g`；不能在两件各增加 `g` 后再无意要求 `2g`。

### 3.2 后续 NFP 策略：固定实际角度下的禁止平移域

固定件材料域为 `A`，待放件在实际角度下的材料域为 `Bθ`，参考点平移为 `t`。禁止平移域由 `A ⊕ (−Bθ)` 及所需间距形成；接触边界的允许与禁止按统一距离规则判定。

后续该策略采用可解释、可验证的构造路线：

1. 将含孔材料域作约束剖分，获得覆盖材料而不填满孔洞的三角形。
2. 在合法条件下合并相邻三角形，减少凸块数。
3. 对两个零件的凸块对计算 Minkowski 和。
4. 将结果并成禁止平移域，或在查询扫描线上直接合并禁入区间。

这是分解后两两求和再取并集的标准几何构造；含孔分解需要专门实现或经过验证的组件，不能把普通无孔剖分直接套上去。可参考 [CGAL 2D Minkowski Sums 的分解与含孔处理说明](https://doc.cgal.org/latest/Minkowski_sum_2/index.html)。此处引用方法，尚未决定引入 CGAL。

项目已有 Clipper2 可用于并集、差集和偏置。但当前单个 `Path` 的 Minkowski 辅助函数不是完整的“带孔材料域排样 NFP”；需要补齐剖分、填充语义、间距、退化接触和验证。

### 3.3 后续板内可行域与扫描线

矩形板上，固定姿态零件的坐标极值可直接给出参考点允许区间；板内孔洞或缺陷另作为障碍扣除。异形板阶段再实现通用 IFP/配置空间包含查询。

扫描线与 NFP 使用同一材料域模型。扫描线与各凸配置障碍相交后，合并禁入区间，即可查询该线上最靠左、最靠下或某方向最近的合法位置。这可降低角度试探与压紧时反复构造整个并集的成本。

搜索有限扫描线是候选生成策略。没在这些线上找到位置只能表示本轮未找到，不能证明整个板面不可放。

恰好放入、零间距接触等情况的可行域可能仅为线或点。除面域外还要保留接触候选，不能因为布尔运算返回零面积就判定不可放。

## 4. 当前规则与组合布局

第一版已实现大件锚定、规则接触组合、组合需求校验和真实几何补隙。组合优先根据成员中最大原件的最小方向包络面积选大件，再比较组合密度与矩形放置评分；避免小件组合先占据大件唯一可用空间。补隙重新读取真实内外环，不把组合包络当成全部占用材料。封闭孔内小件安排在补隙阶段。

用面积、长边、凹度、重复数量等形成多组初始顺序，并保留随机扰动顺序。每次放件时共同枚举“板材、角度、接触位置”，用目标比较候选。

矩形阶段保留 MaxRects 三种评分作为独立 job。后续一般异形放置再加入左底、最小新增占用长度和更多候选分支。孔中可用区域和狭窄凹槽参与补隙候选，逐件按真实材料验证。

构造后可沿多个方向压紧，再试角度微调。每次移动先临时移除该件自身障碍，更新后必须满足几何约束；不能让错误缓存将自身当碰撞对象。

## 5. 后续联合优化：顺序、角度、位置和板材一起改变

该阶段的外层采用多起点加拆除重排的迭代搜索。当前布局、最好布局和待修复需求分别保存。每次从下列邻域选择一种操作：

- 交换两个实例的构造先后，或将一件移到另一位置重新构造。
- 移除一个紧密相邻的小组，用不同顺序和角度重新插入。
- 移除末板上的零件，尝试塞回前板，以减少一张板。
- 移除造成长条空洞或不良余料的一组零件，重建局部布局。
- 改变某件旋转角后，连同受影响邻件一起重新放置和压紧。

先实现少量可复现邻域和明确评分，再根据实测收益增加自适应权重。搜索可接受少量目标较差但几何合法的当前解以跳出局部最优，同时始终保留最好可行解。必需需求未完成的状态与完整可行解分开记录，不能混成一个利用率分数。

## 6. 后续任意角度：特征候选与实数局部细化

允许角度由业务输入定义，内部角度用实数表示。初始候选包含允许域端点、主要边方向、与邻件或板边互补的方向，以及覆盖允许域的粗样本。

对较好角度启动多起点无导数局部细化：试探 `θ±δ`，每次在该实际角度重新查询位置，再逐步减小 `δ`。同时保留跨角度区域的探索，避免全部预算只花在一个初始方向附近。

关键是角度改变后重新求位置，并在组重排时改变顺序；不能先定死顺序和位置再孤立旋转一件。第一版这是有限预算下的实数角度启发式，不保证连续域全局最优。

更强的第二阶段可对小组凸块引入分离线约束，做连续位置/角度局部优化；该路线已有[自由旋转排样与分离线的研究](https://arxiv.org/abs/1707.07177)。它需要初值、凹件分解和独立验证，先作为局部改进器评估，不作为首版的整个大规模求解器。

## 7. 多板优化与缓存

当前规则策略按有限库存逐板构造，末板回填、库存替换和拆除重排在联合搜索阶段增加。只有单板布局生成质量和速度经过验证后，再增加候选排版模式池，用整数优化选择各模式次数；模式池、库存和需求都必须同步约束。

NFP/禁入区缓存按需建立，键至少包括几何指纹、相对姿态、间距、误差设置与算法版本。不同实例只共享相同几何关系，绝对平移通过变换处理。缓存设容量上限和命中统计，不预计算所有类型、所有角度对。

实际角度不能静默取整后复用邻近角度的几何结果。若使用角度桶，只能用有明确转动误差界的保守包络进行筛选，接受放置前再在实际角度复核。

并行单位先选独立多起点任务，各自保存随机状态并只发布已完成候选。固定种子、线程数与工作预算用于回归；受真实墙钟预算影响的生产模式单独报告可复现性边界。

## 8. 独立验证与验收

验证器从原始输入和输出变换重新建立检查，不信任放置器的缓存标记。核对需求数量、实例唯一性、库存、兼容组、板内包含、实际间距、孔洞、允许角度、镜像及固定件。

接近容差的结果使用更严格几何路径或误差界复核。预览图只用于检查布局理解，不能代替细小重叠与间距检查。

必须提供以下拆分对照，保持相同输入和计算预算：

| 组别 | 放置顺序 | 角度搜索 | 用途 |
| --- | --- | --- | --- |
| A | 固定 | 固定允许角 | 左底/NFP 基线 |
| B | 搜索 | 同 A | 测顺序搜索收益 |
| C | 同 A | 实数角度搜索 | 测角度搜索收益 |
| D | 搜索 | 实数角度搜索 | 测联合搜索收益 |

算例包含凹件互嵌、孔中套料、斜边互补、不同数量、有限库存、恰好放入及近间距。专门设计需要换序、需要非直角及需要两者联合才改善的算例。真实生产零件用于判断实际价值，小型已知最优例用于识别明显错误。

记录首个完整合法解时间、最好解随时间曲线、未排件、材料成本、板数、余料、峰值内存和几何合法率。供应商 DLL 仅作相同输入下的外部对照；未运行或缺依赖时明确标记未测。

## 9. 建议的代码组织与实施次序

已新增 `src/iCAX-Engine/foundation/SheetNesting/`，当前接收独立中性多边形/圆输入并单独构建 Clipper2，不引入夹具 VTK 或产品 UI。GeometryData 精确曲线适配属于后续宿主接入。

当前已经落地的框架职责、接口和依赖以[二维排样模块架构](二维排样模块架构.md)为准：调度、注册、验评、比较分别管理；可选输入排序、构造和后处理使用薄流水线组合，每 job 独立状态、共享阶段预算、统一原件校验和评分。下表为后续几何与搜索能力的目标职责，不表示这些算法接口均已实现。

| 模块 | 职责 |
| --- | --- |
| `NestingProblem` | 几何定义、订单、库存、角度与间距契约 |
| `NestingGeometry` | 有界近似、剖分、凸和、包含、禁入区间与接触查询 |
| `NestingPlacement` | 多角度候选、左底/占用长度策略、插入与压紧 |
| `NestingSearch` | 多起点、换序、拆除重排与角度细化 |
| `NestingSolver` | 多板状态、预算、取消、最好解回调和统计 |
| `NestingValidation` | 直接几何复核和明确违规报告 |

上表是目标职责；当前源文件另含 `NestingContactRules.cpp`、`NestingRectangleSearch.cpp`、`NestingParallelogramSearch.cpp`、`NestingComplementChains.cpp`、`NestingRemnants.cpp` 和 `NestingRemnantSearch.cpp`，分别负责跨形状规则接触、矩形行模式、平行四边形行模式、角口袋组合、规整余料测量和留条重排。剖分、凸和、NFP 禁入区间与连续搜索尚未实现。余料测量所用网格不是扫描线放件器。

实施顺序：

1. **输入与验证器**：统一中性文件，能独立判定给定布局是否合法，并输出排版图。
2. **规则排样闭环**：三种基础形状的不同规格混排与规则组合，孔洞/余隙补小件；独立策略 job、有限库存、取消、实际材料验证和规整余料选优，基础版本已实现。
3. **规则策略测评与增强**：扩大真实数据，改善规则单元、组合库及多板构造；持续保留每个 job 结果比较。
4. **扫描线/NFP 左底策略**：实现固定姿态可行位置，作为新的独立策略，与规则策略同预算比较。
5. **顺序与实数角联合搜索**：多起点、换序、拆除重排、角度细化，完成 A/B/C/D 对照，按实测瓶颈增加缓存与并行。

每一步都以可运行算法与有证据的检查结果交付；前几个几何里程碑是内部基础，不提前宣称已完成工业排样。第一版质量由完整需求、几何合法性和同预算对照决定，暂不承诺未经测量的省料比例或计算速度。

## 10. 从余料角度评价一次布局和一个算法

评价一个布局，使用分层比较，不把板数和余料放进任意加权总分：

1. 原始需求、实例、材质、实际材料、间距和板界均合法；完整需求优先。
2. 比较实际已用板数，任何余料收益都不能抵消多开一张板。
3. 同等完成度和板数时，比较最终板中已验证的规整余料矩形面积。
4. 面积接近时保留长宽、方向及估计区间，再考虑低左位置等辅助指标。最小回库尺寸、内孔料是否回收及未来订单适配应由实际业务明确，不以任意长宽比惩罚代替。

规整余料的真实几何比包围盒或总空白面积更直接。固定反例中，两布局使用相同一张100×100板、相同零件，AABB和OBB面积均10000；集中排放留下可验证8075的矩形，分散排放的规整矩形上界仅2850。两者的总用料和总空白面积相同。见[几何对照图](../../output/research/plane-nesting/20261027/visual-review/evaluation-counterexample-cn.png)。

评价一个算法，还要在同输入下记录完整率、板数、余料区间和时间。必须区分：生成器自带见证的算例、随机生成时没有见证的算例、同一输入重复执行、变换/尺度变体及独立job次数。任何已验证的完整结果本身都是新的可行见证；因此随机14749已有旧基线完整解，当前版本漏一件是明确回退，不能用“随机未证”掩盖。两边都未完成的随机例则不能认定无解。

同一个结果池按不同指标重新选优，用来测评价函数的影响；固定各策略结果再做移除策略的边际分析，用来测策略贡献；真正重新执行时再记录墙钟负载影响。这三者不混在一起。更多job消耗更多计算，并行负载也可能改变短时间预算下的候选，不能将完成率提高直接表述成纯速度提升。

构造、最终几何验证和余料评估分别计时。5120件圆形、共3072件的框及插片的独立规模研究中，构造和验证成为主要成本；小算例则可能评估比放置更慢。构造时间预算不等同于整次调用延迟。固定网格下界为零也不代表确实无规整余料：已修复大圆阵列的0下界漏测，但仍保留上界与有限搜索语义。

研究基线与各轮候选的源码、头文件、库、执行文件和哈希分别冻结，公共评估器只重测原始输入与原始姿态，不改变排法。数值以17位保存，避免小数板边的一ULP差异在回放中消失。外部核验采用独立GEOS多边形材料运算及解析圆距离；返回安全矩形、面积聚合与完整需求均从原始几何重算。返回下界的安全检查与乐观上界的独立确认分开统计，不把两者混称完整最优证明。

本轮研究入口为[运行清单](../../output/research/plane-nesting/20261027/fake-study/study.json)、[冻结基线与06的同输入比较](../../output/research/plane-nesting/20261027/fake-study/candidate-06-prefix-wall-comparison.json)、[当前结果与保留反例](../../output/research/plane-nesting/20261027/fake-study/audit/current06-comparisons/index.html)。当前为独立原生算法模块；未接入平面产品界面、CAD曲线适配或真实生产验证。

### 可选跨板矩形回填

后续没有把无稳定收益的输入预排序或高成本压紧默认开启。单纯将库存收紧一张再调用已有构造器的先导中，5次省板都可由同一重排器在原库存及同调用预算下取得；没有独立限板收益，也没有超过原完整策略池，因此该路径保留为负结果。

改为固定其他板的环境，直接把一张源板的矩形原件插入目标空位，全部放下才删除源板。这产生了原布局中不存在的新放置状态。222个捕获的完整初解保持完整，10例各减少一张板；235个含控制的工厂回放、470个原几何结果及1416个正面积余料证书独立核验未发现错误。新候选仍未证明胜过完整策略池，不将10/222当作一般省料率。

`MakeRectangleRefillStage()`现作为可选后处理接入同一个流水线，不新增默认策略。它保留原零件和板材实例号，固定目标位置；迁入单件脱离旧规划组，构造来源统计单列。整个源板是一个提交事务，失败或取消不会留下缺件或半搬状态。阶段内部只做必要原件校验，少一板已严格改善公共前缀，余料由最终统一测量。

当前为保守矩形源板插入：非矩形目标只用外包盒维护空位，可能漏掉实际可放的位置；源矩形、输入顶点和自由区等有明确操作上限。没有实现通用异形回填、扫描线或NFP，也不宣称在固定环境中没插入就全局不可排。完整证据和范围在[最终组件报告](../../output/research/plane-nesting/20261027/exploration-02/pipeline-components/sheet-reduction/direct-refill/integration/research-report.txt)。
