# 管型模板库重建记录

依据：[市场调研](管材型材市场管型调研_2026-09-12.md)。逐项覆盖关系见同名 JSON 清单。

## 当前落地范围

活动库重建为 49 个独立程式模板，对应调研中的 52 个条目的明确构造变体。
这不是 104 项全部完成，也不是 49 套国标标准尺寸表。所有默认尺寸均明确标注为可编辑演示值。
每个模板保留调研 ID、制造路线、截面拓扑和尺寸来源；这些信息随生成截面传递。

- 圆、圆角/尖角方矩管、真椭圆、跑道形分别建模。
- 方矩管支持独立内孔尺寸、偏心以及内外四角半径；内孔尺寸为 0 时按名义壁厚计算，空圆角列表采用说明中的基准值。
- 三角、多边形、梯形、平行四边形及内外圆/六角组合使用独立模板。
- 热轧角钢、冷弯角钢、精密尖角角钢、板焊角钢不混用构造。
- 热轧斜腿/平行翼缘槽钢、冷弯 U/C、内外卷边 C、板焊槽钢独立。
- 热轧斜翼缘 I、平行翼缘 I、热轧 H、焊接 H、剖分 T、焊接 T 独立。
- 冷弯 Z、卷边 Z、冷弯帽型、开缝圆管、矩形双腔以及实心棒材分别建模。

## 几何约定

热轧根部、肢端和外跟半径是实际几何输入，不是薄板偏置的替代品。斜翼缘厚度在端部定义，斜度为角度。
冷弯模板参数明确使用理论中心线交点尺寸；实际外包络由板厚与弯曲半径计算，内外半径相差板厚。
焊接模板使用独立板厚和名义焊脚直线包络，不生成虚假的热轧根圆角；实际焊趾/熔深仍需实测或工艺数据。
开口型材的材料边界本身必须闭合，但不把开口虚构为封闭内孔。

每包为 `profile.json + profile.py + geometry.py`。公共几何只负责圆角多边形、板带、偏置等构造，不按管型 ID 分支。
`geometry.py` 随包携带，因此包离开系统目录仍可独立执行。
逆向识别暂缓；未把上一轮试接的 `recognize.py` 当成新库已完成的能力。

## 尚未完成

- 球扁钢、双球头、热轧帽型、船用 T、钢轨等，需要补充标准截面尺寸表和细部圆角依据。
- 平椭圆、腰型、马蹄圆、P 型具体变体、8 字型、行业挤压型材和市场俗称，需要绑定明确截面图或供应商图纸。
- 其余复杂开口、多腔、通用异型等条目尚未逐项落地。清单中的 `awaiting-section-definition` 表示当前尚无选定并实现的完整截面定义，不表示这些类型不存在或必须由用户提供资料。
- 调研 99–104 为弯曲、变径、变截面、扭转、局部成形及组合件；不能伪装成固定截面直线拉伸模板。
- 标准规格表、焊缝工艺区与机床可加工性尚未验收，不因截面建模成功而宣称已支持实切。

## 切换与恢复

原活动源码库及 Debug 运行库已完整移动到：
`artifacts/profile-library-backups/20260912-before-market-rebuild/source-profile` 和 `debug-profile`。
未删除用户“我的”管型、工程快照或其他用户数据。
旧 ID 未设运行时猜测兼容。产品目录中的旧跑道形引用改为 `racetrack`，失效的选择项按新库调整。
历史工程如仍引用被移除的系统 ID，需另行做明确的数据迁移；本轮未批量改写用户工程。
三款钢楼梯、直梯护栏及不锈钢护栏的旧选择项同步调整，移除已不存在的通用多边形选择项及其显示条件。
产品中的尺寸组合仍须满足所选截面的几何要求；不会为了通过生成而静默缩小热轧圆角。现有产品页面也尚未动态展示新管型的全部专属参数，这与管型库本身可编辑完整参数是不同的入口。

## 验证

原生回归逐个拉伸全部模板，检查实体有效、实体数量为 1、体积为正；覆盖默认值及 1.31 倍尺寸，共 98 组。
这验证了这些构造与参数组合，不代表所有任意参数组合或标准规格均已验证。
Python 回归 39 项通过（库与产品引用一致性 7 项、截面工艺差异 4 项、既有管型运行时 28 项）。
防盗窗默认实体生成回归通过。全套模块化护栏两两布尔交集检查运行约十分钟后主动中止，未得到完整结果，不计入通过项。
三款多踏步钢楼梯制造模型回归通过，包括直跑楼梯使用新 I 型钢、槽钢、椭圆管和不等厚角钢的组合。
