# 楼梯扶手并入扶手护栏

四款目录归为“护栏 / 扶手护栏”。独立 straight_stair_railing 产品模板、运行目录副本和专用旧Python测试已移除，不再维护兼容入口，新增 UnifiedHandrailTests 覆盖替代能力。

- startExtension / finishExtension：两端独立设置。连续顺坡模式沿扶手真实轴向量取；水平模式可直接设置。
- handrailMode：分跨接柱或跨柱连续。连续模式每条直边合并成一根实际管件，接收柱顶截到扶手中心平面以下，再减去扶手外包络形成贴合。保留管截面、转角分界和围墙穿孔刀具，不合并跨坡度变化的弯管。阶梯模式保留分跨构造，隐藏的连续模式草稿不参与计算。
- 杆件款新增 barOrientation 与 horizontalRailCount，横向填充按每跨数量分布。竖杆/围墙参数随方向隐藏，横向计算忽略保留的围墙草稿；返回参数仍保持与宿主输入一致。

验证：四款水平/顺坡、直式/U型、独立两端延伸与真实管长、立柱裁切引用；横向填充数量与无竖杆；41个产品默认显示/制造输出参数一致。原生预览通过横杆与菱形U型跨柱连续扶手、两端不同延伸组合。

此前宽泛目录测试仍含旧32款、四个防盗窗独立入口等历史预期，不能作为当前目录通过证明；当前目录以 GuardrailMarketLibraryTest / WindowCatalogueTest 验证。
