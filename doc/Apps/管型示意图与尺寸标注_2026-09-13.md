# 管型示意图与尺寸标注

## 本次修改

目录加载原先采用 preview=False，没有向左侧提供默认截面，所有管型因而回退为矩形占位图。现在目录返回模板默认参数生成的 previewProfile；单个模板失败仍独立返回错误，不拖垮其他目录项。前端缺少截面时显示“暂无截面”，不再以矩形冒充。

24 个系统包新增 parameterDiagram 元数据，锚点在模板 JSON 内声明，公共运行时仅计算安全坐标表达式，不按管型 ID 猜测尺寸位置。图形仍取与三维拉伸相同的 contours。版本更新至 2026.9.13.5。

主尺寸直接显示名称、数值、尺寸线和引出线；圆角引线显示参数编号、名称和数值，并保持点击定位参数功能。冷弯中心线尺寸、正多边形内切圆构造尺寸、U 肋理论底宽等与外形包络尺寸明确区分。

具体包括：常用管材宽高/直径及适用的壁厚；型钢翼宽、高度和适用的腹板/翼缘厚；不等翼上下翼宽厚；U 肋开口、理论底宽、高度、板厚、内弯半径；P 型管身与安装翼；球扁钢总高、腹板厚、伸出、端角；帽型冠宽和外伸翼；多腔隔板厚等。

这次补的是各入口主尺寸及明确可定位的局部尺寸，不宣称所有制造路线的每个高级参数都有位置标注。来源、JSON 边界、制造路线等非几何位置参数仍在参数列表说明。实际边界替换名义模型时不沿用名义标注；镜像同步转换声明锚点。内孔单独指定时，不把默认壁厚虚标为实际边界间距。
