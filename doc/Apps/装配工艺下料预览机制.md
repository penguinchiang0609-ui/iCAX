# 装配工艺下料预览

装配资源库先显示成品。切换工艺时，场景把当前成品交给模板检查适用性；适用时继续使用当前成品，否则调用模板的示例成品方法。只有切换到“下料件”时才请求制造计划和下料实体。

## 模板与宿主的职责

- 场景拥有成品、当前工艺选择和草稿值。
- 装配模板声明适用范围、示例成品、工艺参数、显示条件及加工规则。前端使用公共参数条件模块，不按工艺名称或 ID 编写加工分支。
- `ResolveAssemblyTemplatePreview` 的 `manufacturingOnly: true` 保留原制造计划和参数回传，只跳过成形示意网格。旧调用的默认行为保持兼容。
- 目录公开的 `generationDigest` 包含装配脚本、共享运行时、成品声明及引用的模具包内容，供预览缓存判断生成规则是否变化。它不进入模板存储参数或产品绑定参数。

## 最终实体接口

`TubeDesigner.PreviewAssemblyManufacturingPart` 接收计划中的标准管型、长度、侧面特征、端部规则和 `previewResourceKey`。它复用原有刀具准备与布尔加工逻辑，并要求结果为有效的单一实体。

接口只发布最终下料 BRep、显示网格和材料引用，不生成底材显示网格、刀具显示网格、刀具集合网格或冻结刀具资源。请求中的旧诊断标记不能放宽实体有效性要求。模具未声明需要截面分析时，跳过该分析；无法可靠读取模具声明时保留分析。

返回值包括 `geometry`、`material`、`bounds`、`length`、`resultValid`、`previewComputed`、`solidCount`。内部 `performanceMs` 用于测量各阶段耗时，不作为工艺参数显示。

## 缓存与异步切换

前端按完整制造输入和依赖内容缓存方案与逐件结果。相同输入可复用进行中的计算；实际实体生成串行执行。切换选择后，旧结果不能覆盖当前选择；无人继续等待的任务不再启动后续零件。失败不缓存，可再次生成。

缓存身份包含模板生成摘要、管型与模具依赖、成品及工艺输入、场景和项目身份、场景代理实例。每次实际计算都发布新的资源标识；即使逐件缓存淘汰后再次计算相同输入，也不会覆盖其他配置仍引用的资源。

JavaScript 方案缓存最多 16 项，逐件结果最多 64 项。已发布的场景临时资源仍由场景生命周期管理；淘汰 JavaScript 缓存不删除可能仍被其他预览引用的场景资源。

刷新复用侧栏 DOM 更新机制，保留最新焦点、文本选区、左右侧栏及嵌套滚动位置。

## 产品模板接入范围

产品通过声明构件和连接节点使用独立装配工艺。目前百叶窗、普通铝合金窗、极简防护网及防盗窗的部分结构提供 `external_templates` 模式，默认仍为 `legacy_processed`。各产品模板声明并限制可用结构，不能推定全部产品或全部结构已支持独立节点工艺。

本次最终实体接口及缓存改造服务于资源库装配预览。产品工艺绑定仍使用原来的持久化加工链路，保存产品绑定所需的加工资源。

## 测量范围

Release 的四个代表用例分别预热一次，再交替调用新旧接口各三次，取中位数。两条路径接收同一份已解析管型的单件请求，每次使用新的资源标识。测试不把速度比例设为通过条件；实体、资源和输入不变的检查独立执行。

| 代表工艺 | 旧接口 / ms | 最终实体接口 / ms | 耗时下降 |
| --- | ---: | ---: | ---: |
| 斜接 | 58.3 | 44.1 | 24.4% |
| 长短包接，启用四个公母 | 122.3 | 99.7 | 18.5% |
| 分段开槽折弯 | 256.1 | 245.1 | 4.3% |
| 柔性缝开槽折弯 | 327.4 | 310.0 | 5.3% |

这些是原生单件预览调用的耗时，不包括计划解析、界面显示和前端网格拉取。切回未变化配置时的缓存复用另由浏览器测试验证，不包含在以上测量中。首次生成复杂开槽实体仍主要耗时于真实布尔加工。
