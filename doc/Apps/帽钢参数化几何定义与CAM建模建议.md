# 帽钢参数化几何定义与 CAM 建模建议

## 1. 定义

帽钢（Hat Section / Top-Hat Section）是一类典型的开口薄壁或型钢截面。

其基本拓扑由：

- 一段顶部水平腰部；
- 左右两个直腿；
- 左右两个向外展开的平腿（帽沿）

组成。

基本形状：

```text
             腰部
        ┌──────────────┐
        │              │
        │              │
        │              │
 ───────┘              └───────
  平腿      直腿  直腿      平腿
```

截面左右对称。

从 CAM 管型库角度看：

> **普通冷弯帽钢与热轧帽钢拓扑一致，因此不建议新增“热轧帽钢”一级类型。**

推荐保留：

```text
帽钢
□ 热轧
```

通过“热轧”开关切换截面细节模型。

---

# 2. 普通冷弯帽钢

普通帽钢通常由等厚板材冷弯形成，因此可以采用：

\[
\boxed{
t=\text{constant}
}
\]

推荐基础参数：

\[
\boxed{
Hat(B,H,F,t,R)
}
\]

其中：

| 参数 | 含义 |
|---|---|
| \(B\) | 顶部腰部宽度 |
| \(H\) | 帽钢高度 |
| \(F\) | 单侧平腿/帽沿宽度 |
| \(t\) | 板厚 |
| \(R\) | 折弯内圆角 |

基础示意：

```text
            B
      <------------>

        ┌──────────┐
        │          │
        │          │ H
        │          │
<-- F -->          <-- F -->
────────┘          └────────
```

---

# 3. 冷弯模式的几何特征

当：

```text
HotRolled = false
```

可以采用：

- 等厚；
- 左右对称；
- 腰部水平；
- 直腿近似竖直；
- 平腿水平；
- 各折弯处由内圆角 \(R\) 连接。

其典型几何可统一使用：

> **理论直线 + Fillet + Offset**

的方式构造。

---

# 4. 热轧帽钢

国内存在专门的热轧帽型钢体系，例如铁道车辆中梁用热轧帽型钢。

热轧后，截面仍保持同样拓扑：

```text
             腰部
        ┌──────────────┐
        │              │
        │              │
        │              │
 ───────┘              └───────
```

但和普通冷弯帽钢相比，最大的变化并不是增加坡度，而是：

\[
\boxed{
\text{不同区域允许采用不同厚度}
}
\]

也就是说：

\[
t=\text{constant}
\]

会升级为：

\[
\boxed{
t_1,\ t_2,\ t_3
}
\]

---

# 5. 热轧帽钢推荐参数

建议热轧模式定义为：

\[
\boxed{
HatHotRolled
(
h,b_1,b_2,
t_1,t_2,t_3,
r_1,r_2,r_3,r_4
)
}
\]

其中：

| 参数 | 含义 |
|---|---|
| \(h\) | 帽钢总高度 |
| \(b_1\) | 两个直腿之间的内宽 |
| \(b_2\) | 单侧平腿长度 |
| \(t_1\) | 顶部腰部厚度 |
| \(t_2\) | 左右直腿厚度 |
| \(t_3\) | 左右平腿厚度 |
| \(r_1\) | 腰部与直腿之间的过渡圆角 |
| \(r_2\) | 直腿与平腿之间的过渡圆角 |
| \(r_3\) | 平腿自由端上侧圆角 |
| \(r_4\) | 平腿自由端下侧圆角 |

---

# 6. 三种厚度的定义

热轧帽钢最重要的特征之一，就是不同区域可以不同厚。

## 6.1 腰部厚度 \(t_1\)

```text
          t1
      ┌────────────┐
      │            │
```

定义：

\[
\boxed{
t_1=\text{顶部腰部厚度}
}
\]

---

## 6.2 直腿厚度 \(t_2\)

```text
      │
      │  t2
      │
```

定义：

\[
\boxed{
t_2=\text{左右直腿厚度}
}
\]

---

## 6.3 平腿厚度 \(t_3\)

```text
══════════════
     t3
```

定义：

\[
\boxed{
t_3=\text{左右平腿厚度}
}
\]

---

# 7. 为什么不能继续只使用统一厚度 \(t\)

普通冷弯帽钢通常可以认为：

\[
t_1=t_2=t_3=t
\]

但热轧帽钢可以出现：

\[
\boxed{
t_1\neq t_2\neq t_3
}
\]

甚至某些典型设计中：

\[
t_1=t_2
\]

但：

\[
t_3>t_1
\]

例如平腿区域为了结构、焊接或连接需求，可能明显加厚。

因此：

> **热轧帽钢不能继续按“等厚板折弯截面”建模。**

---

# 8. \(b_1\) 的定义

推荐：

\[
\boxed{
b_1=\text{两个直腿内侧之间的净宽}
}
\]

示意：

```text
      ┌───────────────┐
      │<---- b1 ----->│
      │               │
      │               │
```

这样定义有几个优点：

- 与内部空间直接对应；
- 便于 CAM 装夹、碰撞与内腔计算；
- 不会因为不同厚度定义造成歧义。

---

# 9. \(b_2\) 的定义

推荐：

\[
\boxed{
b_2=\text{单侧平腿的理论长度}
}
\]

示意：

```text
<----- b2 ----->│
────────────────┘
```

左右两侧默认对称。

---

# 10. \(h\) 的定义

推荐：

\[
\boxed{
h=\text{截面总高度}
}
\]

即从平腿最低外表面到顶部腰部最高外表面的垂直距离。

这样最符合型钢整体尺寸表达习惯。

---

# 11. \(r_1\)：腰部与直腿过渡

位置：

```text
────────────
            ╮
            │
            │
```

\(r_1\) 用于连接：

- 顶部腰部内侧理论直线；
- 直腿内侧理论直线。

如果两者正交：

\[
\alpha_1=90^\circ
\]

则直接：

\[
\boxed{
Fillet(r_1)
}
\]

即可。

不需要再输入圆心或圆心角。

---

# 12. \(r_2\)：直腿与平腿过渡

位置：

```text
       │
       │
       ╰──────────
```

用于连接：

- 直腿；
- 平腿。

如果两者正交：

\[
\alpha_2=90^\circ
\]

则：

\[
\boxed{
Fillet(r_2)
}
\]

即可。

---

# 13. \(r_3,r_4\)：平腿自由端圆角

平腿自由端可能不是上下相同圆角。

示意：

```text
──────────────╮  r3
              │
              │
──────────────╯  r4
```

其中：

\[
\boxed{
r_3=\text{自由端上侧圆角}
}
\]

\[
\boxed{
r_4=\text{自由端下侧圆角}
}
\]

因此不建议只定义一个统一自由端圆角 \(r\)。

热轧模式下应允许：

\[
\boxed{
r_3\neq r_4
}
\]

---

# 14. 角度关系

热轧帽钢和传统热轧槽钢、普通工字钢不同。

它通常不依赖持续斜翼缘来体现热轧特征。

主体仍然可以近似认为：

\[
\alpha_1\approx90^\circ
\]

\[
\alpha_2\approx90^\circ
\]

因此：

- 腰部与直腿近似垂直；
- 直腿与平腿近似垂直。

所以：

> **热轧帽钢的核心特征不是“坡度”，而是“分区厚度 + 轧制圆角”。**

---

# 15. 推荐几何构造原则

整个帽钢仍然可以完全采用解析几何构造。

推荐原则：

\[
\boxed{
\text{理论直线 + Fillet}
}
\]

无需：

- B-Spline；
- Bezier；
- 自由曲线；
- 实测拟合轮廓。

---

# 16. 普通冷弯帽钢构造流程

## Step 1：建立理论中心折线

根据：

\[
B,H,F
\]

建立：

- 左平腿；
- 左直腿；
- 顶部腰部；
- 右直腿；
- 右平腿。

---

## Step 2：添加折弯圆角

在四个折弯位置执行：

\[
\boxed{
Fillet(R)
}
\]

---

## Step 3：生成实体厚度

沿中心轮廓两侧 Offset：

\[
\pm\frac{t}{2}
\]

得到完整截面。

---

# 17. 热轧帽钢构造流程

热轧模式不能简单使用统一中心线 Offset，因为：

\[
t_1,t_2,t_3
\]

可能不同。

推荐直接按各区域内外理论线构造。

## Step 1：定义主体尺寸

利用：

\[
h,b_1,b_2
\]

确定整体骨架。

---

## Step 2：定义区域厚度

分别赋予：

\[
t_1,\quad t_2,\quad t_3
\]

---

## Step 3：建立理论直线

建立：

- 腰部上、下边；
- 两个直腿内、外边；
- 两个平腿上、下边。

---

## Step 4：处理 \(r_1\)

腰部与直腿之间：

\[
Fillet(r_1)
\]

---

## Step 5：处理 \(r_2\)

直腿与平腿之间：

\[
Fillet(r_2)
\]

---

## Step 6：处理自由端

平腿自由端上下分别：

\[
Fillet(r_3)
\]

\[
Fillet(r_4)
\]

---

## Step 7：闭合截面

确保最终截面为单一简单闭合轮廓。

---

# 18. 热轧开关的推荐行为

基础管型：

```text
帽钢
```

UI：

```text
□ 热轧
```

---

## 18.1 HotRolled = false

采用普通冷弯模型：

\[
\boxed{
B,H,F,t,R
}
\]

并保持：

\[
t_1=t_2=t_3=t
\]

---

## 18.2 HotRolled = true

切换成：

\[
\boxed{
h,b_1,b_2,
t_1,t_2,t_3,
r_1,r_2,r_3,r_4
}
\]

热轧开关不仅改变圆角，还改变：

\[
\boxed{
\text{厚度模型}
}
\]

---

# 19. 不建议将热轧帽钢独立成一级类型

不建议：

```text
普通帽钢
热轧帽钢
```

作为两个独立一级类型。

因为它们的拓扑完全一致：

```text
平腿 + 直腿 + 腰部 + 直腿 + 平腿
```

真正变化的是几何细节。

因此更推荐：

\[
\boxed{
帽钢 + HotRolled
}
\]

---

# 20. 推荐数据结构

```cpp
struct HatSection
{
    bool hotRolled;

    // 普通冷弯模式
    double topWidth;        // B
    double height;          // H
    double flangeWidth;     // F
    double thickness;       // t
    double bendRadius;      // R

    // 热轧模式
    double innerWidth;      // b1
    double hotHeight;       // h
    double hotFlangeWidth;  // b2

    double topThickness;    // t1
    double webThickness;    // t2
    double flangeThickness; // t3

    double rootRadius1;     // r1
    double rootRadius2;     // r2
    double toeUpperRadius;  // r3
    double toeLowerRadius;  // r4
};
```

如果数据模型允许，也可以将普通模式和热轧模式参数拆分成两个子结构，避免大量无效字段。

---

# 21. 推荐的内部抽象

更推荐底层抽象成：

```cpp
struct HatColdFormedGeometry
{
    double topWidth;
    double height;
    double flangeWidth;
    double thickness;
    double bendRadius;
};

struct HatHotRolledGeometry
{
    double height;
    double innerWidth;
    double flangeWidth;

    double topThickness;
    double webThickness;
    double flangeThickness;

    double rootRadius1;
    double rootRadius2;
    double toeUpperRadius;
    double toeLowerRadius;
};
```

顶层：

```cpp
struct HatSection
{
    bool hotRolled;

    HatColdFormedGeometry coldFormed;
    HatHotRolledGeometry hotRolledGeometry;
};
```

---

# 22. 参数合法性检查

热轧模式至少应检查：

\[
h>0
\]

\[
b_1>0
\]

\[
b_2>0
\]

\[
t_1>0,\quad t_2>0,\quad t_3>0
\]

\[
r_1,r_2,r_3,r_4\ge0
\]

同时还需检查：

1. \(r_1\) 不得吃掉完整腰部直线；
2. \(r_2\) 不得吃掉完整直腿或平腿；
3. \(r_3,r_4\) 不得相互重叠；
4. 各厚度变化过渡后截面不能自交；
5. 左右轮廓应保持对称；
6. 最终截面必须形成合法简单闭合轮廓。

---

# 23. 和其他热轧型钢的区别

| 类型 | 打开热轧后的主要变化 |
|---|---|
| 角钢 | 圆角规则变化，主体仍等厚、无坡度 |
| T型钢 | 主要增加热轧圆角 |
| 槽钢 | 翼缘内侧出现斜度 |
| 工字钢 | 翼缘内侧出现斜度 |
| 帽钢 | **分区厚度 + 多组轧制圆角** |
| U肋 | 可进一步支持局部加厚 |

因此可以明确：

\[
\boxed{
\text{热轧}\neq\text{一定有坡度}
}
\]

热轧帽钢最主要的几何特征是：

\[
\boxed{
\text{变厚度能力 + 轧制圆角}
}
\]

---

# 24. 最终推荐

基础一级管型保持：

\[
\boxed{
HatSection
}
\]

通过：

```text
HotRolled = true / false
```

控制两套几何规则。

普通模式：

\[
\boxed{
B,H,F,t,R
}
\]

热轧模式：

\[
\boxed{
h,b_1,b_2,
t_1,t_2,t_3,
r_1,r_2,r_3,r_4
}
\]

最终建议遵循三个原则：

1. **不新增热轧帽钢一级类型；**
2. **热轧模式允许不同区域不同厚度；**
3. **所有标准名义圆角仍采用理论直线 + Fillet 构造。**

这样既保持 UI 简洁，也能完整覆盖普通冷弯帽钢和热轧帽型钢的几何差异。
