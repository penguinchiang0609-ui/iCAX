# U肋参数化几何定义与CAM建模建议

## 1. 定义

U肋（U-shaped rib / trough rib）主要用于正交异性钢桥面板，是桥梁钢结构中常见的纵向加劲肋。

从截面几何上看，U肋不应简单理解成普通槽钢，也不是“圆底U型”。

更准确的抽象是：

> **开口梯形 + 两条侧壁斜直线 + 一条底部直线 + 两个底部相切圆弧。**

单独的U肋是开口截面；安装后，两侧顶部通常与桥面板焊接，形成闭口纵向加劲结构。

## 2. 基础截面形状

```text
          B：上口宽
      <-------------->

         \          /
          \        /
           \      /
            \    /
             ╰──╯
             <-->
              B1

               ↑
               │ H
               ↓
```

截面左右对称。

## 3. 推荐基础参数

建议基础U肋定义为：

\[
URib(B,H,B_1,t,R)
\]

其中：

| 参数 | 含义 |
|---|---|
| B | 上口宽度 |
| B1 | 下口/槽底理论宽度 |
| H | U肋总高度 |
| t | 板厚 |
| R | 底角内圆弧半径 |

对于普通等厚冷弯U肋，这5个参数已经能够唯一确定截面。

## 4. 斜边几何关系

因为截面左右对称，所以单侧横向收缩量为：

\[
\Delta x=\frac{B-B_1}{2}
\]

如果侧壁相对于竖直方向的夹角定义为 α，则：

\[
\alpha=\arctan\left(\frac{B-B_1}{2H}\right)
\]

侧壁相对于水平底边的夹角为：

\[
\gamma=90^\circ-\alpha
\]

因此：

\[
\gamma=90^\circ-\arctan\left(\frac{B-B_1}{2H}\right)
\]

## 5. 示例

假设：

\[
B=300,\quad B_1=170,\quad H=280
\]

则：

\[
\Delta x=65
\]

\[
\alpha=\arctan\frac{65}{280}\approx13.07^\circ
\]

侧壁相对于水平底边的夹角：

\[
\gamma\approx76.93^\circ
\]

## 6. 底部圆角R的定义

建议将 R 定义为：

> **侧壁内轮廓与底部内轮廓之间的相切圆弧半径。**

不单独定义圆心角。

圆弧由以下三项唯一确定：

1. 侧壁直线方向；
2. 底部水平直线；
3. 圆弧半径 R。

圆弧同时与侧壁和底边相切。

其圆心角为：

\[
\beta=90^\circ-\alpha
\]

即：

\[
\beta=90^\circ-\arctan\left(\frac{B-B_1}{2H}\right)
\]

对于 300×280×170 的示例：

\[
\beta\approx76.93^\circ
\]

所以U肋底部圆角通常不是90°圆弧。

## 7. 等厚模型

普通冷弯U肋可以按等厚截面处理：

\[
t=\text{constant}
\]

若 R 为内圆角：

\[
R_i=R
\]

中心层半径：

\[
R_c=R+\frac{t}{2}
\]

外圆角半径：

\[
R_o=R+t
\]

## 8. 推荐的几何生成方式

对CAM截面生成器来说，推荐优先生成中心轮廓，再做等距偏移。

### 8.1 中心层

先定义：

\[
R_c=R+\frac{t}{2}
\]

生成：

- 左侧中心斜线；
- 左侧中心圆弧；
- 底部中心直线；
- 右侧中心圆弧；
- 右侧中心斜线。

### 8.2 Offset

中心轮廓两侧分别做：

\[
+\frac{t}{2}
\]

和：

\[
-\frac{t}{2}
\]

的等距偏移，最终得到完整实体截面。

## 9. R 与板厚的关系

工程中常见：

\[
R\approx5t
\]

例如：

\[
t=8\Rightarrow R\approx40
\]

但CAM软件中不建议把 R=5t 写死。

推荐：

\[
R=\text{独立参数}
\]

标准规格或行业模板中可以自动给默认值。

## 10. 顶部自由端

U肋顶部的两个自由端最终通常与桥面板焊接，因此顶部自由端与热轧角钢、槽钢的“自由端圆角”概念不同。

建议：

> **顶部坡口不要定义为U肋基础截面参数。**

坡口属于后续焊接准备或端边加工特征。

基础U肋仍然保持：

\[
B,H,B_1,t,R
\]

## 11. 冷弯U肋

当：

```text
HotRolled = false
```

按普通冷弯等厚U肋处理：

- 等厚；
- 两侧斜直边；
- 底部直边；
- 两个底角圆弧；
- 左右对称。

## 12. 热轧U肋

热轧U肋仍然可以保持一级类型为“U肋”，不必再新增一级类型。

按照现有管型体系，可以增加：

```text
□ 热轧
```

即：

```text
HotRolled = true / false
```

## 13. 热轧开关的推荐行为

### HotRolled = false

采用普通冷弯等厚模型：

\[
URib(B,H,B_1,t,R)
\]

并保持：

\[
t=\text{constant}
\]

### HotRolled = true

基础几何仍然由：

\[
B,H,B_1,R
\]

确定，但厚度模型允许扩展。

第一阶段可以支持：

- 等厚热轧；
- 后续再支持局部加厚热轧。

## 14. 等厚热轧U肋

如果热轧U肋仍为等厚截面，则其几何和冷弯U肋非常接近。

差异更多体现在：

- 制造方式；
- 标准规格；
- 允许偏差；
- 圆角及厚度控制方式。

因此软件层面没有必要重新设计一种一级管型。

## 15. 局部加厚热轧U肋

热轧工艺允许进一步实现局部厚度变化，因此未来可扩展：

```text
UP = 局部平行加厚U肋
```

这时：

\[
t\ne\text{constant}
\]

建议作为热轧U肋的高级厚度模型，而不是重新定义独立一级管型。

## 16. 推荐的数据结构

```cpp
enum class URibThicknessMode
{
    Constant,
    LocalThickened
};

struct URibSection
{
    double topWidth;       // B
    double height;         // H
    double bottomWidth;    // B1
    double thickness;      // t
    double rootRadius;     // R

    bool hotRolled;
    URibThicknessMode thicknessMode;
};
```

## 17. 不建议增加的冗余参数

### 17.1 不建议单独增加侧壁角度

因为：

\[
\alpha=\arctan\left(\frac{B-B_1}{2H}\right)
\]

已经可以由 B、B1、H 自动计算。

否则同时提供 B、B1、H、α 会造成参数过约束。

### 17.2 不建议增加底角圆心角

因为：

\[
\beta=90^\circ-\alpha
\]

已经由侧壁和底边的相切条件唯一决定。

### 17.3 不建议把顶部坡口作为基础参数

顶部坡口属于加工和焊接工艺，而不是基础截面几何。

## 18. 参数合法性

基础条件：

\[
B>B_1>0
\]

\[
H>0,\quad t>0,\quad R>0
\]

另外还需要检查：

- 圆角不能吃掉完整底部直线；
- 圆角不能与顶部自由端发生重叠；
- 内外轮廓Offset后不能自交。

## 19. B1的定义建议

用户输入的 B1 到底表示什么，软件里必须统一。

推荐定义：

> **B1 表示两条理论侧壁延长线与理论底边交点之间的理论宽度。**

先由 B、B1、H 定义理论梯形，再用 R 对两个理论尖角做 Fillet。

这样：

- B、B1、H：负责定义理论梯形；
- R：只负责将尖角替换为相切圆弧。

这种方式最适合参数化几何。

## 20. 几何构造流程

### Step 1：理论梯形

根据 B、B1、H 生成：

- 左理论侧壁；
- 右理论侧壁；
- 理论底边。

### Step 2：底角Fillet

左右两个理论底角分别执行：

\[
Fillet(R)
\]

其中 R 为内圆角。

### Step 3：生成内轮廓

得到两条斜边、两个底角圆弧和底部直线。

### Step 4：生成外轮廓

外轮廓通过内轮廓向材料外侧 Offset t 得到。

### Step 5：封闭顶部板端

连接左右侧壁的内外端点，形成完整封闭截面。

## 21. 和槽钢的区别

U肋与普通槽钢虽然都是开口截面，但几何来源不同。

### 槽钢

传统热轧槽钢主要由：

- 腹板；
- 上下翼缘；
- 翼缘内侧斜度；
- 根部与自由端圆角

组成。

### U肋

U肋的核心几何是：

- 梯形；
- 两条侧壁；
- 底板；
- 两个折弯圆角。

因此：

\[
U肋不建议作为槽钢的一个参数变种
\]

应该保留独立基础管型“U肋”。

## 22. 最终推荐

对于CAM管型库，U肋基础定义建议采用：

\[
URib(B,H,B_1,t,R)
\]

内部自动计算：

\[
\Delta x=\frac{B-B_1}{2}
\]

\[
\alpha=\arctan\left(\frac{B-B_1}{2H}\right)
\]

\[
\beta=90^\circ-\alpha
\]

\[
R_c=R+\frac{t}{2}
\]

\[
R_o=R+t
\]

基础模型建议：

> **理论梯形 + 底角Fillet + 等厚Offset**

UI层保持：

```text
U肋

上口宽 B
高度   H
下口宽 B1
厚度   t
圆角   R

□ 热轧
```

这样既可以覆盖普通冷弯U肋，也给热轧U肋以及后续局部加厚模型保留扩展空间。
