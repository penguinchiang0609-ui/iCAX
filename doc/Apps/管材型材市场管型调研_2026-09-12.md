# 管材 / 型材市场管型调研

> 调研日期：2026-09-12  
> 视角：激光切管、型材三维切割与 CAM 数据模型  
> 完整清单：104 项管型、型材构造和特殊工件

## 1. 核心结论

市面上的“管型”不能靠一个固定名称枚举穷尽。完整覆盖至少包括闭口空心管、开口/开缝型材、冷弯开口型钢、热轧/焊接结构型钢、船用特殊型钢、多腔挤压型材、实心棒材，以及弯管、锥管、变截面等特殊工件。

同一个外形名称还必须继续区分制造路线。角钢应区分热轧、板带冷弯、冷拔/精密冷轧和板焊；槽钢应区分热轧斜腿、热轧平行翼缘、冷弯U/C/卷边C和板焊槽；I/H/T、帽型等也存在热轧、剖分、焊接或冷弯差异。这些差异会改变圆角、局部厚度、翼缘斜度、焊缝和工艺区，不能仅作为备注。

P型、腰型、马蹄圆、8字型、蘑菇/面包/元宝等名称均可能对应多种几何，必须绑定截面图、图纸号和版本。球扁钢及双球头球扁钢应独立建模，不能简化为“扁钢 + 半圆”。

## 2. 证据等级

| 等级 | 含义 |
|---|---|
| A | 国家标准或行业标准明确 |
| B | 机床、控制或 CAD/CAM 厂商公开明确 |
| C | 材料厂、专利、产品目录或明确工程构造 |
| D | 市场俗称，仅证明名称存在，必须用图纸确认 |

## 5. 用户重点关注项

### 5.1 P型

P型不是唯一截面。至少已经确认两类：一类是含台阶、凹角和纵向焊缝的闭口P形钢管；另一类是空心主体外带单侧连续翼板的P-Tube。软件中不应建立一个固定 `PType` 轮廓，而应归入 `CustomClosed` 或 `FlangedHollow`，并绑定图纸号、截面版本、焊缝和装夹方向。

### 5.2 球扁钢

球扁钢是独立的热轧型钢族。球头包含局部增厚、斜面和多个过渡圆角，不能简化为矩形扁钢加半圆。双球头球扁钢也应作为独立模板或自定义截面，不能由单球头简单镜像推导。

### 5.3 冷轧、冷弯与热轧

“冷轧”可能描述原料状态，也可能指精密冷轧成形；“冷弯”描述板带在常温下形成最终截面的工艺。用热轧带钢冷弯形成的C型钢，成品仍属于冷弯截面。CAM数据中应把原料状态与成品成形方式分成两个字段。

### 5.4 角钢与槽钢

热轧角钢的根部属于局部增厚的轧制过渡，冷弯角钢则是板厚两侧的弯曲圆角；板焊角钢根部是焊缝。热轧槽钢还要区分斜腿和平行翼缘，冷弯槽钢则要区分U、C、内卷边、外卷边和多卷边，不能统一成一个 `Channel` 模板。

## 8. 歧义术语与最低图纸要求

| 术语 | 常见解释 | 主要风险 | 最低图纸/参数要求 | 建议分类 |
|---|---|---|---|---|
| 椭圆管 | 严格椭圆；市场也可能泛指扁圆 | 按长短轴自动建模可能错 | 外/内轮廓、曲线类型、长短轴、壁厚 | Ellipse |
| 平椭圆 | 国标独立类型；可能为多段圆弧或直线+圆弧 | 与跑道圆/腰型混用 | 截面DXF、弧段和直线段 | FlatOval |
| 跑道圆/长圆 | 典型为两直线+两端半圆/弧 | 当成椭圆会产生全轮廓误差 | 端弧半径、直线长度、内外轮廓 | Obround/Racetrack |
| 腰型管 | 可指跑道、四圆弧或中部内收 | 同名多形 | 必须提供图纸或扫描轮廓 | CustomClosed |
| P型管 | 台阶闭口P形、空心主体带翼等至少两类 | 按字母外观固定模板会错 | 腔体、翼板、焊缝、方向和图纸版本 | CustomClosed/FlangedHollow |
| 8字/B型 | 可能双腔，也可能只是外轮廓内凹 | 内环数量误判影响切断、重量和挂料 | 内环、隔筋和外轮廓 | MultiCell或CustomClosed |
| 马蹄圆 | 市场俗称，可能拱形+底边或复杂内凹 | 与D型/半圆/腰型混淆 | 图纸、开闭口、底边、内凹 | CustomClosed |
| 半圆管 | 可为闭口D形，也可为开口半圆槽 | 拓扑完全不同 | 是否有底边/内环、开口宽度 | DShape或OpenProfile |
| D型管 | 一平边+圆弧；弧段和内孔并不唯一 | 被当成半圆或偏心圆 | 平边、弧段、内轮廓、朝向 | DShape |
| 蘑菇/面包/元宝 | 市场俗称，无唯一标准几何 | 跨供应商无法复用名称 | DXF/STEP、样件扫描、版本号 | CustomProfile |
| 工字钢/I型 | 可有斜翼缘IPN，也可有平行翼缘IPE | I=斜翼缘的规则不可靠 | 标准系列、翼缘斜度、宽厚和圆角 | ISection+Series |
| H型钢 | 热轧H、焊接H、非对称H等 | 三矩形拼接会漏圆角/焊缝 | 制造路线、板厚、根部和系列 | HSection+Manufacturing |
| 槽钢/U/C | 热轧斜腿/平行翼缘、冷弯U/C/卷边C、板焊槽 | 一个Channel枚举不足 | 制造路线、斜度、卷边、圆角/焊缝 | ChannelFamily |
| 冷轧 vs 冷弯 | 冷轧可指原料或精密成形；冷弯是成品成形方式 | 把热轧带钢冷弯件误归热轧型钢 | 原料状态与成形路线分开记录 | material_process + forming_process |
| 球扁钢 | 热轧局部加厚截面，不是扁钢+标准半圆 | 重量、坡口、碰撞不准确 | 系列、球头宽高、斜面、圆角和朝向 | BulbFlat |
| 双球头球扁钢 | 双侧加厚头部/双球头特殊截面 | 从单球头镜像猜测可能错 | 完整截面图和专用模板 | DoubleBulb |
| 不等边角钢 | 只说明两肢长度不同，不说明厚度是否相同 | 漏掉不等边不等厚型 | 两肢长度和两肢厚度均独立 | Angle(a,b,t1,t2) |

## 9. CAM推荐数据模型

| 优先级 | 字段/能力 | 数据类型 | 建议内容 | 解决的问题 |
|---|---|---|---|---|
| P0 | `profile_topology` | 枚举 | ClosedHollow / OpenProfile / MultiCell / SolidProfile / VariableProfile / Assembly | 决定内外环、切断面、重量和算法分支 |
| P0 | `section_geometry` | 二维精确几何 | 外环、内环、开口曲线、线/圆弧/NURBS及方向 | 任意异型的基础 |
| P0 | `manufacturing_route` | 枚举+备注 | 热轧、冷弯、冷拔、精密冷轧、挤压、焊接、板焊、咬口 | 决定圆角、焊缝、厚度和工艺区 |
| P0 | `thickness_model` | 参数/分段 | 统一壁厚、分段厚度、内外轮廓独立 | 支持冷拔内外异形和热轧局部增厚 |
| P0 | `fillet_and_toe_radii` | 参数集 | 内根、外跟、肢端、翼缘端、折弯内外半径 | 表达热轧/冷弯差异 |
| P0 | `orientation_and_zero` | 坐标系 | 截面原点、0度方向、镜像、翻转、焊缝相位 | 统一导入、套料和机床零位 |
| P0 | `clamping_envelope` | 几何+规则 | 接触区、禁夹区、包络圆、允许姿态 | 判断设备可加工性 |
| P0 | `support_baseline` | 面/线集合 | 可放置面、托料中心、重心和支撑切换 | 影响上料、跟随支撑和下垂 |
| P0 | `machinable_surfaces` | 区域标签 | 可加工面、禁加工面、坡口面、仅打孔面 | 避免进入狭槽/凹角碰撞 |
| P0 | `process_zones` | 区域+规则 | 腹板、翼缘、圆角、焊缝、球头等区域 | 匹配功率、速度、补偿和坡口策略 |
| P0 | `source_and_revision` | 元数据 | 标准号、厂商、图纸号、版本、日期、URL | 保证同名不同形可追溯 |
| P1 | `seam_and_weld` | 线/区域 | 纵缝、咬口、组焊缝、焊趾/焊根 | 影响质量、夹持和禁切规则 |
| P1 | `flange_slope` | 角度/曲线 | 槽/I翼缘斜度、球扁斜面 | 防止把斜面当平行面 |
| P1 | `lips_flaps_ribs` | 特征列表 | 卷边、翻边、压筋、隔筋和外伸翼 | 支持开口/多腔型材工艺和夹持 |
| P1 | `mass_properties` | 计算值 | 截面积、理论重量、重心和惯性矩 | 上料、支撑、报价和运动控制 |
| P1 | `measured_profile` | 公差/点云 | 标准公差、实测轮廓、椭圆度和扭曲度 | 匹配真实来料 |
| P1 | `capability_match` | 规则 | 尺寸、重量、卡盘包络、可达角和轴数 | 软件支持不等于设备可加工 |
| P2 | `multi_cell_connectivity` | 拓扑图 | 腔体、隔筋和开放槽连接关系 | 切断后挂料、热传导和路径顺序 |
| P2 | `variable_section` | 函数/三维实体 | 截面沿轴向尺寸、拓扑或旋转变化 | 处理锥管、扭转和变截面 |
| P2 | `bent_centerline` | 三维曲线+标架 | 弯管中心线、局部坐标和弯曲变形 | 弯管切割与碰撞 |
| P2 | `validation_level` | 枚举 | 名称收录/几何导入/仿真/后处理/干切/实切 | 控制对外宣称与质量闭环 |

## 10. 开发优先级

- **P0**：圆、方、矩形、椭圆、平椭圆/跑道形、热轧/冷弯角钢、热轧/冷弯槽钢、C型、I/H，以及通用拓扑基础。
- **P1**：P型、D型、8字、三角/梯形/六角、卷边C/Z、板焊角槽、焊接H、T型、球扁钢、任意单腔和任意开口截面。
- **P2**：双球头、Sigma/Omega、带翼、多腔、门窗/光伏/工业铝、传动轴异型和船舶专用型材。
- **P3**：市场俗称截面、轨道型材、实心特殊截面、弯管、锥管、变截面、扭转和焊接组合件。
