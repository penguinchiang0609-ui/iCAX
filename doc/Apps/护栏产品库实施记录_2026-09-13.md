# 护栏产品库实施记录

依据《护栏行业款式调研与产品化建议_2026-09-13.md》，沿用独立 JSON＋Python 模板与共享制造几何机制。32 个既有组合式护栏模板升级至 1.3.0，默认仍为水平原款式，不新增重复卡片。

## 本轮实现与入口

资源库 → 产品 → 护栏 → 选原有模板，在右侧参数中调整：

| 参数 | 实际作用 |
|---|---|
| 高程排布／各边坡度角 | 支持直线、左右 L、U 形路径；各边独立坡度、转角累计标高。立柱和竖杆竖直；扶手及横档按真实截面倾斜，并分跨接入立柱。 |
| 阶梯分跨 | 扶手逐跨独立、横档保持水平；立柱连接相邻两跨并按高侧延伸。各跨按较高端标高布置，低侧离地净空需复核。 |
| 高程依据 → 按实际踏步落柱 | 输入踏步进深、升高和各边踏步中心间隔数；首个支承踏步中心为原点。立柱落在整数踏步中心，间距不超过最大柱距；0间隔的边作为水平平台。 |
| 柱间填充 → 横向管材／板条填充 | 生成独立水平填充管，按最大净距或固定数量排布。填充截面宽度此时表示板条高度，深度仍为侧向厚度。 |
| 填充排布方式 | 增加固定杆数反算净距、两侧半间距；保留原均分及固定内间距。固定杆数不强行宣称满足最大净距。 |
| 安装 → 侧装锚固板 | 生成垂直侧装板、四个真实锚栓孔和向下延长的立柱，校验下挂、孔边距及相邻板重叠。 |

角度模式的长度输入为水平投影长度；踏步模式的非平台跨度由间隔数×进深决定，对应手填边长隐藏。加工输出为轴向毛坯长度及真实裁切实体，并附起终点、各边坡度和轴线倾角；另输出立柱安装定位表（XY、支承面及柱顶标高）。预览与制造都执行端面裁切，但穿杆内部加工孔仍按原有目的分离。

矩形、圆管等现有截面均使用实际接收管外包络形成相贯切口，竖杆限制在上下横梁中心面之间，不遗留另一侧碎块。共享转角立柱之外可能交叠的横梁，用互补分角面划分保留区域，避免横梁之间反复做曲面相减。大立柱和柱帽按计算后的柱顶标高定位；横向填充也支持分段顺坡。

柱帽外沿的实际伸出不能按立柱截面推测。高程模式把相邻柱帽的真实资源实体作为管件避让工具，预览和加工共同执行；不更改、缩放配件，也不根据配件ID猜测外形尺寸。原生检查曾发现84mm柱帽与80mm大立柱旁斜扶手相交，此接点已纳入回归。

## 当前边界，不能按已支持出售

- 高程排布目前支持竖杆和横向管材填充，尚不支持板材／玻璃／花格随坡及围墙出头杆随坡。顶部配件目前为柱帽，不包含枪尖等其他模块。
- 高程扶手在柱间分段，不采用水平款的端部伸出，也不是连续弯管扶手。扶手宽度不能超过立柱截面。
- 高程转角采用共用立柱；双立柱之间的跨角连接节点尚未实现，会明确拒绝，不生成缺少连接的转角。
- 顺坡底板保持水平，需要独立水平支座／踏步；不是斜底板贴合坡面。实际踏步模式检查底板不跨越踏步边缘；共用底板上的立柱若不等高会拒绝，不能冒充平底板可安装。
- 踏步模型目前是每段等进深、等升高的中心定位网格，不包含现场不等步长／不等高测量表；平台边仍采用长度参数。此处不生成楼梯承重结构。
- 横向板条使用现有可制造管截面，不是实木、实心板或百叶系统；尚无旋转叶片、搭接及遮视率计算。
- 侧装板限水平直线矩形立柱；尚未实现抱箍、女儿墙夹持或高程侧装支座。螺栓孔不是锚固承载认证，未创建未知规格的锚栓采购件。
- 疏密／高低交替、专业网片、钢索、多种玻璃支承及公路防撞体系仍待后续独立实现。

## 验证

- 既有 Python 回归 36 项；修正旧测试按列表位置误把玻璃／花格归为竖杆，以及已变更截面协议的断言。
- Python 高程与市场结构测试现为11项，与原有36项合计47项。
- 32 个模板的界面参数呈现检查。
- 原生几何测试扩展至26组：连续／阶梯正负坡度、横向填充、侧装板、L/U转角、圆管转角、实际踏步、大立柱柱帽、横向填充随坡；检查有效实体、正体积及零件间无正体积干涉。该验证不等于工程安全或结构强度验证。
- 本轮26组原生检查中，大立柱柱帽的正负坡度两组发现外沿干涉，其余24组未报错；加入真实配件避让后，两组专项回归通过。最终Python 47项及32款参数呈现检查通过。
