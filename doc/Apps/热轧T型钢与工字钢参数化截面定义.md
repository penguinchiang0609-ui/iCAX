# 热轧 T 型钢与热轧工字钢参数化截面定义

> 用途：用于 CAM / CAD 软件中的热轧型钢截面建模、管型库定义、参数合法性校验和后续切割展开计算。
>
> 基准日期：2026-09-18。
>
> 标准依据：
> - 剖分 T 型钢：GB/T 11263-2024《热轧 H 型钢和剖分 T 型钢》，现行，2025-05-01 实施。
> - 热轧工字钢：截至 2026-09-18，GB/T 706-2016《热轧型钢》仍为现行标准；GB/T 706-2026 已发布，将于 2026-12-01 实施。

---

## 1. 总体结论

热轧 T 型钢与传统热轧工字钢虽然外观看起来都包含“翼缘 + 腹板”，但几何定义完全不同，不建议共用一套简单的“矩形翼缘 + 矩形腹板”模型。

| 项目 | 热轧剖分 T 型钢 | 热轧工字钢 |
|---|---|---|
| 基本来源 | 热轧 H 型钢剖分得到 | 独立热轧型钢 |
| 翼缘内表面 | 平行于外表面 | 存在 1:6 斜度 |
| 翼缘厚度 | 恒定 `t2` | 非恒定，`t` 为腿中间厚度 |
| 腹板厚度 | `t1` | `d` |
| 根部圆角 | `r` | `r` |
| 腿端圆角 | 标准参数中通常不单独给出 | `r1` |
| 腹板自由端 | 剖分面 | 无剖分面 |
| 左右对称 | 是 | 是 |
| 上下对称 | 否 | 是 |
| 几何复杂度 | 较低 | 较高 |

程序实现上建议分别定义为：

```text
HotRolledCutT
{
    h,
    B,
    t1,
    t2,
    r
}
```

和：

```text
HotRolledI
{
    h,
    b,
    d,
    t,
    r,
    r1,
    slope = 1/6
}
```

其中工字钢的 `slope` 在国标模板中可以固定为 `1/6`，但底层数据结构建议保留为可配置参数，便于以后支持其他国家标准或企业标准。

---

# 2. 热轧剖分 T 型钢

## 2.1 基本定义

这里讨论的 T 型钢不是任意热轧实心 T 形棒，而是 GB/T 11263-2024 中定义的**剖分 T 型钢**，也就是由热轧 H 型钢沿腹板方向剖分得到的 T 型截面。

因此它有两个非常重要的几何特征：

1. 翼缘上、下表面互相平行，翼缘厚度 `t2` 基本恒定；
2. 腹板底端属于**剖分面**，不是热轧形成的自由圆角端。

---

## 2.2 参数示意图

![热轧T型钢截面参数示意图](./assets/热轧T型钢截面参数示意图.png)

> 图示用于表达参数关系。实际软件建模时，剖分端建议按平直切割面处理，不应把图形渲染中的视觉圆润效果理解成标准圆角参数。

---

## 2.3 参数定义

| 参数 | 含义 | 建模作用 |
|---|---|---|
| `h` | T 型钢总高度 | 控制从剖分面到翼缘外表面的距离 |
| `B` | 翼缘总宽度 | 控制左右翼缘总宽 |
| `t1` | 腹板厚度 | 控制竖直腹板宽度 |
| `t2` | 翼缘厚度 | 控制水平翼缘厚度 |
| `r` | 腹板与翼缘连接处圆角半径 | 控制左右两个根部过渡圆角 |
| `Cx` | 截面重心位置 | 截面特性参数，不是生成基本轮廓的必要输入 |

对于纯几何轮廓生成，最小参数集可以定义为：

```text
h, B, t1, t2, r
```

---

## 2.4 坐标系建议

建议使用如下统一坐标系：

- T 型钢腹板中心线为 `X = 0`；
- 剖分面中心作为原点 `O(0, 0)`；
- `+Y` 指向翼缘方向；
- `+X` 指向截面右侧。

那么：

```text
最下端：Y = 0
最上端：Y = h
翼缘下表面：Y = h - t2
腹板右侧：X = +t1 / 2
腹板左侧：X = -t1 / 2
翼缘右端：X = +B / 2
翼缘左端：X = -B / 2
```

---

## 2.5 根部圆角的精确构造

T 型钢的根部几何非常简单，因为腹板侧面是竖直线，翼缘内表面是水平线，两者理论夹角为 90°。

以右侧根部圆角为例：

```text
腹板右侧：X = t1 / 2
翼缘下表面：Y = h - t2
圆角半径：r
```

圆心为：

\[
C_r = \left(\frac{t_1}{2}+r,\ h-t_2-r\right)
\]

圆弧与腹板的切点：

\[
P_{web}=\left(\frac{t_1}{2},\ h-t_2-r\right)
\]

圆弧与翼缘下表面的切点：

\[
P_{flange}=\left(\frac{t_1}{2}+r,\ h-t_2\right)
\]

左侧直接关于 `Y` 轴镜像即可。

因此这里不需要像工字钢、槽钢那样求斜线与圆弧的复杂相切关系。

---

## 2.6 截面积校验公式

如果忽略外轮廓制造钝化，只按名义参数建模，基础矩形面积为：

\[
A_0=B\,t_2+t_1(h-t_2)
\]

每个根部圆角相对于尖角模型增加的面积为：

\[
A_r=r^2-\frac{\pi r^2}{4}
=(1-\frac{\pi}{4})r^2
\]

左右两侧合计：

\[
\boxed{
A=B\,t_2+t_1(h-t_2)+2(1-\frac{\pi}{4})r^2
}
\]

也就是：

\[
\boxed{
A\approx B\,t_2+t_1(h-t_2)+0.4292037\,r^2
}
\]

这个公式非常适合用于程序单元测试：截面轮廓生成后计算得到的面积，应与该理论值基本一致。

---

## 2.7 参数合法性校验

建议至少做以下检查。

### 基础尺寸

\[
h>0,\quad B>0,\quad t_1>0,\quad t_2>0,\quad r\ge0
\]

并满足：

\[
h>t_2
\]

\[
B>t_1
\]

### 根部圆角不能吃光翼缘内侧直线

单侧腹板外缘到翼缘端部的水平距离为：

\[
L=\frac{B-t_1}{2}
\]

需要：

\[
\boxed{L>r}
\]

等价于：

\[
\boxed{B-t_1>2r}
\]

如果等于 `r`，圆角刚好延伸到翼缘端；如果小于 `r`，当前参数已经无法按标准 T 型截面构造。

### 根部圆角不能吃光腹板直线

根部以下腹板的可用高度为：

\[
h-t_2
\]

所以应满足：

\[
\boxed{h-t_2>r}
\]

---

## 2.8 关于剖分面的处理

这是 T 型钢和普通热轧实心 T 型材最容易混淆的位置。

GB/T 11263 中的 T 型钢来自 H 型钢剖分，因此腹板底部不是一个由轧辊直接形成的自然自由边，而是剖分后的切割面。

对于 CAM 管型库，建议：

```text
WebCutFaceType = Flat
```

也就是说，名义截面中直接用一条直线闭合腹板底部。

不要自动加入：

- 底端圆角；
- 半圆头；
- 热轧腿端 `r1`；
- 任意倒角。

如果现场原材料确实存在锯切、火焰切割、等离子切割或二次打磨造成的端面偏差，应进入“实测轮廓”层处理，而不是污染标准名义模型。

---

## 2.9 `r` 不宜作为绝对实测约束

GB/T 11263-2024 将附录规格中的圆角半径 `r` 列为参考值。

因此建议软件中区分：

```text
NominalProfile
    └─ 标准名义截面

MeasuredProfile
    └─ 实际扫描 / 实测截面
```

标准库中的 `r` 用于：

- 截面生成；
- 标准零件建模；
- 编程预览；
- 理论碰撞计算；
- 默认切割路径推导。

但如果做高精度寻边、扫描匹配、真实切割补偿，则允许通过实测数据覆盖。

# 3. 热轧工字钢

## 3.1 基本定义

传统热轧工字钢与 H 型钢最关键的区别，不只是“翼缘更窄”。

真正决定建模方式的是：

> **传统热轧工字钢的翼缘内表面具有 1:6 斜度。**

因此，标准参数 `t` 不能解释成“恒定翼缘厚度”。

GB/T 706-2016 对工字钢给出的主要参数为：

```text
h, b, d, t, r, r1
```

其中 `t` 的标准定义是**腿中间厚度**。

---

## 3.2 参数示意图

![热轧工字钢截面参数示意图](./assets/热轧工字钢截面参数示意图.png)

> 注意：`r1` 表示腿端圆弧半径。程序几何中应理解为翼缘斜内表面与腿端边界之间的圆弧过渡，而不是把整个翼缘当成普通矩形后简单做四角倒圆。

---

## 3.3 参数定义

| 参数 | 含义 | 建模作用 |
|---|---|---|
| `h` | 截面总高度 | 工字钢上下外表面总距离 |
| `b` | 腿宽度 / 翼缘总宽度 | 控制横向总宽 |
| `d` | 腰厚度 / 腹板厚度 | 控制中间腹板厚度 |
| `t` | 腿中间厚度 | 不是恒定翼缘厚度 |
| `r` | 内圆弧半径 | 腹板与翼缘内表面的根部圆角 |
| `r1` | 腿端圆弧半径 | 翼缘斜面与腿端之间的圆角 |
| `slope` | 翼缘内表面斜度 | 国标工字钢为 `1:6` |

---

## 3.4 为什么不能按 H 型钢建模

错误模型通常是：

```text
上翼缘：矩形
腹板：矩形
下翼缘：矩形
```

这种模型等价于假定翼缘厚度处处等于 `t`。

但国标工字钢中：

- 外翼缘表面基本水平；
- 内翼缘表面按 `1:6` 倾斜；
- 靠近腹板处更厚；
- 越靠近翼缘端部越薄；
- `t` 仅表示指定中间位置处的厚度。

因此工字钢必须采用“**斜直线 + 根部圆角 + 腿端圆角**”联合构造。

---

## 3.5 1:6 斜度定义

定义斜率：

\[
m=\frac{1}{6}
\]

对应斜面与水平面的夹角：

\[
\alpha=\arctan\left(\frac{1}{6}\right)
\]

即：

\[
\boxed{\alpha\approx9.4623^\circ}
\]

这意味着沿水平方向向外移动 `6 mm`，翼缘厚度理论上减少 `1 mm`。

---

## 3.6 `t` 的准确位置

单侧翼缘从腹板边缘伸出的理论长度：

\[
L=\frac{b-d}{2}
\]

标准 `t` 位于这个单侧伸出部分的中间位置。

右侧对应坐标为：

\[
x_m=\frac{d}{2}+\frac{L}{2}
\]

整理得到：

\[
\boxed{x_m=\frac{b+d}{4}}
\]

因此，`t` 并不是在腹板根部测，也不是在翼缘最外端测，而是在单侧翼缘伸出长度的中点处测量。

---

## 3.7 根部厚度和边缘厚度

由于斜度为 `1:6`，从中间测量位置到腹板根部的水平距离为：

\[
\frac{L}{2}=\frac{b-d}{4}
\]

厚度变化量为：

\[
\Delta t=\frac{b-d}{24}
\]

所以，忽略圆角时，腹板根部对应的理论翼缘厚度为：

\[
\boxed{
t_{root}=t+\frac{b-d}{24}
}
\]

翼缘最外端对应的理论厚度为：

\[
\boxed{
t_{edge}=t-\frac{b-d}{24}
}
\]

两端厚度差：

\[
\boxed{
t_{root}-t_{edge}=\frac{b-d}{12}
}
\]

这说明 `t` 只代表中间位置，不可直接拿来生成矩形翼缘。

---

## 3.8 坐标系建议

建议把工字钢截面中心作为原点：

```text
O = (0, 0)
```

并令：

```text
右侧：+X
上方：+Y
```

则：

```text
上外表面：Y = +h / 2
下外表面：Y = -h / 2
右端：X = +b / 2
左端：X = -b / 2
腹板右侧：X = +d / 2
腹板左侧：X = -d / 2
```

由于截面上下、左右均对称，程序实际上只需要精确生成右上 1/4 轮廓，然后关于 X、Y 轴镜像即可。

这是实现上最稳定的方式。

---

## 3.9 右上翼缘内表面支撑直线

定义：

\[
x_w=\frac{d}{2}
\]

\[
x_e=\frac{b}{2}
\]

\[
x_m=\frac{b+d}{4}
\]

在 `x = x_m` 处，翼缘厚度为 `t`。

因此右上翼缘内表面的理论支撑直线为：

\[
\boxed{
y=\frac{h}{2}-t+m(x-x_m)
}
\]

其中：

\[
m=\frac{1}{6}
\]

也可以写成：

\[
y=mx+c
\]

其中：

\[
\boxed{
c=\frac{h}{2}-t-mx_m
}
\]

注意：这个支撑直线并不会完整出现在最终轮廓上，它的两端会分别被 `r` 和 `r1` 圆角截去。

---

## 3.10 根部圆角 `r` 的精确相切关系

根部圆角连接：

```text
腹板竖直边
    ↓
根部圆角 r
    ↓
1:6 翼缘斜直线
```

它不是 90° 四分之一圆。

定义：

\[
m=\frac{1}{6}
\]

\[
s=\sqrt{1+m^2}=\frac{\sqrt{37}}{6}
\]

右上根部圆角圆心为：

\[
\boxed{
C_r=
\left(
 x_w+r,\
 m(x_w+r)+c-rs
\right)
}
\]

圆弧与腹板竖直线的切点：

\[
\boxed{
P_{rw}=
\left(
 x_w,\
 C_{r,y}
\right)
}
\]

圆弧与 1:6 斜线的切点，其 `X` 坐标为：

\[
P_{rs,x}=x_w+r\left(1-\frac{m}{s}\right)
\]

因为：

\[
\frac{m}{s}=\frac{1}{\sqrt{37}}
\]

所以：

\[
\boxed{
P_{rs,x}=x_w+r\left(1-\frac{1}{\sqrt{37}}\right)
}
\]

令：

\[
k=1-\frac{1}{\sqrt{37}}
\]

则：

\[
\boxed{k\approx0.835601}
\]

也就是说，根部半径 `r` 会沿水平方向吃掉大约：

\[
\boxed{0.8356r}
\]

的斜直线理论长度。

切点 `Y` 坐标直接代入斜线即可：

\[
P_{rs,y}=mP_{rs,x}+c
\]

---

## 3.11 腿端圆角 `r1` 的精确相切关系

翼缘外端几何为：

```text
1:6 翼缘斜直线
    ↓
腿端圆角 r1
    ↓
翼缘端部边界
```

对于右上象限，理论翼缘端位置：

\[
x_e=\frac{b}{2}
\]

圆心可写为：

\[
\boxed{
C_{r1}=
\left(
 x_e-r_1,\
 m(x_e-r_1)+c+r_1s
\right)
}
\]

圆弧在斜线上的切点 `X` 坐标为：

\[
\boxed{
P_{r1s,x}=x_e-r_1\left(1-\frac{1}{\sqrt{37}}\right)
}
\]

即：

\[
\boxed{
P_{r1s,x}=x_e-0.835601r_1
}
\]

切点 `Y` 坐标：

\[
P_{r1s,y}=mP_{r1s,x}+c
\]

因此 `r1` 对中间斜直线的水平占用规律和 `r` 完全一致，只是方向相反。

---

## 3.12 `r` 和 `r1` 会不会相交

会。

如果用户允许自由输入参数，那么完全可能出现：

- 根部圆角过大；
- 腿端圆角过大；
- 翼缘宽度过小；
- 腹板过厚；

从而导致两个圆角把中间 1:6 斜直线全部吃光，甚至互相重叠。

单侧理论可用水平长度：

\[
L=\frac{b-d}{2}
\]

根部圆角占用：

\[
k r
\]

腿端圆角占用：

\[
k r_1
\]

因此中间斜直线剩余的水平投影为：

\[
\boxed{
L_{straight}=\frac{b-d}{2}-k(r+r_1)
}
\]

其中：

\[
k=1-\frac{1}{\sqrt{37}}\approx0.835601
\]

所以标准的参数合法性判断应为：

\[
\boxed{
\frac{b-d}{2}>0.835601(r+r_1)
}
\]

如果：

\[
\frac{b-d}{2}=0.835601(r+r_1)
\]

则两个圆弧在理论上刚好相切，中间没有斜直线段。

如果：

\[
\frac{b-d}{2}<0.835601(r+r_1)
\]

则按“两个独立相切圆角 + 中间斜线”的标准构造已经无解，应直接判定参数非法。

---

## 3.13 工字钢参数合法性校验

建议至少包含以下几层。

### 第一层：基础尺寸

\[
h>0,\quad b>0,\quad d>0,\quad t>0
\]

\[
r\ge0,\quad r_1\ge0
\]

并且：

\[
b>d
\]

### 第二层：翼缘端部不能出现负厚度

理论边缘厚度：

\[
t_{edge}=t-\frac{b-d}{24}
\]

必须满足：

\[
\boxed{
t-\frac{b-d}{24}>0
}
\]

否则斜面在到达翼缘端部之前就已经穿过外表面，截面几何失效。

### 第三层：两个圆角不能互相覆盖

\[
\boxed{
\frac{b-d}{2}>0.835601(r+r_1)
}
\]

### 第四层：上下根部圆角不能互相侵入

腹板中间必须保留有效竖直段。

实际应根据根部圆角与腹板的切点位置计算上下切点间距。

如果采用上文的精确圆心公式，上侧根部圆角在腹板上的切点高度为：

\[
y_{rw}=m(x_w+r)+c-rs
\]

由于截面关于 X 轴对称，因此有效腹板直线高度为：

\[
\boxed{H_{web,straight}=2y_{rw}}
\]

应满足：

\[
\boxed{H_{web,straight}>0}
\]

这种做法比简单写成 `h > 2t + 2r` 更准确，因为真实根部还受到 1:6 斜度影响。

---

## 3.14 标准 `r`、`r1` 与实际原材料的关系

GB/T 706-2016 在工字钢规格表中明确说明：

> 表中 `r`、`r1` 数据用于孔型设计，不做交货条件。

因此，软件中不能把标准表中的 `r`、`r1` 当成现场钢材必须精确符合的检测条件。

推荐数据结构：

```text
StandardProfile
{
    h,
    b,
    d,
    t,
    r,
    r1,
    slope
}

MeasuredProfile
{
    actualContour,
    measuredRootRadius,
    measuredEdgeRadius,
    correctionData
}
```

标准模型用于理论编程；实测模型用于真实原材料补偿。

---

# 4. 两种型钢的程序生成流程

## 4.1 T 型钢

推荐生成顺序：

```text
1. 输入 h, B, t1, t2, r
2. 参数合法性校验
3. 建立中心坐标系
4. 生成右半边：
   - 剖分面半段
   - 腹板竖直边
   - 根部 r 圆弧
   - 翼缘下表面直线
   - 翼缘端部竖直边
   - 翼缘上表面
5. 关于 Y 轴镜像得到左半边
6. 闭合轮廓
7. 校验面积、方向、拓扑连续性
```

由于左右对称，只维护半边算法即可。

---

## 4.2 工字钢

推荐只生成右上 1/4 轮廓：

```text
1. 输入 h, b, d, t, r, r1, slope
2. 计算：
   xw = d / 2
   xe = b / 2
   xm = (b + d) / 4
3. 建立 1:6 内翼缘支撑线
4. 计算根部圆角 r 的圆心和两个切点
5. 计算腿端圆角 r1 的圆心和两个切点
6. 检查两个圆角之间是否存在有效斜直线段
7. 生成右上 1/4 边界
8. 关于 X 轴镜像得到右下
9. 关于 Y 轴镜像得到左半边
10. 闭合轮廓
11. 校验面积、轮廓方向、自交、短边和零长度边
```

这种方式比一次性硬编码整个闭合多段线稳定得多。

---

# 5. CAM 软件中的建议数据层级

建议不要把“标准型钢”和“实际材料”混成一个模型。

可以采用三层结构：

```text
ProfileDefinition
    ├─ 标准参数
    │   ├─ h / B / b
    │   ├─ t1 / t2 / d / t
    │   ├─ r / r1
    │   └─ slope
    │
    ├─ NominalGeometry
    │   └─ 由标准参数严格计算得到的理论轮廓
    │
    └─ MeasuredGeometry
        └─ 扫描 / 寻边 / 人工测量得到的实际轮廓
```

这样做有几个好处：

- 型钢库仍然可以保持标准化；
- 不会因为某一批热轧材料的实际误差污染标准规格；
- 切割时可选择名义截面或实测截面；
- 后续做扫描匹配、姿态识别、实际壁厚补偿更加自然。

---

# 6. 不建议的简化方式

## 6.1 T 型钢

不建议：

```text
把剖分面做成热轧圆头
```

也不建议：

```text
自动给腹板底端增加 r1
```

因为剖分 T 型钢的腹板自由端本质上是剖分面。

---

## 6.2 工字钢

绝对不建议：

```text
上翼缘矩形 + 腹板矩形 + 下翼缘矩形
```

也不建议把 `t` 当成全翼缘恒定厚度。

正确结构应该是：

```text
外表面水平
    ↓
端部边界
    ↓
r1
    ↓
1:6 斜直线
    ↓
r
    ↓
腹板竖直边
```

然后利用截面对称关系生成完整轮廓。

---

# 7. 对现有管型库的建议

如果当前系统已经存在：

```text
HSection
TSection
ISection
```

建议不要把传统热轧工字钢直接继承 H 型钢的几何算法，仅修改 `b` 和 `t`。

更合理的是：

```text
SectionProfile
├─ ParallelFlangeSection
│   ├─ HotRolledH
│   └─ HotRolledCutT
│
└─ TaperedFlangeSection
    ├─ HotRolledI
    └─ HotRolledChannel
```

从几何算法角度看：

- H 型钢、剖分 T 型钢属于**平行翼缘体系**；
- 工字钢、传统热轧槽钢属于**斜翼缘体系**。

这种分类比仅按字母外形 `H / T / I / U` 分类更适合 CAM 内核。

---

# 8. 建议的通用斜翼缘几何内核

工字钢和前面分析过的热轧槽钢，本质上存在同一个基础问题：

> 一条斜直线两端分别通过不同半径圆弧与其他边界相切。

因此建议抽一个通用二维算法：

```text
BuildTangentFillet(
    lineA,
    lineB,
    radius,
    expectedRegion
)
```

或者更高层：

```text
BuildTaperedFlange(
    innerBoundary,
    outerBoundary,
    slope,
    rootRadius,
    edgeRadius
)
```

输出：

```text
rootTangentPoint
rootArc
straightSlopeSegment
edgeArc
edgeTangentPoint
```

这样工字钢、槽钢、部分特殊热轧角钢都可以复用相同的“切线圆角”内核，而不是每种管型重复写解析公式。

解析公式仍然应该保留，主要用于：

- 参数合法性预判；
- 单元测试；
- 面积与关键点校验；
- 避免 CAD Kernel 在极端参数下返回错误拓扑。

# 9. 最终推荐参数模型

## 9.1 热轧剖分 T 型钢

```cpp
struct HotRolledCutTSection
{
    double h;      // 总高度
    double B;      // 翼缘宽度
    double t1;     // 腹板厚度
    double t2;     // 翼缘厚度
    double r;      // 根部圆角
};
```

必要校验：

```text
h > t2
B > t1
t1 > 0
t2 > 0
r >= 0
(B - t1) / 2 > r
h - t2 > r
```

---

## 9.2 热轧工字钢

```cpp
struct HotRolledISection
{
    double h;       // 总高度
    double b;       // 翼缘宽度
    double d;       // 腹板厚度
    double t;       // 腿中间厚度
    double r;       // 根部圆角
    double r1;      // 腿端圆角
    double slope;   // 默认 1.0 / 6.0
};
```

必要校验：

```text
h > 0
b > d > 0
t > 0
r >= 0
r1 >= 0

t - (b - d) / 24 > 0

(b - d) / 2
    > (1 - 1 / sqrt(37)) * (r + r1)
```

对于可配置 `slope = m` 的通用实现，最后一个判断应改为：

\[
\boxed{
\frac{b-d}{2}
>
\left(1-\frac{m}{\sqrt{1+m^2}}\right)(r+r_1)
}
\]

这样该内核不再依赖固定的 `1:6`。

---

# 10. 结论

热轧剖分 T 型钢的几何模型比较直接：

```text
恒厚翼缘
+
恒厚腹板
+
两个 90° 根部圆角
+
平直剖分面
```

其核心参数为：

```text
h, B, t1, t2, r
```

而传统热轧工字钢必须按真正的热轧截面处理：

```text
水平外翼缘面
+
1:6 内翼缘斜面
+
根部圆角 r
+
腿端圆角 r1
+
恒厚腹板 d
```

其中最重要的认识是：

> `t` 是腿中间厚度，不是整个翼缘的恒定厚度。

所以对于 CAM 管型库：

- **T 型钢可以归入平行翼缘型材；**
- **传统工字钢必须归入斜翼缘型材；**
- **工字钢不能用 H 型钢模型简单缩窄代替。**
