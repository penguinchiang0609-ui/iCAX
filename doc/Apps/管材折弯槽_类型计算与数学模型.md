# 管材折弯槽：类型、计算方式与数学模型

**版本：2026-09-21｜面向激光切管 CAM / 参数化拆单**

> 本文研究的是“切开部分管壁、保留连接带，再折弯”的槽口，不是钣金刨槽机在厚度方向刨出的 V 沟，也不是折弯机下模。所有三角函数使用弧度，线性尺寸使用 mm。
>
> 证据分为三层：**官方公开参数/公式**、**本文建立的参考几何模型**、**需试样标定的工艺参数**。参考模型可以直接实现，但不等于已经复现某一家软件全部内部算法，也不等于实物工艺已经验证。

## 1. 结论与分类

应把对象分成：**决定折后形状的主体几何、局部释放/定位修饰、多个折弯的组合**。界面可以统一使用 `FoldV`，但内部必须允许不同的几何求解模式，不能把所有商品名称套进一条槽宽公式。

| 层级 | 槽型或结构 | 核心目标 | 计算方法 |
|---|---|---|---|
| 主体 | 尖角 V：对称 / 非对称 | 单个集中转角 | 两个平面、左右半角、实际截面求交 |
| 主体 | 圆角 V | 保留带弯成目标圆角 | 圆弧参考轮廓 + 有限长度折弯 + 展开补偿 |
| 主体 | 左 / 右侧 90° V | 外圆角、内直角 | 四分之一圆弧 + 直切边；左右镜像 |
| 主体 | 包围圆 V | 折后形成指定包围圆 | 最终圆的弧段分配 + 逆向展开 |
| 主体/复合 | 嵌入圆弧、圆弧舌、公母 V | 折后覆盖、定位或插合 | 最终配合轮廓 + 间隙偏置 + 逆变换 |
| 修饰 | 根部圆孔、腰形孔、圆角矩形释放 | 改变根部去除区域 | 基础槽与释放体布尔组合 |
| 修饰 | 底部三槽 / 双桥 / 多桥 | 控制连接带数量与尺寸 | 保留带上的区间布置、桥宽约束 |
| 柔性变体 | 直缝 / U 槽 / 窄缝 | 局部柔性或分布弯曲 | 间隙闭合条件 + 曲率 / 柔性模型 |
| 组合 | 多 V 槽、锯齿槽、圆管分段折弯 | 多小角度形成总转角 | 折线离散、半径基准、槽位反展开 |

市场名称在不同软件中可能重叠。例如，“圆角 V 槽”中的圆弧附加选项，与单列的“嵌入圆弧 V 槽”不一定有相同的轮廓与参数。应根据实际切前几何、折后目标和保留材料辨认，不按名称直接互换。[S1][S3][S5]

**不另分一级类型的内容：**左右镜像、对称与非对称、管材截面 R 角、根部小倒圆角、是否贯穿、壁厚过切、割缝、公母尺寸、微连。它们保留为参数或修饰器，但不能因此取消其各自的约束。

## 2. 本次必须纠正的几何问题

本节修正此前《小管折弯槽口类型与计算方案专题调研.md》（2026-09-13）中的相切圆角假设及左侧90°圆弧方向。

### 2.1 圆角 V 不等于给两条直线做普通相切倒圆角

下面的官方图中，圆弧与斜切边形成尖端；斜切边是所选圆的**径向边**，不是该圆弧的切线。[S1]

![圆角 V 的官方参数示意](https://file.cloud.fscut.com/FvOpPVPlUDTOiJM0TcPMOnwAKl8l)

因此，在本文的等半径闭合参考模型中，圆弧角度应由折弯转角分配：

\[
\alpha_L+\alpha_R=\beta,
\qquad l_L+l_R=R\beta.
\]

不能从“水平线与斜线之间做相切圆角”出发，误写成通用的 \(R(\pi-\beta)\)。二者在 90°时恰好相同，会掩盖错误。将 \(\beta\to0\) 代入，正确参考模型的展开段趋于 0；错误套用的公式却趋于 \(\pi R\)。

### 2.2 左侧 90°槽的圆弧方向

官方示意中，左侧四分之一圆从左下向右上凸入槽内，右侧为竖直切边。[S2][S10]

![左侧90度V槽](https://docs.asteptech.com/assets/%E6%8A%98%E5%BC%AF%E5%9B%A0%E5%AD%90.BDmQG42d.png)

在下文的坐标定义下：

\[
W_{top}=L-R_q,
\]

而不是此前文档给出的 \(L+R_q\)。此前的圆弧支路与图示槽型相反，不能继续用于该模板。

### 2.3 包围圆不等于释放圆孔

“折后形成包围圆”是一个成形目标；“在槽根附近增加圆形去除体”是一个局部几何操作。即使半径相同，也不是相同的槽。[S4][S6][S7]

## 3. 参数、坐标与尺寸基准

### 3.1 角度

定义：

- \(\beta\)：从直管状态开始的目标折弯转角，单弯基础模型取 \(0<\beta<\pi\)。
- \(\Phi\)：折后两段向外延伸的管段之间的内夹角。
- \(\alpha_L,\alpha_R\)：V 槽两侧相对槽深方向的角度。
- \(\gamma\)：切前实际开口角；理想模型中等于 \(\beta\)，工艺补偿后应允许分别保存。

\[
\Phi=\pi-\beta,
\qquad \gamma=\alpha_L+\alpha_R.
\]

例如转过45°，折后内夹角为135°。这是厂商帮助中明确区分的角度语义。[S3][S4]

**编程约束：**界面可输入角度制，求解器内部统一转弧度；三维运动中另保存带符号的转角与有向折弯轴。不要仅保存一个含义不明的 `Angle`。

### 3.2 局部坐标

二维侧视使用 \((x,z)\)：\(x\) 为管轴方向，\(z\) 从槽根参考线向槽口方向。三维的 \(y\) 沿折弯轴。

下文单槽大多将槽根参考线设为 \(z=0\)。这条线是**几何基准**，不自动等于保留壁的真实中性层或瞬时转轴。

方矩管外高 \(H\)，底壁厚 \(t\)，槽根距底部内表面 \(d_i\)，则在底部外表面坐标为0时：

\[
z_0=t+d_i,
\qquad h=H-t-d_i.
\]

若界面使用到底部外表面的距离 \(d_o\)，平行等厚底壁下有：

\[
d_o=t+d_i.
\]

曲面、热轧变厚、局部焊缝与非平行内外壁应从真实截面查询，不能强套此换算。

### 3.3 半径与补偿变量必须分开

| 参数 | 含义 |
|---|---|
| \(R_{section}\) | 管材截面原有的角部半径 |
| \(r_{tip}\) | 切前槽尖局部修圆半径 |
| \(R\) | 圆角 V 的指定成形参考轮廓半径 |
| \(R_c\) | 包围圆目标净空 / 配合半径 |
| \(\rho\) | 选定展开参考层折后的半径 |
| \(R_q\) | 左右90°槽的四分之一圆参考半径 |
| \(K_v\) | 管材切槽折弯经验补偿系数 |
| \(k_n\) | 经明确定义的材料中性层位置比例 |
| \(k_{laser}\) | 激光割缝宽度 |
| \(c\) | 单边配合间隙 |

\(K_v\) 和 \(k_n\) 不应因名称都叫 K 而共用一个数据库字段。

## 4. 尖角 V 槽

### 4.1 解析轮廓

令虚拟尖点为 \((x_0,z_0)\)，则：

\[
x_L(z)=x_0-(z-z_0)\tan\alpha_L,
\]

\[
x_R(z)=x_0+(z-z_0)\tan\alpha_R.
\]

在高于虚拟尖点 \(h\) 的基准层：

\[
\boxed{W=h(\tan\alpha_L+\tan\alpha_R)}.
\]

对称时：

\[
\boxed{W=2h\tan\frac\beta2},
\qquad
\boxed{\beta=2\arctan\frac{W}{2h}}.
\]

左右占用长度分别为：

\[
w_L=h\tan\alpha_L,
\qquad w_R=h\tan\alpha_R.
\]

这些是理想几何公式，不包含真实铰链偏移、回弹或过折。实际根部离中性层较远时，应使用第11节的有限长度或标定运动模型验证。

### 4.2 三维切除体

不用正切的平面表达更适合数值计算：

\[
P_L:\ \cos\alpha_L(x-x_0)+\sin\alpha_L(z-z_0)=0,
\]

\[
P_R:\ \cos\alpha_R(x-x_0)-\sin\alpha_R(z-z_0)=0.
\]

以两平面之间、槽口一侧的区域作为楔形切除体 \(N\)，管材实体为 \(S\)，要求保留的连接带为 \(H_{keep}\)：

\[
\boxed{V_{cut}=(S\cap N)\setminus H_{keep}}.
\]

提取最终实体与切除体的交界得到设计切边。几何上能与任意截面求交，不代表任何截面都具备可制造的保留铰链；还须检查连接区域、局部厚度、开口方向与全过程干涉。

### 4.3 任意拉伸截面

对截面曲线 \(C(u)=(y(u),z(u))\)，将截面代入两平面即可得到：

\[
\Gamma_L(u)=\bigl(x_0-[z(u)-z_0]\tan\alpha_L,\ y(u),\ z(u)\bigr),
\]

\[
\Gamma_R(u)=\bigl(x_0+[z(u)-z_0]\tan\alpha_R,\ y(u),\ z(u)\bigr).
\]

最终只保留切除体边界实际经过的区段。内、外轮廓都需要计算，而不是只在外表面画线。

圆管外半径 \(r_o\)，取：

\[
y=r_o\sin u,\qquad z=r_o\cos u.
\]

于是：

\[
x_{L/R}(u)=x_0\mp(r_o\cos u-z_0)\tan\alpha_{L/R}.
\]

圆柱展开横坐标 \(s=r_ou\)，因此展开切边含有 \(\cos(s/r_o)\)，一般不是平面展开图上的直线 V。

### 4.4 算例

\(H=40,t=1.5,d_i=0.5,\beta=90^\circ\)：

\[
h=38,\qquad W=76.
\]

这里的76 mm是指定外层基准处的名义槽口宽度，不是已经补偿割缝的刀心间距。

## 5. 圆角 V：闭合参考模型

### 5.1 公开关系与模型假设

柏楚公开的补偿关系可用弧度写成：

\[
L=l_L+l_R+K_vt_h\beta.
\]

其中 \(L\) 是槽底展开直段，\(t_h\) 是参与折弯的有效保留壁厚。[S1]

以下建立一个**左右等半径、两侧径向切边、最终共圆**的参考模型。令：

\[
\alpha_L+\alpha_R=\beta,
\qquad l_L=R\alpha_L,
\qquad l_R=R\alpha_R.
\]

则：

\[
\boxed{L=(R+K_vt_h)\beta}.
\]

该简化只对这里明确定义的圆弧模式成立。左右采用不同半径、不同目标曲线或特殊壁厚修整时，不能直接沿用“同一目标圆”的闭合条件。

### 5.2 完整二维坐标

槽底左右端点：

\[
B_L=(-L/2,0),\qquad B_R=(L/2,0).
\]

圆心：

\[
C_L=(-L/2,R),\qquad C_R=(L/2,R).
\]

左圆弧：

\[
\boxed{A_L(u)=\left(-L/2+R\sin u,\ R(1-\cos u)\right)},
\quad 0\le u\le\alpha_L.
\]

右圆弧：

\[
\boxed{A_R(u)=\left(L/2-R\sin u,\ R(1-\cos u)\right)},
\quad 0\le u\le\alpha_R.
\]

两个圆弧向槽口内部凸入，和径向斜边形成尖端。尖端坐标为：

\[
E_L=\left(-L/2+R\sin\alpha_L,\ R(1-\cos\alpha_L)\right),
\]

\[
E_R=\left(L/2-R\sin\alpha_R,\ R(1-\cos\alpha_R)\right).
\]

由尖端向槽口延伸的两条径向直边：

\[
x_L(z)=-L/2+(R-z)\tan\alpha_L,
\]

\[
x_R(z)=L/2-(R-z)\tan\alpha_R.
\]

直边只从各自尖端向上取值，不可向下延伸后替换真实圆弧。

当顶层 \(h\) 高于两侧尖端：

\[
\boxed{W(h)=L+(h-R)(\tan\alpha_L+\tan\alpha_R)}.
\]

对称时：

\[
\boxed{W(h)=L+2(h-R)\tan(\beta/2)}.
\]

### 5.3 为什么该轮廓能闭合

令有效展开层半径：

\[
\rho=R+a,\qquad a=K_vt_h,\qquad L=\rho\beta.
\]

把槽根参考线放在展开层朝圆心方向偏移 \(a\) 的位置。按第11节等曲率运动折弯后，固定侧和运动侧的两个圆心重合，两侧圆弧端点也重合。

这解释了：**补偿改变的是展开长度；切前两圆不是普通的相切倒角，而是折后需要重合到同一参考圆的边界。**

这里 \(a\) 是有效几何偏移。它可由工艺标定确定，不意味着 \(K_v\) 必然具有真实材料中性层比例的物理含义。

### 5.4 非90°算例与回归测试

取 \(R=6,t_h=1.5,K_v=0.62,h=38\)，对称：

| 转角 | 槽底展开直段 L | 圆弧尖端高度 | 顶层槽宽 W |
|---:|---:|---:|---:|
| 45° | 5.442809 | 0.456723 | 31.952477 |
| 90° | 10.885619 | 1.757359 | 74.885619 |
| 120° | 14.514158 | 3.000000 | 125.365410 |

必须测试非90°。只用90°样例验证，无法发现 \(R\beta\) 与 \(R(\pi-\beta)\) 被混淆。

## 6. 左侧 / 右侧90° V

### 6.1 几何与范围

厂商公开的是矩形管、固定90°，外部呈圆角而内部呈直角的模板。[S2]

它不是令普通尖角 V 的 \(\alpha_L=0,\alpha_R=90^\circ\)：这样直接套正切会奇异，也不能得到四分之一圆边。

### 6.2 左手参考模型

设底部圆弧起点为 \((0,0)\)，参考半径为 \(R_q\)。

\[
\boxed{A(u)=(R_q\sin u,\ R_q(1-\cos u))},
\quad 0\le u\le\pi/2.
\]

右侧直切边：

\[
x=L.
\]

同一等曲率展开假设下：

\[
\boxed{L=(R_q+K_vt_h)\frac\pi2}.
\]

这是本文的参考模型推导，**不是厂商已经公开的完整闭式算法**。厂商公开说明了 K 与直段长度的关联，但细节仍需实物 / 输出图纸对照。

当 \(0\le z\le R_q\)：

\[
x_{arc}(z)=\sqrt{2R_qz-z^2},
\]

\[
\boxed{W(z)=L-\sqrt{2R_qz-z^2}}.
\]

所以：

\[
W(0)=L,\qquad \boxed{W(R_q)=L-R_q}.
\]

镜像到右手型可以使用 \(x'=-x\) 后重置定位基准，或在同一包围盒中使用 \(x'=L-x\)。镜像时同时更新固定侧、运动侧、切边朝向和配合侧。

### 6.3 半径并非任意独立输入

若四分之一圆终点恰好接到管材上侧基准层，则 \(R_q=h\)。真实截面圆角、底部位置和过切可能改变有效高度。

客户额外指定其他 \(R_q\) 时，必须增加过渡轮廓或改变目标，不能在同一模板里不加约束地自由设置 \(H,h,R_q\)。

### 6.4 算例

取 \(R_q=28,t_h=1,K_v=0.62\)：

\[
L=44.956191,\qquad W_{top}=16.956191.
\]

顶部开口不是72.956191。后者来自取了相反圆弧支路。

## 7. 包围圆 V

### 7.1 目标与参数

官方“包围圆 V”将半径定义为折后包围圆的半径，并给出 K 对槽底直段长度的影响。[S4]

![包围圆V](https://docs.asteptech.com/assets/%E5%BC%AF%E6%9B%B2%E5%8D%8A%E5%BE%84.CGsqtPGF.png)

若用于包围直径 \(D\) 的圆形零件，径向装配间隙为 \(c_r\)：

\[
R_c=D/2+c_r.
\]

0.1 mm的**径向**间隙意味着直径差0.2 mm；不应与0.1 mm的直径间隙混写。

### 7.2 目标圆的弧段分配

以下是本文的**对称、同半径、完整包围圆参考模型**。

保留带折弯后承担圆心角 \(\beta\)。两侧原有圆弧承担剩余圆周：

\[
\gamma_L+\gamma_R+\beta=2\pi.
\]

对称时：

\[
\boxed{\gamma_L=\gamma_R=\pi-\beta/2}.
\]

90°情况下是：

\[
135^\circ+90^\circ+135^\circ=360^\circ.
\]

与圆角 V 不同：圆角 V 两侧参考弧拼成的是 \(\beta\)，包围圆 V 两侧保留弧拼成的是 \(2\pi-\beta\)。

### 7.3 展开长度与切前坐标

对有效展开层半径 \(\rho=R_c+a\)，取 \(a=K_vt_h\) 作经验初值：

\[
\boxed{L=(R_c+a)\beta}.
\]

不能将两侧的135°弧长相加后当作底部直段的展开长度；底部直段展开的是中间90°弧。

令底部左右端点 \(B_L=(-L/2,0),B_R=(L/2,0)\)，两圆心分别在其上方 \(R_c\)。两侧圆弧向槽外鼓出：

\[
\boxed{A_L(u)=(-L/2-R_c\sin u,\ R_c(1-\cos u))},
\]

\[
\boxed{A_R(u)=(L/2+R_c\sin u,\ R_c(1-\cos u))},
\]

\[
0\le u\le\gamma,\qquad\gamma=\pi-\beta/2.
\]

它们与圆角 V 的正负号及弧角范围不同。

取 \(\alpha=\beta/2\)，两圆弧上端：

\[
E_L=(-L/2-R_c\sin\alpha,\ R_c(1+\cos\alpha)),
\]

\[
E_R=(L/2+R_c\sin\alpha,\ R_c(1+\cos\alpha)).
\]

径向直边为：

\[
x_L(z)=-L/2-(z-R_c)\tan\alpha,
\]

\[
x_R(z)=L/2+(z-R_c)\tan\alpha.
\]

简单模板至少要求：

\[
\boxed{h\ge R_c(1+\cos(\beta/2))}.
\]

还要检查左右材料是否足够、切前拓扑是否连通、保留壁是否被误切，以及三维壁厚与目标圆柱是否干涉。

### 7.4 算例与可信度边界

取 \(R_c=10,t_h=1,K_v=0.62,\beta=90^\circ\)：

\[
L=16.681857,\quad\gamma=135^\circ,\quad h_{min}=17.071068.
\]

单侧保留弧长是23.561945 mm，但底部直段不是两侧弧长之和。

该模型在文中运动假设下可以闭合成圆；尚不能宣称其 K、局部变形和轮廓细节与厂商实现完全相同。真实塑性区是否形成圆、配合间隙是否合格，仍需要夹具和试样校准。

## 8. 嵌入圆弧 / 公母定位

![嵌入圆弧的官方示意](https://docs.asteptech.com/assets/%E5%BC%AF%E6%9B%B2%E8%A7%92%E5%BA%A6.W1Qwe64j.png)

应先确定是“圆弧边覆盖”“舌片进入孔槽”还是“同层轮廓拼合”，然后再生成配对边界。圆角 V 中的附加嵌入圆弧，厂商明确提示可能需要先向管内压入，以便折弯时塞入另一侧。[S3]

### 8.1 在最终状态定义配合

二维装配平面内，公头材料区域为 \(M\)，单边间隙为 \(c\)，母孔目标区域可取：

\[
\boxed{F=M\oplus D_c},
\]

其中 \(D_c\) 为半径 \(c\) 的圆盘，\(\oplus\) 表示 Minkowski 和。

同心圆弧简化为：

\[
r_{female}=r_{male}+c.
\]

矩形公头宽 \(b\) 对应母孔宽 \(b+2c\)，不是 \(b+c\)。深度方向另保存插入深度、底部余量与加工穿透范围。

### 8.2 逆变换回直管

第 \(i\) 个刚性区域折后位姿为 \(T_i\)，最终配合边界为 \(\Gamma_{i,f}\)：

\[
\boxed{\Gamma_{i,0}=T_i^{-1}\Gamma_{i,f}}.
\]

“同一条圆弧”不应直接复制到切前两侧：两侧折后姿态不同，必须各自逆变换。

圆和刚体变换的逆映射仍是圆，但其圆心、所在平面、弧段起止位置会改变。落入可变形保留区的边界则须用该区域的逆变形，而非刚体逆矩阵。

### 8.3 过程约束

除最终间隙外，必须定义折弯 / 压舌 / 插合顺序。若需要舌片先向内弹塑性偏移，单自由度刚体旋转的碰撞模型会错误地判断“必然干涉”；相反，只检查最终状态也可能漏掉中途碰撞。

推荐输入包括：`MaleRegion`、`FemaleRegion`、`ClearanceMode`、`Clearance`、`InsertionDepth`、`PreDeflection`、`AssemblyPath`。

## 9. 释放孔与底部切除

### 9.1 圆孔 / 腰形孔 / 圆角矩形

![释放孔尺寸](https://docs.asteptech.com/assets/%E9%87%8A%E6%94%BE%E5%AD%94%E5%B0%BA%E5%AF%B8.fSaTuFpY.png)

基础去除区域为 \(N_V\)，释放区域为 \(N_r\)：

\[
\boxed{N=N_V\cup N_r}.
\]

圆孔：

\[
(x-c_x)^2+(z-c_z)^2\le r^2.
\]

宽 \(w\)、高 \(l\) 的圆角矩形：

\[
0\le r\le\min(w,l)/2.
\]

**重要：圆孔布尔并集与把 V 尖点替换成相切圆角不是同一操作。**在尖 V 内部构造一个与两边相切的内切圆，再与 V 并集，有可能根本没有增加任何去除区域。需要核对：

\[
\operatorname{Vol}\big((N_V\cup N_r)\cap S\big)-\operatorname{Vol}(N_V\cap S)>\varepsilon_V.
\]

对称夹角内切圆圆心距虚拟尖点 \(q=r/\sin(\beta/2)\) 只是相切构造关系，不能单凭这个式子证明已经形成有效释放孔。

若需要“圆角替换”，应裁剪两条直边、选择正确圆弧支路并重建边界，再检查根部高度与保留材料。

### 9.2 底部三槽与桥宽

![底部三槽](https://docs.asteptech.com/assets/%E5%BA%95%E9%83%A8%E5%88%87%E9%99%A4.C5VVKl9Q.png)

厂商提供的底部切除包含中间槽和两侧槽，可分别设置尺寸。[S6]

保留壁沿铰链方向的有效宽度为 \(B_m\)，中槽长度 \(l_c\)，左右侧槽长度 \(l_s\)。对称、互不重叠、侧槽从边缘向内延伸时：

\[
\boxed{b_{bridge}=\frac{B_m-l_c-2l_s}{2}}.
\]

例如 \(B_m=30,l_c=10,l_s=5\)，每个连接桥名义宽度为5 mm。

一般情形必须使用区间并集：

\[
I_{bridge}=I_{wall}\setminus\bigcup_jI_{slot,j},
\]

\[
B_{remain}=\operatorname{meas}(I_{bridge}).
\]

不要在槽有重叠、角部为曲面或桥数变化时，仍简单相减所有输入长度。

若已经按最终成品切边定义孔槽，并完成割缝补偿，不能再次统一减去一个割缝。只有根据未补偿刀心线估算时，才可近似扣除相邻两刀的半割缝之和。

### 9.3 需要校准的约束

\[
b_{bridge,j}\ge b_{min},\qquad t_{remaining}\ge t_{min}.
\]

\(b_{min},t_{min}\) 不是单靠几何可以决定的常数，须关联材料、壁厚、热影响、搬运、夹具与后续焊接要求。没有连接桥时，应分类为分离零件拼焊，而非一根管连续折弯。

## 10. 直缝、多槽与圆管分段弯曲

### 10.1 直缝不能照搬 V 槽宽度公式

平行槽边的闭合角取决于铰链位置和最先接触的角点。用固定侧边界点 \(a\)、运动侧点 \(b\)、转轴点 \(p\) 的二维模型：

\[
f(\theta)=\left\|p+Q(\theta)(b-p)-a\right\|.
\]

求指定接触对的首次 \(f(\theta)=0\)，并在全部边/面组合中取第一次接触。对于线段和实体，应使用线段/面距离或连续碰撞，而不是仅检测一个点。

该式给出几何接触角，**不是**自由弯曲后在某个载荷下必然达到的角度。长窄缝与柔性区还需要曲率或力学模型。

### 10.2 分布曲率模型

设选定展开参考线弧长为 \(s\)，曲率为 \(\kappa(s)\)：

\[
\theta(s)=\int_0^s\kappa(\xi)\,d\xi,
\]

\[
p(s)=p(0)+\int_0^s(\cos\theta(\xi),\sin\theta(\xi))\,d\xi.
\]

总转角：

\[
\beta=\int_0^\ell\kappa(s)\,ds.
\]

等曲率时 \(\ell=\rho\beta\)。距参考层向圆心偏移 \(v\) 的层，其目标长度为 \((\rho-v)\beta\)，相对参考层少 \(v\beta\)。该关系可以帮助分配多缝的总闭合量，但不会唯一决定槽数、桥宽或成形力。

### 10.3 多 V 槽角度分配

设有 \(n\) 个理想集中折弯，总转角 \(\beta\)：

\[
\boxed{\delta=\beta/n}.
\]

注意：\(n\) 个折弯通常对应 \(n+1\) 段刚性直段。“折弯个数”“波峰个数”“三角形个数”在厂商界面中可能不相同，不宜按截图数量直接对应。圆管圆角 V 的公开图还包含连续锯齿状轮廓。[S8]

![圆管多折弯/锯齿形槽](https://docs.asteptech.com/assets/%E6%8A%98%E5%BC%AF%E4%B8%AA%E6%95%B0.DZHnoHiH.png)

### 10.4 切线折线与内接弦必须区分

**A. 切线折线模型：**以明确选定的铰链参考折线为对象，其直段与半径 \(R_h\) 的目标圆相切。相邻折角间的内部直段长度：

\[
\boxed{p_t=2R_h\tan(\delta/2)}.
\]

起、终点取首末直段与圆的切点时，首末段各长 \(p_t/2\)，第 \(j\) 个槽位：

\[
\boxed{x_j=x_{start}+(j-1/2)p_t},\quad j=1,\ldots,n.
\]

径向最大外凸误差：

\[
\boxed{e_t=R_h[\sec(\delta/2)-1]}.
\]

给定误差 \(e_{max}>0\) 的角度离散条件：

\[
\boxed{n\ge\left\lceil\frac\beta{2\arccos\left(R_h/(R_h+e_{max})\right)}\right\rceil}.
\]

**B. 圆周点的内接弦模型：**相邻采样点夹角 \(\delta\)：

\[
p_c=2R\sin(\delta/2),
\qquad e_c=R[1-\cos(\delta/2)].
\]

两套公式各自正确，但描述不同几何。内接弦长不自动等于直管上槽中心的制造间距；其弦数与折角数也不能直接等同。

### 10.5 半径换算与槽间材料

必须保存 `RadiusDatum`：内弯轮廓、管中心线、外弯轮廓、保留壁中性层、虚拟折线顶点圆或相切圆。

例如圆管平面弯曲的简单同心层模型，中心线半径可由 \(R_{center}=R_{inner}+D/2\) 换算；但制造槽位若沿保留壁参考线计量，还需要再按该参考线偏移换算，不能直接使用中心线半径。

在具体的切线折线、平行偏置假设下，外侧参考线与中心线的半径差等于偏置距离；一般截面或非圆弯曲应从最终实体的参考曲线求取。

相邻槽需保留材料：

\[
\boxed{p_i\ge w_{R,i}+w_{L,i+1}+m}.
\]

这里左右槽占用长度来自同一管轴、同一基准层；非对称槽不能统一用 \(W/2\)。最终以三维去除区域之间的剩余材料为准。

### 10.6 算例

明确输入为**铰链参考切线折线的目标圆半径** \(R_h=50\)，总转角90°，6个折角：

\[
\delta=15^\circ,\qquad p_t=13.165250.
\]

\[
e_t=0.431448.
\]

相同角度下的内接弦长是13.052619，但它不是这里的槽位间距。

以 \(x_{start}=0\) 得6个理想槽位：

\[
6.582625,\ 19.747875,\ 32.913124,\ 46.078374,\ 59.243624,\ 72.408874.
\]

若各槽有效深度18 mm，单槽对称 V 宽度为：

\[
W_i=2\times18\tan7.5^\circ=4.739490.
\]

有限长度保留区、角度补偿与实际管壁需要再反展开，不能在上述槽位上无条件重复添加全部折弯补偿。

## 11. 统一运动学模型

### 11.1 集中铰链

点 \(p\) 绕通过 \(p_0\)、单位方向 \(a\) 的轴旋转：

\[
p'=p_0+R(a,\beta)(p-p_0).
\]

Rodrigues 矩阵：

\[
R=I\cos\beta+(1-\cos\beta)aa^T+[a]_\times\sin\beta.
\]

正负角与轴方向必须统一。下文二维 \((x,z)\) 使用从 +x 向 +z 的正转角；若三维坐标采用右手系，其对应轴方向需据此选择。

该模型适合尖角的初步闭合及刚性段运动，不足以表示长度明显不为0的保留带。

### 11.2 有限长度等曲率保留带

以未变形中性/有效展开参考层为 \(v=0\)，\(v\) 朝圆心方向，\(u\) 沿铰链宽度。令参考层弧长 \(s\in[0,\ell]\)：

\[
\ell=\rho\beta,\qquad\varphi=s/\rho.
\]

变形映射：

\[
\boxed{F(s,u,v)=\left((\rho-v)\sin\varphi,\ u,\ \rho-(\rho-v)\cos\varphi\right)}.
\]

在 \(s=0\) 时是 \((0,u,v)\)，与固定直段连续；在 \(s=\ell\) 时，切向转过 \(\beta\)。

二维旋转矩阵：

\[
Q(\beta)=\begin{pmatrix}\cos\beta&-\sin\beta\\\sin\beta&\cos\beta\end{pmatrix}.
\]

运动侧刚性段上，原坐标 \((x,v)\) 变为：

\[
\boxed{p'=\begin{pmatrix}\rho\sin\beta\\\rho(1-\cos\beta)\end{pmatrix}+Q(\beta)\left[\begin{pmatrix}x\\v\end{pmatrix}-\begin{pmatrix}\ell\\0\end{pmatrix}\right]}.
\]

因此有限长度折弯不只是“绕一个固定槽尖旋转”，还包含由两端切点决定的平移。

### 11.3 中间过程

要检查从平直到最终状态，不能在每个中间角 \(\theta\) 都沿用最终半径而任意缩短保留带。若假定保留带长度 \(\ell\) 不变、每一步仍等曲率，应使用：

\[
\rho(\theta)=\ell/\theta,\qquad0<\theta\le\beta,
\]

并取 \(\theta\to0\) 的直线极限。

真实弯曲可能不是全过程等曲率，尤其存在局部折痕或舌片压入时，应替换为标定路径或更详细的变形模型。

### 11.4 数值验证范围

本文对圆角 V 和包围圆参考模型，在30°、45°、90°、120°、150°下做了两侧圆弧端点的位姿闭合数值检查，坐标误差低于 \(10^{-10}\) mm（理想双精度计算）。

这只验证本参考几何与运动方程的一致性，**未进行实体全程碰撞、激光切面仿真、材料有限元或实物试验**。不得将数值精度解释为制造精度。

## 12. 连续平面折弯与空间折弯

### 12.1 模型判定

相邻有效直段单位方向 \(d_i,d_{i+1}\)：

\[
n_i=\frac{d_i\times d_{i+1}}{\|d_i\times d_{i+1}\|}.
\]

近共线段应跳过，不能对近零叉积归一化。若所有有效法向平行或反平行，整条链可作为平面折弯候选；否则为空间链。

### 12.2 变换链

当 \(T_i\) 定义在前一段局部坐标系中时，第 \(j\) 段：

\[
\boxed{G_j=T_1T_2\cdots T_j}.
\]

每个折弯同时保存直段长度、折角、折弯平面 / 转管角、固定侧、运动侧、参考层和补偿模型。不能把后续局部轴误当成始终固定在原始世界坐标中的轴。

在有向法向、方向和角度分支一致时，可用：

\[
\psi_i=\operatorname{atan2}\big(d_i\cdot(n_{i-1}\times n_i),\ n_{i-1}\cdot n_i\big)
\]

表示相邻弯曲平面的转角，并处理直段和反向的特殊情况。

### 12.3 保持原有产品范围

单个槽可改变周向位置，不代表任何多面框架都应提供空间连续折弯。五面防盗窗仍按此前确定的产品范围，不提供空间连续折弯；优先使用平面折弯子框与连接件的组合。

## 13. 从设计切边到可制造刀路

### 13.1 理想切面与机床实际切面

理想的“平面与管壁求交”仅定义设计切边。外表面轨迹为 \(c(u)\)，实际刀轴为 \(a_{tool}(u)\)，贯穿壁厚的切面可用直纹面近似：

\[
X(u,v)=c(u)+v\,a_{tool}(u).
\]

非坡口机床的法向切割，不保证与设计斜平面一致。必须用实际刀轴与真实内外壁验证，不能因外表面线吻合就认定整个壁厚闭合。

对局部平壁、切割射线与局部壁法向夹角 \(\lambda\) 的简化情形，贯穿厚度导致的侧向位移为 \(t\tan\lambda\)。一般情形直接做内外表面求交。

### 13.2 三种不同的补偿

**几何/成形补偿：**决定槽形、保留段长度和根部位置。

**装配 / 焊接间隙：**在最终姿态中按配合面的法向偏置，再逆映射，不能统一向所有槽宽加相同数值。

**激光割缝补偿：**对名义切边在正确曲面/加工平面内偏置半割缝，方向由保留材料与废料侧决定。

\[
\Gamma_{tool}\approx\Gamma_{nominal}\pm\frac{k_{laser}}2\,\nu.
\]

其中 $\nu$ 是位于所选加工曲面切平面内、垂直于切边切向的单位余法向，不是曲面的空间法向。此式只表示局部轨迹偏置；拐角、圆管展开、坡口和变割缝须单独处理。补偿层只能应用一次。

### 13.3 回弹不等于槽角一律放大

可用试样建立：

\[
\beta_{command}=\beta_{target}+\Delta\beta_{springback}.
\]

若槽边已经形成几何硬限位，结构未给过折空间，则不能只让操作员多折一个角度。需连同槽边避让、成形路径或最终焊接定位一起设计。

### 13.4 过切与 K 表必须关联

厂商帮助提示，壁厚过切会改变局部拼合及补偿条件。[S2]

推荐用材料、实测厚度、槽型、半径、根部余量、管截面圆角、焊缝位置、是否过切、设备和夹具作为试样记录的键。

圆角 V 的经验系数可由合格试样反算：

\[
\boxed{K_v=\frac{L_{good}-R\beta}{t_h\beta}}.
\]

这是当前参考模型内的反算，不应跨不同轮廓生成规则混用。

## 14. 统一求解流程和验收

### 14.1 输入到输出

```text
读取真实管材截面与内外壁
  → 建立折弯轴、槽根参考、固定侧/运动侧/保留区
  → 明确最终角度、目标半径与尺寸基准
  → 选择主体几何模式
  → 解析构造或从最终配合状态逆向展开
  → 加释放孔、连接桥、公母、间隙和过切
  → 生成实际切除体并重建边界
  → 按机床刀轴生成贯穿壁厚的加工模型
  → 检查完整折弯路径、最终尺寸及剩余材料
  → 试样标定补偿并重新生成生产数据
```

### 14.2 碰撞条件

对所有不属于同一连续变形区的刚性材料区域：

\[
\operatorname{int}(S_i(t))\cap\operatorname{int}(S_j(t))=\varnothing,
\quad t\in[0,1].
\]

最终允许设计接触，不允许实体相互穿透。舌片有预变形时，必须使用相应路径。

仅在最终90°姿态不碰撞，不能证明整个折弯过程中不碰撞。离散采样是近似检查，应根据最小特征和运动幅度自适应细分；生产要求更高时使用连续碰撞或扫掠包络。

### 14.3 不要把扫掠碰撞体直接当成唯一槽型

若固定侧 A 可切、运动侧 B 不可切，可以在指定可去除窗口内，用 B 的运动扫掠体修剪 A；但两侧都允许切除时，材料去除分配并不唯一。

还需约束保留桥、公母、外观边界、焊接位置和最小材料量。否则“把所有碰撞部分都切掉”可能产生虽然不碰撞、但没有连接或没有承载意义的结果。

### 14.4 参数优化表达

令待解参数 \(p\) 包括槽位、弧半径、展开段长度、释放尺寸、局部偏置等，可采用：

\[
\min_p\;w_D\|D(p)-D_{target}\|^2+w_g\|g(p)-g_{target}\|^2+w_VV_{removed}(p),
\]

约束为全过程无穿透、桥宽与剩余厚度合格、刀轴/切割可达、废料可分离、最终配合拓扑正确。该优化表达用于明确问题，不表示某个通用求解器无需几何构造即可自动解决全部生产问题。

### 14.5 必须覆盖的回归用例

| 测试 | 验证目标 |
|---|---|
| 45°、90°、120°圆角 V | 排除互补角与弧角混淆 |
| 左右90°镜像 | 圆弧支路、顶部宽度、定位基准 |
| 包围圆与释放圆孔 | 排除不同目标共用错误模型 |
| 对称与非对称 V | 左右占用长度与槽位碰撞 |
| 方矩管真实 R 角、圆管、变厚截面 | 实际内外壁切边与连接区 |
| 有 / 无过切 | 补偿表和局部材料变化 |
| 法向切割 / 倾斜刀轴 | 整个厚度方向的真实贴合 |
| 最终与中途姿态 | 排除终态无碰撞但无法折到位 |
| 释放圆完全落在原槽内 | 排除布尔成功但未增加释放材料 |
| 切线间距 / 弦长 / 半径基准 | 排除分段弯曲槽位误算 |

## 15. 建议的数据模型

```text
CutBendFeature
  sectionGeometry                 # 实际截面及来源
  localFrame
  bendAxis / rootDatum
  fixedRegion / movingRegion / retainedRegion
  targetTurnAngle / finalIncludedAngle / cutOpeningAngle
  geometryMode                    # Sharp / Rounded / Side90 / CircleWrap / EmbeddedArc
  handedness
  leftAngle / rightAngle
  targetRadius / radiusDatum
  tipRadius / sectionCornerGeometry
  effectiveHingeThickness / effectiveLayerOffset
  compensationModelId             # 与几何模式绑定
  rootClearance / rootClearanceDatum
  reliefFeatures[]
  retainedBridges[]
  matingProfile / clearanceMode / clearance
  wallOvercut / throughMode
  kerfModel / toolAxisModel
  deformationModel / assemblyPath
  bendChainId / sequenceIndex
  validationStatus / calibrationSource
```

这保留了统一特征入口，又允许内部求解器分模式工作。对于暂时没有试样数据的组合，应明确标注“几何已验证、工艺未标定”，不要自动显示为“可直接生产”。
