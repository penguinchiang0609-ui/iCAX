# 管型模板单入口协议

## 新增程式管型

每包由 profile.json、profile.py 及需要的私有依赖组成。唯一必需的正向生成入口为：

```python
def build(parameters):
    diameter = parameters["width"]
    wall = parameters["wallThickness"]
    if not 0 < 2 * wall < diameter:
        raise ValueError("壁厚必须大于零且小于外径的一半")
    return {
        "width": diameter,
        "depth": diameter,
        "wallThickness": wall,
        "cornerRadius": 0,
        "contours": [
            {"kind": "circle", "radius": diameter / 2},
            {"kind": "circle", "radius": diameter / 2 - wall},
        ],
        "specification": f"圆管 {diameter} × {wall}",
    }
```

宽、高是实际截面尺寸，contours 是二维材料边界。模板在这一次调用中完成参数校验、截面计算和尺寸计算。内部可以调用 shape() 或 model_N.py 等私有辅助函数，但不再要求第二个 contours(profile) 入口。

定式模板仍直接在 profile.json 的 section 字段中保存同结构结果，不执行脚本。两种形式交给相同的下游截面消费者。

## 公共层职责

- profile_package_runtime.evaluate_section 仅调用一次 build，读取并复制结果中的 contours；缺少轮廓明确报错，不尝试调用旧接口。
- 截面预览、参数图、导出、C++ 拉伸消费同一份结果。
- 产品侧 Profile.contours() 仍可作为框架的“取已有截面”方法存在；它不是模板接口，不重新运行模板。
- 坐标轴交换由公共层对结果副本执行，包含圆心、椭圆参数、线/弧端点和样条控制点。
- 产品侧 clearance 是加工外包络操作：公共层偏置外轮廓，内轮廓保持原样，不修改母材参数，不回调模板。当前解析支持圆、圆角矩形/跑道及凸直线—相切圆弧轮廓；尖角用斜接。不支持的曲线、非凸轮廓等明确要求几何内核偏置，不静默猜测。

## 升级范围

24 个系统包及其几何子模型已移除公开 contours 函数，版本更新为 2026.9.13.6；导入/参数图测试源模板同步升级。独立识别入口不在此次改动范围。

旧脚本仅返回尺寸、依赖 contours 函数取轮廓的包，需要单独迁移并重新打包。没有修改用户工程中已经保存的模板副本，也没有在运行时增加旧接口兼容分支。旧文档中“两函数”的说明以本协议为准。

## 验证

单入口测试检查一次生成、旧回调不被调用、轮廓副本隔离、24 包入口统一和公共坐标/间隙处理。Profile 系列 40 项、市场模板 7 项、端部轮廓 16 项 Python 测试通过；全库原生拉伸、目录求值和多跑楼梯回归通过。

历史原生导入测试仍引用 editable_profile_package.icaxprofile，而当前导入器要求 .ittt，运行该旧测试会在扩展名检查阶段失败，与本次生成入口无关；不能将其记为通过。源码导入测试模板已升级。

补充：防盗窗默认实体测试、Debug 系统目录接口和 24 包浏览器示意图检查通过。全护栏实体交叠检查在该轮测试进程累计运行超过 6 分钟后主动停止，没有得到结论，不计入通过项。
