# 管型反解入口

每个系统管型目录增加 fitting.py，profile.json 声明：

```json
"recognition": {"schemaVersion": 1, "entryPoint": "fitting.py"}
```

正向入口仍为 profile.py 的 build(parameters)，没有新增第二个正向入口。

## 模板职责

```python
def fitting(section, context):
    # 根据完整边界直接测量参数；失败返回 False。
    # context 仅提供 tolerance、geometry 几何查询和 curves 坐标变换。
    ...
```

section 是规范化后的完整解析轮廓数组（外边界及所有内边界），保留输入坐标系。模板自身从几何方向确定姿态并直接推导参数。context 不提供默认参数、正向生成或数值求解器；新增模板不需增加 C++ 或前端管型分支。

失败返回 Python False。成功返回：

```python
{
    "parameters": {...},
    "unresolvedParameters": [...],
    "parameterUniqueness": "not-proven",
    "rotationDegrees": 37.0,
    "rotationUniqueness": "not-proven"
}
```

角度是标准截面坐标系旋转到输入截面坐标系的角度，范围 [0,360)，从截面正法线看逆时针为正，单位为度。不是槽口角度，也不是弧度。

同心圆边界的旋转角不可辨识，标记 non-unique，返回可行代表角度；其他截面也不承诺角度唯一（例如矩形相差 180°的解）。不能将返回的代表解解释为历史建模时唯一的参数。

## 外部调用

使用 profile_package_runtime.generate：

```python
generate({
    "action": "recognize",
    "package": package,
    "section": {"contours": contours},
    "tolerance": 0.001
}, {})
```

保留 recognize / recognize-system / recognize-user 调用协议。调度层返回 results 和 matched，候选包含 rotationDegrees；transform 保留平移及弧度 rotation 字段。反解运行全链路禁止调用 build、evaluate_section、_evaluate 或生成轮廓比较。verification 为 direct-geometric-constraints，不再返回重建验证标志。

候选 parameters 为直接求出的代表解，unresolvedParameters 列出未求出项，不默认补齐；不再返回 representativeParameters。对几何上等价的参数化方式，返回一种可行表示，不声称还原制造历史。

## 当前求解范围与限制

- 24 个系统模板均提供模板自有的直接反解；共享层只做几何查询，不按管型 ID 分支，不进行参数搜索。
- 禁止默认参数猜测以及将输入轮廓写入 materialBoundary 来伪造成功。
- 所有声明子模型经默认／缩放尺寸、旋转平移、反向和分段边界测试；范围见《管型直接反解实现状态_2026-09-13.md》。
- 不是任意 Python 脚本的通用逆运算；各模板仅接受满足自身解析约束的完整轮廓，不满足返回 False。
- 不支持的曲线类型由调度层报告 unsupported-geometry；程序错误报告 error，不伪装成几何不匹配。
- 未穷举全部等价表示，结果 exhaustive 为 false。纯几何不能识别制造来源，旋转对称或参数表示歧义不应伪装成唯一解。
