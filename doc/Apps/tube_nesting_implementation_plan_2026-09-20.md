讨论及更新日期：2026-09-20

用途：供后续 GPT-5.6-sol 或其他开发者按模块直接实施、测试与接入。

状态：四姿态表、连续相位带界求解、表驱动顺序/方向/有限母材求解、CP-SAT 小规模完整模型与动态邻域、TubeDesigner 生产替换、锁定前缀异形端续排、严格零件优先级、识别服务桥接、测试和 1000×10 基准均已实现。当前 BRep 展开桥接只标记 `NumericOnly`，不冒充原始 BRep 残差证书，也不允许该数值谱驱动生产互嵌；这类零件自动使用安全轴向包络。未来识别服务可通过同一 DTO 直接提供 `NativeCertified`。

## 0. 执行摘要与阅读路线

### 0.1 最终决定

完整流程是：

~~~text
最终零件 BRep + 母材截面/可识别的原始壁面 + 已确定的 X 轴
    → 识别母材壁面、加工面及左右端口，保留孔、内壁与厚度信息
    → 原生端口边界参数化/展开，验证二维降维的适用条件
    → 每种端口独立建立按误差自适应的频谱与原曲线索引
    → 每个有向类型对计算正正、正反、反正、反反四个最佳相对姿态
    → 固化节约量、姿态、误差界、工艺版本，生成不可变关系表
    → 初始顺序 + 两方向 DP + 有限长度母材分段
    → 局部/跨母材搜索 + 扰动 + CP-SAT 动态邻域联合优化
    → 独立验证、组合真实位姿、复核几何与工艺、预览/导出
~~~

1. 用户最初的“一维长度 + 四种最佳姿态表 + 约束求解顺序”保留为核心数学模型。绕轴最佳姿态只在配对层求一次，排序层只查表。
2. 本文件同时规定表的生成算法和表下游的求解算法，不再把整个几何前处理排除在方案之外。
3. 几何主路线不默认打散圆弧/NURBS，不按固定角度步长旋转试拼，也不对每个配对反复做完整三维布尔。
4. 频谱只提供紧凑表示与快速运算；真正目标是最小化“最大干涉所需的轴向间距”，不是最大化相关性、也不是仅对齐主谐波。
5. 一套求解器按残差、有效阶数和上下界差自适应。直截断自然便宜，复杂截断自然多花成本；不在业务层按截断类型写三套分支。
6. 约束求解是正式模块：小规模完整模型用于全局精确求解/校验；大规模用快速可行解热启动、动态大邻域重排和必要的界。不是固定每 50 件永久分组。
7. 6000/12000 等母材长度、有限库存、正反向、相邻合法性、每件恰好一次，都必须进入模型。优化实际采购总长/成本，不只优化一条无限长序列。
8. “几何配对在指定误差内最优”“固定顺序分段最优”“完整整数模型全局最优”是三个不同结论，分开记录。
9. 1000 种 × 每种 10 件：几何预处理按类型做，四项表按类型共享；排序仍处理 10000 个实例及其数量约束。
10. 旧锯切核心仍供尚未迁移的其他调用方使用，但 TubeDesigner 生产入口已由本实现直接取代，未设置运行时回退开关；有限库存优先政策仍由产品适配层显式保留。
11. 已排母材不是普通“剩余长度”：锁定前缀保持不动，最后一件作为虚拟前驱，首个新零件继续使用对应的有向四姿态表项；之后与普通序列完全相同。
12. 每种零件持久化 `nestingPriority`，默认 `0`，数字越小越优先。相同数字作为一层联合优化；一层全部排入后，其顺序、方向、绕轴姿态和母材分配转成固定前缀，下一层只能从开放异形端续排或使用剩余母材。某层未全部排入时，后续层不启动。

## 1. 已确认模型与范围

### 1.1 符号

| 符号 | 含义 |
| --- | --- |
| T | 零件类型数，目标规模 1000 |
| q_i | 类型 i 的数量，代表场景为 10 |
| N | 总件数，N = Σq_i，代表场景为 10000 |
| L_i | 类型 i 的最大轴向长度 |
| a、b | 正反向，0 = 正向，1 = 掉头；不是绕轴角度 |
| S(i,a,j,b) | i 在前、j 在后时的已知净节约量 |
| B_t | 母材规格 t 的名义长度，如 6000 或 12000 mm |
| C_t | 母材 t 的净可用长度 |
| c_t | 采用一根 t 母材的目标成本 |

同一件在序列中只有一个正反向状态：不能让它与左邻居连接时为正向，与右邻居连接时又为反向。解决这一点只需两状态 DP，不涉及绕轴搜索。

### 1.2 四种最佳组合：上游求解、下游固定输入

对每个有向类型对存储：

```text
S(i,0,j,0)  正向 i -> 正向 j
S(i,0,j,1)  正向 i -> 反向 j
S(i,1,j,0)  反向 i -> 正向 j
S(i,1,j,1)  反向 i -> 反向 j
```

每项还可带上游计算出的最佳相对绕轴姿态引用。整个排序期间，该项的数值固定；不会因为后面接了第三件而重新计算。

本方案采用相邻可加模型。第 5—10 节负责验证模型适用性并生成关系表；第 11—16 节负责在固定表下决定顺序、方向和母材。排序内核不得调用 `FindBestCutLineMatch`、BRep 运算或绕轴采样函数。每项结果必须说明模型范围、可行性及误差界，不能把未认证的局部试拼叫作最佳值。

若真实调用端暂时没有这张表：先用明确标注的测试表打通内核，并报告缺少生产输入。不能将全零表、任意角度采样结果或未验证的默认值冒充准备好的最佳关系表。

### 1.3 重复件与合法分组

- 两两表按类型存储，不按实例重复建立。
- 实际顺序使用 N 个轻量实例，每个实例包含类型索引和稳定的实例编号。
- 同类 10 件可以散布在任意位置和任意可兼容母材中，不能强制连排。
- 类型合并需覆盖影响长度、四项关系、允许正反向和硬约束的全部属性。仅端头形状相同不够。
- 兼容组可按确实不能混用的材料、截面、规格等硬条件分开；这是物理隔离，不是为了加速固定切成 50 件的小批。
- 同一兼容组必须允许全局交互。局部邻域可以暂时只处理少数母材，但其成员不能永久锁死。

### 1.4 模型成立的条件

- 相对绕轴变换的合法参数域由输入提供，本文件不重新争论哪些管型可以旋转；几何层只须执行真实的变换映射。
- 若可用姿态构成可组合的变换集合，且没有额外的绝对角度/夹具约束，开放链中的相对旋转可逐件组合；无需在求 AB 时考虑 C、D。
- 若另有固定绝对姿态、跨多件耦合工艺、非相邻干涉等条件，必须先证明这些条件已被模型覆盖，否则四项标量表不足以证明整条链有效。不能在排序器中临时改 AB 的表值。
- 对第 6 节的“共同材料纤维上单区间、轴向有序”模型，相邻分离可沿链传递，能证明非相邻不穿透。更一般的形状不能直接继承这一结论。
- “相同型号”不自动意味着二维单曲线模型有效；识别结果有独立准入状态。不满足时保留原生几何并明确 unsupported/requires_general_model，不捏造端口曲线。

## 2. 长度与计费的唯一语义

### 2.1 基础公式

一根母材内的序列 p_1…p_m、方向 a_1…a_m 的占用为：

```text
U = sum(L[p_k]) - sum(S(p_k,a_k,p_(k+1),a_(k+1)))
                                    k = 1 ... m-1
可行条件：U <= C_t
```

没有跨母材节约；每根的首件、尾件不与另一根的零件相接。

例如 L_A = L_B = 3100 mm，S(A,0,B,0) = 250 mm，则 U = 5950 mm，可装入净可用长度为 6000 mm 的母材。

### 2.2 切缝、件间距和端部余量只计一次

新内核使用规范化后的“净节约量”，允许为负值：

```text
netSaving = geometricSaving - pairProcessLoss
usableLength = nominalLength - fixedFrontReserve - fixedTailReserve
```

纯讨论模型中各工艺损耗为 0，netSaving 就是用户说的节约量。实际适配时，上游负责把既有相邻损耗准确折入表中；固定首尾消耗折入可用长度。每项损耗必须有唯一归属，不能同时扣在零件长度、关系表和母材边界上。

`geometricSaving`、`pairProcessLoss` 和归一化版本可作为诊断保留，但热路径只读取 netSaving。不得把“净节约量为 0”解释为禁止相邻；禁止必须有独立标志。

P0 要求首尾预留量不依赖首尾零件的正反向。若调用方存在方向相关的首尾成本或特殊母材端面，不能强行压成常量：明确标记为不受该简化模型支持，或另行实现带首尾状态的分段转移及对应证明、测试。

互嵌节约与可共刀不是同一事实。仅凭正的 saving 不能设置 `CommonCutWithPrevious=true`，也不能推导切割次数或已通过加工验证。

### 2.3 整数精度及单调性

沿用核心 `Length = int64_t`；建议每单位 0.01 mm。表、零件和母材必须使用同一单位及版本。

保守量化：零件长度向上取整；净节约量向下取整，包括负数的数学 floor；净可用长度向下取整。这样不会因量化把超长方案变成可行。返回的最优性若存在，只针对该整数模型。

要求每个合法表项满足：

```text
L_i > 0
S(i,a,j,b) <= min(L_i,L_j)
```

不人为要求 S 非负；负值表示额外间隔。上述上界保证相邻加入新件不会使占用变短，也保证规范化放置的左右边界不倒退。超界项须拒绝或交由上游解释为不同模型，不能偷偷 clamp。

累计长度、成本、数量乘法和不可达哨兵相加必须防 int64 溢出。不可达状态采用独立可达位或带保护的 INF，不能直接对 INT64_MAX 加减。

### 2.4 已排母材的固定前缀与异形开放端

本场景不是把 `remainingLength = B-E0` 当成一根新的平头母材。固定前缀最后一件的
异形端会影响首个新零件能够回嵌多少，因此一根续排母材需要以下状态：

```text
physicalStockInstanceId  // 真实母材唯一 ID
sourceStockTypeId        // 原 6000/12000 等母材行
B                        // 原母材绝对总长
E0                       // 已锁定前缀的绝对末端 usedLength
(q,dq,thetaq)            // 最后锁定零件类型、正反向、绝对绕轴角
tailDeadZone
```

前缀的零件顺序、位置、方向和姿态都是硬锁定值，不进入本轮排列变量。对首个新零件
`(p,d)`，把最后锁定零件看成虚拟前驱，直接使用不可变表项：

```text
S0 = S(q,dq,p,d)
x_start(p) = E0 - S0
x_end(p)   = E0 - S0 + L_p
theta(p)   = normalize(thetaq + deltaTheta(q,dq,p,d))
```

第二个及以后零件继续使用第 2.1 节公式。因合法表项保证 `S0 <= L_p`，新序列的末端
不会退回 `E0` 之前；在本方案的轴向有序/相邻可加前提下，无需让更早的锁定零件再次
参与配对。最终容量约束按绝对坐标检查：

```text
lastEnd + tailDeadZone <= B
```

如果四个首边方向都无合法表项，或开放尾部容量不足，该实物母材本轮不可接续，但
不等于整个订单无解；求解器可选择其他续排实例或新母材。`NumericOnly/Missing` 端口
继续遵守生产安全降级，只能得到不互嵌的平面包络连接。

库存和目标必须避免双计：先从原母材行的有限库存扣除已经锁定的实物，再加入一个
`quantity=1` 的续排实例；该实例的本轮新增采购成本、计费名义长度和“新开母材数”均
为 0。它仍是一个不可复制的物理槽位。多个锁定计划即多个不同实例，不能按同规格
余料合并。

TubeDesigner 返回时按 `physicalStockInstanceId` 将新放置项追加到原计划，保留旧计划
ID 和固定前缀；重新计算合并后的 `usedLength`、`remainingLength`、件数和利用率。续排
结果的首个新放置项允许 `nestedWithPrevious=true`，因为其前驱存在于固定前缀而不在
本轮新放置数组中。

当前支持边界是“开放端由已知锁定计划的最后一件形成”。对于来源不明的任意扫描
余料端面，必须先由识别服务生成一个等价端口类型、方向与绝对姿态，再进入同一机制；
仅给剩余长度不足以严谨计算互嵌，不能默认套用本能力。

### 2.5 严格零件优先级

每种制造零件持久化一个非负整数 `nestingPriority`，默认值为 `0`，允许范围为
`0..1000000`，数字越小越优先。浏览器请求使用字段 `priority`，原生服务必须与零件
实体上的权威值逐项核对；请求值不一致时拒绝求解，避免旧界面或并发修改产生过期结果。

优先级不是目标函数中的软权重，而是严格的分层边界。求解器按不同优先级升序执行：

1. 同一优先级的所有零件仍放入同一个完整顺序、方向、姿态、母材分配问题联合优化。
2. 本层完成后，所有已用母材、零件顺序和姿态立即冻结。
3. 每根尚有余量的母材按第 2.4 节转换为带最后一件端口状态的续排实例；下一层只能
   接在这些开放端之后，或者消耗尚未使用的普通母材库存。
4. 新开母材从有限库存中扣减；不限量母材仍保留。跨层续排始终合并回同一个
   `physicalStockInstanceId`，不能重复计数或伪装成平头余料。
5. 某层出现未排零件时立即停止；所有数字更大的优先级均返回“未启动”，不得越级填缝。

只有一个优先级时直接走原单层求解路径，不引入额外复制和求解开销。多个优先级的
最优性范围明确记为 `strict-priority-fixed-prefix-layers`：每层在已冻结前缀下按本层模型
求优；它不允许后续层反向调整前层，也不宣称跨层联合重排的全局最优。

修改数量或优先级都会使已保存排样任务失效。旧项目没有该字段时按 `0` 迁移；产品拆单、
标准件、冲孔件和导入件都通过同一个制造零件组件获得该默认值，复制到独立下料零件时
必须保留它。

## 3. 新内核数据契约

下面的语义契约已落为 `PairTableSnapshot`、`BuildPairTable` 与 `PairTableSolver::Solve`。TubeDesigner 的 `SolveManufacturingNesting` 只调用该入口；旧 `Solver` 不再是该产品入口的回退路径。

### 3.1 输入

```cpp
enum class Direction : uint8_t { Forward = 0, Reverse = 1 };

struct PartTypeInput {
    std::string typeId;
    std::string compatibilityKey;
    int64_t maximumLength;
    uint32_t quantity;
    bool allowedDirection[2];
};

struct PairEntry {
    bool valid;
    int64_t netSaving;
    uint32_t poseMetadataIndex; // 引用只读元数据，不在此搜索姿态
};

struct StockInput {
    std::string stockTypeId;
    std::string compatibilityKey;
    int64_t nominalLength;
    int64_t usableLength;
    int64_t costUnits;
    std::optional<uint32_t> availableCount; // nullopt=不限；0=不可使用
    // 下列字段非空时表示一根不可复制的已排实物母材：
    std::string sourceStockTypeId;
    std::string fixedInstanceId;
    int64_t initialProcessedEnd;
    std::string initialPredecessorTypeId;
    Direction initialPredecessorDirection;
    double initialPredecessorRotationRadians;
};

struct InstanceRef {
    uint32_t typeIndex;
    uint32_t ordinalWithinType;
};
```

每个实例的业务 ID、订单号可在旁表维护。不要在候选评估的热循环中复制字符串或几何对象。

有向表索引采用一个固定约定并做单测：

```text
state(i,a) = 2*i + a
index(i,a,j,b) = state(i,a) * (2*T) + state(j,b)
```

方向性不可省略。没有契约证明时，不得令 S(i,a,j,b) 等于 S(j,b,i,a)，也不得仅计算/存储半张表。

同类型不同实例的连接需要对角类型块 S(i,a,i,b)。一个实例不能接到自身；两个同类型实例则可以连接。

区分三种状态：

1. 已提供、合法、节约为 0：正常参与求解。
2. 已提供、`valid=false`：此方向组合禁止相邻，但可分到不同母材。
3. 未提供或未完成计算：输入不完整。不得按 0 或禁止连接默默处理。

每张表必须带 `schemaVersion`、长度单位、零件类型定义哈希和工艺配置版本。一次求解锁定不可变快照，禁止后台换表导致同一候选两次评分不同。

表完整性在同一硬兼容组内检查；不同硬兼容组之间不要求生成无意义的连接数据。对于有需求的类型，quantity 必须为正、至少一个方向允许；同一组内类型 ID 和最终实例 ID 必须唯一。库存需满足 `0 < usableLength <= nominalLength`、规范化 `costUnits >= 0`，产品已有的“负值表示使用默认价格”等约定应先在适配层消解，不能作为负采购成本直接进入新内核。

旧接口中的 `MaxParts`、`MaxDistinctOrders` 等附加硬约束若在新请求中存在，必须传递并在每段验证；尚未实现时显式返回 unsupported。不能为了使用简化 DP 而丢弃这些字段。

### 3.2 设置

至少显式提供：

- `objectivePolicy`：见第 4 节。
- `inventoryPolicy`：联合优化，或旧产品有限库存优先。
- `timeBudgetMs`、`maxEvaluations`、`randomSeed`、取消令牌。
- `candidateWidth`：起步可用 32，质量档位可用 64；是工程初值，不是实测最优参数。
- `constructionRuns`、`stagnationPasses`、扰动次数与强度上限。
- `enableMatchSpliceSeed`、独立种子预算及规模上限。
- `constraintMode`：disabled / full_exact / hybrid_lns；CP 时间、建模规模、线程与取消预算。
- `proofPolicy`：只需可行 / 配对误差内最优 / 尝试完整整数模型证明，分层设置。
- 分段 DP 的状态/转移预算，以及有限库存标签预算。
- 可选的已验证 incumbent，用于超时保底；必须匹配本次输入版本。

时间预算涵盖新核心内的候选建立、构造、DP、搜索、复核和结果组装。不涵盖上游节约量生成，且报告时必须分开。

### 3.3 输出与状态

每根输出母材类型/实例 ID、顺序实例列表、方向、选中 PairEntry 引用、占用长度及余料；每个需求的实际完成数量可复核。

状态拆分，不用一个 `optimal` 包办：

```text
solutionStatus: complete_feasible | partial | no_solution_found |
                proven_infeasible | invalid_input | unsupported
terminationReason: completed | time_limit | evaluation_limit |
                   cancelled | state_limit
globalOptimalityProven: bool
fixedOrderSplitOptimal: bool
fixedOrderSplitScope: 当前顺序哈希、库存/目标/模型版本
lowerBound: optional<...>
proofScope: full_model | fixed_order | restricted_neighborhood | none
objectiveComponentsProven: 已证明的字典序目标前缀
geometryValidation: not_run | certified_model | full_geometry_checked | failed
manufacturingValidation: not_run | passed | failed
pairTableHash: 本次锁定表的版本
```

- 固定顺序分段精确，不代表全局顺序最优。
- 搜索没找到完整解，不代表已证明无解。
- 有限库存标签被截断时不能标记精确。
- 部分结果需列出全部未排实例和原因，不能通过漏件降低成本。
- 多兼容组汇总时，任何一组未完成或缺乏证明，不能给整个订单盖全局最优章。
- 未实现合法下界时输出空值，不能把当前最好值或候选子图最优值当下界。

## 4. 有限长度母材的目标函数

### 4.1 独立新内核默认目标

全部需求是硬约束。完整可行方案优先于任何部分方案。完整方案之间采用明确的字典序，而不是未经论证的大权重混合：

| 模式 | 按顺序最小化 |
| --- | --- |
| `MinPurchasedLength`，无报价时默认 | 总母材名义长度、母材根数、总占用长度 |
| `MinPurchaseCost`，有可靠报价 | 总成本、总母材名义长度、母材根数、总占用长度 |

同一种母材时，最小总名义长度等价于最少根数。6000/12000 混用时不能只数根数：若两方案都可行，3×6000 的总长 18000 小于 2×12000 的 24000。

末级“总占用长度”作为当前模型的紧排偏好，不声称等于实际不可回收废料。最大长度之和也不是净材料体积；互嵌存在时，不能以 ΣL/总母材长度冒充材料利用率并输出超过 100% 的结果。

若需要余料价值、切刀数、订单切换等目标，必须提供与所选组合一致的数据及目标定义，并扩展 DP/搜索状态。P0 不自行发明余料货币价值。

### 4.2 旧产品规则不得静默改变

当前 `NestingAdapter.cpp` 已有“先排有限库存，再将未满足需求交给不限量母材”的两阶段规则。这不等于所有原料联合最低成本。

- 接入旧工作流时，默认保留该规则，并输出 `inventoryPolicy=FiniteFirstLegacy`。
- 两阶段各自完成、各自最优，也不自动构成联合问题全局最优。
- 新内核可以提供 `JointCost`，但切换产品业务规则需显式配置/确认，不夹带在算法升级中。
- 旧目标顺序和统计字段继续有版本边界，不用新默认值无声覆盖旧保存的项目。

## 5. 几何前处理：先知道母材和两端，再谈展开

### 5.1 输入、坐标与可信来源

输入是最终用于加工的有效零件 BRep，不是渲染网格。已确定拉伸轴为 X 轴；记录轴线在 YZ 平面的中心/基准、完整局部坐标变换、长度单位、源文件哈希、几何公差与原生 face/edge 身份。

规范化轴向坐标为 x∈[0,L]，L=x_max−x_min。极值须基于原生几何的包围/极值计算，不得只查顶点或显示三角网格；曲线/曲面内部可能有极值。公差影响应保留在长度界中。

母材截面包含外轮廓、所有内轮廓、多腔和材料侧信息：

1. 有模板/物料给出的真实母材截面时优先复用，并核对它确实与最终零件残留壁面一致。
2. 仅有导入 BRep 时，从未加工的轴向壁面直接恢复截面及配准。可以使用已证明未受加工影响的截切位置；不能随便在中点截一次就当作母材。
3. 无足够残留几何、无法唯一恢复时，返回 missing_stock_section / ambiguous_section，并指出所缺信息。X 轴已知不等于截面必然可唯一恢复。
4. 必须识别的是母材截面几何，不必先命名“圆管/方管/某模板”。若调用管型模板反解，必须遵守 AGENTS.md 的直接反解要求，禁止调用正向 build/evaluate 数值搜索来冒充反解。

### 5.2 识别并逻辑剔除原始壁面

母材每条截面轮廓可形成参考拉伸壁面：

~~~text
S_j(s,x) = (x, y_j(s), z_j(s))
~~~

逐个检查最终 face 的支撑曲面、位置、参数范围和材料侧是否属于某个参考壁面，输出 original_skin / machined / uncertain 及证据。曲面可能被建模器表示为平面、圆柱面或等价 B-spline，需采用有公差界的等价判断，不能只依赖曲面类型枚举。

不能仅以 normal·X≈0 判定为皮面：纵向槽侧壁也可能平行 X。不能把所有圆柱面直接归成外皮：孔壁同样可能是圆柱面。

“剔除皮面”只是在分类图中排除这些节点，不删除原 BRep，不丢弃内皮，也不破坏加工面与壁面的公共边来源。

### 5.3 加工面连通分组，不把 Sewing 当作识别器

1. 通过 OCCT TopExp::MapShapesAndAncestors 等建立 edge→face 邻接。
2. 在非皮面上建立共享边的邻接图，用 BFS/并查集得到加工面连通分量。
3. 顶点相触不等于同一个加工端；周期面接缝的双 coedge 不等于两条物理切边。
4. 对有效 BRep，分组直接使用已有拓扑，无须先 Sewing。只有来源确有缝隙、且已确认修复不会改变语义时，才按受控公差单独做修复并保存前后差异。
5. 需要返回“端口 shape”时，可把已分类面组装为 shell/compound；它不一定是闭合 solid。

OCCT 的 Sewing 是拓扑缝合工具，不会判断某组面是左端、右端还是孔；其公差操作不能代替语义识别。[R5]

### 5.4 区分左端、右端、孔和跨端开口

加工面连通组只是候选，不是“一组必对应一端”。可靠分类按母材参考壁面上的材料/缺料区域进行：

1. 在各参考壁面 chart 上收集最终保留皮面的 trim 区域，按原有拓扑和参数曲线构建材料区域；其在有限参考带中的补集是缺料区域。
2. 参考轴向带覆盖 [x_min−margin, x_max+margin]。两侧 margin 位于零件之外，作为左外部、右外部种子；margin 仅用于分类，不计入节约。
3. 周期接缝及相邻 chart 必须连通，不能把接缝误判为切口。
4. 沿二维参考壁面补集传播：只与左外部相连的缺料边界属左端，只与右外部相连的属右端；两者均不连的是局部孔/缺口候选。
5. 同时连到两端的纵向开槽等，标为 cross_end_opening。一个加工面连通组若含多个角色，按边界及区域拆分角色引用，不强塞进 Left/Right 二选一。
6. 不用三维“空气连通性”做这个判定：外部空气通常本来就是连通的。也不按加工面的 x 重心或法向粗分左右。

孔的位置、深度、是否通到对侧，来自最终 BRep 的壁面 trim、内部孔壁与内外皮连接关系；不存在在算法里凭空再“设置一个对冲孔”的步骤。盲孔、对穿孔和端口必须保留各自来源。

若拓扑损坏或壁面区域分类不确定，报告错误/待修复位置；不能凭端口外观猜测后继续认证。

### 5.5 端口输出与厚度保留

对已分类端口，提取“该端加工面与原始皮面的公共边”，并保存：

- 左/右端角色及其加工面集合。
- 外壁、内壁、各腔壁上的切边及 coedge 朝向。
- 连接这些边的加工面，用于厚度方向和局部凹入核验。
- 孔/槽区域、跨端开口、原始 shape、Face/Edge ID。
- 分类公差、无法归类的片段及适用性状态。

已有公共边可直接取出，通常不必再做一次曲面求交。不得只留外圈后丢掉内圈和加工深度。

### 5.6 本层模块契约

~~~text
AnalyzeTubeGeometry(FinalShape, AxisFrame, optional StockSection, Tolerances)
  -> StockSectionGeometry
  -> WallCharts[] + FaceRoleMap + EdgeProvenance
  -> LeftEndRegion / RightEndRegion / InteriorFeatures / CrossEndFeatures
  -> AxialBounds + NativeGeometryRef
  -> status + diagnostics + versionHash
~~~

同类型只分析一次。只要最终几何、截面、轴系或公差改变，后续展开、频谱及相关表项都失效。

## 6. 原生展开与二维模型的严格准入

### 6.1 展开的究竟是什么

展开的是“母材壁面上的截断边界”，不是把任意端面曲面整体摊平。对于参考拉伸壁面，横坐标沿截面轮廓弧长 s，纵坐标沿 X 轴 x：

~~~text
C(t) = (x(t), y(t), z(t)) → (s(t), x(t))
~~~

一般拉伸壁面的弧长展开可保持壁面内的长度；圆管则可用 θ=atan2(z−z_c,y−y_c)，图上按需换成 s=Rθ。运算中角度统一用弧度，不与旧“周长相位 mm”字段混用。

### 6.2 直接利用原生曲线，不默认离散折线

1. 取公共边在对应壁面上的原生 pcurve，如 BRep_Tool::CurveOnSurface；保留参数区间、局部位置变换、边方向和壁面编号。
2. 将壁面参数转换到统一 (s,x) 或 (θ,x)；原参数不保证天然就是弧长或极角，须明确变换。
3. 建立可求值、可求导、可给区间界的组合曲线对象。展开后类型可能变化，例如圆管上平面斜截线变为正弦函数，不能硬标为二维圆弧。
4. 在周期接缝处做参数提升/必要分段，保持连续的角度区间及整数圈数。这里的“分段”是原生曲线/参数分段，不是把圆弧打散成折线。
5. 校验各段端点、朝向、周期闭合、源曲线与 pcurve 的一致性公差。边界相交或重合要保留拓扑，不能靠几何去重误删。
6. 数值积分/FFT 可在后续建系数时采样原曲线，但原生曲线始终是残差认证的依据；采样不替代几何输入。

OCCT pcurve 及接缝接口提供这些基础数据；不会自动输出本方案的端口语义或误差证明。[R6]

### 6.3 圆管的统一朝向约定

规范化后，绕 +X 旋转 φ 采用右手规则，θ'=θ+φ。掉头选择绕 Y 轴旋转 π，并将轴向包围长度规范化：

~~~text
Flip(x,y,z) = (L−x, y, −z)
Flip(θ,x)   = (−θ, L−x)

l_reverse(θ) = L − r_forward(−θ)
r_reverse(θ) = L − l_forward(−θ)
~~~

l/r 分别是头部/尾部轴向边界。不能只交换左右端，也不能用行列式为 −1 的镜像代替真实刚体掉头。实现中保留齐次矩阵与公式的一致性测试。

### 6.4 单周期函数模型准入条件

后续高性能频谱公式针对有证明的二维模型：

- 两件属于同一材料纤维坐标系，旋转变换有正确映射。
- 相互作用的轴向带内，每条材料纤维的占用能由头 l(θ) 和尾 r(θ) 之间的一个区间表达，或有已证明等价的降维。
- 所使用的端函数覆盖所需完整周期、单值且连续；所有壁厚层的分离约束已包含，或已证明可用同一边界代表。
- 允许的轴向放置维持“前件在前、后件在后”的有序语义；不能通过任意穿越或整件套入孔洞改变问题。
- 若省略了中部孔，必须证明它们在所有允许的端部重叠带之外，或者省略不会改变本次最优解；仅“看起来是中间孔”不够。

对厚壁斜截，外壁和内壁边界可能不同；外轮廓拟合再好，也不自动代表全厚度。可采用受证明的有限层/材料分支模型，目标取所有层的最大值；连续厚度上的极值若不能化为有限层，须保留连续变量的严格界，不能抽几层就宣布精确。

一般非圆截面的弧长平移不等于任意绕轴旋转。实际允许变换若恰好对应周期坐标平移，可用频谱相位式；否则按输入变换的真实 chart/分支映射计算，不能以改变角度范围掩盖坐标映射错误。这不改变用户给定的角度参数域。

### 6.5 不满足准入时的明确处置

| 识别结果 | 处理 |
| --- | --- |
| 连续单值、厚度与变换映射已验证 | 进入第 7—9 节同一自适应求解器 |
| 多条受证明的材料分支 | 保留分支；固定姿态取所有分支最大值；证书覆盖每支 |
| 台阶跳变、回勾、多轴向材料区间 | 保留原生分段/完整区域，标记 requires_general_model |
| 母材或端口无法可信恢复 | missing/ambiguous，不生成假的最佳表项 |
| 原生数据拓扑无效 | invalid_geometry，给出具体实体诊断 |

有限连续傅里叶多项式不能以任意小一致误差逼近真正有跳跃的函数。不能无限加阶、忽略 Gibbs 现象或只看均方误差就宣称已认证。[R8]

一般区域问题可另外实现参数空间碰撞/NFP 模型，但不作为本版高性能路线的隐含“万能回退”。其输入须保留孔及厚度，完整处理允许角度和接触边界，另立证明与基准。CGAL 的某个 arrangement/Minkowski 接口存在，不等于已经支持全部原生 NURBS、任意三维厚度与无误差接触。[R9]

若以后实现区域回退，禁止区应按“材料内部相交”定义。闭集 Minkowski 和/正则化布尔可能丢掉恰好接触时的低维可行通道；必须明确接触允许还是要求正间隙，并选用保留相应拓扑的信息结构，不能声称任意多边形布尔自动给出了精确拼接答案。

允许输出经验证的保守“零互嵌/留间隔”可行表项，但必须显式由策略选择，标为 conservative_feasible、最优性 unknown。默认严格最佳表模式遇到 unsupported 就报告，不能静默降级成零表。

## 7. 每个端口独立建立自适应频谱

### 7.1 表示、阶数和数据

对已通过准入的端函数 f(θ)，使用实三角多项式：

~~~text
f_hat_K(θ) = c0 + Σ[k=1..K] (p_k cos(kθ) + q_k sin(kθ))
||f − f_hat_K||∞ ≤ E_K
~~~

K 是最高谐波阶数，不是采样点数，也不是每几度转一次。K=8 有 17 个实系数，K=16 有 33 个。不同零件、不同端口所需阶数不同，不规定所有零件必须 8—16 阶。

原生曲线是事实源，有限频谱通常是带误差的紧凑表示。用正交积分得到的是傅里叶系数；若使用一致误差最小化拟合，仍是同一三角基底，但应标明 fittingMethod，不能混称为精确原曲线。周期函数工具及一致逼近可参考 [R7]，不能直接借用其数值输出作为本项目严格证书。

~~~text
EndProfile:
  nativeBoundaryRef, materialBranchId, periodicMappingVersion
  orientationConvention, sourceTolerance, sourceHash
  levels[]:
    K, c0, p[1..K], q[1..K]
    residualUpper E_K
    derivativeBounds M1, M2
    certificateStatus, certificateVersion
~~~

### 7.2 一套流程自动分配成本

~~~text
从 K=0 开始
    → 建立/复用当前阶系数
    → 对原生边界计算全域残差上界
    → 若已经满足当前所需误差，则缓存该层
    → 否则请求 K=1、2、4、8、16……的下一层
    → 达到资源上限仍不满足则返回未认证/不支持原因
~~~

不得先对所有端口计算 64 阶再删掉小系数来宣称“直截断零成本”。系数少、残差小的端口自然提前停止；平端通常停在常数层，圆管平面斜截通常只有一阶主项，复杂端口按自身误差继续增加。

这是误差驱动的计算层分支，不是业务层识别平端/斜端/复杂端后调用不同算法。允许根据已认证系数做代数化简，但不得以几何类型名称替代认证。

默认系数构造采用原生参数曲线上的自适应积分，统一归一化为：

~~~text
c0  = (1/(2π)) ∫[0,2π] f(θ) dθ
p_k = (1/π)    ∫[0,2π] f(θ) cos(kθ) dθ
q_k = (1/π)    ∫[0,2π] f(θ) sin(kθ) dθ
~~~

不必先把曲线反解成密集点：对按 θ 正向覆盖周期的原生段，代入 f(θ)=x(t)、dθ=θ'(t)dt，逐段积分 x(t)·cos(kθ(t))·θ'(t) 等。转向点先按原生参数分段，翻转参数方向时同时调整积分上下限，接缝不重复积分。复用积分节点的原生求值和谐波递推，按需增算新阶。

数值积分产生的系数只是候选；第 7.3 节针对实际存储系数验证原生残差，因此积分误差也会反映到残差里，不能再重复扣同一误差。若另用系数区间表示，计算链须一致地传播该区间。

FFT 可作为后续可插拔候选系数生成器，但要处理混叠并沿用同一原生残差验证。频谱尾能量、均方误差或有限检查点只能作为选阶线索，不能证明未采到的位置没有尖峰。

### 7.3 对原生曲线给出全域残差界

对某段原生边界参数 t∈[a,b]，定义：

~~~text
R(t) = x(t) − f_hat_K(θ(t))
θ'(t) = (y(t) z'(t) − z(t) y'(t)) / (y(t)^2 + z(t)^2)
R'(t) = x'(t) − f_hat_K'(θ(t)) θ'(t)
~~~

这里 y、z 已减去轴线中心。圆管壁面半径远离 0；不能在分母可能跨 0 的区间直接使用该式。

实现一个 NativeCurveBounds 服务：

1. 直线/圆锥曲线使用解析区间式；B-spline/NURBS 按 knot span 转为可界定的 Bézier/rational Bézier 段，保留原曲线而非折线。
2. 用控制包围、区间有理运算和导数界取得 x、y、z 及一阶/必要二阶导数的包围；分母含 0 或无法界定时细分/报告，不输出假界。
3. 对区间中点 t_c、半宽 w，可用：
   sup|R| ≤ |R(t_c)| + w·sup|R'|。
   较宽时细分参数区间，必要时用二阶 Taylor 界。
4. 对所有原生段完整覆盖，取最大残差上界；接缝、结点、导数不连续点分别处理。
5. 把源曲线/pcurve 一致性误差、几何公差、系数与求值舍入纳入界。相同误差不得重复计入，也不得漏计。

使用带向外舍入的区间运算或经验证的等价包围实现。普通 double + std::sin 后加一个任意 1e−9 不是数学证书。若某 CAD 曲线类别尚无可信 Bounds 实现，应明确 unsupported_certificate；可以做数值候选，但不能对它返回 certified。

若已认证较高阶 K_h，则较低阶可复用：

~~~text
E_K ≤ E_Kh + Σ[k=K+1..K_h] sqrt(p_k^2 + q_k^2)
M1 ≤ Σ k sqrt(p_k^2 + q_k^2)
M2 ≤ Σ k^2 sqrt(p_k^2 + q_k^2)
~~~

M1/M2 是当前多项式导数界，不能混当原生曲线导数界。不要用未计算的频谱尾部假设代替原生残差验证。

### 7.4 误差预算及发布规则

分别配置 nativeTolerance、profileResidualBudget、fixedPhaseGap、pairOptimalityGap，统一为轴向长度单位；角度仅决定姿态，不用“角度够细”替代长度误差要求。

例如最终要求配对长度差≤0.01 mm，只是可配置示例，不保证每个源 BRep 的公差足够支撑。原始几何不确定度已经超过预算时必须报告，不通过多加阶制造虚假的更高精度。

每层频谱不可变；升级生成新层/新版本。已发布表锁定使用过的证书版本，不允许另一个线程原地修改系数或 E_K。

## 8. 四个最佳相对姿态的数学定义

### 8.1 单个方向组合的目标

A 在前、B 在后。把选定方向的 A 尾函数记为 f=r_A，B 头函数记为 g=l_B。B 的轴向起点为 d，相对旋转为 φ：

~~~text
A 的尾位置：f(θ)
B 的头位置：d + g(θ−φ)

无穿透要求：f(θ) ≤ d + g(θ−φ)，对全部材料纤维成立
D(φ) = max_θ [ f(θ) − g(θ−φ) ]
D* = min_{φ∈Ω} D(φ)
geometricSaving* = L_A − D*
~~~

Ω 直接使用输入的允许角度域，可以是周期区间的并集或离散集合。多材料分支时，内层最大值还要覆盖所有经过验证的分支；不能只看其中一个。

有序包围区间模型要求 d≥max(0,L_A−L_B)。在完整规范化单区间模型下该性质应由几何自然满足；求解时可以加入这一经过证明的物理下界。工艺间距按第 2 节独立规范化；若工艺是法向距离/刀具包络而非简单轴向损耗，须在几何层正确建模，不能随意减一个常数。

四个组合分别求解 A+/B+、A+/B−、A−/B+、A−/B−，返回各自可行角度、轴向间距和最优性差距；不是从四组中挑一组后丢掉其余三组。

### 8.2 “频谱对频谱”如何计算

复数记法 f_hat=Σ a_k exp(ikθ)，g_hat=Σ b_k exp(ikθ)，则：

~~~text
g_hat(θ−φ) 的系数 = b_k exp(−ikφ)
H_φ(θ) = f_hat(θ) − g_hat(θ−φ)
H_φ 的系数 = a_k − b_k exp(−ikφ)
D_hat(φ) = max_θ H_φ(θ)
~~~

构造差谱只需 O(K)；计算最大值和外层最佳 φ 仍需求解，不是做一次系数相减就已经得到最佳节约。采用相位递推、连续数组和缓存，避免为每个 k 重复调用昂贵的三角函数。

若 ||f−f_hat||∞≤E_A、||g−g_hat||∞≤E_B，令 E=E_A+E_B，则对所有 φ：

~~~text
D_hat(φ) − E ≤ D(φ) ≤ D_hat(φ) + E
~~~

因此固定角度 oracle 返回 D_hat∈[d_lo,d_hi] 时，d_hi+E 是安全放置上界；不是直接用 d_lo 或拟合峰值放置。

### 8.3 主谐波和相关性只用来找候选

候选来源包括强共同谐波的全部等价相位、全频相关函数的局部峰、允许域边界、已知好相位与局部改进。第 k 阶的对齐候选为：

~~~text
φ_m = (arg(b_k) − arg(a_k) + 2πm) / k，m=0..k−1
~~~

零幅值没有可靠相位。候选最终必须落在 Ω 内并由真实目标的带界计算复核；它们只改善上界，不能排除其余角度。

反例：

~~~text
f(θ)=2cosθ+cos2θ
g(θ)=2cosθ−cos2θ
φ=0：max(f−g)=2
φ=π/3：max(f−g_shift)=1.5
~~~

两者主谐波在 0 对齐，完整相关函数也在 0 取最大，但 φ=π/3 的最大干涉更小。可加常数以满足物理坐标规范化，不改变这个相位比较。必须把该例固化为测试。

### 8.4 简单谱的自然退化与解析标尺

常数谱不依赖 φ；残差已达到预算时无需外层相位搜索。

单谐波 f=c_A+ρ_A cos(θ−α_A)，g=c_B+ρ_B cos(θ−α_B)，在完整周期允许域上：

~~~text
φ* = α_A−α_B
D* = c_A−c_B + |ρ_A−ρ_B|
~~~

它可以作为统一求解器的解析回归标尺及经系数验证的代数优化。受限角度域必须检查可行对齐点及各区间边界。不能仅因零件名叫“斜截断”就套公式忽略残差、内壁或加工特征。

## 9. 不按固定角度扫描的带界求解算法

### 9.1 固定相位：求全周最大值

输入当前 f_hat/g_hat、φ 和内层容差，先建立差谱 H。保留对 θ 的完整区间覆盖，用最大堆管理各段上界：

~~~text
对 J=[m−w,m+w]：
U_J = H(m) + |H'(m)|·w + 0.5·M_θ·w²
M_θ ≥ ||H''||∞，可由 Σ k²·差谱幅值 给出

d_lo = 已评价点 H 值的最大下界
d_hi = max(d_lo, 所有未排除区间的 U_J)
~~~

以端点、中点、上次活跃点和数值驻点作候选，提高 d_lo。若 U_J≤d_lo，可丢弃该段；否则二分最高上界段。直至 d_hi−d_lo 达标，返回区间及接触点 θ_j。

求根/区间 Newton 可加速驻点定位，但完整区间覆盖必须保留，不能只找到几个局部峰就返回“全局最大”。有限三角多项式也可转代数驻点问题，需处理周期接缝、重根及恒等常数；首版不依赖每次完整高次求根。

所有上/下界均需包含求值舍入；多分支分别覆盖再取最大。

### 9.2 相位区间下界：用少量接触点约束整段角度

对于 I=[φ_0−r,φ_0+r]，记 t=φ−φ_0。从当前/父区间选择少量 θ_j；近最大接触点有利于收紧界，但任意点都能给合法下界：

~~~text
v_j = H_{φ0}(θ_j)
s_j = g_hat'(θ_j−φ0)
M ≥ ||g_hat''||∞

D(φ0+t) ≥ max_j(v_j+s_j·t) − 0.5·M·t² − E
L_I = min_{|t|≤r} [max_j(v_j+s_j·t) − 0.5·M·t²] − E
~~~

这里相位一阶导数为 +g'，不能写错符号。

计算 L_I 不需要角度均匀扫描：若干直线的上包络减去同一个二次项，每个上包络片段上是凹函数，最小值在片段端点。因此检查 I 两端及上包络折点即可。首版可枚举所有有效直线两两交点（接触点数 J 时 O(J²)），多检查非活跃交点不影响正确性；后续可用有序上包络优化。

这几条直线是相位下界的证明工具，不是把管材圆弧离散成折线。对接近并行线、交点坐标及 v/s 的不确定度必须做保守区间处理；可用统一误差 ν≥δv+r·δs，再从下界减去 ν。不能用未经包围的浮点交点声称严格下界。

可进一步取 max(L_I, 合法物理下界, 其他已证明下界)。接触点不全只会使下界较松，不会使正确下界失效。

### 9.3 全局分支定界与自适应加阶

~~~text
SolveOrientedPair(A_end, B_end, Ω, epsilon, budget):
    校验几何模型/版本，选择当前最便宜的已认证谱层
    用允许相位和安全间距建立可行上界 U，保存 pose
    计算强谐波/相关性候选，用固定相位 oracle 改善 U
    用区间并完整覆盖 Ω；周期接缝处拆开，不遗漏端点

    while 未取消且有预算:
        对保留相位区间计算/更新 L_I
        GlobalLower = min(U, min_I L_I)
        若 U−GlobalLower <= epsilon: 返回 certified_epsilon_optimal

        取 L_I 最小的区间 I
        若 L_I >= U: 安全剪枝
        否则：
            在下界模型建议点/中点尝试改善 U
            若拟合残差主导差距：请求更精确谱层
            若固定相位最大值区间太宽：细化内层
            否则：二分 I，保留整个允许域覆盖

    返回 best_feasible、已知 gap/界、终止原因
~~~

允许离散角度域时逐个合法值使用固定相位 oracle，可按合法下界剪枝；不能擅自把连续 Ω 改成离散角度网格。

频谱升级后的残差、系数、接触点及区间界必须使用一致版本。旧界如确实仍界定同一原生问题可继续保留，否则重新计算；不混用新版系数和旧版残差。并行缓存升级采用发布新对象，不原地覆盖。

建议起步预算规则：令最终 ε 为目标，先争取 E_A+E_B≤ε/8、固定相位 oracle 的多项式上下界差≤ε/8，其余交由外层真实 U/L 差控制。未满足时优先升级对残差贡献较大的端口；加阶后若界未改善，继续细化原生残差区间或报告预算耗尽。这个比例只是可调初值，最终认证条件始终是 U−L≤ε，不能用“各参数已经设置好”代替检查。

活动区间从队列取出到完成剪枝/分裂期间，仍须计入 GlobalLower。取消或预算中断时将它放回，或把其下界与队列一起汇总；不能漏掉尚未处理完的区间而虚报差距闭合。

初始安全间距可在纯几何有序模型中用 d=L_A，代表无轴向互嵌；工艺有额外间隔则另加。若无合法角度或整件不兼容，应返回 forbidden，而不是数值失败。

### 9.4 返回什么，才算“找到了最佳姿态”

~~~text
PairPoseResult:
  typeA, dirA, typeB, dirB
  phaseRad, relativeTransform, axialShiftSafe
  shiftLowerBound, optimalityGapMm
  geometricSavingSafe = L_A − axialShiftSafe
  certifiedModelId, sourceHashes, profileVersions
  status: certified_epsilon_optimal | best_feasible |
          conservative_feasible | forbidden | unsupported | failed
  terminationReason, elapsed, evaluationCounts
~~~

若 U−L≤ε，则当前姿态的安全间距 U 比原生已建模最优间距至多多 ε，损失的节约量至多 ε。这里 ε 同时包含内层、拟合与舍入误差，不是只看某个角度区间宽度。

仅最小化近似谱到差距 σ，通常只能推出原问题安全损失≤σ+2(E_A+E_B)；直接维护原问题 U/L 可以避免遗漏这项。源几何公差与模型降维误差另须按契约纳入。

机器角度量化、变换落地和长度量化后，必须重算该实际角度的安全间距/误差界。不要将未量化 φ 的证书直接贴到已舍入角度上。物理角度单位、周期和零相位明确写入元数据。

### 9.5 高性能与严格性同时成立的边界

- 快在多数配对能用低阶谱、少量活跃点和较紧下界提前结束。
- 任意复杂曲线、近似平坦的多峰目标或极小容差仍可能产生大量细分；没有统一微秒级最坏情况保证。
- 本算法已在 `PairPoseTable.cpp` 中实现并接入产品；它是项目自研的带界组合，不是照搬某篇论文的现成代码。常数谱和解析谐波已有永久测试，复杂真实端谱仍需持续扩充独立参考数据集。
- 一次最终三维碰撞通过只证明那个候选可行，不能补回一个不合法降维模型丢失的全局最优性。
- 在原生单区间模型准入和数值包围均完成前，可以输出“数值估计”，不得输出 certified。

## 10. 表生成、并行与几何模块接口

### 10.1 两阶段流水线

阶段 A 按类型并行：读取不可变最终几何 → 截面/壁面识别 → 端口原生展开 → 准入验证 → 端谱初始层。正反向尽量由同一已验证几何变换派生，不重做四次导入。

阶段 B 按有向类型对并行：读取两个类型的端谱 → 对四种方向调用统一配对器 → 工艺规范化 → 保守整数化 → 发布表。每个任务可包含一小块类型对以摊薄调度开销，不能一线程只处理一个固定业务订单组。

1000 种最多 4T²=400 万项，其中同类型不同实例使用的对角块必须保留。兼容组分离后实际项数是 Σ4T_g²；不能为了少算而合并不等价的几何或直接丢掉跨类型连接。

### 10.2 线程与缓存规则

- 每个工作线程使用私有计算工作区；只读原生数据、只读已发布谱层及只读配置。
- OCCT 对象延迟缓存、适配器和具体调用是否可并发必须逐项核实；不能把共享 shape 指针“const”视为所有下游操作线程安全。预热、私有适配器或隔离副本按实际 API 选择。
- 频谱加阶按端口缓存键合并请求，使用单次构建/发布，避免 1000 个配对同时重复为同一端口算高阶。
- 缓存键至少包括几何/截面哈希、端口角色、材料分支、坐标约定、源公差和算法版本。配对缓存还包括方向、Ω、工艺模型和误差要求。
- 不同长度的零件可以复用真正相同的局部端形状计算，但必须验证归一化偏置、厚度、角度域等完全等价；不能仅因为低阶系数相近就共用最佳表项。
- 单个零件改变只失效其端谱及所在类型的入边/出边；数量改变但类型几何不变，不重算配对表。
- 表生成、CP-SAT 和多起点搜索共用总线程预算；禁止每个外层工作线程再各自开满 CP/几何线程造成过量并发。
- 保存每阶段真实进度及错误统计；超时未算的项为 missing，不能默认为 forbidden 或 0。

### 10.3 热数据与诊断数据分离

排序热路径只读取净节约、合法位及姿态索引。位姿、几何证书、上下界、接触点和来源哈希放在冷存储，支持按表项查询。

单项需要显式区分：已认证近最优、仅可行、真正禁止、不支持、尚未计算。只有策略允许且已验证可行的项能进入生产快照。质量不同的表允许使用，但必须在输出声明质量等级，不能统一改名“四项精确最佳表”。

一次排序锁定完整快照。若后台精化得到更好的表，新表只能触发一次明确的新求解；不能修改正在运行的评分。

SolveConstraintNesting(table, scope,
                       incumbent, ...)  -> ConstraintSolveResult
ValidateNestingPlan(plan, snapshot)      -> ModelValidationReport
ReconstructAndValidateGeometry(plan)    -> GeometryValidationReport
~~~

接口是新增模块建议，不声称这些函数已存在。几何层不直接操纵 UI，排序层不持有可变 BRep，约束层不在线调用配对器。没有生产端谱时可用显式测试表开发下游；没有严格误差服务时不能用一个空 certificate 字段绕过准入。

## 11. 初始顺序：借用匹配拼接，但不冒充经典最优

### 11.1 经典与通用版本的边界

经典 Euler-Splice 利用特定端头标量代价结构求解，不能直接把任意四项表替换进去并保留原证明。

通用 Match-Splice 可以作为启发式种子。但一般表的拼接代价可能在合并后变化，因此不能盲目沿用一次算好的静态最小生成树和旧拼接值。需要更新代价，或明确采用能始终构造合法序列的启发式拼接流程。

“输入是矩阵”本身不是不适用证据：矩阵可能刚好具有特殊结构；若要启用经典精确分支，必须有受验证的结构识别器和证明范围，不能拟合近似端投影后声明精确。

### 11.2 P0 必须有的轻量种子

实现至少两类可运行种子，并用同一套真实评分比较：

1. 长件优先的多起点构造，以当前表项、方向与库存实际可行性选择追加/插入位置。
2. 高节约连接优先的链合并：每件初始为一条链，连接可兼容链的端点，保证实例不重复、方向一致且不提前封闭成不可输出的子环。合并后更新链信息。

第二类只是借用了“匹配、拼接”的构造思想，不等于论文完整 Match-Splice。不能在诊断里用经典算法名称冒充实现。

候选按类型和方向建立，选择时映射到仍可使用的实例；同类件耗尽必须更新候选。允许多个固定随机种子和稳定的 tie-break，以获取不同初始顺序。

最终每个初始顺序都要经过分段器和完整可行性验证。连接节约最多的长序列，不一定得到最少母材。

### 11.3 论文 Match-Splice 种子的接入条件

将其作为可插拔策略，不阻塞基础版本发布：

- 使用真实四项表，不以投影近似替代。
- 无向端点匹配要求对应的反向一致性，例如 S(i,a,j,b) = S(j,1-b,i,1-a)，还要正确处理方向禁用。不能对不满足的输入强行对称化。
- 对不满足无向表示条件的输入，使用独立实现的有向一致构造，或跳过该种子。跳过不是输入无解。
- 完整匹配、接环和拆环必须覆盖每个实例恰好一次；最终输出是一条或多条合法开放序列。
- 超过种子预算时回到已有种子；匹配构造失败不能升级成全局不可行结论。
- 不在 10000 件上默认建立 20000 个端点的稠密完整匹配图。
- 若采用稀疏候选匹配，标明其启发式范围；不能用它的最优值作完整问题界。
- 作者代码先用于验证和对照；任何源码引入需核实许可、依赖及商业分发条件。

选择种子的依据是“同样总时间后的母材成本和解质量”，不是只看初始顺序节约多少。

## 12. 固定顺序的最佳正反向：两状态 DP

给定某一段顺序 p_i…p_j。定义 D[k][b] 为截至 k、最后一件方向为 b 时的最小占用长度。

```text
D[i][b] = L[p_i]                         若该方向允许，否则不可达
D[k][b] = min_a {
    D[k-1][a] + L[p_k] - S(p_(k-1),a,p_k,b)
}                                       只允许合法表项
U(i,j) = min(D[j][0], D[j][1])
```

保存前驱方向即可回溯。复杂度 O(4m)，m 为该段件数；不回溯时工作内存 O(1)，回溯为 O(m)。

禁止把相邻四项分别取最大后直接相加。例如 A、B、C 各长 100：

```text
AB 的四项为 [[10,0],[10,0]]：B 正向才能省 10。
BC 的四项为 [[0,0],[10,10]]：B 反向才能省 10。
```

独立取最大会假报节约 20；固定 A-B-C 顺序的真实最优仅节约 10，占用 290。该案例必须成为单元测试。

这与绕轴无关：只是在选择中间零件唯一的正反向状态。

## 13. 不限库存时，固定顺序的精确分段

### 13.1 前提

本节只在以下条件同时成立时声称固定顺序精确：

- 每个实例恰好出现一次，顺序已固定。
- 相邻代价按本文件模型可加，表与零件方向规则固定。
- 首尾固定消耗已规范化到 C_t。
- 母材规格可不限量使用，成本对每根可加。
- 附加约束为空，或可被每段的完整可行性判断准确表达，且不会破坏两状态 DP 的充分性。
- 不因性能预算跳过合法分段、截断标签或限制最大件数。

若还有方向相关的加工成本、夹持状态或其他历史约束，不能只保留“末件方向下的最短长度”再事后过滤；须扩展 DP 状态/非支配标签或交给第 16 节完整建模。仅件数、该段订单集合等与内部方向选择无关的约束，可在枚举段时维护。

### 13.2 递推

令 F[j] 表示前 j 件的最优目标向量，F[0] = 零向量。对每个 i < j，若 U(i,j-1) <= C_t，则允许用一根 t 装下连续段 [i,j)。

```text
F[j] = lexicographic_min over (i,t) {
    F[i] + stockContribution(t, U(i,j-1))
}
```

例如默认目标下：

```text
stockContribution = (B_t, 1, U(i,j-1))
```

有报价时在最前面增加 c_t。记录前驱 i 和母材类型 t，可回溯全部母材边界。回溯出的每一段再执行一次第 12 节 DP，恢复方向与选中关系表项。

精确性来自：任何固定顺序的合法排样，都能写成若干连续段；最后一段必然对应某个 i 和 t。递推检查所有这些情况。两段之间没有节约，因此方向可分别求最优。

### 13.3 推荐实现，不存全量段矩阵

```text
F[0] = zero
for i = 0..N-1:                    // 前缀拓扑序
    if F[i] 不可达: continue
    初始化以 i 为首件的两个方向长度
    for j = i..N-1:
        若 j > i，按两状态递推加入 p[j]
        若两个方向都不可达: break
        used = 两个方向长度最小值
        对每个满足 used <= C_t 的母材规格松弛 F[j+1]
        若 used > 所有可选母材的最大 C_t: break
```

最后一条提前结束依赖第 2.3 节的单调性。若后续扩展模型破坏单调性，必须删除或重证此剪枝。零增量连接合法，不能因“通常每根只装几十件”硬设精确算法窗口。

最坏时间 O(N²(4+K))，K 为可用母材规格数；工作内存 O(N+K)，不计输入表及输出。实际可按每个起点能容纳的后续件数截断；但若大量连接的增量为 0，仍可能接近二次复杂度。

若主动设段长上限或因时间停止，只能称为受限解码/启发式解码，不得设置 `fixedOrderSplitOptimal=true`。取消时返回先前已完成并验证的 incumbent，而不是未完成 DP 的半成品。

### 13.4 为什么还需要外层顺序搜索

以全部节约量为 0、6000 母材为例：

```text
顺序 3600,3600,2400,2400：连续分段最少需要 3 根。
顺序 3600,2400,3600,2400：分成两段，每段 6000，只需 2 根。
```

分段器对第一条顺序求得精确答案 3，不能由此证明整个问题最优为 3。允许跨根改变顺序后，才能找到 2。

## 14. 有限库存与混合库存

有限“长度”和有限“数量”是两个不同约束。6000 长度有限，并不说明该规格只有有限根；接口须分别表达。

### 14.1 小规模有限库存：带资源计数的分段标签

固定顺序下，以以下状态扩展第 13 节：

```text
(prefixIndex, usedCountOfFiniteType1, ..., usedCountOfFiniteTypeK)
```

一次分段转移消耗相应规格的一根。无限规格不增加资源维度。状态保存目标向量和回溯信息。

同一前缀，若标签 A 的资源用量逐项不多于 B，且目标向量不劣于 B，则在当前非负、可加目标下 B 可被支配删除。真实单根余料应有独立身份；不能将端部条件不同的余料当成同一池合并。

只有完整搜索这些状态、且剪枝保持正确时，才可声称固定顺序有限库存分段精确。状态规模可能按 ∏(Q_t+1) 增长，必须配置预算，不承诺与不限库存同样快。

### 14.2 大规模有限库存：可行计划 + 库存账本 + 联合修复

生产级主搜索始终维护库存账本：

- 已使用真实母材不能重复计数。
- 移除、重排一批母材时，先将它们的数量归还到局部可用账本。
- 候选方案先在临时账本中验证，接受时原子提交，拒绝时全部回滚。
- 使用局部带库存标签、最佳插入、交换、整根清空与重插等方法寻找改进。
- 不限库存 DP 可作候选生成/松弛，但其结果必须经库存修复，才能成为 incumbent。
- 标签预算耗尽或修复失败只说明该次尝试未成功，不是已经证明无解。

不能把“先求无限库存最优，再删掉超库存的母材”作为输出。不能把有限料不足部分默认为允许购买同规格无限料，除非输入确实提供了这一选择。

### 14.3 当前接入状态

有限库存、混合 6000/12000、停用规格和不限量规格均已进入新路径。核心 `PairTableSolver` 支持联合库存优化；TubeDesigner 为保持既有业务规则，先解有限库存，再把真实剩余需求送入不限量阶段。两阶段并存时不会报告整单全局最优。库存不足时保留可验证的部分方案，且区分“已证明不可行”和“预算内未找到完整解”。

## 15. 顺序改进与扰动

### 15.1 快速局部改动

首版实现：单件 relocate、两件 swap、短连续段 relocate，以及跨母材的对应操作。每项都要处理首尾、相邻位置和同类型不同实例。

固定当前方向，将 X 从 A-X-B 移到 C-D 之间时：

```text
deltaSaving = S(A,B) + S(C,X) + S(X,D)
            - S(A,X) - S(X,B) - S(C,D)
```

首尾用边界哨兵处理，在基础模型下相应 S = 0；不能引入跨母材虚构节约。该公式用于互不重叠位置；相邻/重叠位置必须专门处理或用去重后的受影响边集合计分。

可尝试 X 的两种方向。但“只查几个表项”的复杂度仅对未改变其他件方向及内部顺序的局部变动成立。若重新优化整段方向，需要重新执行 DP；不得仍宣称其代价是常数。

禁止直接套对称 TSP 的 2-opt 两端公式：一般有向表下，反转整段会改变内部边及方向。P0 可以先不做整段反转；若做，必须完整计算或实现经过验证的正向/反向段摘要。

### 15.2 两层评估，避免每个候选都全局分段

1. 在当前可行多根计划上，候选先检查受影响边、受影响母材的长度和库存。
2. 对有希望的候选，精确重算受影响母材的方向 DP 和目标向量。
3. 周期性、较大扰动后、或发现边界改善机会时，将计划串成全局顺序并执行完整分段。
4. 接受结果前重新验证母材容量、数量和目标；分段可让原本不同母材的零件重新组合。

“节约量增加”只是候选优先级，最终接受标准必须是第 4 节的完整目标。可在主目标相等时接受紧排改进；不能为了多省一点局部长度，接受实际母材采购成本更高的最终 best。

局部改善停滞不代表最优；也不能因为纯局部过滤没看到收益，就永远不做全局重新分段。

### 15.3 跨母材邻域

至少覆盖：

- 从一根移一件到另一根的任意可行插入位置。
- 两根之间一对一交换，并重新优化这两根的方向。
- 清空一根母材，尝试把全部零件重新插入其他母材，以减少开料数量/成本。
- 拆解若干当前母材，保留其所有实例，联合重排、重选 6000/12000 等规格。
- 至少一种允许较大结构变化的短段移动或二换一邻域，避免只有单件移动。

母材集合由搜索动态选择；同一实例可在不同迭代进入不同邻域。不得把这种动态邻域实现成永久的 50 件分块。

### 15.4 候选表与探索

按类型/方向选取高潜力后继和前驱，建议初始 K=32，另加同类连接、边界候选和少量多样性候选。候选不足时构造器需要扩大搜索，不能把“候选里没有”当成“全表没有”。

候选集合可以随停滞扩大、刷新或混入低评分边。只看节约最大的边，可能错过更好的容量组合。候选限制不能支撑全局最优声明。

### 15.5 扰动与 best 保留

```text
best = 已验证的最好完整方案
current = best
while 有预算且未取消:
    current = 局部改善(current)
    如满足触发条件，执行全局重新分段/有限库存修复
    独立验证 current
    若 current 比 best 好，替换 best
    若停滞，扰动 current，再修复和改善
return best
```

扰动允许临时更差，但不能覆盖 best。完整可行性不满足的中间状态只允许存在于修复器内部，不向用户发布为可用方案。

对于不限库存且每件单独可装入的基本模型，可先构造“一件一根”的合法保底计划，再逐步改进。有限库存不存在这个可行性保证，不能照搬。

## 16. 约束规划：完整模型、热启动与动态大邻域

### 16.1 求解器职责与使用模式

采用 OR-Tools CP-SAT 作为首选离散求解后端；所有长度、节约、费用使用第 2 节的整数契约。API 及状态参考官方资料 [R10]。它只决定顺序、方向和母材，不求连续绕轴角度。

提供三个明确模式：

| 模式 | 范围 | 可给出的结论 |
| --- | --- | --- |
| full_exact | 当前完整兼容组，全部实例、合法边、母材选择和硬约束 | 完整求解并证明时为该整数模型全局最优；超时给 incumbent 和合法界 |
| hybrid_lns | 固定其他母材，动态解放若干母材/实例，联合求解 | 当前邻域的改进或邻域最优，不是全局最优 |
| disabled | 使用 DP 与快速搜索 | 可行最好解，除独立已证明子问题外无全局证明 |

完整模型是开发 oracle 和可选精确路径，不默认在 10000 件上构造全稠密模型。大规模生产默认 hybrid_lns + 快速搜索。模型规模限额触发时明确返回 model_size_limit 或切换到已配置的启发式模式，不假称完成精确求解。

### 16.2 索引与变量

以下是可直接实现的“每根母材一条路径”模型。实例 p=1..N，方向 a∈{0,1}，母材槽位 k=1..M，规格 t；每个槽位有一个虚拟节点 0。

~~~text
u_k                   Bool：槽位 k 是否启用
z_kt                  Bool：槽位 k 选择规格 t
x_pka                 Bool：实例 p 放在 k 且方向为 a
h_pk                  Bool：实例 p 是否放在 k，h_pk=Σ_a x_pka
z_pqk                 Bool：p 在 k 上直接接到 q，p≠q，p/q 都是真实实例
e_paqbk               Bool：上述边使用方向 a、b
start_pk, end_pk       Bool：0→p、p→0
loop_pk               Bool：p→p，表示 p 不在 k 上
loop_0k               Bool：0→0，表示该母材未启用
U_k                   Int：母材 k 的实际占用
~~~

方向禁用时不建对应 x/e 或固定为 0；不兼容实例/规格、forbidden 表项同样不建合法边。不同实例共享同一类型的 S 值，但实例身份和需求不能省略。

M=N 总能表示任何由非空母材构成的完整方案。可按经过证明的主目标成本界进一步缩小 M，但不能无条件取“当前最好解的根数”：混合规格最低成本方案可能使用更多根便宜短料。成本含 0 时，基于最小正成本的根数界尤其不可直接套用。任意人为缩小 M 必须标为受限模型。

### 16.3 每件恰好一次、母材规格和库存

~~~text
对每件 p：Σ_{k,a} x_pka = 1
对每个 p,k：h_pk = Σ_a x_pka，h_pk 为 Bool
对每根 k：Σ_t z_kt = u_k
对每个 p,k：h_pk ≤ u_k
对每根 k：u_k ≤ Σ_p h_pk ≤ N·u_k

有限库存 t：Σ_k z_kt ≤ availableCount_t
停用规格 t：z_kt = 0
~~~

仅允许该根规格兼容的实例，例如不兼容时 h_pk+z_kt≤1。已有单根库存/余料身份不可复用，需独立规格/身份槽或额外身份选择约束，不能当作无限同质料。

每根最大件数可写 Σ_p h_pk≤Σ_t maxParts_t·z_kt。最大订单种类用 orderPresent_ok 与 h_pk 的 OR 等价关系计数，不能只用单向约束导致订单数被假置为 0。其他未建模硬约束必须拒绝，而不是在结果里备注一下。

### 16.4 路径、方向一致性和禁止子环

对每根 k 建一个 circuit：

- 节点 0 的自环取 loop_0k=1−u_k。
- 每个真实节点 p 的自环取 loop_pk=1−h_pk。
- 加入 start_pk 对应 0→p、end_pk 对应 p→0。
- 每对 p≠q 只加入一条图弧 z_pqk，不能为四种方向重复加入同一图弧。
- 关联 Σ_{a,b} e_paqbk=z_pqk，e_paqbk≤x_pka，e_paqbk≤x_qkb。
- start_pk≤h_pk、end_pk≤h_pk；非法组合没有 e。
- 使用 C++ AddCircuitConstraint / AddArc 等对应 API，按锁定依赖版本验证名字和语义。[R11]

当 u_k=1 时，虚拟节点不能自环，所有被分配节点必须和它处于同一条非平凡环；删掉虚拟节点后就是一条开放路径。未分配节点各自自环。

这一步同时保证每个被选件一个前驱/后继，并排除与母材起点脱离的 A→B→C→A 子环。仅写“入度=出度=1”没有这个保证，零增量/零长度推进也不能用来偷偷排除环。

x_pka 只有一个被选方向，所以同一件作为前边的后件、后边的前件时方向相同。不允许分别取 AB、BC 的最大节约来绕过一致性。

### 16.5 长度与目标

~~~text
U_k = Σ_p L_type(p)·h_pk
      − Σ_{p≠q,a,b} S(type(p),a,type(q),b)·e_paqbk

0 ≤ U_k ≤ Σ_t C_t·z_kt
~~~

虚拟节点连接没有节约；不同母材没有跨根节约。由于第 2 节的有序/单调长度条件，U_k 与沿路径重建的末端坐标一致。不要直接对最大长度包围区间用 NoOverlap：真实互嵌本来就允许这些区间重叠。

目标采用第 4 节字典序：

~~~text
MinPurchasedLength:
  C1=Σ B_t z_kt
  C2=Σ u_k
  C3=Σ U_k

MinPurchaseCost:
  C1=Σ c_t z_kt
  C2=Σ B_t z_kt
  C3=Σ u_k
  C4=Σ U_k
~~~

实现顺序优化：先最小化第一项；只有该项已证明最优，才固定它的最优值并求下一项。前项超时只得到可行值时，可以固定当前值进一步改善后项，但必须记录“前项未证明”，不能声称整个字典序最优。也可实现经过上界证明且不溢出的权重编码，默认不采用随意大权重。

整组全局最优要求完整图、完整合法槽位/规格、全部硬约束、未被截断的需求、全部目标层的证明。禁用允许非零相对/绝对 gap 就提前报 optimal 的配置；检查实际目标界与整数精度，不能只看一个状态字符串或大整数转 double 后的等号。

### 16.6 热启动、对称性与性能控制

1. 第 11—15 节先给已验证方案，将分配、方向、边、规格等作为 AddHint。Hint 是提示，不是硬固定；不能因为锁死初始顺序而阻止求解器改进。[R11]
2. 同质可交换母材槽可用 u_k≥u_(k+1) 等消除槽位置换；有身份/余料差异的槽不能这样合并。
3. 完全相同实例可增加可证明安全的序号对称约束，但不能强制它们连排。带不同订单/加工属性的实例不再完全等价。
4. 建模时间、求解时间、变量/弧数量、峰值内存分别计量；求解前就要检查预算，不能先申请巨大图才报告超限。
5. CP-SAT 的 wall time、确定性工作预算（若选用）、线程数、随机种子和停止请求显式管理。不能在 UI 线程同步阻塞。
6. 稀疏候选边可用于加速受限求解，但该图的最优值通常是完整问题的上界候选，不是完整问题的下界。
7. 完整有向实例边已经是 O(N²)，带每根槽位的简单模型可达 O(MN²)，四个方向再乘常数。类型表仅 400 万项，不意味着 CP 变量也只有 400 万。

例如 N=10000 时，即便不乘母材槽位，四方向有向实例候选已约 4 亿项。因此本模型默认服务可控规模的完整精确求解和动态局部重优化；不能承诺把全量稠密模型交给通用求解器即可很快证明最优。

### 16.7 大规模动态 LNS：约束求解如何实际提速

~~~text
输入：全局已验证 best、同一不可变表、库存账本
循环：
    按余料、弱连接、昂贵母材、难放实例或多样性选择若干根
    取出这些根的全部实例，保留实例身份，不丢需求
    固定其余母材，将被取出母材的库存归还临时账本
    为解放实例建立上述 CP 模型：
        可改变所有顺序、方向、连接、分根和规格
        使用“全库存减去固定部分”的可用库存
        可以启用新的允许规格和槽位，不限于原先这几根
    将原局部排法作为 hint，在独立短预算内求解
    合并回固定部分，独立验证完整计划与库存
    若完整目标改善，则原子提交 best；否则不覆盖 best
    更换/扩大邻域或回到快速搜索/扰动
~~~

邻域按模型规模和实际耗时自适应，成员每轮可变化。可以从少量母材开始，但这不是固定每 50 件独立排一次，也不是牺牲跨组交互的永久分组。需要有跨根、跨长度组合和扩大邻域机会，否则不能减少母材根数。

LNS 内的 OPTIMAL 仅表示“其余方案固定时、本次所建邻域内最优”。固定部分的代价作为常量加入评估。邻域库存不足、无改善或超时不等于整单不可行。

### 16.8 状态、下界与精确验证

- 完整模型 FEASIBLE：有可行解，未证明全局最优。
- 完整模型 INFEASIBLE：只有在所有需求、边和母材范围完整且无临时改进限制时，才能推出该模型无解。
- “要求比 incumbent 更好”的模型 INFEASIBLE：可用于证明没有更好解，但不能把已有可行订单标成不可排。
- UNKNOWN/超时：保留已验证 incumbent；没有 incumbent 则 no_solution_found。
- 局部/候选子图模型的界和最优状态只标记该范围，不能展示为整单全局差距。
- 任意快速下界必须是已证明的松弛；尤其不能直接用 ΣL/母材长，因为它忽略互嵌。

正式测试以 N≤7 的完整排列、方向、断点和规格枚举作为独立 oracle（规模按组合数控制），比较 CP、DP 及验证器。所有优化后的稀疏化、对称约束和槽位裁剪先过该 oracle，再用于生产。

## 17. 全流程调度、快照与可复现性

### 17.1 从最终几何到排样

~~~text
锁定最终零件、母材与工艺配置版本
    → 几何缓存命中检查；必要时识别、展开、准入验证
    → 按需建立/升级已认证端谱
    → 生成/复用四姿态配对，明确 missing/unsupported/质量等级
    → 完整表与工艺规范化通过后发布不可变快照
    → 按真实硬兼容条件分组，建立类型索引与实例引用
    → 构造可行保底/多初始顺序，按库存策略分段与修复
    → 根内/跨根快速搜索、扰动、周期性重新分段
    → hybrid_lns 约束重排，或独立 full_exact 模式
    → 统一目标维护已验证 best
    → 独立查表模型验证、方向回溯、真实位姿重建
    → 按证书范围复核几何及加工条件
    → 只发布与当前输入版本一致的结果、状态与分阶段耗时
~~~

排序期间不重新计算绕轴角度。若前处理无法完成生产表，报告具体缺项；可继续独立测试下游，但不能用测试表发生产加工结果。

### 17.2 预算与取消

分别设置 geometryBudget、pairTableBudget、orderingBudget，并在 orderingBudget 内设置 constraintBudget 子预算；还可设总墙钟上限。CP 的建模/求解同时消耗子预算和排序总预算，不通过重置子任务计时绕过总限额。报告不能将预计算分钟数隐藏在“排样只用一秒”之外。

取消检查进入原生段细分、配对区间队列、表任务批次、候选循环、段枚举、库存标签和 CP 停止接口。不可中断的第三方调用要隔离并限制使用，不能阻塞 UI 的取消响应。

未完成表项只存可恢复中间状态或明确的已验证可行结果，不标为最优。排序取消只返回已完成验证的 incumbent，不发布正在修复的半成品。

### 17.3 可复现与过期结果

固定输入/算法版本、种子、工作预算、线程模式时提供可复现测试模式。仅相同墙钟预算不能保证跨机器或不同线程调度得到相同顺序。

并行多起点使用独立随机流与稳定 tie-break；CP 内部并行结果应按实际支持程度声明，不承诺任意线程数下位级一致。所有候选最终按同一目标向量比较，不能因完成先后覆盖更好的结果。

UI 进度区分识别、端谱、配对、初始排样、快速搜索、约束重排、验证。几何有效性、最优性差距和已排件数展示真实状态。输入改变立即废弃旧任务发布权，缓存的可复用部分由版本键判断，不恢复过时结果。

## 18. 结果重建与验证器

### 18.1 坐标及姿态引用

在本文件的归一化长度模型中，令母材前预留为 front：

```text
x_first = front
x_next = x_previous + L_previous - S(previous,dirPrevious,next,dirNext)
end_i = x_i + L_i
```

最后一个 end 加尾预留不得超过名义长度。重算占用须与 ΣL-ΣS 一致。正节约可能造成轴向包围区间重叠，这是模型允许的互嵌，不要因区间重叠一律拒绝。

输出选中的方向和 PairEntry 的姿态元数据引用。实际相对变换到产品 TRSF 的解析/组合交给上游契约对应的适配层，首件基准姿态也由该契约给出；不能在排序器里根据角度数值“猜”矩阵。元数据缺失或版本不匹配时，不输出声称可直接加工的虚构位姿。

### 18.2 独立验证器必须检查

- 每个实例恰好一次，需求数量全匹配，无未经授权超产。
- 同一件只有一个正反向，且方向允许。
- 每个相邻表项合法且版本正确；不同母材之间无节约。
- 每根容量、兼容键及库存数量/身份合法。
- 全量重新求和与增量计分完全一致。
- 目标向量可从最终结果独立重算。
- 位姿引用、顺序与表索引一致。
- 任何“精确”“最优”“不可行”的状态都有相应范围与证据。

几何有效、加工有效、数学模型可行分别标记。排序核心不能仅凭表计算完成就声称已验证碰撞、共切或 NC。

### 18.3 实际刚体姿态重建

在第 6 节的圆管/已验证相位映射约定下，每根首件选择合法基准相位 ψ_1。选中相邻表项后：

~~~text
ψ_(k+1) = ψ_k + φ_pair(k,k+1)  (mod 2π)
x_(k+1) = x_k + L_k − netSaving(k,k+1)
WorldTransform_k =
    StockFrame · TranslateX(x_k) · RotateX(ψ_k) · CanonicalFlip(dir_k)
~~~

CanonicalFlip 包含第 6.3 节的长度规范化平移，不能在 adapter 中再次掉头。净节约与几何节约之差形成工艺间距；不要在构造变换时又减一次工艺损耗。

该简式只在表约定支持相位相加时使用；其他 chart/截面变换用表的真实变换组合规则。首件绝对相位/夹具限制未纳入输入时，不声称满足这些未建模条件。

### 18.4 几何与工艺验证的边界

模型验证器独立全量重算，不调用构造器的缓存分数。几何验证器核对所用端模型证书、实际量化姿态、变换组合、零件在母材中的位置、厚度/材料分支与接触约定。

对于未由单区间模型证明的整链关系，使用轴向包围区间索引筛选实际可能相交的实体，再做相应原生几何校验；必须包含可能相遇的非相邻件，不能只检查链边。失败时不能仍输出“可加工”。也不能只删一条边就声称已正确解决全部全局姿态耦合。

刀具可达、割缝/热影响、夹持、共刀、加工顺序及 NC 属工艺验证，只有这些规则确实进入输入并经过验证才能置 manufacturingValidation=passed。排样成功不等于自动生成了可执行刀路；本方案不要求重写机床或 NC 模块。

## 19. 性能设计与今天已有的证据

### 19.1 数据规模

T=1000 时，2T=2000 个方向状态，稠密有向表共 4,000,000 项。当前 `PairEntry` 为 16 字节，四百万项的容量约 61 MiB；状态、`int64` 节约量和姿态索引都在其中。姿态元数据为冷数据，构建后对完全相同的记录做有界去重。

N=10000 的实例不能扩成 400,000,000 项的方向表；仅 int64 就约 3.2 GB。类型共享是必须项。

热数据优先连续数组；姿态元数据分离为冷数据。输入不可变，候选评估不分配大对象、不复制全量表，不在内层做字符串查找。

重复数量有利于复用表和候选，但不意味着 10000 件可以简单压成 1000 个各访问一次的节点。高重数精确建模如需进一步研究，必须保留访问次数与方向的一致性。

### 19.2 本机实测只覆盖局部内核

2026-09-20 曾在 Intel Core Ultra 9 275HX、Windows、MSVC `/O2` 上运行独立 C++ 微基准：1000 类型、10000 实例、400 万项 int64 随机表；逐件 relocate，尝试被移动件的两种方向，其他件方向不变。

| 一轮候选宽度 | 候选位置评估次数 | 中位耗时 |
| --- | ---: | ---: |
| 32 | 319955 | 8.98 ms |
| 64 | 639880 | 16.69 ms |
| 遍历全部位置 | 99980001 | 857.65 ms |

另测固定顺序、仅计算最优值的两方向 DP：39996 次状态转移，平均约 0.062 ms；不含方向回溯。

重要限制：上述是随机候选、合成表、单轮局部操作的吞吐测试，不是 LKH，不是完整排样，不含构造、全局分段、有限库存、几何输入、UI 或收敛质量。不能据此宣传“10000 件全局最优 1 秒完成”。

原微基准位于工作区 `tmp/order-search-benchmark-4244716814e54ac89a56de80077fa4d1/benchmark.cpp`。它不是持久化产品测试依赖；实施阶段应在正式测试目录建立可复现的基准。

### 19.2.1 当前实现的 1000×10 直切完整核心基准

2026-09-20 在同一台 Intel Core Ultra 9 275HX、Windows、MSVC Release x64 上，用当前代码实测：1000 个类型、每类 10 件、正反均允许、400 万表项、常数端谱、3 mm 件间工艺损耗、6000 mm 不限量母材；生产档参数启用快速构造、固定顺序精确分段和 8 次动态邻域。

连续三次独立进程结果：

| 阶段 | 三次耗时 | 中位数 |
| --- | --- | ---: |
| 四姿态表生成、校验及姿态元数据压缩 | 0.140 / 0.142 / 0.136 s | 0.140 s |
| 10000 实例顺序、方向与有限长度分段 | 0.718 / 0.713 / 0.691 s | 0.713 s |

结果放置 10000/10000 件，使用 1347 根母材；400 万 `PairEntry` 加去重后的 1001 条姿态元数据容量为约 64.0 MiB。该数据证明“全直切/常数谱”会自动走 O(1) 配对快路，且万件快速可行解是秒内量级。它不包含上游 BRep 识别、UI/导出，也不证明该万件排列全局最优；复杂端谱仍按 19.5 分布单独计时。

### 19.3 论文速度不能混用

2025 年论文报告，经典特殊代价下 Euler-Splice 的 20000 件测试低于 0.1 秒。这不是任意表的完整多母材算法速度。通用 Match-Splice 的匹配步骤明显更昂贵，任意代价下也没有原来的最优保证。[R1]

### 19.4 实施期性能验收

必须分阶段记录：表校验、候选建立、每类种子、方向 DP、分段 DP、库存标签/修复、局部搜索、全局验证、输出。报告首次完整可行解时间和总耗时。

建议用 1/5/15/60 秒几个可配置预算作测量点，不把它们当事先保证的完成时限。每个预算报告 best 的实际母材成本/总长、根数、完整性与峰值内存。

必须比较相同总预算下：

- 轻量种子 + 搜索。
- 匹配拼接种子 + 搜索。
- 无扰动与有扰动。
- 仅根内改进与含跨根/重新分段的改进。

增加稀疏合法连接、强方向偏好、大量同类件、零增量连接、长度临界及有限库存样本；不能只在均匀随机表上报一个平均时间。

### 19.5 四姿态配对性能：常数谱已测，复杂谱仍需真实数据验收

常数谱完整表的当前实测见 19.2.1。下表其余复杂度仍是容量规划估计：T=1000、最多 400 万项；端口提取与初始谱准备好；优化 C++，最多 16 个表生成工作线程；示例配对容差 0.01 mm。真实低阶/高阶分布必须由生产端口数据验证。

| 自适应计算实际走到的复杂度 | 假设的单项完整配对耗时 | 400 万项的算术外推 |
| --- | ---: | ---: |
| 常数/很少有效系数、几乎无需细分 | 1—10 μs | 约 0.3—5 秒 |
| 低阶约 4—8、上下界容易收紧 | 0.05—0.3 ms | 约 20 秒—3 分钟 |
| 约 8—16 阶、有一定相位细分 | 0.2—2 ms | 约 1—17 分钟 |
| 高阶、多峰或严格小容差 | 2—20 ms 或更多 | 约 10 分钟—3 小时或更多 |

这些行描述同一自适应求解器的工作量，不代表按几何类型写四条业务路径。相同 K 也可能有不同搜索成本。常数情形仍有输入读取、证书验证、表写入和线程调度开销，第一行不等于整单端到端耗时。

外推公式：

~~~text
pairTableTime ≈ 4T² × meanPairCpuTime / effectiveParallelSpeedup
~~~

若平均单项 1 ms，则是约 5.6—8.3 分钟。若希望 400 万项在 60 秒完成，在上述加速假设下需把平均单项做到约 0.12—0.18 ms 以下，且还要留出调度、缓存升级和结果存储成本。没有真实端口数据和实现基准，不能保证达到这个门槛。

端谱预处理费用为所有类型/端口的原生分析与认证之和，不随同类 10 个实例重复，但也不计在上述表内；高阶升级需单独累计。首轮与缓存命中后的重排分别报告。

早期“曲线折线化后求包络”的试验不是当前选定主路线，其吞吐不能拿来声称傅里叶带界算法已测得同样性能。

### 19.6 约束求解和完整排样的性能边界

一维只说明位置坐标少，不消除排列、方向与分箱组合。当所有 S=0，本问题仍包含普通有限母材分箱；任意表再加入顺序相关收益，不能因“已经一维”推断通用精确求解必定很快。

- 快速搜索：常数谱 1000×10 的当前完整核心可行解中位约 0.71 秒；有限库存组合、复杂谱、结果验证和解质量仍须按真实订单分别测量。
- LNS：首轮可试 0.1/0.5/2 秒等局部总预算，计入建模，按改进率/耗时自适应；这些是实验预算，不是承诺解完。
- 完整 CP：时间取决于有效变量/弧、方向耦合、库存和证明难度；不承诺全量最优在秒级，也不一概宣称必须到天。给时间上限、最好可行值、合法下界和实际差距。
- 全量执行时间分解为：几何分析 + 端谱认证 + 表生成 + 顺序/约束优化 + 验证/输出；缓存重用和流水线并行另列。

### 19.7 正式性能验收数据

至少发布以下指标，不只给平均毫秒数：

1. 原生 face/edge 数、端口段数（原生段，不是折线段）、实际 K 分布、残差及 unsupported 比例。
2. 单配对 P50/P95/P99/max、内外细分数、达到认证比例、超时比例。
3. 1/4/8/16 线程吞吐、有效加速、峰值内存、谱升级和缓存命中。
4. 1000 类型/10000 实例的表生成、首次完整可行解、不同总预算下的采购目标与状态。
5. CP 建模耗时、变量/弧数量、求解耗时、改进率、界和 scope；仅局部最优与完整最优分开统计。
6. 相同数据和预算比较：纯快速搜索、加入 CP-LNS、匹配种子开/关、不同误差目标；保证真实几何及最终验证条件一致。

当前 64.0 MiB 是常数谱基准中 `Entries.capacity + Poses.capacity` 的常驻容量，不是进程峰值。复杂谱若产生大量不同姿态，冷元数据可能显著增加；压缩器在唯一记录超过上限时会提前放弃，避免再建立无界的百万项哈希表。区间队列、类型谱、实例、CP 模型及 BRep 仍须另计峰值。

## 22. 必须固化的测试样例

### T01：单件与需求计数

单件没有相邻节约；同类 10 件必须恰好输出 10 个不同实例。允许散布，不允许丢件、重复、超产或实例自连接。

### T02：四项方向一致性

使用第 12 节 A-B-C 案例，固定顺序最优占用 290，不是 280。增加禁用 Reverse 的版本，确认方向掩码有效。

### T03：整数容量边界

两个 3100，连接节约 250，在 6000 内占用 5950。另设 6000.00 恰好可放、6000.01 不可放及量化前临界值；验证非零首尾预留只扣一次。

### T04：禁止跨母材计节约

两件分别放在两根时，各自使用 L；不得把它们的强节约项带到采购用量或剩余长度计算中。

### T05：固定顺序精确不等于全局精确

第 13.4 节的 3600/2400 样例：当前顺序最少 3 根，改变顺序后 2 根。第一条结果只能标记固定顺序分段最优。

### T06：混合规格不能只比较根数

零件长度 4500×3、1500×3，全部节约为 0。6000 和 12000 都不限量、按长度计价。最优总名义长度为 18000，可用 12000+6000；2×12000 虽也是可行方案，但总长 24000，更差。

同成本/同总长情况下，按配置的后续目标比较，不能在测试里默认一定选择 3 根 6000。

### T07：匹配拼接反例

四件 A/B/C/D，各件长度统一为 100；对每一无序配对，所有正反向及反向读取的节约相同：

| 配对 | AB | AC | AD | BC | BD | CD |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 节约 | 5 | 5 | 6 | 1 | 3 | 4 |

```text
D-C-A-B：节约 4+5+5=14，占用 386。
C-D-A-B：节约 4+6+5=15，占用 385。
B-A-D-C：同样节约 15。
```

当天使用作者发布的通用 Match-Splice（三次拼接版本）得到节约 14，穷举全部 4!×2^4=384 种排列/方向得到 15。这是合成数学表，不声称来自实际管材几何。[R2]

测试用途：证明不能随意设置全局最优；把 14 的顺序输入局部改善后，应至少找到这个相邻交换带来的 15。不要要求所有启发式实现都必须先输出同一条 14 的初始序列。

### T08：非对称表与整段反转

构造 S(A,0,B,0) 与 S(B,0,A,0) 不相等的表；所有目标都从正确方向读取。若实现反转操作，检查内部边变化，禁止只改两端的错误计分。

### T09：有限库存

三个 3500，只有 1 根 6000 和 1 根 12000，节约为 0：不可使用 2 根 6000；允许选择合法的 12000 方案。另测仅 1 根 6000 时无法完成全部需求，必须列出未排件且不超用库存。

增加产品数量 -1/0/正整数的转换测试。分别验证联合成本策略与旧有限库存优先策略，不把两者输出差异误报成算法错误。

### T10：非法边与缺表

`valid=false` 的组合不连接，但可通过换方向或换母材解决。未提供表项为 invalid_input；合法零节约项正常参与。候选子图没有连接时需扩展候选，不得声称全表无解。

### T11：增量与全量差分

随机生成固定种子的合法整数表，执行至少 10000 次 relocate/swap/短段操作；对每次操作比较增量值与独立全量重算，覆盖首尾、相邻、跨根及同类实例。

### T12：精确子程序穷举对照

固定顺序 N<=6，枚举 2^N 个方向和 2^(N-1) 个断点集合，选择合法母材，与方向/分段 DP 比较。有限库存另枚举库存分配，不能用不限库存 DP 作为其正确性 oracle。

全局小样本可再枚举排列或使用独立的集合状态精确程序作为标尺。不得用同一份 DP 同时当被测程序和唯一 oracle。

正式测试现已固定 5 组随机 6 件有向四姿态表，独立枚举全部排列、`2^N` 个方向、`2^(N-1)` 个断点以及一份有限库存的分配，并逐项比较采购总长、母材根数和占用长度。该 oracle 不调用被测 DP；Debug 的独立枚举后端与 Release 的 CP-SAT 后端均通过。原先当天运行的 100 组临时样本只作为补充记录，不再是唯一证据。

### T13：取消、预算与快照

取消发生在构造、DP、库存标签和搜索各阶段时，均不发布半成品。存在 incumbent 则保留可行最好解；不存在时报告 no_solution_found/取消原因，而不是 proven_infeasible。输入版本改变后旧回调不能覆盖新结果。

### T14：稠密、大量重复与退化输入

1000×10；同类型全部可相邻；大量 forbidden；净 saving 为负；saving 达到 min(L_i,L_j) 导致零增量。验证内存按类型表增长，零增量下不会靠非法窗口截断却仍报告精确。

### T15：旧接口与真实产品

旧锯切、梯形、端曲线路径的已有测试继续通过；新表模式中强制让几何匹配入口抛错，仍能完成排样。原生适配、TRSF、预览、导出和两侧栏真实浏览器交互都必须覆盖。

### G01：截面和皮面不是简单法向分类

同一模型包含原始外壁、内壁、平行 X 的槽侧壁和圆柱孔壁。要求恢复正确截面，槽/孔不能误判为皮面；无足够残留母材证据的样本返回 ambiguous。

### G02：两端、侧孔、盲孔与对穿孔

带斜端、局部侧孔、盲孔、对侧贯通孔的有效 BRep，核对公共边/加工面来源、内外壁连接和深度；不能把侧孔误当右端。前后整体刚体变换后分类不变。

### G03：周期接缝与端口连通

同一物理端口跨圆柱接缝、边有双 pcurve、多个 face 表示同一壁面；结果与不同建模切面位置一致。不多算物理切边，不把接缝当孔。

### G04：纵向开槽连接两端

参考壁面缺料区同时连到左右外带，要求标为 cross_end_opening，不强制一个加工面组只属于一端；准入失败必须可解释。

### G05：原生展开与掉头

圆弧/NURBS 不先打散，展开后回代在源公差内一致；检验掉头公式及两次掉头恢复。改零相位只改变坐标表达，不改变最佳节约。

### G06：常数、单谐波和阶数自适应

平端谱在满足源误差后停于 K=0，单谐波对照第 8.4 节解析解。复杂连续曲线自动升阶；测试不允许用零件类型名称分派求解器。

### G07：采样漏峰和跳变

构造有限采样点之间的窄峰，残差验证必须发现，不能因采样全为零返回常数证书。真正跳变端函数不允许靠加阶报告任意小一致误差达标。

### G08：相关性反例

使用第 8.3 节曲线，确认只对齐主谐波或只取相关峰不够；求解器能找到比 φ=0 更小的最大间距，并对整个 Ω 保留合法下界。

### G09：区间上下界方向

随机有限三角多项式，对大量 (θ,φ) 点及独立高精度结果验证内层上界、外层接触下界的符号和覆盖。该随机测试只是找错误，不能代替向外舍入实现及其边界分析。

### G10：允许域、重根、平台与预算

允许域跨接缝、多个区间、离散点、不可行空域；目标多峰/恒定/近平台、相切重根、预算耗尽。完整覆盖不丢区间；超时只报 best_feasible 和真实 gap。

### G11：厚度与孔导致外轮廓不充分

构造外壁投影一致但内壁/厚度加工不同的零件，要求准入或多分支约束能区分；不能因为外谱一样就复用完整几何证书。

### G12：四项、角度量化和并行缓存

四个方向分别核对原生实体与变换；机器角度量化后重算安全距离。多线程并发请求同一端口加阶，不重复发布、不混系数/残差版本。修改单类型只失效关联项。

### C01：约束模型与完整枚举

受控 N≤7，枚举排列、方向、断点和母材类型/库存，比较第 16 节完整 CP 的目标向量；与方向/分段 DP 对照但不以同一个 DP 作为唯一 oracle。

### C02：脱离母材的子环

制造高节约 A→B→C→A 子环，尤其令增量为 0；简单度约束会错误接受的构造，circuit 必须拒绝。每根删掉虚拟节点后恰好一条开放路径。

### C03：方向一致及非法边

将 T02 的方向冲突例放入 CP；不得返回不存在的 280 占用。实例自身禁止连接，同类型不同实例允许；forbidden 不得通过大惩罚偷用。

### C04：槽位裁剪与混合规格

构造“更多短料比更少长料便宜”的情况，完整模式不能把 M 固定成当前少根方案的根数后假报全局最优。零价料不能触发无效除法或成本根数界。

### C05：Hint 和字典序

故意给较差合法 hint，求解仍能改顺序/规格；第一目标未证明时第二目标的完成不使全局标记变真。非零 gap 终止与整数精确证明明确区分。

### C06：LNS 跨根和库存

选中两根以上联合重排才能改善的案例；固定部分占用库存正确扣除，被解放库存归还，接受/拒绝均无超用。邻域成员随迭代改变。

### C07：状态范围

完整、稀疏候选图、固定其他根的邻域、仅寻找严格改进四种模型分别验证 OPTIMAL/INFEASIBLE/UNKNOWN 映射，不能混成整单最优或整单无解。

### C08：超时、取消与并行预算

建模期间和求解期间均可结束；返回的 incumbent 可独立验证；求解器线程与外层线程总预算受控。没有可行解不能从 hint 或未完成回调中伪造结果。

### C09：固定前缀异形端续排

构造一根已用至 `E0` 的锁定母材，使最后零件到首个新零件的四姿态表项具有非零净
节约和非零相对绕轴角。Debug 独立枚举后端与 Release CP-SAT 都必须得到
`start=E0-S0`，正确组合绝对绕轴角，并保持固定前缀逐字段不变。另测反向前驱、负
saving、无合法首边、尾部不足、未知前驱、两根同规格但不同实例、有限库存扣减和
续排失败后改用新母材。续排实例只能使用一次，且不能增加采购长度或新开母材数。

## 23. 最优性与下界：禁止错误承诺

| 结果 | 可以声明 | 不能声明 |
| --- | --- | --- |
| 原生几何模型 + 带界配对，U−L≤ε | 该方向组合在指定模型/公差内 ε 最优 | 任意三维形状无条件精确、整单顺序最优 |
| 有限谱数值拟合/相关峰候选 | 候选及已测数值 | 原生几何全域最优或无碰撞证书 |
| 固定顺序的完整两方向 DP | 此顺序/此段的方向最优 | 所有排列最优 |
| 第 13 节完整 DP | 指定顺序、不限库存下的分段最优 | 整体排样最优 |
| 完整资源标签 DP | 指定顺序及库存下的分段最优 | 外层排列最优 |
| 经典结构识别后 Euler-Splice | 被证明适用的单根子问题最优 | 任意表或多母材最优 |
| 种子 + 局部搜索 + 扰动 | 已验证可行及目前最好 | 停滞即最优 |
| 完整 CP，全部目标层证明完成 | 当前完整整数模型全局最优 | 未建模几何/工艺或原始连续尺寸全局最优 |
| CP-LNS / 候选受限模型 | 本次邻域/子图的可行值及局部证明 | 整单全局最优或全局下界 |
| 小样本完整全局枚举 | 对该整数模型的全局最优 | 对未建模工艺也最优 |

任何全局最优声明还必须覆盖当前目标向量和库存政策；只证明第一目标最优，不自动证明所有后续目标最优。

没有经过证明的界时，质量差距为 unknown。尤其禁止用 ceil(ΣL/B) 直接当有互嵌问题的根数下界，因为 ΣL 尚未扣可实现的节约。候选边受限的最优值也不是原问题合法下界。

本方案提供第 16 节完整精确模型，但不要求快速生产模式对 10000 件在固定短时内给出全局最优证明。若要求必须证明，选择 full_exact 并保留其时间/规模边界；超时就报告未证明，不通过修改状态字段“完成”。

配对误差与量化会累积：某固定计划 m 件、各边损失≤ε_e 时，其占用保守损失可按各边误差与长度/节约量化项求和；不能把单边 0.01 mm 称为整根或整单也只差 0.01 mm。采购目标还有容量临界跳变，连续长度的微小误差可能改变所需根数。

因此“安全整数表的全局最优”不自动是“原始连续几何的全局最优”。若要证明后者，需额外用原生几何上下界构造合法乐观松弛、处理临界项并闭合整体差距；未实现时明确 proofScope，不夸大证书。

## 26. 可直接交给后续实施者的维护与扩展说明

本文件 2.2 对应当前实现基线。后续开发先读取适用 AGENTS.md、最新源码和工作区改动，保留用户已有内容；不得重新把 TubeDesigner 接回旧 `Solver`，也不得在顺序热路径恢复在线端线匹配或固定角度扫描。

几何线按 G0—G4 推进：以最终 BRep、已确定 X 轴和可信母材截面为输入，识别原始壁面及加工区域，区分左右端、孔和跨端开口；保留原生曲线、内外壁和厚度，建立参数展开与准入证据；使用同一套按残差自适应的频谱表示和带界 min-max 配对器，计算四个方向组合的相对姿态、安全节约与误差。不得默认圆弧打散、固定绕轴步长、只取相关峰、以外轮廓代替全厚度，或将不支持结果填成零最佳值。

离散线的 M1—M4、C1—C2 已有可运行实现：以固定版本四项表为唯一相邻代价，包含需求、方向 DP、有限长度分段、库存、快速构造、完整 CP-SAT 小模型和动态 LNS。扩展搜索邻域或目标时必须继续遵守这条边界。不要把固定每 50 件分组改成主算法，不在排序器里重新求绕轴姿态。

先用独立枚举、解析配对标尺和严格界测试验证两层，再汇合到 M5/M6 的原生请求、真实刚体位姿、预览、统计和导出。完整实现与分阶段交付要区分；没有端口准入/残差界时不要宣称几何配对已严格认证，没有完整 CP 证明时不要宣称整单数学最优。

下一阶段优先补齐：识别服务直接产生 `NativeCertified` 残差证书、取消令牌、复杂真实端谱 P50/P95/P99 基准、正式持久化基准以及浏览器/导出全链路验收。每次扩展都应继续提交支持/不支持矩阵、永久单元/差分/集成测试、模型/几何/加工状态和可复现性能报告。
