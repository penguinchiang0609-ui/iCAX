# 方管模板完整定义

本文是后续实现采用的定义方案，不表示当前代码已经全部调整完成。

## 1. 截面定义

方管包含方形管和矩形管，截面由一个封闭外轮廓和一个封闭内孔组成。宽、高表示外轮廓包围尺寸，允许宽高不同；角部支持圆角或尖角，半径为 0 表示尖角。

默认内孔居中，四边直边壁厚相同，四个外角采用统一半径 R，内圆角自动计算。

所有尺寸和半径的单位都是 mm。本文的“壁厚”指直边处的壁厚基准；启用内孔偏心或独立内外圆角后，局部壁厚可能不同。

## 2. 完整字段表

共 16 个字段：14 个 double、2 个 bool。数值字段始终保存明确数值，是否使用独立半径由开关决定，不使用空值或负数哨兵。

| 字段名 | 界面名称 | 类型 | 默认值 | 界面可见 | 生效条件 |
|---|---|---|---:|---|---|
| `width` | 宽 | double | 60 | 是 | 始终 |
| `depth` | 高 | double | 40 | 是 | 始终 |
| `wallThickness` | 壁厚 | double | 2 | 是 | 始终 |
| `cornerRadius` | R（外） | double | 3 | 是 | 独立外圆角关闭 |
| `useOuterRadii` | 启用独立外圆角 | bool | false | 否 | 始终决定外角取值方式 |
| `outerRadius1`（R1） | 左下外圆角 | double | 3 | 否 | 独立外圆角开启 |
| `outerRadius2`（R2） | 右下外圆角 | double | 3 | 否 | 独立外圆角开启 |
| `outerRadius3`（R3） | 右上外圆角 | double | 3 | 否 | 独立外圆角开启 |
| `outerRadius4`（R4） | 左上外圆角 | double | 3 | 否 | 独立外圆角开启 |
| `useInnerRadii` | 启用独立内圆角 | bool | false | 否 | 始终决定内角取值方式 |
| `innerRadius1`（r1） | 左下内圆角 | double | 1 | 否 | 独立内圆角开启 |
| `innerRadius2`（r2） | 右下内圆角 | double | 1 | 否 | 独立内圆角开启 |
| `innerRadius3`（r3） | 右上内圆角 | double | 1 | 否 | 独立内圆角开启 |
| `innerRadius4`（r4） | 左上内圆角 | double | 1 | 否 | 独立内圆角开启 |
| `innerOffsetX` | 内孔水平偏心 | double | 0 | 否 | 始终，0 表示不偏移 |
| `innerOffsetY` | 内孔竖直偏心 | double | 0 | 否 | 始终，0 表示不偏移 |

默认值仅为示例规格。R1～R4、r1～r4 对应八个独立数值字段，不是逗号分隔字符串或 JSON。字段名使用 `outerRadius1`～`outerRadius4`、`innerRadius1`～`innerRadius4`，以符合参数键命名规则。

不定义内宽、内高参数；不定义 `outerCorners`、`innerCorners` 角部 JSON 参数。不增加倒角、自定义曲线模式。

## 3. 坐标和角号

以外轮廓中心为原点，截面 X 向右，Y 向上。四角从左下开始逆时针编号：

| 角号 | 位置 | 外角字段 | 内角字段 |
|---|---|---|---|
| 1 | 左下 | outerRadius1（R1） | innerRadius1（r1） |
| 2 | 右下 | outerRadius2（R2） | innerRadius2（r2） |
| 3 | 右上 | outerRadius3（R3） | innerRadius3（r3） |
| 4 | 左上 | outerRadius4（R4） | innerRadius4（r4） |

内角编号随内孔移动，不因偏心改变。偏心为正时，内孔向右或向上移动。

## 4. 半径取值规则

对每个角 i，先求实际外圆角，再求实际内圆角：

```text
实际外圆角[i] = useOuterRadii ? Ri : cornerRadius
实际内圆角[i] = useInnerRadii ? ri : max(实际外圆角[i] - wallThickness, 0)
```

| 独立外圆角 | 独立内圆角 | 实际外角 | 实际内角 |
|---|---|---|---|
| 关闭 | 关闭 | 四角均采用 R | 四角均采用 max(R−壁厚, 0) |
| 开启 | 关闭 | 分别采用 R1～R4 | 按对应实际外角减壁厚计算 |
| 关闭 | 开启 | 四角均采用 R | 分别采用 r1～r4 |
| 开启 | 开启 | 分别采用 R1～R4 | 分别采用 r1～r4 |

这两个开关互相独立，含义都是“是否手工指定这组半径”。关闭独立内圆角表示自动推导，仍然生成内孔和内角。

0 是有效半径，表示尖角。例如：统一 R=0 且两个开关关闭时，内外四角都是尖角；独立内圆角开启且 r1=0 时，左下内角明确为尖角。

关闭开关保留对应数值，但这些数值不参与几何计算或适用性校验。重新开启使用保留值，生成过程不自动改写它们。首次通过编辑器开启时，可由编辑操作将当前四个实际半径写入对应字段，使切换前后形状一致；加载已经开启的定义时必须使用保存值。

## 5. 内孔尺寸与偏心

内孔尺寸仅为生成过程中的派生量：

```text
内孔宽度 = width - 2 × wallThickness
内孔高度 = depth - 2 × wallThickness
内孔中心 = (innerOffsetX, innerOffsetY)
```

不把这些派生量作为可输入参数，也不写回返回的 parameters。

偏心不改变内孔尺寸。对应四边直边厚度为：

```text
左侧 = wallThickness + innerOffsetX
右侧 = wallThickness - innerOffsetX
下侧 = wallThickness + innerOffsetY
上侧 = wallThickness - innerOffsetY
```

自动内圆角仍按“对应实际外角−壁厚基准”计算。偏心情况下不保证内外圆弧同心，必须对完整轮廓进行包含性检查。

## 6. 几何约束

所有数值必须有限。宽、高、壁厚必须大于 0，且宽、高都必须大于两倍壁厚。实际生效的半径必须不小于 0。

外角的相邻半径之和不得超过对应边长：

```text
外R1 + 外R2 ≤ width       外R4 + 外R3 ≤ width
外R1 + 外R4 ≤ depth       外R2 + 外R3 ≤ depth
```

内角采用相同规则，但边长使用派生内孔宽、高。等号表示中间直线段缩为零，应省略零长度边，不创建退化线段。

偏心必须满足 `abs(innerOffsetX) < wallThickness`、`abs(innerOffsetY) < wallThickness`。这些只是直边处必要条件；完整内轮廓还必须严格位于外轮廓内部，不能与外轮廓接触、相交或穿出，且两条轮廓都不能自交。

几何容差统一采用宿主截面容差。无效组合返回明确错误，不通过截断半径、移动内孔或偷偷修改输入来勉强生成。

## 7. 界面与模板职责

当前普通界面只显示宽、高、壁厚、R（外）。其余字段声明 `presentation.visible=false`，参数面板与参数示意图都遵守该标记，不产生空高级分组。

两个开关及逐角字段同样不显示。它们保留为模板内部、导入及反解可使用的能力。以后若需要开放高级编辑，通过修改模板声明开放，不在前端添加方管专用分支。

统一 R 在独立外圆角开启时禁用。外角逐项字段只在独立外圆角开启时适用，内角逐项字段只在独立内圆角开启时适用。显示和禁用条件复用公共 `parameterConditions.mjs`，几何脚本采用相同分支规则。

字段定义、展示名称及条件由方管模板维护；生成与反解规则由方管自己的 Python 脚本维护。

## 8. 生成、反解与返回约定

生成器读取上述 16 个字段，内部计算实际半径和内孔尺寸，输出外轮廓及内孔轮廓。返回的 parameters 必须与宿主规范化输入完全一致，不能混入派生字段。

反解直接从完整轮廓求尺寸、壁厚基准、半径、偏心及姿态。能够用统一外 R 表达时，优先关闭独立外圆角；内角符合自动推导规则时，优先关闭独立内圆角，否则使用独立半径并开启对应开关。

内外包围尺寸必须满足相同壁厚基准：`(外宽−内孔宽)/2` 与 `(外高−内孔高)/2` 在容差内一致。不满足时，本定义无法表达，返回不匹配，不引入内宽、内高字段补救。

反解不能调用正向生成进行数值搜索。不支持的轮廓明确报告不支持或不匹配。

## 9. 取值示例

默认值：宽 60、高 40、壁厚 2、R=3，两个开关关闭，偏心为 0。派生内孔为 56×36，外四角 R3，内四角 R1。

独立外角：开启独立外圆角，R1～R4 分别为 3、4、5、6，壁厚为 2；独立内圆角关闭，实际内角依次为 1、2、3、4。

独立内角：保持默认外角，开启独立内圆角，r1～r4 都设为 0；外轮廓四角为 R3，内孔四角为尖角，仍需通过内外轮廓包含性检查。
