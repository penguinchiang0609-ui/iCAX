# 热轧角钢与热轧槽钢参数化建模说明

> 面向管材/型钢 CAM 的截面参数化建模。重点不是复刻轧制毛坯的微观不规则，而是建立**标准名义截面 + 可校准参数**的稳定几何模型。
>
> 当前日期：2026-09-18。现行基础标准仍为 **GB/T 706-2016《热轧型钢》**；**GB/T 706-2026** 已于 2026-05-25 发布，将于 **2026-12-01** 实施，并全部代替 GB/T 706-2016。

---

## 1. 总体建模原则

热轧角钢、热轧槽钢都不建议直接建成自由曲线截面。

对于 CAM 管型库，更合适的方式是：

1. 以标准给出的名义尺寸作为基础参数；
2. 轮廓由直线、圆弧和确定的斜线解析构造；
3. 标准规格由规格库自动带出参数；
4. 保留“自定义/实测截面”作为高级覆盖模式；
5. 标准中的圆角参数主要用于名义几何，不应假定实物圆角与理论值完全一致。

---

# 2. 热轧角钢

## 2.1 截面特征

标准热轧角钢的名义截面可理解为：

- 两条互相垂直的外边；
- 两条等距内边，形成名义厚度；
- 根部内圆角 `R`；
- 两个自由端圆角 `r1`。

它不是“两个矩形硬拼”的尖角 L 形，但也没有必要把内侧建成连续自由曲线。

示意：

```text
          自由端
            ┌─
            ╰ r1
            │
            │  ← 直线段
            │
            ╰── R
               ─────────────╮
                            r1
```

---

## 2.2 标准符号与软件建议符号

GB/T 706-2016 对角钢常用：

- `B`：不等边角钢长边宽度；
- `b`：短边宽度；等边角钢只用 `b`；
- `d`：边厚度；
- `r`：内圆弧半径；
- `r1`：边端圆弧半径。

为了和通用 CAM 参数保持一致，软件内部建议统一为：

| 软件参数 | 含义 | 对应标准参数 |
|---|---|---|
| `B` | 水平边总宽 | `B` 或 `b` |
| `H` | 竖直边总宽 | `b` |
| `t` | 名义边厚 | `d` |
| `R` | 根部内圆角 | `r` |
| `r1` | 自由端圆角 | `r1` |

因此统一模型可以定义为：

```text
HotRolledAngle(B, H, t, R, r1)
```

等边角钢只是：

```text
B = H
```

不等边角钢则：

```text
B != H
```

无需建立两套完全不同的几何内核。

---

## 2.3 `r1` 的默认关系

GB/T 706-2016 的角钢截面资料中规定名义边端圆弧：

```text
r1 = t / 3
```

因此，对于“国标标准规格”模式，可以只保存：

```text
B, H, t, R
```

并自动计算：

```text
r1 = t / 3
```

但对于通用型钢库，不建议在几何内核中把 `r1=t/3` 写死。

更合理的是：

- 几何层：`r1` 为独立参数；
- GB/T 706 规格库：自动给 `r1=t/3`；
- 其他标准、实测截面：允许独立覆盖 `r1`。

---

## 2.4 轮廓构造

先构造名义等厚 L 形骨架：

- 水平腿宽：`B`；
- 竖直腿高：`H`；
- 厚度：`t`。

然后处理两个类型的圆角。

### 根部圆角

水平内边与竖直内边之间做半径为 `R` 的相切圆弧：

```text
Fillet(innerHorizontal, innerVertical, R)
```

### 自由端圆角

水平腿与竖直腿的自由端分别构造半径为 `r1` 的端部圆弧。

在 CAD/OCC 实现中，建议基于理论边界线做精确相切构造，不建议用离散点拟合。

---

## 2.5 `R` 与 `r1` 是否可能直接相接

可以。

对水平腿内侧，根部圆角与自由端圆角之间的理论直线长度为：

```text
L_B = B - t - R - r1
```

对竖直腿内侧：

```text
L_H = H - t - R - r1
```

因此：

### 正常情况

```text
B > t + R + r1
H > t + R + r1
```

两个圆弧之间存在直线段。

### 临界情况

```text
B = t + R + r1
```

或：

```text
H = t + R + r1
```

对应方向上的中间直线长度为 0，`R` 与 `r1` 正好相切连接。

### 非法情况

```text
B < t + R + r1
```

或：

```text
H < t + R + r1
```

按“直线 + 两个独立圆角”的模型构造会发生圆角重叠，应判定参数非法，或切换到特殊自定义轮廓处理。

标准规格通常会留下明显的中间直线段，因此临界情况更多是自定义参数时需要防御。

---

## 2.6 截面面积验证

统一到 `B、H、t、R、r1` 后，不等边/等边角钢可用同一形式验证：

```text
A = t(B + H - t) + 0.215(R² - 2r1²)
```

等边角钢 `B=H=b` 时：

```text
A = t(2b - t) + 0.215(R² - 2r1²)
```

其中 `0.215` 是标准采用的近似系数。

该公式非常适合作为几何构造后的面积自检：

```text
abs(A_geometry - A_formula) < tolerance
```

如果面积差明显超限，通常说明圆角方向、轮廓闭合或参数解释存在错误。

---

## 2.7 建议的数据结构

```text
HotRolledAngle
{
    B      // 水平边宽
    H      // 竖直边宽
    t      // 边厚
    R      // 根部圆角
    r1     // 边端圆角

    standard      // GB/T 706、EN、JIS...
    specification // 例如 L50x50x5
}
```

标准规格数据库负责填入参数，几何内核只负责按照参数构造。

# 3. 热轧槽钢

## 3.1 与普通等厚 U 型的本质区别

传统 GB/T 706 热轧槽钢不能简单建成等厚 U 型。

它的重要特征是：

> **翼缘/腿的内侧存在斜度。**

GB/T 706-2016 中传统热轧槽钢的腿内侧名义斜度为：

```text
1 : 10
```

即：

```text
k = 0.1
```

因此翼缘靠近腹板的位置更厚，靠近槽口的位置更薄。

示意：

```text
槽口方向 →

┌────────────────────
│\
│ \
│  \       ← 腿内侧斜线，1:10
│   \
│    ) R
│    │
│    │  腹板
│    │
│    ) R
│   /
│  /       ← 腿内侧斜线，1:10
│ /
│/
└────────────────────
```

---

## 3.2 标准参数

GB/T 706-2016 热轧槽钢使用：

| 参数 | 含义 |
|---|---|
| `h` | 截面总高度 |
| `b` | 腿宽度/翼缘总宽 |
| `d` | 腰厚度/腹板厚度 |
| `t` | 腿中间厚度 |
| `r` | 内圆弧半径 |
| `r1` | 腿端圆弧半径 |

注意：

> `t` 不是整个翼缘恒定厚度，而是**腿中间厚度**。

这也是热轧槽钢与普通等厚 U 型参数模型最容易混淆的地方。

---

## 3.3 为什么 `t` 定义为“腿中间厚度”

设腹板外侧为：

```text
x = 0
```

腹板内侧理论线为：

```text
x = d
```

槽口端为：

```text
x = b
```

翼缘伸出腹板内侧的长度：

```text
L = b - d
```

其几何中点：

```text
xm = d + (b-d)/2
   = (b+d)/2
```

标准参数 `t` 就对应这一区域中点附近的名义腿厚。

---

## 3.4 1:10 斜面的解析表达

定义：

```text
k = 0.1
```

以下翼缘为例，先忽略两端圆角，其内侧理论直线可写为：

```text
y(x) = t + k(xm - x)
```

其中：

```text
xm = (b+d)/2
```

于是：

- `x` 越靠近腹板，翼缘越厚；
- `x` 越靠近槽口，翼缘越薄。

上翼缘关于截面水平中心线镜像即可。

---

## 3.5 根部理论厚度与槽口理论厚度

在不考虑圆角截断的理论斜线上：

### 靠腹板位置

```text
t_root = t + k(b-d)/2
```

传统国标斜腿槽钢 `k=0.1`：

```text
t_root = t + (b-d)/20
```

### 靠槽口位置

```text
t_toe = t - k(b-d)/2
```

即：

```text
t_toe = t - (b-d)/20
```

这里的 `t_root`、`t_toe` 是**理论斜线外推到对应 x 位置得到的厚度**。真实轮廓靠近根部和端部时会被 `r`、`r1` 圆角替代。

一个基本合法性条件是：

```text
t_toe > 0
```

---

## 3.6 10# 槽钢示例

GB/T 706-2016 中典型 10# 槽钢参数：

```text
h  = 100 mm
b  = 48 mm
d  = 5.3 mm
t  = 8.5 mm
r  = 8.5 mm
r1 = 4.2 mm
```

腿伸出长度：

```text
b - d = 42.7 mm
```

半长：

```text
(b-d)/2 = 21.35 mm
```

1:10 斜度产生的半程厚度变化：

```text
Δt = 21.35 × 0.1
   = 2.135 mm
```

因此理论根部厚度：

```text
t_root = 8.5 + 2.135
       = 10.635 mm
```

理论槽口厚度：

```text
t_toe = 8.5 - 2.135
      = 6.365 mm
```

所以 `t=8.5` 绝不能理解成“整条翼缘都是 8.5 mm”。

---

## 3.7 圆角构造

### 根部 `r`

根部是：

```text
腹板内侧理论直线
        +
翼缘内侧 1:10 理论斜线
        +
半径 r 的相切圆弧
```

建议算法：

```text
Fillet(webInnerLine, flangeSlopeLine, r)
```

### 腿端 `r1`

槽口处由：

```text
翼缘内侧斜线
        +
槽口端部边界
        +
半径 r1 的相切圆弧
```

构成。

建议：

```text
Fillet(flangeSlopeLine, toeEndLine, r1)
```

由于这里存在斜线，圆角切点距离不再能像 90° 等厚模型那样只用 `r` 或 `r1` 直接相减。

因此程序中更推荐：

1. 先建立无限理论直线；
2. 解析求相切圆弧或调用稳定的 2D Fillet；
3. 得到切点后裁剪理论直线；
4. 检查根部圆角与端部圆角是否重叠；
5. 最终检查轮廓闭合、无自交且面积为正。

不要只靠经验长度公式硬截断斜线。

---

## 3.8 截面面积验证

GB/T 706-2016 给出的槽钢截面面积计算形式为：

```text
A = h*d + 2*t*(b-d) + 0.339*(r²-r1²)
```

这里也能说明 `t` 为什么采用“腿中间厚度”：

对于线性变化的翼缘厚度，其平均值正好等于中点厚度 `t`，因此主体翼缘面积可以直接写成：

```text
2*t*(b-d)
```

再通过圆角项修正。

该公式同样可以作为几何实现的回归测试。

---

## 3.9 推荐的软件模型

如果只针对 GB/T 706-2016 传统斜腿槽钢：

```text
HotRolledChannel(h, b, d, t, r, r1)
```

内部固定：

```text
slope = 0.1
```

但对于长期的 CAM 管型库，更建议把斜度参数显式保留：

```text
HotRolledChannel(h, b, d, t, r, r1, slope)
```

其中：

```text
传统斜腿槽钢：slope = 0.1
平行腿槽钢：  slope = 0
```

建议实现上：

- 几何内核可以共用；
- 产品/标准层仍可分别暴露“斜腿热轧槽钢”和“平行腿热轧槽钢”两个标准类型；
- 不要为了共用代码而把不同标准的规格语义强行混在一起。

# 4. GB/T 706-2026 对槽钢模型的影响

截至 2026-09-18：

- **GB/T 706-2016**：仍为现行标准；
- **GB/T 706-2026**：已发布；
- **实施日期：2026-12-01**；
- 新版将全部代替 GB/T 706-2016。

新版标准编制说明显示，热轧槽钢体系中增加/吸收了**平行腿槽钢**相关内容，并沿用了 YB/T 4705-2018 的相关尺寸、外形及允许偏差体系。

因此，从软件架构角度，提前把 `slope` 作为截面参数是合理的。

但建议标准规格数据库仍保留明确的标准来源：

```text
GB/T 706-2016 斜腿槽钢
GB/T 706-2026 斜腿槽钢
GB/T 706-2026 平行腿槽钢
YB/T 4705-2018 平行腿槽钢
```

这样未来做标准切换时不会混淆规格数据。

# 5. 标准名义轮廓与实际材料的区别

这是 CAM 中必须单独考虑的一层。

GB/T 706-2016 对角钢、槽钢的 `r`、`r1` 数据都有类似说明：

> 圆角数据用于孔型设计，不作为交货条件。

这意味着：

- 标准给出的圆角非常适合作为默认参数化轮廓；
- 不能把标准 `r/r1` 当作每一根实物材料的精密检测尺寸；
- 实际热轧材料还会受到轧制、磨损、公差、批次等影响；
- 对普通排样、切割轨迹生成，标准名义轮廓通常足够；
- 对高精度搭接、贴合、坡口、免修配插接等场景，应允许实测参数或扫描轮廓覆盖标准值。

因此推荐分层：

```text
标准规格
   ↓
名义参数轮廓
   ↓
可选：实测参数修正
   ↓
可选：扫描/导入真实截面
```

# 6. 两种型钢的统一设计建议

## 6.1 热轧角钢

推荐：

```text
HotRolledAngle(B, H, t, R, r1)
```

特点：

- 基本等厚；
- 根部圆角 `R`；
- 两个自由端圆角 `r1`；
- 等边/不等边可以共用模型；
- GB/T 规格中 `r1` 默认可由 `t/3` 得到。

## 6.2 热轧槽钢

推荐：

```text
HotRolledChannel(h, b, d, t, r, r1, slope)
```

特点：

- 腹板厚度 `d`；
- `t` 是腿中间厚度，而不是恒定翼缘厚度；
- 传统斜腿槽钢内侧斜度 `slope=0.1`；
- 根部、腿端分别用 `r`、`r1` 相切；
- `slope=0` 可作为平行腿槽钢几何基础。

# 7. CAM 实现层建议

建议把“标准规格”和“截面几何”彻底解耦。

## 标准数据库层

负责：

```text
标准号
型号
规格名称
B/H/h/b/d/t/R/r/r1/slope
理论面积
理论重量
允许偏差
```

## 几何内核层

负责：

```text
Line
Arc
Fillet
Trim
Wire Close
Self-Intersection Check
Area Check
```

## 校验层

至少做：

1. 所有长度、厚度、圆角必须为正；
2. 角钢检查 `B/H` 是否足以容纳 `R+r1`；
3. 槽钢检查 `t_toe > 0`；
4. 所有 Fillet 必须存在合法切点；
5. 构造完成后 Wire 必须闭合；
6. 不允许自交；
7. 面积必须为正；
8. 几何面积与标准面积公式进行容差比较。

---

# 8. 建议结论

对于管材/型钢 CAM，这两种热轧型钢都可以用稳定的解析参数模型实现，不需要自由曲线：

```text
热轧角钢
= 等厚 L 基体
+ 根部圆角
+ 两个边端圆角
```

```text
热轧槽钢
= 腹板
+ 两条线性变厚的翼缘
+ 1:10 内侧斜度（传统斜腿型）
+ 根部圆角
+ 腿端圆角
```

真正需要特别区分的是：

- **冷弯角钢 vs 热轧角钢**；
- **普通等厚 U 型/冷弯槽钢 vs 传统斜腿热轧槽钢**；
- 标准名义截面 vs 实际轧制截面。

从产品建模角度，建议以这两个解析模型作为基础，再由不同国家/行业标准规格库向其填参。
