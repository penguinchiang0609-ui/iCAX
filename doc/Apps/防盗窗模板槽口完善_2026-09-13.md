# 防盗窗产品内槽口

保留产品 Python 自己生成加工几何的方式，不读取模具库，不调用模具模板。单面外框、开启口固定框、活动扇框共用 `security_window_frame_geometry.py`；多面防盗窗的开启框也经过同一入口。

## 此次调整

- 圆角 V 槽采用真实三点圆弧，保留槽根两侧圆弧与短底边的避空构造；不再将半径静默限制为槽深的 45%，也不将圆角解释为成形半径。过大尺寸明确拒绝。
- 公母口在管顶附近设置搭接台阶，不再用另一条多边形覆盖整个圆角/边弧轮廓。
- 左右弧侧轮廓使用互为镜像的真实四分之一圆弧，替换原二次曲线采样。沿用产品自己的直角框工程展开模型，不冒充独立模具的其他边弧构造。
- K 补偿为每个直角的 `π/2 × K × min(壁厚, 槽底距外底面)`，同时用于展开长度、槽位和槽根轴向宽度；半径不随 K 改变。槽底距离为 0 时按壁厚自动取值。
- 释放孔以圆的最低点对齐槽底，不能再把圆心放在槽底导致底桥被切穿。“不过切”只贯穿进刀侧壁，不再用孔径猜测切深。孔径不允许达到槽口有效高度。
- 底部避空与壁厚过切不下移指定槽底。槽口连同附加避空结构必须位于毛坯内，且不得与相邻槽口相交。
- 折弯截面按实际上下平直支承边、内外壁间距校验，不按管型 ID 识别；不满足条件明确拒绝。非折弯工艺不受此限制。
- 展示仍为装配示意，制造输出为开槽展开母材；保持轻量展示与加工输出分离。无关子参数不参与生成或校验。

## 验证边界

数学回归覆盖真实半径、公母保形、K 增量、左右镜像、释放孔与单侧切深。原生回归覆盖尖 V、圆角、左右边弧、公母组合、贯穿/单侧释放孔，检查实体有效且底桥保持连通；另调用实际产品预览接口。

上述是产品模板的工程几何与试折补偿模型，不是材料塑性成形仿真。保留产品的试折提示；不声称已经验证任意材料折后尺寸、回弹或承载。
