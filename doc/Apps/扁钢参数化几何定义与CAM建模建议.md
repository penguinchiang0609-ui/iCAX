# 扁钢参数化几何定义与 CAM 建模建议

## 1. 定义

扁钢（Flat Bar）本质上是宽度明显大于厚度的矩形截面长材。

从 CAM 截面参数化角度看，扁钢是所有型材中最简单的一类。

基础截面：

```text
              B
       <------------>

       ┌────────────┐
       │            │
       │            │ T
       └────────────┘
```

基础参数只需要：

\[
\boxed{
FlatBar(B,T)
}
\]

其中：

| 参数 | 含义 |
|---|---|
| \(B\) | 扁钢宽度 |
| \(T\) | 扁钢厚度 |

截面积：

\[
A=B\times T
\]

---

# 2. 普通扁钢模型

如果不考虑热轧轮廓细节，则扁钢可以直接按理想矩形建模：

\[
\boxed{
FlatBar(B,T)
}
\]

四条边均为理论直线：

- 上边水平；
- 下边水平；
- 左边竖直；
- 右边竖直。

四个理论角均为：

\[
90^\circ
\]

---

# 3. 热轧扁钢

热轧扁钢和理想矩形扁钢相比，主体尺寸仍然由：

\[
B,\quad T
\]

控制。

其主要名义几何差异在于：

> **纵向边缘通常存在圆钝或圆角，不应机械地理解为绝对尖角矩形。**

因此可以抽象为：

```text
        R              R
         ╭────────────╮
         │            │
         │            │
         ╰────────────╯
        R              R
```

推荐热轧模式：

\[
\boxed{
FlatBar(B,T,R)
}
\]

其中：

\[
R=\text{角部名义圆角半径}
\]

---

# 4. 热轧开关设计

按照统一的管型体系，建议保持一级类型：

```text
扁钢
```

并增加：

```text
□ 热轧
```

即：

```text
HotRolled = true / false
```

---

## 4.1 HotRolled = false

采用：

\[
\boxed{
FlatBar(B,T)
}
\]

截面为严格矩形：

```text
┌──────────────┐
│              │
│              │
└──────────────┘
```

不需要额外圆角参数。

---

## 4.2 HotRolled = true

增加：

\[
R
\]

截面变为：

\[
\boxed{
FlatBar(B,T,R)
}
\]

示意：

```text
╭──────────────╮
│              │
│              │
╰──────────────╯
```

因此对于扁钢：

> **热轧开关主要改变角部轮廓，不改变主体拓扑，也不引入坡度或变厚度。**

---

# 5. 圆角 \(R\) 的几何关系

扁钢相邻两条理论边互相垂直。

因此每个角部圆角可以直接通过：

\[
\boxed{
Fillet(R)
}
\]

构造。

其名义圆心角均为：

\[
\boxed{
90^\circ
}
\]

不需要额外定义：

- 圆心；
- 圆弧起点；
- 圆弧终点；
- 圆心角；
- 坡度。

---

# 6. 四角是否必须使用相同 \(R\)

对于基础标准模型，建议四角统一：

\[
\boxed{
R_1=R_2=R_3=R_4=R
}
\]

这样参数最简洁。

如果未来需要支持：

- 厂家非标轧制；
- 实测轮廓；
- 特殊边部处理；

可以再扩展独立圆角。

但不建议第一版直接暴露四个不同的 \(R\)。

---

# 7. \(R\) 不建议写死为固定公式

热轧扁钢实际边缘会受到：

- 轧辊孔型；
- 轧制工艺；
- 规格；
- 轧辊磨损；
- 尺寸公差

等影响。

因此：

\[
R
\]

更适合作为：

\[
\boxed{
\text{名义/近似轮廓参数}
}
\]

而不是强制由 \(B\) 或 \(T\) 按固定公式计算。

不建议写死：

```text
R = T / 2
R = T / 3
R = 某固定比例
```

---

# 8. 推荐的 R 输入方式

UI 可以设计成：

```text
扁钢

宽度 B
厚度 T

☑ 热轧

圆角 R：
○ 自动
○ 自定义
```

其中：

## 自动模式

系统根据：

- 标准规格；
- 默认规则；
- 厂家规格库

给出一个名义值。

## 自定义模式

用户直接输入：

\[
R
\]

适合：

- 实测截面；
- 非标准规格；
- 特定厂家材料。

---

# 9. 实际热轧轮廓与名义模型的区别

需要特别区分：

\[
\boxed{
\text{名义截面}
}
\]

和：

\[
\boxed{
\text{实际轧制截面}
}
\]

名义模型可以表示为：

```text
╭──────────────╮
│              │
│              │
╰──────────────╯
```

但实际材料可能存在：

- 侧边轻微倾斜；
- 局部鼓形；
- 圆角半径变化；
- 边部圆钝不完全对称；
- 宽度、厚度尺寸偏差。

这些属于：

\[
\boxed{
\text{制造公差 / 实际轮廓偏差}
}
\]

不建议作为基础截面参数。

---

# 10. 为什么不建议把公差做进基础几何

如果把实际轧制误差全部参数化，可能会变成：

```text
B
T
R
左侧倾角
右侧倾角
上边鼓度
下边鼓度
左上R
左下R
右上R
右下R
...
```

这会让基础管型模型失去意义。

因此推荐：

> **基础模型保持标准名义截面；实测轮廓另走自由轮廓或扫描轮廓模式。**

---

# 11. 热轧扁钢与钢板切条的区别

CAM 中需要注意：

> **热轧扁钢和从钢板上切出的一条矩形条料，不应完全等同。**

钢板切条通常可以近似认为：

```text
┌──────────────┐
│              │
└──────────────┘
```

其切割边由后加工形成。

而真正热轧扁钢的纵向边缘由轧制形成，更容易存在：

- 圆钝；
- 边部圆角；
- 截面不正；
- 实际轮廓偏差。

因此：

```text
□ 热轧
```

这个开关是有实际几何意义的。

---

# 12. 推荐几何构造流程

## Step 1：生成理论矩形

根据：

\[
B,\quad T
\]

生成理想矩形。

---

## Step 2：判断热轧模式

如果：

```text
HotRolled = false
```

直接完成截面。

如果：

```text
HotRolled = true
```

继续执行圆角构造。

---

## Step 3：四角 Fillet

四个理论角分别执行：

\[
\boxed{
Fillet(R)
}
\]

生成热轧名义轮廓。

---

# 13. 参数合法性检查

基础条件：

\[
B>0
\]

\[
T>0
\]

热轧模式下：

\[
R\ge0
\]

同时必须满足：

\[
\boxed{
R\le\frac{\min(B,T)}{2}
}
\]

否则相邻圆角可能相互重叠。

对于典型扁钢：

\[
B\gg T
\]

所以更实际的限制通常是：

\[
\boxed{
R\le\frac{T}{2}
}
\]

如果：

\[
R=\frac{T}{2}
\]

则上下两个圆角在侧边方向恰好相切，侧边直线长度变为零。

若：

\[
R>\frac{T}{2}
\]

则普通“矩形 + 四角 Fillet”模型失效。

---

# 14. 推荐数据结构

基础版：

```cpp
struct FlatBarSection
{
    double width;       // B
    double thickness;   // T

    bool hotRolled;
    double radius;      // R，仅热轧模式有效
};
```

如果需要支持“自动/自定义”：

```cpp
enum class RadiusMode
{
    Auto,
    Custom
};

struct FlatBarSection
{
    double width;
    double thickness;

    bool hotRolled;

    RadiusMode radiusMode;
    double radius;
};
```

---

# 15. 与其他型钢的热轧差异

| 类型 | 打开“热轧”后的主要几何变化 |
|---|---|
| 扁钢 | 四角圆钝/圆角 |
| 角钢 | 根部 \(R\) + 自由端 \(r_1\) |
| T型钢 | 主要增加热轧圆角 |
| 槽钢 | 翼缘内侧出现坡度 + 圆角 |
| 工字钢 | 翼缘内侧出现坡度 + 圆角 |
| 帽钢 | 分区厚度 + 多组圆角 |
| U肋 | 可进一步支持局部加厚 |

因此对于扁钢：

\[
\boxed{
\text{热轧变化最小}
}
\]

核心就是：

\[
\boxed{
\text{矩形}
\rightarrow
\text{圆角矩形}
}
\]

---

# 16. 最终推荐

扁钢基础一级管型保持：

\[
\boxed{
FlatBar
}
\]

UI：

```text
扁钢

宽度 B
厚度 T

□ 热轧
```

普通模式：

\[
\boxed{
FlatBar(B,T)
}
\]

热轧模式：

\[
\boxed{
FlatBar(B,T,R)
}
\]

并建议：

1. \(R\) 作为可选/可覆盖参数；
2. 不把 \(R\) 写死为厚度的固定比例；
3. 不把侧边倾斜、鼓度等制造公差加入基础参数；
4. 实际扫描轮廓另走自由轮廓模式；
5. CAM 中区分“热轧扁钢”和“钢板切条”。

这样既保持模型简单，也能表达热轧扁钢真正有意义的截面差异。
