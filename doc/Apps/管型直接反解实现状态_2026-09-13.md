## 当前直接反解

| 模板 | 规则及范围 |
|---|---|
| round / round-bar | 同心圆或单圆，半径直接给出尺寸与壁厚 |
| rect-bar | 四条矩形边及四个等半径角弧；含腰圆退化边界 |
| rect | 同心、等壁厚且内外统一角半径的圆角矩形；独立四角、偏心、异厚等扩展尚未反解 |
| racetrack | 两端半圆、两条切线及内外壁对应；含退化圆管 |
| oval | 同心同轴的内外椭圆，直接取轴长和角度；独立内轴时名义壁厚不可确定，不填默认值 |
| open-tube | 两条同心反向圆弧和两条径向连接边，直接求开口角与开口方向 |
| multi-cell | 当前双矩形腔模型；测量各壁、隔板厚度与隔板偏移 |
| polygon-bar | 正六／八边形的等半径、等角步进关系，求对边尺寸与姿态 |

## 本次补齐的 15 个模板

- angle：冷弯中心线；热轧根、跟、趾圆角；精密直角；焊脚等长截距。
- channel：等边／不等边、内卷边／外卷边、斜腿／平行翼缘及焊接槽钢。
- h-section / i-section / unequal-i：翼缘、腹板、偏心、斜度与各组圆角。
- welded-h / t-section：独立板厚、腹板偏心、圆角与直线焊脚分开测量。
- omega / z-section：配对完整两侧边界，反解中心线尺寸和内弯半径。
- u-section：外侧理论交点尺寸、斜壁法向厚度、内外弯曲半径。
- bulb-flat：五个相切支承线交点、30°斜边、球头半径和端角；支持镜像。
- p-tube：安装翼、外侧三个圆角和完整内孔；支持镜像。
- combined-hollow：外圆内六角、外六角内圆。
- curve-hollow：D 型半圆外弧、偏置内侧弦、同心内外弧。
- polygon：正三／五／六／八边形（独立内相位和逐角半径）、任意三角、直角／等腰梯形、平行四边形等厚内孔。

全部 24 个模板现已提供直接反解；不再有 IMPLEMENTED=False 占位入口。
这不等于任意导入自由曲线或任意制造来源都能由名义参数反推：不属于上述参数模型的完整边界仍返回 False。
几何相同的无卷边 C 与等边 U 返回 U 的代表参数；圆外壁无法将内孔相位与整体转角唯一分离，返回内相位 0 的代表姿态。制造历史不是截面几何可确定的信息。
