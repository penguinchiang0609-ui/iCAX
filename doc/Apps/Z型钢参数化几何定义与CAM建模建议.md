# Z型钢参数化几何定义与 CAM 建模建议

## 1. 定义

Z 型钢是一类典型的冷弯开口型钢。

其基本截面由：

- 一条中间腹板；
- 上翼缘；
- 下翼缘；

组成，并且上下翼缘向相反方向伸出，形成典型的 Z 形截面。

基础示意：

```text
          ───────────
          │
          │
          │
──────────
```

与槽钢相比：

```text
槽钢 C：

────────
│
│
────────


Z 型钢：

        ────────
        │
        │
────────
```

Z 型钢没有镜面对称面，但基础截面通常具有较强的中心对称特征。

---

# 2. 本文范围

本文只讨论普通结构用冷弯 Z 型钢，包括：

- 普通 Z 型钢；
- 不等翼缘 Z 型钢；
- 卷边 Z 型钢；
- 斜卷边 Z 型钢。

不讨论：

- 热轧 Z 型钢板桩；
- 带锁口钢板桩；
- 其他特殊热轧 Z 形截面。

因此本管型不设置“热轧 Z 型钢”几何模型。

---

# 3. 基础 Z 型钢

最简单的等翼缘 Z 型钢可以定义为：

\[
\boxed{
Z(H,B,t,R)
}
\]

其中：

| 参数 | 含义 |
|---|---|
| \(H\) | Z 型钢高度 |
| \(B\) | 上下翼缘宽度 |
| \(t\) | 板厚 |
| \(R\) | 主折弯内圆角 |

示意：

```text
            B
       <---------->

       ┌──────────
       │
       │
       │ H
       │
────────
<---- B ---->
```

对于普通冷弯 Z 型钢：

\[
\boxed{
t=\text{constant}
}
\]

即整个截面采用统一板厚。

---

# 4. 推荐直接支持不等翼缘

实际工程中 Z 型钢经常用于檩条、支撑、组合搭接等场景。

为了实现相邻构件搭接，上下翼缘可能故意采用不同宽度：

\[
\boxed{
B_1\neq B_2
}
\]

因此更推荐基础模型直接定义为：

\[
\boxed{
Z(H,B_1,B_2,t,R)
}
\]

其中：

| 参数 | 含义 |
|---|---|
| \(H\) | 总高度 |
| \(B_1\) | 上翼缘宽度 |
| \(B_2\) | 下翼缘宽度 |
| \(t\) | 板厚 |
| \(R\) | 主折弯内圆角 |

等翼缘只是：

\[
B_1=B_2
\]

的特殊情况。

---

# 5. 普通 Z 型钢推荐模型

基础版本：

\[
\boxed{
ZSection(H,B_1,B_2,t,R)
}
\]

示意：

```text
               B1
        <-------------->

        ┌──────────────
        │
        │
        │ H
        │
────────┘
<-- B2 -->
```

这种定义可以同时覆盖：

- 等翼缘 Z；
- 不等翼缘 Z。

---

# 6. 卷边 Z 型钢

工程中非常常见的另一类是卷边 Z 型钢。

即在上下翼缘自由端再增加一段短边：

```text
          │
          └──────────
          │
          │
──────────┐
          │
```

卷边可以显著提高局部稳定性，因此在建筑檩条等应用中非常常见。

---

# 7. 卷边参数

建议新增：

\[
C_1,\quad C_2
\]

分别表示：

- 上翼缘卷边长度；
- 下翼缘卷边长度。

于是可以定义：

\[
\boxed{
Z(H,B_1,B_2,t,R,C_1,C_2)
}
\]

其中：

### 普通 Z

\[
C_1=C_2=0
\]

### 对称卷边 Z

\[
C_1=C_2=C
\]

### 非对称卷边 Z

\[
C_1\neq C_2
\]

---

# 8. 是否需要把普通 Z 和卷边 Z 分成两个一级类型

不建议。

不建议设计：

```text
Z型钢
卷边Z型钢
```

两个独立基础类型。

更推荐统一成：

\[
\boxed{
Z型钢
}
\]

通过：

\[
C_1,\ C_2
\]

控制是否存在卷边。

这样：

\[
C_1=C_2=0
\]

自然退化为普通 Z。

这种模型更适合 CAM 管型库，也避免重复维护。

---

# 9. 卷边角度

卷边不一定永远与翼缘垂直。

常见有两种：

## 9.1 直卷边

卷边与翼缘近似垂直：

\[
\boxed{
\theta=90^\circ
}
\]

示意：

```text
│
└────────
```

---

## 9.2 斜卷边

卷边向内或向外倾斜：

```text
 ╲
  ╲
   └────────
```

因此通用模型可以进一步加入：

\[
\theta_1,\quad\theta_2
\]

定义：

\[
\boxed{
ZSection(
H,B_1,B_2,t,R,
C_1,C_2,
\theta_1,\theta_2
)
}
\]

---

# 10. UI 第一版不建议暴露所有参数

虽然底层可以支持：

\[
C_1,C_2,\theta_1,\theta_2
\]

但普通用户界面没必要第一版全部展示。

推荐 UI：

```text
Z型钢

高度       H
上翼缘     B1
下翼缘     B2
厚度       t
折弯半径   R

□ 卷边

卷边长度   C
卷边角度   θ
```

默认：

\[
C_1=C_2=C
\]

\[
\theta_1=\theta_2=\theta
\]

高级模式再允许上下两侧单独设置。

---

# 11. 折弯圆角

冷弯 Z 型钢通常由等厚钢板或钢带连续辊弯成形。

因此主截面可以统一认为：

\[
\boxed{
t=\text{constant}
}
\]

主腹板与翼缘之间的两个折弯位置：

```text
──────────╮
          │
          │
          ╰──────────
```

都可以使用：

\[
\boxed{
Fillet(R)
}
\]

进行构造。

---

# 12. 卷边圆角

如果存在卷边，则翼缘与卷边之间同样需要折弯圆角。

第一版可以直接共用：

\[
R
\]

即：

\[
\boxed{
R_{\text{main}}=R_{\text{lip}}=R
}
\]

如果以后需要更精细地兼容厂家实际尺寸，可扩展：

\[
R_{\text{main}}
\]

和：

\[
R_{\text{lip}}
\]

但不建议基础版本一开始就增加两个独立半径。

---

# 13. 推荐几何构造方式

对普通冷弯 Z 型钢，最适合采用：

\[
\boxed{
\text{中心线/中性层折线 + Fillet + Offset}
}
\]

进行生成。

---

## 13.1 先生成理论中心折线

普通 Z：

```text
────────
       │
       │
       └────────
```

卷边 Z：

```text
│
└────────
       │
       │
────────┐
        │
```

---

## 13.2 添加折弯圆角

在所有折弯位置执行：

\[
Fillet(R_c)
\]

若用户输入的 \(R\) 定义为内圆角，则中性层半径：

\[
\boxed{
R_c=R+\frac{t}{2}
}
\]

外圆角：

\[
\boxed{
R_o=R+t
}
\]

---

## 13.3 做等厚 Offset

中心层向两侧：

\[
+\frac{t}{2}
\]

和：

\[
-\frac{t}{2}
\]

进行等距偏移，得到完整实体截面。

由于整个 Z 型钢是等厚冷弯板件，这种方式非常适合。

---

# 14. 高度 \(H\) 的定义必须统一

软件中必须明确 \(H\) 到底表示：

- 外轮廓总高度；
- 中心线高度；
- 两翼缘中心线之间距离；
- 两理论尖角之间距离。

推荐 UI 中将：

\[
\boxed{
H=\text{截面外轮廓总高度}
}
\]

作为用户尺寸。

这样最符合实际选型和测量习惯。

底层生成时再根据：

\[
t,\ R
\]

转换为中心层几何。

---

# 15. \(B_1,B_2\) 的定义

推荐：

\[
\boxed{
B_1=\text{上翼缘外轮廓理论宽度}
}
\]

\[
\boxed{
B_2=\text{下翼缘外轮廓理论宽度}
}
\]

宽度从腹板对应理论位置量到翼缘自由端。

实际实现时应统一：

- 是从外侧交点量；
- 还是从中心层交点量。

推荐对用户始终采用**外尺寸**，底层转换到中性层。

---

# 16. 卷边长度 \(C\) 的定义

建议：

\[
\boxed{
C=\text{卷边外轮廓理论长度}
}
\]

如果是直卷边：

```text
│
│ C
│
└────────
```

如果是斜卷边：

```text
  ╲
   ╲ C
    ╲
     └────────
```

即 \(C\) 沿卷边自身方向测量。

---

# 17. 卷边角度 \(\theta\) 的定义

建议定义：

\[
\boxed{
\theta=\text{卷边与翼缘之间的内夹角}
}
\]

例如：

### 直卷边

\[
\theta=90^\circ
\]

### 斜卷边

根据实际截面输入其他角度。

这样几何定义比较直接。

---

# 18. 推荐最终参数模型

底层通用模型建议：

\[
\boxed{
ZSection(
H,
B_1,
B_2,
t,
R,
C_1,
C_2,
\theta_1,
\theta_2
)
}
\]

其中：

### 普通等翼缘 Z

\[
B_1=B_2
\]

\[
C_1=C_2=0
\]

### 普通不等翼缘 Z

\[
B_1\neq B_2
\]

\[
C_1=C_2=0
\]

### 对称卷边 Z

\[
C_1=C_2=C
\]

\[
\theta_1=\theta_2=\theta
\]

### 非对称卷边 Z

允许：

\[
C_1\neq C_2
\]

或：

\[
\theta_1\neq\theta_2
\]

---

# 19. 推荐数据结构

```cpp
struct ZSection
{
    double height;          // H

    double topFlange;       // B1
    double bottomFlange;    // B2

    double thickness;       // t
    double bendRadius;      // R

    double topLip;          // C1，0表示无卷边
    double bottomLip;       // C2

    double topLipAngle;     // theta1
    double bottomLipAngle;  // theta2
};
```

---

# 20. UI 简化版

推荐普通 UI：

```text
Z型钢

高度 H
上翼缘 B1
下翼缘 B2
厚度 t
折弯半径 R

□ 卷边

卷边长度 C
卷边角度 θ
```

内部默认：

```text
C1 = C2 = C
θ1 = θ2 = θ
```

高级模式才展开：

```text
上卷边长度 C1
下卷边长度 C2
上卷边角度 θ1
下卷边角度 θ2
```

---

# 21. 参数合法性检查

至少需要检查：

\[
H>0
\]

\[
B_1>0
\]

\[
B_2>0
\]

\[
t>0
\]

\[
R\ge0
\]

\[
C_1\ge0,\quad C_2\ge0
\]

角度应满足合理范围，例如：

\[
0^\circ<\theta_i<180^\circ
\]

同时需要检查：

1. 主折弯圆角不能吃掉整个翼缘；
2. 卷边圆角不能与主圆角发生非法重叠；
3. 卷边不能穿过腹板；
4. 上下卷边不能与其他轮廓发生自交；
5. Offset 后轮廓必须保持简单闭合；
6. 最终截面不能出现负长度直线段。

---

# 22. Z 型钢与槽钢的区别

虽然二者都是开口型钢，但截面拓扑不同。

## 槽钢

上下翼缘向同一侧：

```text
────────
│
│
────────
```

## Z 型钢

上下翼缘向相反侧：

```text
        ────────
        │
        │
────────
```

因此 Z 型钢不能简单作为槽钢的一个参数变种。

建议单独保留一级基础管型：

\[
\boxed{
Z型钢
}
\]

---

# 23. Z 型钢与卷边槽钢不应混淆

卷边槽钢：

```text
│──────┐
│      │
│──────┘
```

卷边 Z 型钢：

```text
       │
       └──────
       │
       │
───────┐
       │
```

两者虽然都可能有唇边，但主体拓扑不同。

因此：

\[
\boxed{
Z型钢
}
\]

仍应独立于：

\[
\boxed{
槽钢
}
\]

存在。

---

# 24. 关于“热轧”属性

本模型不处理热轧 Z 型钢。

普通结构用 Z 型钢按：

\[
\boxed{
\text{ColdFormed}
}
\]

理解即可。

需要特别注意：

> 原材料使用热轧钢板或热轧钢带，并不意味着成品 Z 型钢就是“热轧 Z 型钢”。

如果截面最终由连续辊式冷弯成形，则它仍然属于：

\[
\boxed{
\text{冷弯 Z 型钢}
}
\]

因此本 Z 型钢类型不建议提供普通“热轧”开关。

---

# 25. 最终推荐

Z 型钢建议作为独立一级管型：

\[
\boxed{
ZSection
}
\]

底层通用参数：

\[
\boxed{
H,B_1,B_2,t,R,C_1,C_2,\theta_1,\theta_2
}
\]

普通 UI 则简化为：

\[
\boxed{
H,B_1,B_2,t,R,C,\theta
}
\]

这样一个类型即可覆盖：

\[
\boxed{
\text{普通 Z}
\rightarrow
\text{不等翼缘 Z}
\rightarrow
\text{卷边 Z}
\rightarrow
\text{斜卷边 Z}
}
\]

而不需要为了每一种变体增加新的一级管型。

核心建模原则仍然保持：

\[
\boxed{
\text{等厚中心层折线 + Fillet + Offset}
}
\]

这套模型足够规整，也适合 CAM 截面库长期扩展。
