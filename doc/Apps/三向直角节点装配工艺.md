# 三向直角节点装配工艺

三根直管在同一端点汇交，轴线两两垂直。A、B 组成 L，C 沿第三个方向进入共同角面。工艺模板为 `orthogonal-corner`，成品造型独立定义在 `templates/finished-product/shapes.json`，资源库使用“三向直角节点”折叠分组。

| 连接 | 可选工艺 |
| --- | --- |
| A / B | 双端斜接、A 长件包接 B |
| C | 端面贴焊、轮廓插入、圆弧公母 |

六种组合共用同一个三构件成品。初次只生成成品，点击“下料件”后才生成加工方案与三件真实下料。条件参数由模板声明，插入或公母启用时直接显示对应字段；隐藏草稿保留，但不影响其他分支。前端使用通用成品和工艺编辑器。

工艺复用既有端切、相贯轮廓孔、圆弧插舌和配对母槽刀具。双端斜接时 C 入口分别落在 A、B 共同角面，各构件只切自己的材料；包接时 C 由 A 的长端承接。产品只提供原管、截面、库存余量及永久端点。加工位置和 C 的退切量由真实截面、节点和制造坐标推导，不移动成品来迁就刀具。

首版适用于三根独立、居中、统一圆角的方矩管，A/B 采用相同有效截面。连续折弯 L 与第三根管的组合需另行实现连续母材的加工映射。模板检查 C 入口的平直壁范围、内孔范围、插入深度和公母槽与斜接缝的关系；无法确认的截面和方位明确拒绝。

产品模板声明 `properties.topology = "orthogonal-corner"`，提供三个同端点的 `participantAnchors`、各自的 `assemblyFrame.member` 及真实 `sectionFrame`，即可由宿主提供三角色绑定。隐藏验证产品 `assembly-orthogonal-corner` 仅用于原生回归，不进入普通产品目录。实际绑定通过 `productBinding.operationScript` 调用本模板的 `build_bound_operations`；宿主核对输入不变、所有启用工序一一覆盖、工具参数与定位合法。

候选与最终实体均检查 A/B、A/C、B/C 三对材料碰撞、声明的接触距离以及 C 的实际入口位置和远侧壁。绑定及接触要求随产品保存，重开后继续核验。现有整件制造的 `not-ready / not-verified` 状态门槛继续保留；局部无碰撞不等于全部公差或装配顺序已获验证。

验收包含六种原生例子、六种实际产品的生成/拆单/检查/应用/保存重开、最大公母参数、非法节点与超界参数拒绝、旧 L/T 工艺以及全目录下料。浏览器回归覆盖条件字段、成品缓存、仅点击下料时计算，以及最新焦点、选区、左右及嵌套滚动位置和节点监听器。记录保存在 `artifacts/orthogonal-corner-20261002/`；目录中的 UI 截图仅验证界面结构，模型几何由原生实体及实际计划矩阵验证。
