# 1. 执行摘要

## 1.1 核心结论

激光切割**不能全面替代小管冲孔行业**，但能够大范围替代传统模具中的“纯去料类”工序，并显著减少专用冲头、凹模、芯棒、定位夹具和换模库存。

传统冲孔模具可按功能分成两类：

1. **去料类模具**  
   包括圆孔、方孔、长圆孔、D形孔、钥匙孔、异形孔、窗口、群孔、鱼嘴、V形缺口、斜切、相贯口和定尺切断等。此类特征多数可以由激光直接完成。

2. **塑性成形类模具**  
   包括翻边孔、拉伸孔、沉孔、压窝、凸台、桥形、百叶窗、压筋、缩口、扩口、压扁、卷边和翻孔攻牙等。此类工艺依赖材料塑性流动，纯激光切割无法直接完成。

最合理的工艺路线是：

> **激光负责开孔、开槽、相贯、鱼嘴、修边和切断；小型压力机或专用成形工位保留翻边、压窝、凸台、胀缩、压扁和螺纹成形。**

## 1.2 对CAM产品最重要的判断

传统模具名称繁多，但从几何内核看，大多数适合激光替代的模具可以归并为五种母类：

| 几何母类 | 典型传统模具 | CAM中的本质 |
|---|---|---|
| 固定方向轮廓扫掠 | 圆孔、方孔、长圆孔、D孔、钥匙孔、芯模冲孔 | 冲头二维截面沿冲压方向扫掠，与管体求交 |
| 配合体相交 | 单鱼嘴、双刀鱼嘴、圆管接圆管、方管接圆管 | 支管外表面与目标实体或偏置实体求交 |
| 平面截交 | 直切、斜切、角切、端部切断 | 管材与指定平面求交 |
| 参数化缺口 | V口、U口、角部缺口、折弯焊接槽 | 在指定面或管端去除参数化区域 |
| 阵列组合 | 群孔、排孔、圆周孔、螺旋孔 | 对基础特征进行线性、圆周或螺旋阵列 |

因此，CAM产品不应按模具厂商的商品名称逐个建立功能，而应以通用几何特征为核心，再叠加工艺语义、割缝补偿、加工顺序和机床能力约束。

# 2. 调研范围与术语

## 2.1 小管范围

本报告按设备结构、夹持难度和典型应用，将以下范围作为产品研究边界：

- **核心小管范围**：外径或外接圆约 6～60 mm；
- **扩展小中管范围**：约 60～120 mm；
- 截面包括圆管、方管、矩形管、椭圆管、圆角多边形管及其他异形管。

该范围是工程产品规划口径，不是统一行业标准。

## 2.2 术语约定

- **冲孔**：冲头与凹模共同剪切材料，通常有芯模或内部凹模支撑；
- **穿孔/刺孔**：没有完整内部凹模支撑，容易造成管壁凹陷或翻卷；
- **近侧壁**：冲头或激光首先接触的管壁；
- **远侧壁**：与近侧壁相对的管壁；
- **对穿孔**：沿同一轴线在近侧壁和远侧壁形成两个孔；
- **管面法向孔**：切割方向随管面局部法向变化；
- **固定方向孔**：孔轴线保持固定空间方向，模拟机械冲头的运动方向；
- **几何等效**：零件表面的开口轮廓一致；
- **工艺等效**：孔壁方向、光亮带、断裂带、毛刺、热影响等也满足原工艺要求。

# 3. 小管冲孔行业及典型应用

小管冲孔和管端切口广泛应用于：

- 家具、桌椅、货架和展示架；
- 护栏、围栏、楼梯扶手和防盗窗；
- 健身器材、自行车、童车和运动器械；
- 汽车座椅骨架、排气管、支架和管路；
- 空调、制冷、换热器集管；
- 医疗器械、手术器械和精密管件；
- 电器结构件、五金管件和流体连接件；
- 脚手架、农业机械和轻型钢结构。

专用管件模具厂通常同时提供：

- 管壁冲孔；
- 管端鱼嘴和相贯切口；
- 角切、V形缺口和矛形切口；
- 管材切断；
- 压扁、缩口、扩口和修边；
- 芯模冲孔、凸轮冲孔和组合模具。

# 4. 传统管材冲孔模具的分类

## 4.1 按模具组织形式分类

| 模具形式 | 说明 | 典型应用 |
|---|---|---|
| 单工序模 | 每次行程完成一个孔或一个切口 | 单圆孔、定位孔、单个槽口 |
| 复合模 | 一次行程完成多个动作 | 冲孔加切断、压扁加冲孔 |
| 级进模 | 工件逐步送料，每个工位完成不同动作 | 固定规格、大批量管件 |
| 多工位转盘模 | 工件转位后依次完成不同方向特征 | 多面孔、多角度孔 |
| 群孔模/排孔模 | 一组冲头一次完成多个孔 | 散热孔、筛孔、排孔 |
| 模块化冲孔单元 | 多个C形或侧冲单元按位置组合 | 长管多位置固定孔型 |
| 专机组合模 | 与送料、旋转、切断、检测集成 | 汽车、家具和高产量生产线 |

## 4.2 按管材支撑方式分类

### 4.2.1 无芯模冲孔

管材仅由外部模座或夹具支撑，冲头直接压入管壁。

特点：

- 模具简单、成本低；
- 上下料方便；
- 薄壁管容易凹陷、失圆或压扁；
- 孔边可能发生翻卷、拉伸和毛刺；
- 有时会利用凹陷形成定位、铆接或螺钉座结构。

### 4.2.2 固定芯棒冲孔

在管内插入带凹模口的芯棒，冲头从外侧冲向芯棒。

特点：

- 孔口平整；
- 管壁变形小；
- 尺寸和形状一致性较好；
- 适用于圆管、方管和矩形管；
- 需要解决芯棒插入、抽出、焊缝避让和废料排出。

### 4.2.3 分体芯模、开槽芯模

芯棒在冲孔位置设置分块凹模、开槽或活动镶块，适用于：

- 小内径管；
- 长管深处冲孔；
- 内部有焊瘤的焊管；
- 废料难以排出的结构。

### 4.2.4 浮动芯模、抽芯模

冲孔前芯模进入工作位置，冲孔后缩回、分解或抽出。

适用于：

- 孔后存在翻边或凸起；
- 管端截面发生变化；
- 固定芯棒不能直接退出的零件。

### 4.2.5 对向双冲模

两个冲头从管材两侧相向工作，可用于：

- 同时冲两个对称孔；
- 一次形成上下孔；
- 提高两面孔的位置关系；
- 一侧为功能孔、另一侧允许形成不同形态的孔。

### 4.2.6 凸轮或斜楔径向冲孔模

压力机竖直运动，通过斜楔或凸轮转换为水平或径向冲孔动作，适用于：

- 管侧孔；
- 多方向孔；
- 多个径向冲头同时动作；
- 上方空间受限的工件。

### 4.2.7 长芯棒加轴向送料、旋转分度

管材套在长芯棒或支撑杆上，通过送料轴和旋转轴依次加工，适合：

- 长管多孔；
- 圆周多角度孔；
- 集管、家具管和散热管；
- 孔型固定但位置较多的零件。

## 4.3 按零件几何分类

### 基础孔型

- 圆孔；
- 方孔、矩形孔；
- 长圆孔、腰形孔；
- 椭圆孔；
- D形孔、双D孔；
- 钥匙孔；
- 六边形、八边形及其他多边形孔；
- 月牙孔；
- 开口槽、封闭槽；
- 任意异形定位孔；
- 多孔、排孔和交错孔。

### 管端和缺口类

- 单鱼嘴、双鱼嘴；
- 偏心鱼嘴；
- V形、U形和角形缺口；
- 单侧、双侧缺口；
- 鞍形口和相贯口；
- 斜角切口；
- 矛形切口；
- 管端斜切、坡口和定尺切断；
- 插接舌片、定位槽和卡扣槽。

# 5. 适合激光替代的几何母类

## 5.1 固定方向轮廓扫掠

适用特征：

- 圆孔；
- 方孔、矩形孔；
- 长圆孔；
- D形孔、双D孔；
- 钥匙孔；
- 多边形孔；
- 任意异形孔。

几何本质：

> 将冲头二维轮廓沿固定冲压方向扫掠成柱状实体，再与管材实体或管面求交。

## 5.2 配合体相交

适用特征：

- 圆管接圆管鱼嘴；
- 方管接圆管鱼嘴；
- 矩形管接圆管；
- 偏心相贯；
- 斜交相贯；
- 任意支管接任意目标实体。

几何本质：

> 支管外表面与目标管、目标实体或其偏置实体求交。

## 5.3 平面截交

适用特征：

- 定尺直切；
- 斜切；
- 角切；
- 端部切断；
- 平面坡口的基准轮廓。

几何本质：

> 管材与指定平面求交。

## 5.4 参数化缺口

适用特征：

- 对称V形缺口；
- 非对称V形缺口；
- U形缺口；
- 方管角部缺口；
- 折弯焊接V槽；
- 管端局部去除。

## 5.5 阵列组合

适用特征：

- 直线排孔；
- 矩形阵列孔；
- 圆周均布孔；
- 交错孔；
- 螺旋孔；
- 缺失单元的非完整阵列。

# 6. 统一参数体系

## 6.1 管材基础参数

| 参数 | 含义 |
|---|---|
| `SectionType` | 圆管、方管、矩形管、椭圆管、异形管 |
| `D`、`R` | 圆管外径、外半径 |
| `B`、`H` | 方矩管外宽、外高 |
| `t` | 壁厚 |
| `rc` | 方矩管外圆角半径 |
| `rci` | 内圆角半径，不应简单固定为 `rc - t` |
| `θw` | 焊缝圆周角位置 |
| `zw` | 焊缝或局部缺陷的轴向参考位置 |

| `FaceId` | 方矩管或多面截面的面编号 |
| `p0` | 特征基准点 |
| `a` | 冲头轴线、孔轴或加工方向单位向量 |
| `ψ` | 异形轮廓绕自身轴线的旋转角 |
| `Datum` | 尺寸基于外表面、内表面、中面或投影平面 |
| `WallScope` | 近侧壁、远侧壁、两侧壁或所有相交壁 |
| `Tolerance` | 尺寸、位置、同轴度和轮廓度要求 |
| `KeepSide` | 去除或保留哪一侧材料 |

## 6.3 传统模具工艺参数

- 冲头轮廓和名义尺寸；
- 凹模轮廓；
- 单边或总冲裁间隙；
- 芯棒外形；
- 芯棒与管内壁间隙；
- 芯模插入长度；
- 夹紧区域和防扁结构；
- 压料、退料机构；
- 废料排出方向；
- 模具行程；
- 允许冲压力；
- 冲头入射方向；
- 焊缝避让角度；
- 允许管材尺寸公差。

公开资料通常不会给出统一的芯棒间隙，因为它取决于：

- 管材内径公差；
- 焊缝内凸高度；
- 管材直线度；
- 芯棒插入长度；
- 是否需要快速抽芯；
- 废料排出方式；
- 润滑和磨损要求。

因此，芯棒间隙应作为项目工艺参数，而不是写死为固定行业数值。

## 6.4 激光工艺参数

- 名义几何轮廓；
- 割缝宽度及补偿方向；
- 激光头姿态；
- 2.5D法向切割或固定方向切割；
- 穿孔方式；
- 引入、引出和微连接；
- 切割顺序；
- 热积累控制；
- 近侧壁、远侧壁或双面加工；
- 防止对侧内壁挂渣的策略；
- 气体种类和压力；
- 坡口角和钝边；
- 管材夹持、旋转和随动限制；
- 机床可达性和碰撞约束。

传统模具参数和激光参数必须分层保存，不能混为一个参数集合。

# 7. 冲压间隙、冲孔力与激光割缝

## 7.1 冲压间隙

设：

- 冲头名义尺寸为 \(D_p\)；
- 凹模尺寸为 \(D_d\)；
- 总冲裁间隙为 \(C_t\)；
- 单边间隙为 \(c\)。

则：

\[
D_d=D_p+C_t
\]

\[
c=\frac{C_t}{2}
\]

UniPunch公开的经验估算中，总间隙可按材料和板厚近似为：

\[
C_t=
\begin{cases}
0.15t,&\text{铝}\ 
0.20t,&\text{低碳钢}\ 
0.25t,&\text{不锈钢}
\end{cases}
\]

该数值是供应商经验参考，并非适用于所有材料、冲速、质量要求和模具结构的统一强制标准。

## 7.2 激光切换时的尺寸基准

传统冲孔的功能孔尺寸主要由**冲头尺寸**决定，凹模尺寸比冲头大是为了获得合理剪切和排料间隙。

改为激光切割时，应采用：

- 零件功能孔的名义尺寸；或
- 冲头截面的名义尺寸。

不应直接采用凹模尺寸。

设激光割缝宽度为 \(k\)，对内孔，激光中心轨迹通常向废料侧偏置约：

\[
\Delta=\frac{k}{2}
\]

冲压间隙 \(C_t\) 与激光割缝 \(k\) 的物理含义不同，不能直接换算。

## 7.3 冲孔力

冲孔力的基本关系为：

\[
F\approx P\cdot t\cdot \tau_s
\]

其中：

- \(P\)：被剪切轮廓总周长；
- \(t\)：材料厚度；
- \(\tau_s\)：材料抗剪强度。

群孔模同时冲出 \(N\) 个孔时，可近似表示为：

\[
F_{total}\approx\sum_{i=1}^{N}P_i t\tau_s+F_{strip}
\]

其中 \(F_{strip}\) 为退料、弹簧和摩擦等附加力。

激光没有总冲压力限制，但孔数增多会增加：

- 穿孔次数；
- 总切割周长；
- 热输入；
- 管材变形风险；
- 对侧内壁挂渣；
- 加工节拍。

# 8. 固定方向冲孔的真实几何关系

## 8.1 “冲头圆孔”不等于“展开面圆孔”

设圆管：

- 外半径为 \(R\)；
- 管轴为 \(Z\)；
- 冲头沿 \(Y\) 方向径向运动；
- 冲孔中心轴向位置为 \(z_0\)。

圆管外表面可表示为：

\[
x=R\sin\theta
\]

\[
y=R\cos\theta
\]

\[
z=z
\]

将圆管展开后定义：

\[
u=R\theta,\qquad v=z-z_0
\]

设冲头截面位于垂直于冲压方向的平面内，其边界为：

\[
F(p,q)=0
\]

由于冲头沿 \(Y\) 方向扫掠，圆管表面上的真实孔口边界满足：

\[
F\left(R\sin\frac{u}{R},v\right)=0
\]

这才是固定方向机械冲头在圆管上形成的真实表面轮廓。

## 8.2 圆形冲头

设冲头半径为 \(a\)，则冲头截面为：

\[
p^2+q^2=a^2
\]

映射到圆管展开面后：

\[
R^2\sin^2\left(\frac{u}{R}\right)+v^2=a^2
\]

因此，机械冲头形成的“圆孔”在圆管展开图上通常不是圆。

其圆周方向最大展开宽度为：

\[
W_u=2R\arcsin\left(\frac{a}{R}\right)
\]

用管径 \(D=2R\)、孔径 \(d=2a\) 表示：

\[
\boxed{W_u=D\arcsin\left(\frac dD\right)}
\]

如果直接在展开面画直径为 \(d\) 的圆，其宽度为 \(d\)。两者相对差为：

\[
\varepsilon_w=
\frac{\arcsin(d/D)}{d/D}-1
\]

| 孔径/管径 \(d/D\) | 真实冲头轮廓与展开圆的宽度差 |
|---:|---:|
| 0.20 | 约 0.68% |
| 0.40 | 约 2.88% |
| 0.60 | 约 7.25% |
| 0.80 | 约 15.91% |

示例：

- 圆管外径 \(D=20\text{ mm}\)；
- 冲头直径 \(d=8\text{ mm}\)；
- \(d/D=0.4\)。

则真实机械冲孔轮廓的最大展开宽度为：

\[
W_u=20\arcsin(0.4)=8.23\text{ mm}
\]

而简单展开圆孔的宽度只有 8.00 mm。

对于大管小孔，该差异较小；对于小管大孔，差异会迅速扩大。

## 8.3 任意冲头轮廓映射

设冲头平面上的一点为：

\[
(p,q)
\]

对于径向、过圆心的固定方向冲孔，其在近侧圆管展开面上的坐标为：

\[
u=R\arcsin\left(\frac pR\right)
\]

\[
v=q
\]

因此同一关系可用于：

- 方孔；
- 长圆孔；
- D形孔；
- 钥匙孔；
- 多边形孔；
- 任意草图异形孔。

该解析关系仅适用于：

- 圆管；
- 冲头轴线径向通过管心；
- 主要处理近侧管壁；
- 轮廓没有跨越超过半圆。

偏心冲头、斜向冲头、椭圆管和异形管应使用三维扫掠实体求交。

## 8.4 通用三维算法

定义冲头二维区域为 \(\Omega\)，冲压方向单位向量为 \(\mathbf a\)，则冲头扫掠实体为：

\[
S_p=
\left\{
\mathbf q+\lambda\mathbf a
\mid
\mathbf q\in\Omega,\lambda\in\mathbb R
\right\}
\]

最终孔口曲线为：

\[
C=\partial T\cap\partial S_p
\]

其中 \(T\) 为管材实体。

以OpenCascade为例，可采用以下流程：

1. 将冲头二维轮廓构造成 `Face`；
2. 沿冲头轴线构造足够长的 `Prism`；
3. 使用管材外壳或实体与 `Prism` 求 `Section`；
4. 按冲头入射方向区分近侧和远侧交线；
5. 对交线排序、闭合和方向统一；
6. 根据名义尺寸、割缝和功能基准做补偿；
7. 转换为机床可执行的2.5D或3D轨迹。

## 8.5 激光替代的等效层级

应区分四种替代层级：

1. **表面轮廓等效**：管外表面的孔口边界一致；
2. **投影尺寸等效**：沿功能轴观察时的尺寸一致；
3. **孔壁方向等效**：孔壁方向接近机械冲头轴线；
4. **工艺表面等效**：光亮带、断裂带、毛刺和热影响也满足要求。

普通2.5D管材激光通常可以完成前两项，但不一定能完全复制后两项。

# 9. 孔、槽及异形孔模具参数

## 9.1 圆孔

推荐参数：

\[
\{d,z_0,\theta_0,\mathbf a,WallScope,Datum\}
\]

周长：

\[
P=\pi d
\]

CAM必须区分：

- 管面展开圆孔；
- 管面法向圆孔；
- 固定方向冲头圆孔；
- 同一公共轴线的对穿孔；
- 允许锥度的普通孔；
- 销轴或螺栓配合孔。

## 9.2 长圆孔

建议采用：

- 总长 \(L\)；
- 宽度 \(W\)；
- 端部半径 \(r=W/2\)；
- 方向角 \(\psi\)。

中间直线段长度：

\[
L_s=L-W
\]

周长：

\[
P=2(L-W)+\pi W
\]

也可写为：

\[
P=2L+(\pi-2)W
\]

圆管上的固定方向长圆冲头，应整体执行扫掠求交，不能直接在展开面绘制同尺寸长圆孔。

## 9.3 方孔和矩形孔

参数：

\[
\{A,B,\rho,\psi\}
\]

其中：

- \(A,B\)：外包尺寸；
- \(\rho\)：四角圆角；
- \(\psi\)：轮廓旋转角。

带四个相同圆角时，周长为：

\[
P=2(A+B)-8\rho+2\pi\rho
\]

即：

\[
P=2(A+B)+(2\pi-8)\rho
\]

机械冲头通常不会采用数学意义上的无限尖角。激光虽然可以生成很小的角部半径，但应根据光斑、割缝、切割速度、热积累和装配功能设置最小有效圆角。

## 9.4 单D孔

推荐参数：

- 基准圆直径 \(d\)；
- 圆心到平边距离 \(c\)；
- 或平边弦长 \(b\)；
- 方向角 \(\psi\)。

几何关系：

\[
b=2\sqrt{\left(\frac d2\right)^2-c^2}
\]

不建议仅保存外包宽、高，因为相同外包尺寸可能对应不同圆弧半径和不同平边深度。

## 9.5 双D孔

推荐参数：

- 基准圆直径 \(d\)；
- 两个平边之间距离 \(H_f\)；
- 两侧是否对称；
- 方向角 \(\psi\)。

对称双D孔中，单侧平边到圆心距离为：

\[
c=\frac{H_f}{2}
\]

## 9.6 钥匙孔

推荐参数：

- 大圆直径 \(D_h\)；
- 颈部宽度 \(W_n\)；
- 颈部长度 \(L_n\)；
- 颈部末端半径 \(r_n\)；
- 大圆中心到颈部末端中心距 \(C\)；
- 方向角 \(\psi\)。

需要区分：

1. 圆头加矩形颈；
2. 圆头加长圆颈；
3. 大圆和小圆相交；
4. 带止转平边的安装孔。

D孔、钥匙孔、多边形孔和任意异形孔非常适合激光替代，因为传统冲压通常需要为每种尺寸和方向制作专用冲头。

## 9.7 任意异形孔

推荐使用统一的 `PunchProfile`：

- 二维轮廓 \(\Omega\)；
- 轮廓基准点；
- 冲头轴线 \(\mathbf a\)；
- 轮廓旋转角 \(\psi\)；
- 近侧/远侧壁范围；
- 尺寸基准；
- 割缝补偿规则。

# 10. 对穿孔、同轴孔与双面孔

对穿孔不能简单保存为两个彼此无关的普通孔，应定义成一个具有公共轴线的组合特征。

## 10.1 `ThroughPunch`参数

| 参数 | 含义 |
|---|---|
| `L=(p0,a)` | 公共孔轴线 |
| `Profile` | 冲头截面或功能孔轮廓 |
| `NearWall` | 近侧壁 |
| `FarWall` | 远侧壁 |
| `Coaxial` | 是否要求同轴 |
| `Δz` | 两孔允许的轴向偏差 |
| `Δθ` | 两孔允许的圆周角偏差 |
| `Tc` | 同轴度公差 |

若冲头轴线径向通过圆管中心，则：

\[
\theta_{far}=\theta_{near}+\pi
\]

\[
z_{far}=z_{near}
\]

若冲头偏心或斜向进入，远侧孔位置应由公共轴线与远侧管面求交获得，不能简单增加180°。

## 10.2 激光加工方式

1. 旋转到近侧和远侧，分别切两个孔；
2. 从近侧切穿后继续加工远侧壁；
3. 使用五轴激光或机器人沿公共孔轴加工。

通常第一种最常见，但同轴度受以下因素影响：

- 管材圆度和椭圆度；
- 旋转轴精度；
- 卡盘中心误差；
- 管材挠曲；
- 两次定位误差；
- 焊缝和截面扭转。

因此CAM和工艺数据库必须保留“两个孔属于同一同轴特征”的语义。

# 11. 群孔、排孔及阵列孔

## 11.1 矩形阵列

推荐参数：

\[
\{n_z,n_c,p_z,p_c,\gamma,s\}
\]

其中：

- \(n_z\)：轴向行数；
- \(n_c\)：圆周或横向列数；
- \(p_z\)：轴向间距；
- \(p_c\)：圆周弧长间距；
- \(\gamma\)：阵列整体旋转角；
- \(s\)：错位量。

圆管中弧长和角度关系：

\[
p_c=R\Delta\theta
\]

\[
\Delta\theta=\frac{p_c}{R}
\]

## 11.2 圆周均布阵列

若圆周均布 \(N\) 个孔：

\[
\Delta\theta=\frac{2\pi}{N}
\]

\[
p_c=\frac{2\pi R}{N}
\]

## 11.3 交错阵列

第 \(j\) 行第 \(i\) 个孔：

\[
\theta_{j,i}=\theta_0+i\Delta\theta+(j\bmod2)\frac{\Delta\theta}{2}
\]

\[
z_{j,i}=z_0+jp_z
\]

## 11.4 螺旋阵列

\[
\theta_i=\theta_0+i\Delta\theta
\]

\[
z_i=z_0+ip_z
\]

## 11.5 几何和工艺应分开建模

阵列几何参数之外，还应保存：

- 同一区域允许连续切割的最大孔数；
- 跳孔距离；
- 奇偶行分组；
- 中间向两端或一端向另一端的切割顺序；
- 近侧、远侧孔的加工先后；
- 是否降功率或采用脉冲；
- 是否采用无引线小孔工艺；
- 废料是否可能掉入管内并卡住；
- 局部热积累上限。

群孔从几何上容易激光化，但在大批量、固定规格和单行程多冲头场景中，传统群孔模仍可能有明显节拍优势。

# 12. 鱼嘴、鞍形口与相贯口

## 12.1 参数体系

| 参数 | 含义 |
|---|---|
| `BranchSection` | 被开鱼嘴的支管截面 |
| `TargetSection` | 目标管或目标实体截面 |
| `r` | 圆形支管外半径 |
| `R` | 目标圆管外半径 |
| `β` | 两管轴线夹角 |
| `e` | 两轴线最短距离，即偏心量 |
| `z0` | 鱼嘴轴向基准位置 |
| `ψ` | 支管绕自身轴线的滚转角 |
| `g` | 装配间隙 |
| `b` | 焊接坡口角 |
| `l` | 坡口钝边 |
| `TrimSide` | 保留哪一侧材料 |
| `FitType` | 外贴、内插、套接或其他配合方式 |

## 12.2 圆管接圆管通用公式

设：

- 支管轴线为 \(Z\)；
- 目标管轴线与支管轴线夹角为 \(\beta\)；
- 目标管轴线位于 \(XZ\) 平面；
- 两轴线在 \(Y\) 方向偏心为 \(e\)；
- 目标有效半径为 \(R_e\)。

若考虑装配间隙 \(g\)，可采用：

\[
R_e=R+g
\]

支管截面周边点：

\[
x=r\cos(\theta+\psi)
\]

\[
y=r\sin(\theta+\psi)
\]

鱼嘴轴向轮廓为：

\[
\boxed{
z(\theta)=z_0+x\cot\beta
\pm\csc\beta\sqrt{R_e^2-(y-e)^2}
}
\]

代入圆形支管后：

\[
z(\theta)=z_0+r\cos(\theta+\psi)\cot\beta
\pm\frac{
\sqrt{R_e^2-[r\sin(\theta+\psi)-e]^2}
}{\sin\beta}
\]

存在条件：

\[
|r\sin(\theta+\psi)-e|\le R_e
\]

正负号对应目标圆柱的不同交线分支，应根据支管端部方向和保留侧自动选择。

## 12.3 90°同心鱼嘴

当：

\[
\beta=90^\circ,\qquad e=0
\]

公式化简为：

\[
z(\theta)=z_0
\pm\sqrt{R_e^2-r^2\sin^2(\theta+\psi)}
\]

展开坐标：

\[
u=r\theta
\]

\[
v=z(\theta)
\]

## 12.4 任意支管截面接圆管

如果支管不是圆管，将支管外轮廓参数化为：

\[
[x(s),y(s)]
\]

则：

\[
\boxed{
z(s)=z_0+x(s)\cot\beta
\pm\csc\beta\sqrt{R_e^2-[y(s)-e]^2}
}
\]

因此：

- 方管接圆管；
- 矩形管接圆管；
- 椭圆管接圆管；
- 圆角方管接圆管；

本质上都是同一个几何特征，不需要分别开发独立算法。

## 12.5 目标不是圆管时

当目标对象为：

- 方管；
- 椭圆管；
- 异型材；
- 多管组合节点；
- 任意钣金、铸件或曲面；

应采用通用三维方法：

1. 建立支管外表面；
2. 建立目标实体或考虑间隙后的偏置实体；
3. 求两者交线；
4. 选择支管端部的有效闭合轮廓；
5. 处理轮廓分支、尖点和退化交线；
6. 根据焊接间隙、坡口、钝边和割缝做补偿。

## 12.6 单鱼嘴模与双刀鱼嘴模的合并

“单冲鱼嘴模”和“双刀鱼嘴模”的主要差异是：

- 模具动作方式；
- 冲压行程次数；
- 刀具分布；
- 生产节拍。

最终零件鱼嘴轮廓可以完全相同，因此在CAM中应统一为 `SaddleJoint`，不应拆成两个几何功能。

# 13. 斜切、角切与端部平面切割

## 13.1 参数定义

| 参数 | 含义 |
|---|---|
| `z0` | 切割平面的基准轴向位置 |
| `μ` | 切割平面相对垂直管轴平面的倾角 |
| `φ` | 倾斜方向在截面内的方位角 |
| `b` | 坡口角 |
| `l` | 钝边 |
| `KeepSide` | 保留平面哪一侧 |
| `LengthDatum` | 长度按最长点、最短点或管轴交点测量 |

切割平面可表示为：

\[
z=z_0+\tan\mu(x\cos\phi+y\sin\phi)
\]

对于半径为 \(r\) 的圆管：

\[
x=r\cos\theta,\qquad y=r\sin\theta
\]

得到：

\[
\boxed{
z(\theta)=z_0+r\tan\mu\cos(\theta-\phi)
}
\]

最高点和最低点的轴向差：

\[
\Delta z=2r|\tan\mu|
\]

## 13.2 两根管等角斜接

设两根管轴线夹角为 \(\beta\)：

- \(\beta=180^\circ\)：直线连接；
- \(\beta=90^\circ\)：直角连接。

对称等角斜接时，每根管相对垂直端面的倾角为：

\[
\mu=\frac{180^\circ-\beta}{2}
\]

例如直角连接：

\[
\beta=90^\circ,\qquad \mu=45^\circ
\]

这类模具属于纯平面截交，几何上非常适合由激光替代。

# 14. V形缺口与折弯焊接V槽

## 14.1 普通边缘V形缺口

参数：

- 缺口深度 \(h\)；
- 夹角 \(\alpha\)；
- 开口宽度 \(w\)；
- 根部圆角 \(\rho\)；
- 缺口方向 \(\psi\)；
- 对称或非对称；
- 缺口中心位置。

对称尖V：

\[
\boxed{
w=2h\tan\left(\frac{\alpha}{2}\right)
}
\]

反算角度：

\[
\alpha=2\arctan\left(\frac{w}{2h}\right)
\]

非对称V形，左右两侧角分别为 \(\alpha_1\)、\(\alpha_2\)：

\[
w=h(\tan\alpha_1+\tan\alpha_2)
\]

\[
\alpha=\alpha_1+\alpha_2
\]

存在根部圆角 \(\rho\) 时，应先生成理论尖V，再根据两侧直线的相切关系构造根部圆弧。

圆管上的固定方向V形冲头，应采用“冲头扫掠体与管面求交”，不能简单把平面V形直接贴到展开图。

## 14.2 方管折弯焊接V槽

此类模具通常同时完成：

1. 去除方管三面或局部管壁；
2. 保留一面作为铰链；
3. 对保留壁压出折痕或局部减薄；
4. 后续折弯；
5. 焊接固定。

推荐参数：

- 目标转角 \(\delta\)；
- 铰链所在面；
- 铰链线到切口外侧面的有效高度 \(H_e\)；
- V形口宽度 \(w\)；
- 剩余铰链厚度 \(t_r\)；
- 压痕深度 \(s=t-t_r\)；
- 根部圆角；
- 焊接间隙 \(g\)。

理想尖角、零折弯半径、对称V槽的几何近似为：

\[
\boxed{
w=2H_e\tan\left(\frac{\delta}{2}\right)
}
\]

非对称折弯：

\[
w_1=H_e\tan\delta_1
\]

\[
w_2=H_e\tan\delta_2
\]

\[
\delta_1+\delta_2=\delta
\]

该公式是理想几何近似。实际生产还应考虑：

- 材料回弹；
- 折弯内半径；
- 保留壁厚；
- 中性层移动；
- 焊缝收缩；
- 激光热影响；
- 切口根部圆角。

### 激光替代边界

激光可以完成：

- 三面V形切除；
- 保留第四面；
- 预留焊接间隙；
- 增加定位槽和止口。

普通穿透式激光不能直接等效完成：

- 指定深度的机械压痕；
- 局部塑性减薄；
- 受控铰链厚度和折弯半径。

因此该特征属于：

> **切除几何可替代，折痕成形需保留机械成形或采用专门的激光刻槽/复合工艺验证。**

# 15. 管材切断及共边切割

## 15.1 传统切断模的功能

传统管材切断模除了分离材料，还可能承担：

- 周向夹紧；
- 防止截面塌陷；
- 控制切断顺序；
- 降低凹陷和毛刺；
- 实现接近无料损的剪切切断。

因此，激光在几何上可以替代切断，但不一定在截面保持、无热影响和节拍方面完全等效。

## 15.2 激光切断参数

| 参数 | 含义 |
|---|---|
| `z0` | 管轴与切割平面的交点 |
| `μ` | 斜切角 |
| `φ` | 倾斜方位 |
| `k` | 激光割缝宽度 |
| `LengthReference` | 最长点、最短点或中心点 |
| `CommonCut` | 是否与下一零件共边 |
| `EndQuality` | 端面垂直度、毛刺和热影响要求 |

直切：

\[
z=z_0
\]

斜切：

\[
z=z_0+\tan\mu(x\cos\phi+y\sin\phi)
\]

## 15.3 共边切割长度补偿

若两个零件共用一条激光割缝，割缝宽度为 \(k\)，必须明确：

- 左件保证长度；
- 右件保证长度；
- 两件各承担 \(k/2\)；
- 或在两件之间增加补偿余量。

因此共边切割不仅是一条几何线，还包含长度基准和尺寸优先级语义。

# 16. 不能被纯激光直接替代的成形模具

以下工艺依赖材料塑性流动，不能仅靠切除轮廓完成：

| 成形模具 | 形成结构 | 纯激光替代性 |
|---|---|---:|
| 沉孔、压窝模 | 螺钉头沉台 | 不能直接替代 |
| 翻边孔、拉伸孔 | 孔周立边或套筒 | 不能直接替代 |
| 凸台、焊接凸点 | 局部凸起 | 不能直接替代 |
| 翻孔攻牙 | 提高有效螺纹高度 | 不能完全替代 |
| 百叶窗模 | 切开并抬起材料 | 不能直接替代 |
| 桥形模 | 卡扣或穿带桥 | 不能直接替代 |
| 压筋、压线模 | 加强和定位结构 | 不能直接替代 |
| 压字、凹凸标记 | 立体字符 | 可改激光标记，但结构不同 |
| 压扁、缩口、扩口 | 改变管端截面 | 不能替代 |
| 卷边、翻边、包边 | 管口安全或连接结构 | 不能替代 |
| 铆接凸缘、铆螺母座 | 机械连接功能 | 不能直接替代 |

激光可以为这些成形工序提供：

- 预开孔；
- 预切轮廓；
- 定位缺口；
- 工艺起始切口；
- 后续成形的尺寸基准。

但后续仍需要冲压、旋压、滚压、扩缩口或其他成形设备。

# 18. 小管激光加工的特殊风险

## 18.1 小孔能力不是一个固定数字

孔能否加工不能只用“最小孔径”判断，还应考虑：

- 孔径与壁厚比；
- 孔径与管径比；
- 材料；
- 光源和光斑；
- 孔的圆度和锥度；
- 入口、出口尺寸差；
- 内壁挂渣；
- 位置精度；
- 是否允许后续去毛刺和清洗。

## 18.2 对侧内壁挂渣

激光切穿近侧管壁后，熔融金属可能飞向远侧内壁并重新凝固。风险通常随以下因素增加：

- 管径减小；
- 壁厚增加；
- 孔密度增加；
- 功率和连续热输入增加；
- 管内空间封闭；
- 对侧壁距离较近。

可能影响：

- 医疗和食品管件洁净度；
- 液压、气动和制冷管路；
- 后续插管装配；
- 内部流体阻力；
- 内壁防腐层；
- 疲劳寿命。

建议在CAM中建立“背壁风险”模型，输入至少包括：

- 内径；
- 壁厚；
- 材料；
- 孔径和孔周长；
- 激光功率；
- 辅助气体；
- 对侧壁距离；
- 连续孔数量；
- 切割方向。

高风险时可推荐：

- 降功率或脉冲切割；
- 分段切割；
- 跳跃式孔序；
- 降低局部热集中；
- 内置防飞溅件或牺牲芯棒；
- 切后清渣；
- 改用机械冲孔。

## 18.3 小管刚度和热积累

小直径、长悬伸、薄壁管材可能出现：

- 气流或随动引起振动；
- 局部软化；
- 密集孔热积累；
- 管材弯曲和扭转；
- 卡盘夹持变形；
- 孔位漂移；
- 表面变色。

## 18.4 焊缝和实际截面

焊管的焊缝内凸、外凸和焊缝角度会影响：

- 芯棒插入；
- 激光反射和局部切割质量；
- 孔位和装配；
- 夹持后的截面变化。

因此系统应支持：

- 焊缝角度输入；
- 焊缝视觉或传感定位；
- 特征自动避让；
- 实际截面补偿；
- 方矩管扭转补偿。

## 18.5 圆孔的几何语义

圆管上的“圆孔”至少包含：

1. 管面法向切割形成的表面圆形；
2. 固定空间方向切割形成的圆柱孔；
3. 正视投影为圆的装配孔；
4. 对侧同轴的双面孔；
5. 仅要求通气或泄水的普通开口。

不同语义对应不同轨迹和质量要求，不能用一个“圆孔”命令全部替代。

# 19. 经济性判断模型

不能简单规定“超过多少件就冲孔、低于多少件就激光”。需要综合：

- 孔数；
- 总切割周长；
- 管壁厚度和材料；
- 是否需要旋转和多面加工；
- 模具复杂度；
- 芯棒长度；
- 上下料方式；
- 内壁清渣；
- 激光尾料；
- 模具寿命；
- 产品改版频率；
- 质量和洁净度要求。

## 19.1 冲孔单件成本

\[
C_{punch}=
\frac{C_{die}+C_{fixture}+C_{setup}}{N}
+T_{punch}R_{press}
+C_{maint}
+C_{scrap}
\]

## 19.2 激光单件成本

\[
C_{laser}=
\frac{C_{program}+C_{verify}}{N}
+T_{laser}R_{laser}
+C_{gas}
+C_{clean}
+C_{tail}
\]

## 19.3 理论交叉批量

当激光单件运行成本高于冲孔时，理论交叉批量可近似表示为：

\[
N^*=\frac{C_{die}+C_{fixture}}
{C_{laser,run}-C_{punch,run}}
\]

实际决策还要加入：

- 模具能否跨型号复用；
- 产品是否在模具回本前改版；
- 换模和仓储成本；
- 模具维修停机；
- 激光设备利用率；
- 质量返工和清渣成本。

# 20. CAM特征模型与数据结构建议

## 20.1 `PunchProfile`

用于圆孔、长圆孔、方孔、D孔、钥匙孔、多边形孔和任意异形孔。

核心参数：

\[
\{\Omega,\mathbf p_0,\mathbf a,\psi,WallScope,Datum,Kerf\}
\]

其中 \(\Omega\) 为冲头平面轮廓。

## 20.2 `ThroughPunch`

用于同轴双面孔。

核心参数：

\[
\{\Omega,\mathbf L,NearWall,FarWall,T_c\}
\]

## 20.3 `Pattern`

用于群孔、排孔和螺旋孔。

核心参数：

\[
\{BaseFeature,n_z,n_c,p_z,\Delta\theta,s,\gamma,MissingCells\}
\]

## 20.4 `SaddleJoint`

用于鱼嘴、鞍形口和相贯口。

核心参数：

\[
\{BranchSection,TargetGeometry,\beta,e,\psi,z_0,g,b,l\}
\]

## 20.5 `PlaneCut`

用于直切、斜切和角切。

核心参数：

\[
\{z_0,\mu,\phi,b,l,KeepSide,LengthDatum\}
\]

## 20.6 `VNotch`

用于普通V形缺口。

核心参数：

\[
\{h,\alpha,w,\rho,\alpha_1,\alpha_2,\psi\}
\]

## 20.7 `BendVNotch`

用于方管折弯焊接V槽。

核心参数：

\[
\{\delta,H_e,w,HingeFace,t_r,\rho,g\}
\]

## 20.8 `SurfaceContour`

用于任意开窗、自由轮廓和局部槽口。

建议参数：

- 原始二维或三维轮廓；
- 轮廓所在基准面；
- 投影或包覆方式；
- 切割方向；
- 保留侧；
- 近侧/远侧壁；
- 割缝补偿；
- 微连接和掉料策略。

## 20.9 传统模具名称与CAM特征的合并关系

| 传统模具名称 | CAM统一特征 |
|---|---|
| 单孔芯模、凸轮芯模、模块化冲孔单元 | `PunchProfile` |
| 圆孔、方孔、长圆孔、D孔、钥匙孔、多边形孔 | `PunchProfile.Profile`的不同参数 |
| 对穿模、上下双冲模、同轴孔模 | `ThroughPunch` |
| 群孔模、排孔模、多冲头模 | `Pattern(PunchProfile)` |
| 单鱼嘴模、双刀鱼嘴模 | `SaddleJoint` |
| 圆管接圆管、方管接圆管、矩形管接圆管 | `SaddleJoint`的不同截面参数 |
| 角切模、斜切模、端部切断模 | `PlaneCut` |
| 普通V缺口、非对称V缺口 | `VNotch` |
| 折弯焊接V槽 | `BendVNotch` |
| 任意开窗、异形开槽 | `SurfaceContour` |

# 21. 产品开发优先级与验证方案

## 21.1 第一阶段优先特征

建议优先开发：

1. 圆孔、方孔、矩形孔、长圆孔；
2. D孔、双D孔、钥匙孔和任意异形孔；
3. 固定方向冲头扫掠与管面求交；
4. 对穿孔和同轴孔；
5. 线性、圆周、交错和螺旋阵列；
6. 圆管接圆管鱼嘴；
7. 方矩管接圆管及偏心、斜交相贯；
8. 直切、斜切和角切；
9. 普通V形缺口；
10. 任意表面开窗和槽口。

## 21.2 第二阶段

- 五轴坡口和钝边；
- 复杂目标实体相贯；
- 实测截面和焊缝补偿；
- 背壁风险模型；
- 热积累智能排序；
- 与后续翻边、压窝和攻牙工序联动；
- 机器人或弯管后3D切割。

## 21.3 推荐的样件验证矩阵

至少选择以下代表性样件：

| 样件 | 目的 |
|---|---|
| 大管小圆孔 | 验证简单展开和扫掠模型差异较小时的效率 |
| 小管大圆孔 | 验证 \(d/D\) 较大时的真实冲头轮廓 |
| 长圆孔、D孔、钥匙孔 | 验证异形轮廓映射和尺寸补偿 |
| 同轴对穿孔 | 验证双面定位和同轴度 |
| 密集排孔 | 验证节拍、热变形和内壁挂渣 |
| 90°同心鱼嘴 | 验证基础相贯算法 |
| 偏心斜交鱼嘴 | 验证通用相交算法 |
| 方矩管接圆管 | 验证圆角截面和真实截面影响 |
| 端部斜切 | 验证长度基准和共边补偿 |
| 普通V缺口 | 验证参数化几何 |
| 折弯焊接V槽 | 验证激光切除加后续折弯的混合工艺 |
| 医疗或流体小管 | 验证背壁挂渣和洁净度 |

## 21.4 每个样件应记录的数据

- 材料和壁厚；
- 管径或截面尺寸；
- 实测椭圆度、圆角和扭转；
- 焊缝位置；
- 特征名义尺寸；
- 激光加工时间；
- 冲压加工时间；
- 换模、调机和编程时间；
- 位置精度；
- 轮廓度；
- 同轴度；
- 孔口圆度和锥度；
- 外壁和内壁毛刺；
- 对侧内壁挂渣；
- 热影响和变色；
- 后处理时间；
- 单件综合成本；
- 废品率和重复稳定性。

## 21.5 最终形成三档工艺数据库

1. **可直接替代**  
   激光在尺寸、质量、节拍和成本上均满足要求。

2. **条件替代**  
   需要特定光源、五轴切割、背壁保护、二次清理或后续成形。

3. **保留冲压/成形**  
   激光不能形成所需结构，或在节拍、洁净度、精度和成本上不具优势。

# 22. 最终结论

## 22.1 市场定位

不建议把小管激光产品宣传为“全面替代冲孔机”。更准确的定位是：

> **替代大量去料型专用模具，合并冲孔、开槽、鱼嘴、相贯、修边和切断工序；对于翻边、压窝、凸台、胀缩和压扁等特征，形成激光预切加机械成形的混合工艺。**

## 22.2 最值得开发的四个几何内核

1. 任意冲头轮廓沿固定轴线扫掠并与管面求交；
2. 任意支管截面与目标实体求交；
3. 任意平面与管材截交；
4. 参数化V形、U形和角部缺口。

叠加以下能力后，可覆盖绝大多数纯去料型管材冲压模具：

- 同轴对穿孔；
- 线性、圆周和螺旋阵列；
- 割缝补偿；
- 坡口和钝边；
- 热加工排序；
- 背壁风险控制；
- 机床可达性和碰撞检查。

## 22.3 产品设计中的关键原则

- 不按模具商品名称堆功能；
- 保留孔和切口的功能语义；
- 区分表面轮廓等效与孔壁工艺等效；
- 同轴孔不能拆成两个无关联普通孔；
- 鱼嘴应由截面、夹角、偏心和间隙统一生成；
- 方矩管应考虑真实圆角和扭转；
- 小管必须重点处理背壁挂渣、热积累和夹持变形；
- 传统模具参数和激光工艺参数必须分层；
- 激光替代结论最终应由样件和成本数据验证，而不是只看几何可切性。

## 调研边界说明

本报告基于公开厂商资料、公开工艺指南和几何推导整理。模具制造商通常不会公开专用模具的完整刀口曲线、芯棒配合、热处理、寿命和调试参数，因此：

- 报告中的冲头映射、鱼嘴、斜切和V口公式适合作为CAM参数模型；
- 经验间隙、最小孔径和工艺能力不能作为无条件保证值；
- 正式产品化前，应通过真实冲压件、激光样件和测量数据进行对照验证；
- 对医疗、食品、流体、疲劳结构和高精度销孔，应单独制定质量判定标准。
