# 产品显示脚本协议 v2

## 调用与职责

公开显示入口为 `display(parameter_values)`。宿主从产品实例组件读取模板引用和参数值，定位模板 Python 文件，将参数值传给这个入口。脚本根据这些值生成成品显示模型，返回 `icax.display-model` 第 2 版。

结果不包含产品模板身份、输入 `parameters`、执行记录、制造方案或加工调用。宿主自己保存模板引用、输入快照与生成状态，不要求脚本回传输入参数进行核对。零件属性中的管型固有参数属于截面定义，可随必要管型信息保存，不是产品输入参数回传。

显示模型是产品唯一的基础 `items` 与 `resources`。制造入口 `manufacturing(parameter_values)` 返回 `icax.manufacturing-model` 第 4 版，只包含引用这些基础零件的连接与工艺声明，详见[产品制造声明协议 v4](产品制造输入协议v4设计.md)。宿主组合两份输出，交给下游生成实际制造件。几何资源复用不合并零件，也不规定拼接、折弯或下料方案。

## 显示结果

顶层精确为八个字段：`schema`、`schemaVersion`、`coordinateSystem`、`lengthUnit`、`resources`、`items`、`roots`、`annotations`。数组即使为空也保留；新第 2 版不允许 `connections`。

| 字段 | 含义 |
|---|---|
| `schema` / `schemaVersion` | 固定为 `icax.display-model` / `2` |
| `coordinateSystem` / `lengthUnit` | 必需的坐标约定与长度单位；当前产品为右手坐标和 `mm` |
| `resources` | 几何声明数组，节点为 `key/operator/inputs/arguments`；依赖必须在资源表中存在且无环 |
| `items` | 独立实例，含 `key/displayName`，以及可选的 `geometry/children/properties` |
| `items[].geometry` | `{resource, placement?, instanceKey?}`；资源引用必须存在 |
| `roots` | 实例树的全部真实根；子实例只能有一个父节点，分组可不含几何 |
| `annotations` | 成品尺寸与说明标注数组 |

`placement` 提供 `origin/xAxis/yAxis/zAxis`，使用完整、正交、单位、右手的世界坐标。分组不叠加父变换。省略放置时直接使用资源自身坐标；省略放置也必须省略 `instanceKey`。`instanceKey` 只用于兼容旧几何根引用，不是零件或数据库实体身份。

`properties` 可携带零件角色、设计尺寸、材质、分类、采购方式和实际管型／板型等固有组件。`categoryKey`、`materialCategory`、`sourcing` 等属性表达对象自身事实；它们不属于某条制造路线。加工状态、加工区间、刀具、工艺选择与调用记录不能放进显示属性。

窗口的 `assemblyFrame.member` 保留真实设计起终点和右手截面坐标系；管型组件的 `tubeDesigner.profile.sectionResource` 引用公共 `resources` 中保留原轮廓基准的截面。截面资源可以同时被多个零件引用，不产生独立母材实体。渲染节点的规范化局部坐标不能替代管型截面的原坐标基准；原内联轮廓暂保留供旧组件读取兼容。

全部连接都由制造入口声明，可以表达参与零件、端部、侧面、设计接触点和方向。焊接方式、槽口资源及折弯路线等属于制造工艺输入，工艺执行及毛坯准备在下游进行。成品显示实体可以已经裁切或包含组合装饰，不能直接等同于加工初态。

## 两件引用同一个几何资源

下面假设模板包已经声明模型资源 `rail-display`，其中保存一段长 `1000 mm` 的零件几何。`template:rail-display` 是该包资源引用，宿主解析其真实几何后求值。结果表只声明一个共享资源，两个显示实例分别放在世界坐标原点和 `X=600 mm` 的位置。

```json
{
  "schema": "icax.display-model",
  "schemaVersion": 2,
  "coordinateSystem": "right-handed-x-width-y-depth-z-height",
  "lengthUnit": "mm",
  "resources": [
    {
      "key": "rail.shape",
      "operator": "resource",
      "inputs": [],
      "arguments": { "reference": "template:rail-display" }
    }
  ],
  "items": [
    {
      "key": "rail.left",
      "displayName": "左构件",
      "geometry": {
        "resource": "rail.shape",
        "placement": {
          "origin": [0, 0, 0],
          "xAxis": [1, 0, 0],
          "yAxis": [0, 1, 0],
          "zAxis": [0, 0, 1]
        }
      },
      "properties": { "role": "left", "length": 1000 }
    },
    {
      "key": "rail.right",
      "displayName": "右构件",
      "geometry": {
        "resource": "rail.shape",
        "placement": {
          "origin": [600, 0, 0],
          "xAxis": [1, 0, 0],
          "yAxis": [0, 1, 0],
          "zAxis": [0, 0, 1]
        }
      },
      "properties": { "role": "right", "length": 1000 }
    }
  ],
  "roots": ["rail.left", "rail.right"],
  "annotations": []
}
```

`rail.left` 与 `rail.right` 是两个零件实例；共享的是 `rail.shape` 的几何定义。长度属性是显示零件信息，不要求与产品输入参数字典同形，也不替代真实几何。

## 宿主读取与兼容

宿主校验八个顶层字段、资源依赖、引用、实例树与刚体放置，解析外部模型资源并执行显示几何求值。资源保留范围包括显示实体及固有组件引用的截面等必要节点，不只看渲染根的依赖。模板身份与输入参数来自产品实例组件。

新显示文档保存为 `icax.display-model` 第 2 版，旧第 1 版可兼容读取其 `connections`；这不允许新显示结果继续写连接。旧保存中的 `icax.neutral-model` 第 1 版几何图和第 2 版资源表也保留读取兼容，内部适配结构不写回公开返回值。

完整纯脚本实际输出见[单面窗共享模型](../examples/product-manufacturing/v4-v-notch-window.display.actual.json)与[三面窗共享模型](../examples/product-manufacturing/v4-three-face-window.display.actual.json)，对应制造声明与宿主输入见[制造协议 v4 的示例](产品制造输入协议v4设计.md#实际返回值)。
