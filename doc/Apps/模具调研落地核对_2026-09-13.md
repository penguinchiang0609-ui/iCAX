# 模具调研落地核对

依据《小管冲孔模具与激光替代性调研报告.md》。本文记录几何实现核对，不把报告中的厂商宣传或经验数字当作已验证的加工保证。

## 本次落实

| 报告内容 | 原实现问题 | 处理 |
|---|---|---|
| 9.4 单 D 孔 | 矩形拼半圆，参数只有总长和高度 | 改为基准圆直径 D、圆心至平边距离 c，保留圆的大侧；0 ≤ c < D/2 |
| 9.5 双 D 孔 | 实际返回 capsule，与腰形孔重复 | 改为同一基准圆截两条对称平边；0 < H < D |
| 9.6 钥匙孔 | 无对应模板 | 新增圆头＋圆端颈模板；D、W、圆心距 C，验证颈部确实伸出圆头 |
| 9.2 长圆孔 | 分类为槽口，长度意义不清 | 归冲孔；明确总长含半圆，直段长 L−W |
| 5、8、10、13、14、16、18 | 模具页没有表达几何与加工的边界 | 按冲孔、端面、槽口组织；相贯开孔纳入冲孔，端面相贯仍归端面；右栏增加分类说明及模板描述 |

新增孔型完全由各自 tool.json + tool.py 提供，沿用统一轮廓拉伸，不增加 C++ 孔型分支。图标和参数示意图由模板提供。

## 不改变的职责边界

- 模具定义形状。位置、方向、壁范围、阵列和端面尺寸基准由使用记录管理，不塞入模具形状参数。
- 模具接收真实截面进行适用性分析，不依赖管型名称或 ID。
- 已有端面斜切和槽口 K 因子逻辑本次未扩展；右侧提示明确区分刀口圆角与折弯成形半径。
- 模具库预览目前是母材与刀具体，不是切后成品、折弯成形仿真或工艺验证。

## 后续仍需单独闭环的内容

- 普通边缘 V 缺口与折弯焊接槽的独立语义、成形预览及闭合干涉。
- 端面最长／最短点基准在任意真实截面上的极值核对（现有斜切脚本按包围盒估计斜向跨度，非所有截面均精确）。
- 固定轴扫掠与曲面展开轮廓、同轴对穿与独立双面孔的完整操作级语义审核。
- 激光割缝、背壁防护、热累积及最小孔能力需设备／材料／壁厚试切数据，不能从报告推导统一阈值。
- 钥匙孔当前只实现圆端颈，未声称覆盖平端颈、双圆相交和所有止转孔。

## D 孔版本处理

单／双 D 模板升级为 2.0.0，使用新的尺寸参数。旧 spanAlong/spanAcross 不做猜测映射；运行时拒绝旧参数，避免悄悄改变既有零件。已保存实体／冻结刀具仍按原持久化机制保留，主动重算需重新选择新版并设置尺寸。不能把旧腰形孔尺寸自动转换成双 D 孔。
