# 管型几何定义与参数总表

> 版本：2026-09-17  
> 本文只讨论二维截面和必要的三维位置几何。  
> 不讨论材料牌号、力学性能、表面处理、焊接质量、库存规格和生产工艺。

## 文档性质说明

本文不是国家标准原文，也不是对任何一个国家标准的逐条转录，而是三部分内容的合并整理：

1. **标准依据**：引用国家标准的名称、适用对象和标准化的截面类别；标准状态以国家标准全文公开系统为准。
2. **几何事实**：根据轮廓拓扑和基本几何关系推导出的定义，例如跑道形的直线段 `= 总宽 − 总高`。
3. **统一表达建议**：为了让不同截面能够使用一致的数据模型而提出的字段和分类，不代表国标规定了这些字段名称。

因此，本文中的“参数表”是几何建模定义，不是国标规格表；“国标依据”也不等于某个自定义截面已经符合该标准。需要声明产品符合某个标准时，仍必须逐项核对该标准正式文本中的范围、截面图、尺寸系列和允许偏差。

## 1. 国标原始定义层

这一层只回答一个问题：**现行国家标准把哪些截面作为标准化产品或标准化截面来描述。**

国标通常给出标准名称、截面系列、尺寸符号、尺寸表、允许偏差和检验要求；它不负责为软件提供一个覆盖所有异型截面的统一 JSON schema。下表是本项目几何归纳应先尊重的标准边界。

| 国标 | 国标直接覆盖的对象 | 几何上应先保留的定义 |
|---|---|---|
| GB/T 706-2016《热轧型钢》 | 热轧型钢标准系列 | 角钢、槽钢、工字钢等热轧开口截面的标准轮廓和尺寸系列 |
| GB/T 11263-2024《热轧H型钢和剖分T型钢》 | 热轧 H 型钢、剖分 T 型钢 | H 型和剖分 T 型的标准轮廓、尺寸符号和系列 |
| GB/T 6725-2017《冷弯型钢通用技术要求》 | 冷弯型钢通用要求 | 冷弯开口或闭口型材的几何、尺寸和允许偏差通用边界 |
| GB/T 6728-2025《结构用冷弯型钢》 | 结构用冷弯型钢 | 结构用冷弯型钢的标准化截面和尺寸表达 |
| GB/T 3094-2012《冷拔异型钢管》 | 冷拔异型钢管 | 异型闭口钢管作为产品的尺寸和轮廓定义；不能把所有自定义曲线都自动归入标准 |
| GB/T 17395-2024《钢管尺寸、外形、重量及允许偏差》 | 钢管尺寸、外形、重量和偏差 | 钢管外径、壁厚、长度、外形和偏差的通用表达；不是全部异型截面的分类表 |
| GB/T 702-2017《热轧钢棒尺寸、外形、重量及允许偏差》 | 热轧钢棒 | 圆棒、方棒等实心棒材的尺寸表达，不含管腔 |
| GB/T 9945-2025《热轧球扁钢》 | 热轧球扁钢 | 球扁钢的标准实心轮廓，不能简化成扁钢加半圆 |
| GB/T 2585-2021《铁路用热轧钢轨》 | 铁路用热轧钢轨 | 钢轨完整实心轮廓和标准基准 |
| GB/T 11264-2025《热轧轻轨》 | 热轧轻轨 | 轻轨完整实心轮廓和标准基准 |

截至本文日期，国家标准公开系统显示 GB/T 706-2016、GB/T 11263-2024、GB/T 6725-2017、GB/T 6728-2025、GB/T 3094-2012、GB/T 17395-2024、GB/T 702-2017、GB/T 9945-2025、GB/T 2585-2021 和 GB/T 11264-2025 为现行版本或现行适用版本；已经发布但尚未实施的新版本另行标注，不能提前当作当前实施依据。

### 1.1 国标定义出的几何大类

按照标准化对象，先得到以下**原始大类**：

| 国标原始大类 | 轮廓定义 | 典型标准对象 |
|---|---|---|
| 圆形钢管 | 外圆与内圆构成一个闭口孔腔 | 结构用、流体用、精密用圆管 |
| 异型钢管 | 外轮廓和内轮廓不是普通圆形，仍属于闭口管 | 冷拔异型钢管、特定产品异型管 |
| 冷弯闭口型钢 | 板带连续弯曲形成闭口截面 | 方矩形、闭口异型、结构用冷弯空心型材 |
| 热轧开口型钢 | 一个连续的开口实心材料区域 | 角钢、槽钢、工字钢等 |
| 热轧 H/T 型钢 | H 形或由 H 型钢剖分得到的 T 形开口截面 | H 型钢、剖分 T 型钢 |
| 冷弯开口型钢 | 薄壁板带折弯形成的开口轮廓 | C、U、Z、帽型、Ω 型及复杂折边 |
| 实心棒材 | 一个封闭外轮廓，没有内孔 | 圆棒、方棒、矩形棒 |
| 球扁钢 | 带球头过渡的连续实心轮廓 | 热轧球扁钢 |
| 轨道/导轨 | 由标准完整轮廓定义的复杂实心截面 | 钢轨、轻轨及专用导轨 |

### 1.2 国标没有直接统一定义的名称

下列名称不能直接当作一个全国统一的国标几何品种，必须继续查具体产品标准、行业标准、企业标准或图纸：

- 椭圆管、扁圆管、长圆管、跑道管；
- 三角管、梯形管、菱形管、任意多边形管；
- 多腔管、带翼管、卡扣型材、门窗型材、光伏型材；
- 蘑菇形、面包形、元宝形、腰形等市场俗称；
- 任意曲线异型管、变截面管、局部成形管。

这些名称可以是某个具体产品的形状名称，但在没有对应标准原文或图纸时，不能声称它们已经由国标给出了唯一的宽、高、壁厚和圆角定义。它们应先进入“非统一国标截面”类别，再由轮廓或明确的几何公式定义。

### 1.3 国标标准族与几何字段的关系

国标里的字段名称不一定与软件字段相同，但几何含义可以对应：

| 国标常见含义 | 几何字段含义 | 不能做的事 |
|---|---|---|
| 外径、外宽、外高 | 外边界包围尺寸 | 不能同时把它们和同一方向的内尺寸全部当独立输入 |
| 壁厚 | 管壁的标称或基准厚度 | 不能用壁厚替代非等壁异型管的完整内轮廓 |
| 腹板厚度 | 开口型钢中腹板局部厚度 | 不能叫作管壁厚度 |
| 翼缘厚度 | 翼缘局部厚度 | 不能与腹板厚度强行合并为一个厚度 |
| 根部圆角 | 两个板段或肢的过渡圆弧 | 不能默认等于外轮廓所有角的圆角 |
| 边长/肢宽/翼缘宽 | 从标准基准到边界的尺寸 | 必须注明是外包尺寸、内尺寸还是中心线尺寸 |
| 标准轮廓 | 标准表中确定的完整截面 | 不能只保存几个包围盒尺寸而声称保留标准轮廓 |

### 1.4 这一层不做合并

在完成国标原始层之前，以下对象暂不合并：

- 方管和角钢：一个是闭口空心，一个是开口实心；
- 椭圆管和跑道管：都可能用宽、高描述，但轮廓方程不同；
- 圆管和圆棒：一个有内孔，一个无内孔；
- H 型钢和工字钢：几何可以共用部分算法，但标准系列和标准轮廓先分开；
- 冷弯槽钢和热轧槽钢：都像 U/C，但标准轮廓和圆角体系不同；
- 标准球扁钢和任意“T+圆弧”：标准实心轮廓不能被近似组合替代；
- 多腔型材和单腔方矩管：孔的数量和拓扑不同。

后面的“统一几何模型”和“最终分类总表”才是我们的归纳层。

## 2. 我们的归纳总则

软件归纳只保留两个维度：

1. **腔体类别**：单腔体、型材（0 腔体）、多腔体；
2. **复杂度类别**：常规、高级。

这里的“型材”专指 0 腔体的开口或实心截面，不是“所有型材”的泛称。

### 2.1 六个归纳分组

| 腔体类别 | 常规 | 高级 |
|---|---|---|
| 单腔体 | 方管、圆管、椭圆管、腰型管 | D 型管、P 型管、多边形管、星形管、U 肋 |
| 型材（0 腔体） | L、C、U、T、H、I | 球扁钢、帽钢、工字钢（两个翼板不等宽）、圆棒、多边形棒、星形棒、导轨 |
| 多腔体 | — | 二腔方管 |

“常规/高级”是软件参数化能力的分级，不是国标等级：

- **常规**：使用少量明确尺寸即可唯一生成轮廓。
- **高级**：需要独立轮廓、多个局部尺寸、非对称参数、复杂圆角，或通常通过导入完整截面表达。

### 2.2 默认截面与热轧高级属性

默认不把热轧截面单独拆成新的一级管型，而是：

```text
管型基础定义：规则、可参数化的标准截面
高级属性：热轧 / 导入轮廓 / 非对称轮廓 / 样条轮廓
```

默认几何按“冷成形标准截面”处理。这里的默认值只表示软件的基础参数化模型，不表示所有国标产品都由同一工艺制造。对于标准术语明确区分冷弯、冷轧时，标准身份仍按标准原文保存。

热轧作为当前管型的高级属性，主要用于：

- 翼缘厚度不一致；
- 腹板和翼缘过渡不是简单圆弧；
- 翼缘边界为样条或复杂曲线；
- 标准表给出了完整轮廓，但不适合用少量参数重建。

这类截面优先导入完整轮廓。导入后只要求几何可表达、可校验、可用于后续计算，不强行提供所有尺寸的参数化编辑。

### 2.3 常规单腔体

| 管型 | 几何定义 |
|---|---|
| 方管 | 矩形外轮廓 + 矩形内孔；`宽 = 高`；壁厚和角部 R 为主要参数 |
| 圆管 | 外圆 + 内圆；外径和壁厚/内径为主要参数；可选内孔偏心 |
| 椭圆管 | 外椭圆 + 内椭圆；外宽、外高、内轮廓为主要参数 |
| 腰型管 | 外轮廓为两条平行直线和两端半圆；宽、高足以确定严格跑道形，直线段和端部半径为派生值 |

方管是矩形管的特例；腰型管不与椭圆管合并，因为两者的轮廓方程不同。

### 2.4 常规型材（0 腔体）

| 管型 | 几何定义 |
|---|---|
| L | 两个互相垂直的肢组成的开口 L 形区域；无内孔 |
| C | 腹板、上下翼缘及可选卷边组成的开口轮廓 |
| U | 腹板和两翼缘组成的 U 形开口轮廓；是否带卷边独立表达 |
| T | 翼板和腹板组成的 T 形开口轮廓 |
| H | 腹板和上下翼板组成的 H 形开口轮廓；默认上下翼板同宽、同厚，腹板等厚 |
| I | 腹板和上下翼板组成的 I 形开口轮廓；默认上下翼板同宽、同厚，腹板等厚 |

这里的 L、C、U、T、H、I 是几何入口，不代表热轧或冷弯产品名称。热轧、焊接以及标准截面号保存为高级属性或标准身份。

### 2.5 高级单腔体

| 管型 | 几何定义 |
|---|---|
| D 型管 | 外轮廓由直线和圆弧组成，内孔为对应异型闭口轮廓 |
| P 型管 | 含台阶、局部凸起或非对称曲线的单腔闭口轮廓 |
| 多边形管 | 外多边形 + 内多边形；边数、顶点和角部圆角可独立定义 |
| 星形管 | 多瓣凸起/凹谷组成的闭口轮廓；瓣数、顶点、谷底和内轮廓必须明确 |
| U 肋 | U 形折弯/成形的单腔或近似闭口截面；是否闭合必须由实际轮廓判断，不能只按名称判断 |

高级单腔体不能只用“宽、高、壁厚”猜测，必要时直接保存外轮廓和内轮廓。

### 2.6 高级型材（0 腔体）

| 管型 | 几何定义 |
|---|---|
| 球扁钢 | 腹板与球头连续形成的实心轮廓，不等同于扁钢加半圆 |
| 帽钢 | 顶部、腹板、翼缘和可选卷边组成的多折边开口轮廓 |
| 不等翼工字钢 | I 形轮廓的上下翼板宽度不相等；翼板和腹板局部厚度可独立定义 |
| 圆棒 | 单一实心圆轮廓；没有内孔，也没有壁厚 |
| 多边形棒 | 单一实心多边形轮廓；规则或不规则均可表达 |
| 星形棒 | 多瓣实心轮廓；不能与星形管共用“内孔”逻辑 |
| 导轨 | 标准完整实心轮廓，使用标准轮廓或导入轮廓，不强行参数化 |

### 2.7 多腔体

多腔体统一放在高级类。第一阶段只定义一种：**二腔方管**。

二腔方管的几何结构为：

```text
一个矩形外轮廓
+ 两个并列的方形内腔
+ 中间一根竖向隔筋
```

两个内腔尺寸相同、上下对齐，外壁和中间隔筋均为直壁。第一阶段不支持三腔、多腔、横向分腔、错位腔、不同尺寸内腔、圆角腔或局部开口。

多腔体的基础数据为：

```text
outerContour
cavityContours[]
optionalOpenings[]
```

第一阶段的二腔方管不再把外宽、外高和隔筋偏心作为独立输入，而是用两个相同的方腔直接定义。其外轮廓尺寸由下式派生：

```text
外宽 = 2 × 方腔边长 + 隔筋厚 + 2 × 外壁厚
外高 = 方腔边长 + 2 × 外壁厚
```

二腔方管的参数为：

| 参数 | 含义 |
|---|---|
| `cellSize` | 每个方形内腔的边长；两个内腔相同 |
| `wallThickness` | 外壁厚度 |
| `ribThickness` | 中间竖向隔筋厚度 |

两个内腔左右并列、上下对齐，内腔角和外角第一阶段均为直角；不提供独立偏心、独立腔尺寸、圆角腔及其他分腔方式。输出仍保留派生的 `width`、`depth`，供管型库和三维拉伸使用。

二腔方管的外部包围尺寸由这三个参数派生，不单独输入外宽、外高、内宽、内高：

```text
width = 2 × cellSize + ribThickness + 2 × wallThickness
depth = cellSize + 2 × wallThickness
```

如果左右两个腔体不相等，就不再属于第一阶段的二腔方管，应使用后续的高级多腔轮廓定义。

### 2.8 本归纳层的边界

- 只按三大腔体类别和常规/高级分组，不再按热轧、冷轧、焊接重复建立一级管型。
- 标准名称、标准号、标准截面号仍然保留，作为管型的属性而不是新的拓扑类别。
- 热轧复杂截面优先作为高级导入轮廓，不强迫提供参数化编辑。
- “工字钢默认翼板等厚、腹板等厚”是本软件常规参数化模型的约定；如果标准热轧截面不满足，就进入高级热轧/导入轮廓。
- 直线段、端部半径、内宽、内高等能由基础尺寸推导出的量，不再作为重复输入。

## 3. 统一几何模型

### 3.1 截面用材料区域定义

用二维平面上的材料区域 `S` 表示截面：

```text
S = 外边界 − 内孔边界 − 其他孔边界
```

每条边界由直线段、圆弧、圆、椭圆或受支持的自由曲线组成。

| 类型 | 几何判断 | 边界表达 |
|---|---|---|
| 实心 | 没有孔 | 1 个外边界 |
| 单腔闭口 | 1 个孔 | 1 个外边界 + 1 个内边界 |
| 多腔闭口 | 多个孔 | 1 个外边界 + 多个内边界 |
| 开口型材 | 材料区域直接连到外部 | 1 个不闭合的材料轮廓，或由中心线和厚度生成 |
| 组合件 | 多个相互独立的材料区域或实体 | 多个区域/实体及其关系 |

轮廓的顺时针、逆时针方向不决定内外关系；内外关系由包含关系判断。边界不能自交、重叠、相交或仅接触。除非明确支持多实体，不能把互相分离的材料块当成一个截面。

### 3.2 统一坐标

- 截面原点：默认取外轮廓包围盒中心，或由标准基准指定。
- `X`：宽度方向，向右为正。
- `Y`：高度方向，向上为正。
- 管材长度方向为 `Z`。
- 所有尺寸单位为 `mm`。
- 偏心统一用 `offsetX`、`offsetY`，不是把内宽、内高当成独立输入。

### 3.3 参数的三种状态

一个几何参数不能用“空值”“负数”或特殊字符串表示未指定。应明确区分：

1. **固定取值**：参数直接参与几何计算。
2. **自动推导**：例如内孔尺寸由外宽、高、壁厚推导。
3. **不适用/未启用**：用独立的布尔开关表达，保留草稿值但不参与计算。

`0` 是合法几何值。例如半径为 `0` 就是尖角；它不表示未指定。

### 3.4 统一参数类型

| 参数类型 | 含义 | 例子 |
|---|---|---|
| `length` | 长度、宽度、高度、壁厚、半径 | `width`、`height`、`wallThickness` |
| `angle` | 角度，单位为度 | 翼缘角、折线转角 |
| `point` | 一个二维点 | 多边形顶点 |
| `contour` | 有序边界段集合 | 任意异型管外轮廓 |
| `bool + value` | 可选参数及其是否启用 | 内孔偏心、独立内圆角 |
| `count` | 数量 | 腔数、瓣数、边数 |

## 4. 闭口空心管

闭口空心管的共同定义是：一个连续外边界包围一个或多个封闭内孔。常规“壁厚”只是规则截面的简化参数；对于任意异型管，必须以完整内外轮廓为准。

### 4.1 圆管

圆管是外圆和内圆构成的单腔闭口截面。

#### 几何参数

| 参数 | 含义 | 是否可由其他参数推导 |
|---|---|---|
| `outerDiameter` | 外圆直径 `Dₒ` | 否 |
| `wallThickness` | 壁厚 `t` | 与 `innerDiameter` 二选一 |
| `innerDiameter` | 内圆直径 `Dᵢ` | 与 `wallThickness` 二选一 |
| `offsetX` | 内圆心相对外圆心的水平偏移 | 默认 0 |
| `offsetY` | 内圆心相对外圆心的竖直偏移 | 默认 0 |

若以壁厚输入：

```text
Dᵢ = Dₒ − 2t
```

内外圆心重合时是同心圆管；允许偏心时，内圆仍必须完整位于外圆内部。圆管没有外角半径、内角半径和内宽/内高参数。

### 4.2 方管和矩形管

方管、矩形管属于同一几何类型：

```text
方管：width = height
矩形管：width ≠ height
```

#### 最小完整参数

| 参数 | 含义 |
|---|---|
| `width` | 外轮廓宽度 `B` |
| `height` | 外轮廓高度 `H` |
| `wallThickness` | 直边处壁厚基准 `t` |
| `outerRadius` | 统一外圆角 `R`；`0` 表示尖角 |
| `offsetX` | 内孔水平偏心，默认 0 |
| `offsetY` | 内孔竖直偏心，默认 0 |

默认情况下，内孔尺寸由外尺寸和壁厚推导：

```text
innerWidth  = width  − 2 × wallThickness
innerHeight = height − 2 × wallThickness
```

默认内孔居中，四个外角使用同一个 `outerRadius`。如果没有单独指定内角，内角半径按壁厚基准推导：

```text
innerRadius = max(outerRadius − wallThickness, 0)
```

只有在确实需要非等圆角截面时，才增加：

```text
useOuterRadii + outerRadius1..outerRadius4
useInnerRadii + innerRadius1..innerRadius4
```

四个角从左下开始逆时针编号。关闭开关时，保留的逐角数值不参与计算。不能用四个 JSON 字符串代替四个明确的数值字段，也不能把内宽、内高再作为用户输入字段。

#### 尖角、圆角、偏心

- `outerRadius = 0`：外角为尖角。
- `innerRadius = 0`：内角为尖角。
- 偏心不改变内孔尺寸，只改变内孔中心位置。
- 偏心后四边局部壁厚可以不同，但内孔仍不能穿出外轮廓。
- 外圆角和内圆角是否独立，属于参数是否启用，不应靠空值猜测。

### 4.3 椭圆管

椭圆管由外椭圆和内椭圆构成。

#### 几何参数

| 参数 | 含义 |
|---|---|
| `outerWidth` | 外椭圆长轴方向包围尺寸 |
| `outerHeight` | 外椭圆短轴方向包围尺寸 |
| `innerWidth` 或 `wallThickness` | 内椭圆尺寸或等效壁厚 |
| `offsetX`、`offsetY` | 内椭圆中心偏移 |
| `rotation` | 椭圆主轴相对截面坐标的旋转角，可选 |

如果内外椭圆不共中心或不共轴，不能用一个壁厚完整描述，应直接保存内外椭圆参数。

### 4.4 长圆管、扁圆管、跑道管

这里需要把两个概念分开：

- **椭圆管**：外轮廓是椭圆，没有直线段。
- **跑道管/长圆管/标准扁圆管**：外轮廓是“两段平行直线 + 两端半圆”。

对于严格的跑道形，宽度和高度已经足够，直线段长度不是独立参数。

#### 几何参数

| 参数 | 含义 |
|---|---|
| `outerWidth` | 总宽度 |
| `outerHeight` | 总高度 |
| `wallThickness` 或 `innerContour` | 内孔由壁厚推导，或直接指定内轮廓 |
| `offsetX`、`offsetY` | 内孔中心偏移，可选 |

跑道形的派生关系为：

```text
endRadius     = outerHeight / 2
straightLength = outerWidth − outerHeight
```

其中 `outerWidth >= outerHeight`。当 `outerWidth = outerHeight` 时退化为圆；当 `outerWidth > outerHeight` 时才有直线段。内孔如果也是标准等距跑道形，同样由内孔宽、高推导；如果内孔不是等距偏置，则直接保存 `innerContour`。

因此，`straightLength` 和 `endRadius` 只能作为只读的派生值，不应再作为用户输入参数。

只有以下情况不能只靠宽、高确定轮廓：

- 两端不是半圆；
- 两端圆弧半径不同；
- 侧边不是直线；
- 内外轮廓不是同类型或不是等距偏置；
- “腰形”等俗称实际指的是椭圆、圆弧组合或自定义曲线。

这些情况应改为独立的 `outerContour` 和 `innerContour`，而不是继续给普通跑道管增加 `straightLength` 参数。

### 4.5 多边形管

多边形管由外多边形和内多边形组成。三角管、梯形管、菱形管、六角管和任意多边形管都属于同一拓扑。

#### 规则多边形的参数

| 参数 | 含义 |
|---|---|
| `sideCount` | 边数 `n` |
| `outerSize` | 外接圆、内切圆、边长或标准定义的尺寸基准 |
| `rotation` | 多边形相位角 |
| `cornerRadius` | 统一角部圆角，可为 0 |
| `wallThickness` | 仅在内外边界为等距偏置时使用 |

#### 任意多边形的参数

```text
outerVertices = [P1, P2, ..., Pn]
innerVertices = [Q1, Q2, ..., Qm]   // 可选，按实际内孔表达
```

梯形、菱形等不应强行套用“规则多边形”参数。外轮廓和内轮廓边数不同、方向不同或不是等距偏置时，直接使用两个轮廓。

### 4.6 内外异形组合管

外轮廓和内孔使用不同几何族时，属于内外异形组合管，例如：外六角内圆、外圆内六角、外多边形内多边形。

#### 几何参数

```text
outerContour
innerContour
innerOffsetX
innerOffsetY
innerRotation
```

这里不能只用一个“壁厚”字段，因为不同方向上的局部壁厚可能不同。`outerShape`、`innerShape` 只能作为快捷输入，最终仍应得到明确的两个轮廓。

### 4.7 任意单腔异型管

适用于 D 型、扇形、半圆闭口、水滴形、蘑菇形、面包形、元宝形等无法用少量标准参数唯一描述的截面。

#### 几何定义

```text
outerContour = 外边界
innerContour = 内边界
```

如果需要参数化，可由直线、圆弧、椭圆弧和样条曲线组成；但参数化结果必须能唯一生成完整轮廓。名称不能代替轮廓。

### 4.8 多腔和混合型材

本节是多腔体的通用几何底层，不代表第一阶段要一次支持所有多腔形式。第一阶段产品定义只开放上一节的“二腔方管”；其余多腔、混合型材留作后续高级扩展。

多腔型材有一个外边界和多个封闭内孔；内孔之间由隔筋连接。若同时包含开放槽、卡扣、翼边或局部开口，则是“多腔/开口混合型材”，不能继续当普通方管。

#### 几何参数

| 参数 | 含义 |
|---|---|
| `outerContour` | 外边界 |
| `cavities[]` | 腔体列表，每个腔体是闭合轮廓 |
| `ribContours[]` | 隔筋或局部连接材料 |
| `openings[]` | 向外开放的槽、缺口或卡口 |
| `offset/rotation` | 各腔体相对基准的位置和方向 |

`rows`、`columns`、腔体比例等只是规则多腔的快捷参数，不能覆盖任意隔筋和错位腔体。任意多腔最终必须落为轮廓集合。

## 5. 开口型材

开口型材的核心特征不是“缺少一个面”，而是材料区域本身没有封闭内孔。角钢、槽钢、Z 型钢、工字钢、H 型钢和 T 型钢均属于开口型材。

### 5.1 角钢

角钢是 L 形开口材料区域，由两条互相垂直的肢组成。它不是方管的一半，因为它没有封闭内孔，也没有“内宽、内高”这样的管腔参数。

#### 几何参数

| 参数 | 含义 |
|---|---|
| `legA` | 第一肢外伸尺寸 |
| `legB` | 第二肢外伸尺寸；等边角钢时 `legA = legB` |
| `thicknessA` | 第一肢厚度 |
| `thicknessB` | 第二肢厚度；等厚角钢时两者相同 |
| `rootRadius` | 内根部圆角，可为 0 |
| `outerRootRadius` | 外根部过渡圆角，可选 |
| `tipRadiusA/B` | 肢端圆角，可选 |

如果两个肢等厚、根部和端部均为尖角，最简定义就是 `legA、legB、thickness` 三个尺寸；但标准热轧角钢的真实根部轮廓不能默认简化为尖角。

### 5.2 槽钢、U 型钢、C 型钢

槽钢是一个腹板连接两条翼缘的开口截面。U 型、C 型、卷边 C 型本质上都是开口轮廓，区别在于翼缘方向、卷边和弯折段。

#### 无卷边槽钢参数

| 参数 | 含义 |
|---|---|
| `overallHeight` | 截面总高 `H` |
| `flangeWidth` | 翼缘外伸宽度 `B` |
| `webThickness` | 腹板厚度 `t_w` |
| `flangeThickness` | 翼缘厚度 `t_f` |
| `webFlangeRadius` | 腹板与翼缘交界圆角 |
| `flangeSlope` | 翼缘斜度；无斜腿时为 0 |

#### 冷弯或卷边槽钢增加

```text
foldSequence       // 从基准边开始的折弯段
foldAngles[]
foldRadii[]
lipLengths[]       // 卷边长度，可为 0
lipAngles[]
```

不要用一个“槽钢宽度”字段替代腹板、翼缘、卷边和圆角；不同部位的尺寸作用不同。

### 5.3 Z 型钢

Z 型钢是由腹板、上下翼缘组成的折线开口截面。上下翼缘可以错向，也可以带卷边。

#### 几何参数

```text
webHeight
topFlangeLength
bottomFlangeLength
thickness
topFlangeAngle
bottomFlangeAngle
topLipLength
bottomLipLength
foldRadii[]
```

是否对称、是否卷边都由参数表达；不能用 U 型钢镜像后再隐式假设所有圆角和尺寸相同。

### 5.4 帽型、Omega 型材

帽型/Ω 型材是多折边开口截面，通常包括顶部、两侧腹板、外翼缘和可选卷边。

#### 几何参数

```text
topWidth
webHeights[]
flangeWidths[]
lipLengths[]
foldAngles[]
foldRadii[]
thickness
```

当顶部不是单一平面、存在压筋、卡槽或局部孔槽时，应直接采用折线/圆弧轮廓，不要继续用少量宽高字段猜测。

### 5.5 T 型钢

T 型钢是翼缘和腹板组成的开口截面。剖分 T 型钢可以由 H 型钢沿腹板方向分割得到，但几何定义仍然是一个完整的 T 形轮廓。

#### 几何参数

```text
overallHeight
flangeWidth
webThickness
flangeThickness
rootRadius
flangeSlope       // 可选
```

焊接 T 型或由板材组合的 T 型，在只关注几何时仍可归入同一 T 形轮廓；焊缝不是截面几何字段。

### 5.6 工字钢和 H 型钢

I/H 型截面由腹板和上下翼缘组成。

#### 几何参数

```text
overallHeight
flangeWidth
webThickness
flangeThickness
rootRadius
flangeSlope
topBottomSymmetry
```

- H 型钢通常以翼缘较宽、上下翼缘近似平行作为几何特征。
- 工字钢可以有斜翼缘或不同的翼缘系列。
- 非对称 I/H 型钢不能只用一个 `flangeWidth` 和一个 `flangeThickness`，应分别定义上下翼缘。
- 只讨论轮廓时，热轧和焊接不需要另设一套几何参数；如果需要表示焊缝或板件关系，那是装配/制造信息，不是基本管型定义。

### 5.7 任意开口型材

适用于复杂冷弯型钢、门窗开口型材、支架型材、桥架型材和无法由角钢/槽钢/Z/帽型/T/I/H 唯一表达的轮廓。

#### 几何定义

```text
openContour = 按顺序排列的直线、圆弧和自由曲线
thickness   = 仅在使用中心线模型时提供
```

厚壁实心开口型材应直接保存材料边界；薄壁型材可以保存中心线加厚度，但两种模型不能混用而不说明基准。

## 6. 实心型材

### 6.1 圆棒

```text
diameter
centerX / centerY       // 可选，表示截面基准位置
```

圆棒只有外圆，没有内孔；不能与圆管共用“壁厚”字段。

### 6.2 方棒、矩形棒、扁钢

```text
width
height
cornerRadius
```

方棒是 `width = height` 的矩形棒。扁钢是宽度明显大于厚度的矩形/圆角矩形实心截面。它们没有内孔，也没有名义壁厚。

### 6.3 多边形棒

规则多边形棒：

```text
sideCount
outerSize
rotation
cornerRadius
```

不规则多边形棒直接用：

```text
vertices[]
```

### 6.4 球扁钢

球扁钢不是“扁钢加一个圆”，也不是 T 型钢。它是腹板与局部球头连续形成的实心单一轮廓。

#### 几何参数

```text
webWidth
webThickness
bulbContour
bulbWidth
bulbHeight
transitionRadii[]
```

如果球头轮廓不是标准圆弧，应直接保存完整球头曲线。球头与腹板的过渡必须连续，不能用两个互相接触的独立实体冒充一个截面。

### 6.5 钢轨、导轨及其他标准实心异型材

钢轨和导轨是标准化的复杂实心截面，通常包含轨头、轨腰、轨底和多个圆弧过渡。

#### 几何定义

```text
standardContour
datumLines[]
functionalSurfaces[]
```

不能仅用“总高、总宽、厚度”重建真实钢轨轮廓。需要精确几何时必须保存标准截面表或完整轮廓。

## 7. 不能当成普通管型的对象

### 7.1 弯管

弯管不是新的二维截面管型，而是：

```text
sectionProfile + centerlineCurve + localFrame
```

截面可以是圆管、方管、椭圆管或任意异型管；弯曲中心线、截面姿态和变形另行描述。

### 7.2 锥管和变截面管

```text
section(s) + centerline(s) + orientation(s)
```

截面尺寸随长度变化时，不能把首端宽高当成整根管的定义。若截面拓扑也变化，则必须用分段或事件描述。

### 7.3 局部成形件

胀形、缩口、压扁、局部冲压件不是单一恒定管型，应描述成沿长度变化的实体或截面序列。

### 7.4 焊接组合件

多个管材、板材或型钢拼焊成的框架不是一个新的“管型”。如果只关心最终截面，取最终材料区域；如果需要表达各构件来源，则另建组合件关系。

### 8.1 标准的边界

以下情况不能因为“看起来像”就直接声明符合某个国标：

- 自定义多边形管、椭圆管、腰形管、曲线异型管没有对应的标准系列表。
- 内外轮廓不同、偏心、多腔、带翼、带卡扣的型材，不能只引用方矩管或冷弯型钢标准。
- 软件用参数生成的轮廓如果没有落入标准尺寸系列，只能标为“参数化几何”或“非标截面”。
- 旧版标准已经废止时，不应继续把旧版写成当前依据；例如 GB/T 6728-2017 已由 GB/T 6728-2025 取代，GB/T 11263-2017 已由 GB/T 11263-2024 取代。

## 9. 基于国标原始层的合并建议

只有完成上一层的标准分类后，才做软件层的合并。合并的是**几何生成模型**，不是抹掉标准身份。每个合并后的对象仍必须保留 `standardBasis`、`standardSection` 或“非标准截面”状态。

| 国标原始对象 | 是否可以共用几何模型 | 合并后的几何族 | 必须保留的差异 |
|---|---|---|---|
| 圆管、结构用圆管、流体用圆管、精密圆管 | 可以 | 圆形闭口管 | 标准依据、外径/壁厚系列、偏差要求 |
| 方管、矩形管、方形冷弯闭口型钢 | 可以 | 方矩形闭口管 | 方形是 `宽=高`；标准系列和圆角表不能丢 |
| 等边角钢、不等边角钢 | 可以 | 角形开口轮廓 | 两肢尺寸、两肢厚度、标准根部轮廓 |
| 热轧槽钢、冷弯 U/C 型材 | 只能共用开放轮廓底层 | 槽形/开口轮廓 | 热轧与冷弯的边界、圆角、斜度、卷边参数必须分开 |
| 工字钢、H 型钢 | 只能共用 I/H 轮廓底层 | I/H 开口轮廓 | 标准系列、翼缘宽度/斜度、根部圆角、H/I 名称不能混掉 |
| H 型钢、剖分 T 型钢 | 只能共用轮廓段生成器 | H/T 开口轮廓 | T 是独立标准对象，不能当作任意 H 型钢自动截半 |
| 冷弯 C、Z、帽型、Ω、复杂折边 | 可以共用折线/圆弧轮廓引擎 | 冷弯开口轮廓 | 各自折弯段、卷边、圆角和标准截面仍独立 |
| 各类冷拔异型钢管 | 可以共用闭口异型轮廓容器 | 单腔闭口异型管 | 外轮廓、内轮廓、标准尺寸系列不能简化成宽高壁厚 |
| 椭圆管、跑道管 | 不能当成同一个轮廓公式 | 曲线闭口管 | 椭圆是椭圆曲线；跑道是直线+半圆，宽高相同也不等价 |
| 三角、梯形、六角等多边形管 | 可以 | 多边形闭口管 | 规则/不规则、顶点、内外轮廓和圆角 |
| 二腔方管及后续多腔、带翼、卡扣型材 | 可以共用多腔轮廓容器 | 多腔/混合闭口型材 | 第一阶段只开放二腔方管；其他腔体数量、隔筋、开口和局部轮廓后续再扩展 |
| 圆棒、方棒、矩形棒、多边形棒 | 可以共用实心轮廓容器 | 实心型材 | 圆、矩形、多边形的轮廓参数分别保留 |
| 球扁钢、钢轨、轻轨、导轨 | 只能共用实心轮廓容器 | 标准实心异型材 | 每个标准的完整轮廓和基准面必须独立保存 |

### 9.1 合并后的三层结构

```text
国标身份层
├─ standardBasis       // 采用的标准或“非标准截面”
├─ standardSection     // 标准截面号/规格，若有
└─ standardStatus      // 现行、历史、非标准、待核对

几何族层
├─ closed_hollow
├─ open_section
├─ solid_section
└─ variable_section

具体轮廓层
├─ 参数化轮廓
└─ 完整 contour 数据
```

例如，方管和矩形管可以共用 `closed_hollow + rectangular` 生成器，但仍要保存它是方形还是矩形、采用哪个标准、是否为标准尺寸系列。冷弯 C 型钢和热轧槽钢可以共用开放轮廓的底层几何接口，但不能在标准身份层合并成同一种槽钢。

### 9.2 合并的判定条件

只有同时满足以下条件才允许合并为一个几何族：

1. 截面拓扑相同：闭口、开口、实心和多腔不能跨拓扑合并。
2. 轮廓数据能被同一套几何对象表达：例如同为直线/圆弧段，或同为外轮廓与内轮廓集合。
3. 合并不会丢失国标规定的尺寸含义：腹板、翼缘、肢宽、根部圆角等不能被一个无意义的总宽度替代。
4. 标准身份仍然独立保存：共用生成器不等于互相宣称符合对方标准。
5. 对于没有统一国标的形状，必须标记为非标准或待核对，不能借用最相似的标准名称。

## 10. 几何定义的推荐字段

下面是与材料无关的最小公共描述。它不是某一个管型的全部参数，而是所有几何定义应有的外层结构。

```json
{
  "geometryType": "closed_hollow | open_section | solid | variable_section | assembly",
  "profileFamily": "round | rectangular | oval | polygon | channel | angle | ...",
  "coordinateSystem": {
    "origin": "declared_datum",
    "xDirection": "width",
    "yDirection": "height"
  },
  "outerContour": [],
  "innerContours": [],
  "parameters": {},
  "enabledParameters": {},
  "datum": {},
  "tolerance": {}
}
```

### 10.1 哪些字段属于几何

- 外宽、外高、外径、边长、壁厚。
- 内孔尺寸、内外圆角、弯曲半径、折线角度。
- 多边形顶点、轮廓段、孔数量、腔体位置。
- 偏心距、旋转角、基准线、对称性。
- 长度方向的中心线、变截面函数和截面姿态。

### 10.2 哪些字段不属于本文

- 材料牌号、屈服强度、抗拉强度、硬度。
- 热轧、冷弯、冷拔、焊接等制造路线本身。
- 焊缝质量、表面粗糙度、镀层和涂层。
- 库存编码、供应商、价格、重量报价。
- 切割速度、刀具、机床、折弯补偿和 CAM 参数。

制造路线只有在改变实际截面边界时，才需要作为轮廓来源的说明；它不能替代轮廓本身。

## 12. 定义时必须避免的错误

1. 把方管的内宽、内高和壁厚同时作为独立输入，造成相互矛盾。
2. 把 `0` 当成“未指定”；对半径来说，`0` 就是尖角。
3. 用一个统一 `R` 去代替本来不相同的多个角部半径。
4. 用“角钢 = 方管的一半”的方式定义角钢；角钢没有内孔。
5. 把圆管和圆棒共用壁厚字段。
6. 把椭圆管和长圆管混为一类；椭圆没有直线段，长圆有。
7. 把多腔型材强行压成一个内孔。
8. 用俗称代替实际轮廓。
9. 用材料或制造路线名称代替几何定义。
10. 只记录外包围尺寸，不记录圆角、内孔、孔数、偏心和真实轮廓。

## 13. 本文确定的定义原则

- **标准规则截面**：保存标准尺寸字段，并能生成标准真实轮廓。
- **参数化非标截面**：保存能唯一生成轮廓的参数；不能生成唯一轮廓时，改为轮廓数据。
- **任意截面**：以 `outerContour`、`innerContours` 为最终权威数据。
- **可选几何**：使用 `enabled + value`，不使用空值或负数哨兵。
- **派生尺寸**：只作为计算结果，不与基础尺寸重复输入。
- **定式截面**：直接保存完整轮廓，不伪造一套并不适用的参数。
- **三维对象**：在二维截面之外单独描述中心线、姿态和沿程变化。

这套原则先把“管型是什么”定清楚，之后无论进入哪个模板、哪个界面或哪种导出格式，都只能是同一几何定义的不同表现，不能再由前端或某个模板临时发明一套字段。
