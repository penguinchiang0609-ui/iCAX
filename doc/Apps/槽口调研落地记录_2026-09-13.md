# 槽口调研落地记录

依据《小管折弯槽口类型与计算方案专题调研.md》开展改造。用户随后明确：V 槽圆角的产品语义是槽根避空，与释放孔同类，不是相切展开。现已撤除误加分支，V 槽包版本为 3.0.1；边弧槽保留 3.0.0。

## 已接入可用参数及实体

### V槽

- 保留原 `rounded` 刀口圆角及其历史计算，不静默改变用户已有形状。
- 已撤除 `developed` 相切圆角展开槽、专用右圆角参数及示意图。保留原圆角避空几何，不能用“弧长＋K”重新定义它。现有 K 补偿未在此次撤除中改动。
- β 为折弯开口角，最终夹角为 180°−β，不再把参数名称作为成形夹角。
- 新增根部三槽修饰器，沿实际平直铰链公共区间布置中槽和两侧槽。每座桥按 `(B−lc−2ls)/2−kerf` 检查，不能小于输入最小桥宽。圆角曲面展开桥宽未实现，因此没有用名义外宽代替。
- 释放孔支持圆孔、腰形孔、圆角矩形，沿用近侧限深／贯穿和布尔并集机制。
- 同心圆弧闭口截面可生成 V 槽实体，实际圆柱刀路由现有 C++ 实体相交取得，不在展开图上拼三角形。
- 新增对称尖角多槽：δ=β/n，p=2Rc·sin(δ/2)，弓高 e=Rc·(1−cos(δ/2))。可按槽数或正的最大弓高误差自动求槽数，限制 2～64；检查槽距大于单槽开口。Rc 明确为中心线半径，不是内弯半径。
- 多槽刀具在同一模板生成后保持统一定位，外部特征放置仍属于公共层。

### 边弧槽

- 原任意角边弧保留为 `legacy`。
- 新增明确的 `side90` 模式，固定 90°；四分之一圆支路向外展开，底部宽度 L、顶部宽度 L+R，左右互为镜像。
- L=π(R+K·tₕ)/2 为调研的工程推导；R 取实际有效槽深。本次不提供未经验证的指定成形外半径选项。
- 从输入轮廓验证两对正交平直壁及四分之一圆角，不用管型 ID 或模板标签判断。
- 原“切断底部桥接”仍明确表示断开，不改名冒充三槽减应力。

## 参数、示意图与存储

- 新参数进入 Python 和前端的参数迁移白名单，随刀具快照保存。
- 示意图增加通用声明式条件变体，模板声明显示哪种图形；前端不按模具 ID 写几何分支。
- 保持局部 DOM 更新，未更改焦点和滚动位置保护机制。
- 计算结果记录折弯角、最终夹角、根部基准、分段槽距与弓高误差，并明确 `formingValidation=not-performed`。

## 验证

- Python：保留原圆角坐标、K 补偿、侧90镜像、三槽桥宽、自动分段及释放孔闭合回归；增加已撤除选项不再暴露、旧值不得静默映射的检查。
- 原生实体：原尖／圆／平底及原边弧回归；侧90左右镜像、根部两座桥保留、圆管六槽真实切除。误加分支的实体测试已移除。
- UI：模具页、冲孔向导；真实浏览器回归左右滚动、焦点、监听器和画布节点保持。

## 尚未完成的研究项

本次没有实现目标折弯状态逆映射、成形实体预览及闭合碰撞优化；也没有完成公母目标状态自动配合、壁厚过切后的重新标定、五轴刀轴与割缝刀路、版本化材料 K 数据库或样件标定。根部割缝参数只用于桥宽校核，不是刀路补偿。非平直铰链的 K 值和实际中性层仍需专门建模。

名义切除体通过实体测试，不等于折弯后已保证贴合或强度合格。
