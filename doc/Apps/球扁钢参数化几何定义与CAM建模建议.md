# 球扁钢参数化几何定义与 CAM 建模建议

## 1. 定义

球扁钢（Bulb Flat / Bulb Plate）是一类典型的热轧不对称型钢，常用于船舶、海洋工程、桥梁及其他钢结构。

它不应简单理解为：

> 扁钢 + 一个半圆球头

其标准名义截面更准确地说，是由：

- 一段长直腹板；
- 一侧局部增高的“球头”；
- 球头斜直线；
- 若干相切圆角

共同组成的非对称截面。

因此从 CAM 参数化角度看，球扁钢不需要使用自由曲线或样条曲线，可以完全采用：

> **理论直线 + 相切 Fillet**

来构造。

---

## 2. 基础截面示意

简化示意：

```text
            球头
          ╭────╲
         │      ╲
         │       ╲
         │        ╰────────────────────╮
         │                             │
         ╰─────────────────────────────╯

         <----------- b --------------->
```

更完整地考虑圆角：

```text
             r1
           ╭────╲
          │      ╲
          │       ╲      球头斜面
          │        ╲
         r2         ╰── r1 ────────────────╮
          ╰─────────────────────────────────╯
                                             r
```

---

## 3. 推荐基础参数

建议定义：

\[
\boxed{
BulbFlat(b,h,t,r_1,r_2,r)
}
\]

其中：

| 参数 | 含义 |
|---|---|
| \(b\) | 截面总宽度 |
| \(h\) | 球头位置的截面总高度 |
| \(t\) | 长直腹板厚度 |
| \(r_1\) | 球头上部及球头向腹板过渡处圆角 |
| \(r_2\) | 球头下侧与底边连接处圆角 |
| \(r\) | 腹板自由端上下圆角 |

其中某些标准资料还可能给出：

\[
d_x
\]

它表示截面重心位置，属于**截面计算结果**，不应作为基础几何输入参数。

---

# 4. 球头不是圆，也不是椭圆

球扁钢名称中的“球”很容易让人误解成：

- 半圆；
- 椭圆；
- 大圆弧；
- 样条曲线。

实际上标准名义截面可以按：

```text
竖直球头侧边
      │
      │
      ╰ r1
         ╲
          ╲   ← 球头斜直线
           ╲
            ╰ r1
──────────────────── 腹板上表面
```

进行解析构造。

也就是说核心仍然是：

\[
\boxed{
直线 + 圆角 + 直线 + 圆角 + 直线
}
\]

---

# 5. 球头斜面角度

标准球扁钢截面中，球头斜面通常按固定构造角处理。

建议在国标模式中内部固定：

\[
\boxed{
\alpha=30^\circ
}
\]

这里的 \(30^\circ\) 可理解为球头斜面与球头竖直方向之间的构造角。

因此球头斜面与水平腹板方向之间的锐角为：

\[
\boxed{
60^\circ
}
\]

所以 CAM 参数模型中通常不需要让用户再单独输入这一角度。

---

# 6. \(r_1\) 的几何定义

\(r_1\) 用于球头上部的两个主要过渡位置。

## 6.1 球头顶部过渡

```text
竖直球头侧边
      │
      │
      ╰── r1
           ╲
            ╲  球头斜面
```

构造关系：

> 竖直直线 + 斜直线 + Fillet(\(r_1\))

不需要单独输入：

- 圆心；
- 切点；
- 圆心角。

---

## 6.2 球头斜面向腹板过渡

```text
球头斜面
      ╲
       ╲
        ╰── r1 ───────── 腹板上表面
```

构造关系：

> 球头斜直线 + 腹板水平直线 + Fillet(\(r_1\))

因此同一个 \(r_1\) 可以用于球头上、下两处主要过渡。

---

# 7. \(r_1\) 的圆心角

因为球头斜面相对于水平腹板为：

\[
60^\circ
\]

所以斜面与水平腹板之间的方向夹角为：

\[
60^\circ
\]

相应 Fillet 圆弧的转角由两条理论直线的切线方向自动决定。

因此建模时不建议单独增加：

\[
\text{ArcAngle}
\]

只需要：

\[
r_1
\]

以及两条理论直线即可。

同理，球头顶部的 \(r_1\) 也通过竖直球头边与斜面自动确定。

---

# 8. \(r_2\) 的几何定义

\(r_2\) 位于球头下部：

```text
球头外端
    │
    │
    │
    ╰────────────── 底边
     r2
```

它连接：

- 球头竖直外侧；
- 截面水平底边。

两条理论直线互相垂直，因此可以直接处理为：

\[
\boxed{
Fillet(r_2)
}
\]

其名义圆心角为：

\[
\boxed{
90^\circ
}
\]

---

# 9. 腹板自由端圆角 \(r\)

球扁钢另一侧的普通腹板自由端通常采用上下两个小圆角：

```text
────────────────╮
                │
                │
────────────────╯
              r
```

上下圆角均可使用：

\[
\boxed{
Fillet(r)
}
\]

其基本理论线为：

- 水平腹板上表面；
- 竖直自由端；
- 水平腹板下表面。

因此上下圆角通常都是：

\[
\boxed{
90^\circ
}
\]

的相切圆角。

---

# 10. 推荐几何构造流程

## Step 1：建立长直腹板

根据：

\[
b,\quad t
\]

先建立基础扁钢主体。

---

## Step 2：确定球头总高

利用：

\[
h
\]

确定球头顶部位置。

---

## Step 3：建立球头竖直边

在球头一侧建立理论竖直边。

---

## Step 4：建立 30° 球头斜线

根据固定构造角：

\[
\alpha=30^\circ
\]

建立球头斜直线。

---

## Step 5：球头顶部 Fillet

执行：

\[
\boxed{
Fillet(r_1)
}
\]

连接：

- 球头竖直边；
- 球头斜面。

---

## Step 6：球头斜面与腹板 Fillet

再次执行：

\[
\boxed{
Fillet(r_1)
}
\]

连接：

- 球头斜面；
- 腹板上表面。

---

## Step 7：球头下部 Fillet

执行：

\[
\boxed{
Fillet(r_2)
}
\]

连接：

- 球头竖直边；
- 截面下底面。

---

## Step 8：腹板自由端 Fillet

腹板另一端上下分别执行：

\[
\boxed{
Fillet(r)
}
\]

最后得到完整封闭截面。

---

# 11. 不建议使用自由曲线

对于标准名义截面，不建议使用：

- B-Spline；
- Bezier；
- 椭圆；
- 任意轮廓拟合；
- 实测样条作为标准基础模型。

基础模型应保持：

\[
\boxed{
Line + Fillet
}
\]

只有在支持：

> 实测型材 / 扫描截面 / 厂家非标轧制轮廓

时，才需要额外提供自由轮廓模式。

---

# 12. 标准规格模式

球扁钢通常按类似：

```text
HP 80×5
HP 100×7
...
```

这样的规格体系选型。

因此 UI 可以分为两种模式。

## 12.1 标准规格模式

用户选择：

```text
规格：HP 80×5
```

系统自动读取：

- \(b\)
- \(t\)
- \(h\)
- \(r_1\)
- \(r_2\)
- \(r\)

用户无需逐项输入。

---

## 12.2 自定义模式

允许用户输入：

\[
\boxed{
b,h,t,r_1,r_2,r
}
\]

用于：

- 非标型材；
- 厂家自定义规格；
- 实际测量数据；
- 非国标规格。

---

# 13. 热轧属性

球扁钢本身就是典型的热轧型材。

因此不建议将其设计成：

```text
扁钢
□ 球头
□ 热轧
```

更合理的是直接保留独立一级类型：

```text
球扁钢
```

内部可以直接视为：

```text
HotRolled = true
```

UI 上甚至可以不再提供“热轧”开关。

---

# 14. 为什么球扁钢应该是独立基础类型

球头会改变截面的：

- 拓扑；
- 截面质心；
- 惯性矩；
- 切割路径；
- 装夹方向；
- 特征识别；
- 标准规格体系。

因此：

\[
\boxed{
球扁钢 \neq 普通扁钢的一个小圆角变体
}
\]

推荐作为独立基础类型：

\[
\boxed{
BulbFlat
}
\]

---

# 15. 推荐数据结构

```cpp
struct BulbFlatSection
{
    double width;          // b
    double height;         // h
    double thickness;      // t

    double bulbRadius1;    // r1
    double bulbRadius2;    // r2
    double endRadius;      // r
};
```

球头斜面角度可以内部固定：

```cpp
constexpr double BulbSlopeAngle = 30.0;
```

如果以后需要兼容不同标准，可以扩展为：

```cpp
double bulbSlopeAngle;
```

但不建议第一版直接暴露给普通用户。

---

# 16. 参数合法性检查

建议至少检查：

\[
b>0
\]

\[
h>t>0
\]

\[
r_1>0,\quad r_2>0,\quad r\ge0
\]

同时检查：

1. 两个 \(r_1\) 圆角之间必须能够保留有效斜直线，或恰好相切；
2. \(r_2\) 不能与上部 \(r_1\) 发生非法重叠；
3. 球头轮廓不能穿过腹板下底面；
4. 自由端圆角 \(r\) 不能超过腹板厚度允许范围；
5. 最终截面必须为简单闭合轮廓，不能自交。

---

# 17. CAM 中的推荐模型

最终推荐：

\[
\boxed{
BulbFlat(b,h,t,r_1,r_2,r)
}
\]

内部固定或由标准库给出：

\[
\boxed{
\alpha=30^\circ
}
\]

几何生成核心原则：

> **先建立理论直线，再通过 Fillet 生成标准名义圆角。**

不需要输入：

- 球头宽度；
- 圆心位置；
- 圆弧起止角；
- 各圆弧圆心角；
- 样条控制点。

---

# 18. 最终结论

球扁钢虽然名称中有“球”，但其标准名义截面并不是一个复杂自由曲线轮廓。

对于 CAM 参数化建模，可以规整地抽象为：

\[
\boxed{
若干直线 + 两个r_1 + 一个r_2 + 两个r
}
\]

其中核心参数为：

\[
\boxed{
b,h,t,r_1,r_2,r
}
\]

基础几何完全可以解析构造。

因此建议：

- 球扁钢作为独立一级管型；
- 天然按热轧型钢处理；
- 标准模式按规格库自动带出参数；
- 自定义模式允许修改几何参数；
- 不使用自由曲线作为标准名义模型；
- 所有圆角均采用“理论直线 + Fillet”的统一构造逻辑。
