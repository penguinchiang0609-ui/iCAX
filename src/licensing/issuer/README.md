# TubeDesigner 离线授权签发工具

## 首次准备

把整个 TubeDesigner-Issuer 文件夹复制到 Windows x64 隔离签发电脑，运行 TubeDesigner-Issuer.exe。无需另装 Python，不要只复制 exe，_internal 目录不可缺少。本工具包不含私钥、不预置信任根。

1. 在隔离电脑点击“新建签发库”，输入两次至少 16 个 UTF-8 字节的口令。生成口令加密的 P-256 私钥、公钥及签发者编号。不要在客户电脑或在线开发电脑生成正式密钥。
2. 从 TPM 厂商官方渠道独立取得 DER 格式根证书及中间证书，核对根证书 SHA-256 指纹后导入。不可直接信任客户随申请提供的根。导入不修改 Windows 系统信任库。
3. 点击“导出构建公钥”，将 IssuerTrust.generated.h 交给开发人员，放入 src/licensing/include 并重新构建客户端。该文件只含公钥。当前产品版本 0.1.0，授权主版本范围默认 0 至 0。
4. 点击“备份签发库”，保存到安全介质。备份含加密私钥、公钥配置、台账、厂商证书；口令必须另外保管。BACKUP_INCOMPLETE 标记表示备份未完成，不得用于恢复。

## 申请、签发与激活

1. 客户以管理员运行 TubeDesigner，在“关于 → 授权”导出永久或试用申请 .tdreq，发给你。试用申请会创建 TPM NV 项，请不要反复生成。
2. 打开签发库，导入申请。验证设备受限密钥、随机证明、EK 厂商证书链，查看同设备已有签发次数；失败即拒绝，不退回软件绑定。
3. 填写客户、永久/试用、版本范围、设计/拆单/STEP/下料权限。试用限定 1 至 30 天，必须使用试用申请；同一 EK 重复试用由台账拒绝。天数从签发起算，不是首次激活起算。
4. 审核后输入口令，导出 .tdact 给客户。签发先入台账，导出失败或取消可重新选择记录导出相同文件，无需重复签发。
5. 客户导入激活。先验证内置签发公钥，再通过对应 TPM 解密；复制到其他设备不能激活。永久授权不依赖日期。
6. 每次签发后备份。恢复时打开完整备份目录即可；旧台账会丢失新签发与重复试用记录，不能随意回滚。台账不是独立防篡改审计系统。

仅交付 .tdact；绝不把私钥、签发库或台账随客户端分发。离线永久授权不能远程撤销。TPM 清除或密钥状态改变需重新申请并人工审核。

## 安全与兼容性边界

试用以 TPM 单调计数器记录小时水位，不依赖磁盘最后使用时间。同小时不反复写，回拨至已有小时之前拒绝；久未运行需补推进计数，可能较慢。时钟冻结及同小时内回拨不能被完全阻止，不是严格可信的离线 30 个自然日。

要求可用 TPM 2.0、RSA EK 厂商证书链、ECC P-256 受限密钥及所需 TBS 命令权限。管理员身份不能保证所有固件和企业策略兼容。已验证当前 Intel PTT 实机，不代表所有型号均认证通过；加密狗尚未选型接入，不支持设备不会自动放行。

厂商链完全离线验证，当前不检查 CRL/在线吊销。根与中间证书需人工维护。签发机、备份应使用受控账号和加密磁盘；工具不配置目录权限，不保证 Python 私钥内存擦除。口令遗失不能恢复。

工具不是防篡改壳，不承诺客户端二进制不可绕过。默认 GUI 使用真实 TPM 验证；issuance.py 与 test_*.py 是独立软件密钥测试，不是生产回退入口。禁止发行客户端信任测试公钥。
