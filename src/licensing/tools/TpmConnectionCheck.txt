TubeDesigner TPM 连接检测

适用于软件提示“Cannot open TPM 2.0”的电脑。

1. 将 ZIP 全部解压到出现问题的电脑的桌面文件夹中，不要直接在压缩包内运行。
2. 右键 Run-TpmConnectionCheck.cmd，选择“以管理员身份运行”。
3. 检测会生成并打开同目录的 TPM-Connection-Report.txt，请将报告发回。

此工具只查询设备版本并打开、关闭 TPM 2.0 连接。
不联网、不读取授权文件或密钥、不发送 TPM 命令，不清除 TPM、不更改系统配置。
不需要安装 Python 或开发环境。适用于 Windows x64。

报告中的 contextStatus 是与软件相同连接操作的 Windows 返回码。
若为 0x00000000，只表示此次连接成功，不代表授权申请、厂商证书或激活通过。
若检测成功而软件仍报错，请一并提供软件版本、最新报错及是否以管理员身份运行。

不要为此错误清除 TPM；清除会影响设备绑定及 Windows 中已有的 TPM 密钥。
