# SheetNesting

独立 C++20 二维板材排样模块。矩形、平行四边形和圆以不同规格混排为基础能力，另提供类规则组合与小件补隙；采用多策略独立 job 运行、统一验证和结果选优。

## 策略与 job

`IStrategy::Run` 接收当前 job 的问题快照与预算，返回完整的布局/未排需求。`StrategyRegistry` 注册工厂，每次 job 都创建新的策略对象。库存、实例编号、分组、布局和停止状态均保存在 job 内。

`RunPortfolio` 为每个策略创建独立输入副本，串行建立策略对象后按 `Workers` 并行执行，保留每个 job 的结果、验证和诊断。注册表在运行期间只读；调用者提供的取消函数应满足并发调用要求，或使用自己的线程安全取消令牌。

整体架构与职责边界见[二维排样模块架构](../../../../doc/Plane/二维排样模块架构.md)。执行调度、策略注册、候选验评和最终比较分别在 `NestingJobs.cpp`、`NestingStrategies.cpp`、`NestingAssessment.cpp`、`NestingRanking.cpp`，调度器不按具体算法 ID 分支。

`SheetNestingExactFill.h` 提供可选 `MakeExactFillContactFactory()`。它仅尝试单规格库存的一张板：零件零间距、同材料、无孔多边形、非自由旋转、最多 20 个原件，且真实材料总面积与板内面积在严格数值误差内相等；支持多规格、多数量与明确的离散允许方向。逐次从板减去已放真实轮廓得到空区，选最低最左空区顶点，用待排零件的真实顶点对齐生成候选，按共享边长度和面积排序后有限回溯。每个候选核对板界及真实碰撞，完成后对原问题重新 `Validate`；不适用、未找到或耗尽预算时保留全部需求并返回 Partial，取消返回 Cancelled。不适用或搜索失败不证明不可排；仅顶点接触候选并不覆盖所有可能的填充方式，不支持正间距、圆、孔、连续角度或多板订单。该工厂不自动注册到默认策略池，可显式纳入独立 job；时间与尝试次数由调用者提供的预算约束。

`SheetNestingRepeatCell.h` 提供可选 `MakeRectangleRepeatCellFactory(constructor, columns, rows)`：把板内有效区域分成若干相同单元，以减少后的真实数量调用指定构造器，只有单元完整合法且真实材料面积填满，才平移展开为全部原件，再对原输入完整校验。单元形状与构造器的每种配置仍是一个独立job，不在包装器中枚举策略，不自动扩展默认策略表。准备、内部构造、原件展开、核对共用调用方的时间、尝试和锁存取消；单元未完成时清空内部布局，保留全部原需求。

该工厂当前仅支持可按合法方向成为轴向满矩形的真实原件、零件零间距、一个兼容板材规格、真实需求面积等于可用板内面积、最多4096个原件与4096个单元。每个原始需求行的正数量必须被单元数整除；不把分拆成数量1的等尺寸需求行重新归并。源轮廓、允许角度、原ID保持不变，外板边距只加一次。单元及展开结果除共享校验外，还按浮点舍入尺度独立检查真实轮廓、界内和每对交叠；较大的用户容差不能把细缝、越界或微凹口作为满矩形接受。失败只是该单元假设未成功，不代表整板不可排。

密实块库的fair搜索仍以最多512原件、规划边长512、面积65536的精确整数问题为内部范围。大物理尺寸可沿X/Y分别按所有原件尺寸与板边长的公约数严格缩放，恢复实际毫米坐标；不能整除或仍超范围的输入保留原需求，不能称为任意实尺寸支持。条纹/棋盘必要条件、自动区域与相邻原件释放位于 `NestingRectangleStripeRepair` / `NestingRectangleStripeRegions`，供原件局部精确重排复用，宏块修补失败且有剩余预算时可调用。局部不可行结论不外推到整板。

`SheetNestingPipeline.h` 提供可选的薄流水线：`IPartOrder` → `IStrategy` → 若干 `IPostProcessor`。`MakePipelineFactory` 仍注册到同一个 `StrategyRegistry`，每 job 新建所有组件，不自动扩张默认策略数量。输入排序只能返回原规格下标的完整排列；构造器仍保留自身动态选件逻辑。后处理收到原问题和不可变当前解，只返回候选，由公共验评与比较决定是否接受；非法、失败、变差或同分候选保留原解。

`SheetNestingRaster.h` 提供可选 `MakeConservativeRasterFactory(settings)`，每个配置创建一个独立扫描 job；调用者明确提供物理步长、原始规格下标的完整优先序、扫描方向和是否轮流，构造器不会在一个 job 内枚举顺序。几何保持原始坐标，只将落点量化。单元只要可能与真实外环材料相交即保守占用；严格对齐网格的边界接触可共用边，非对齐及数值不确定边界额外保守，可能损失密度。候选还逐件检查原始几何和板界，最终结果经过公共需求、库存及几何校验。

该实现当前限于零件间距为零、一个矩形板材类型的首张板、允许 0° 的无孔直线多边形、同材质；即使允许其他角度或自由旋转，本 job 也只尝试 0°。不适用时原需求完整保留，不代表不可排。网格每边最多 4096 单元、整板最多 2097152 单元；最多 64 个规格、5000 件、单轮廓 512 点、所有形状掩码合计 2097152 单元，每 job 最多 500000 个候选且受调用者更低的时间/尝试和取消约束。2240×6000 mm 板以 3 mm 步长在网格数量范围内，但密度、耗时和是否完成仍须按订单实测；最终公共验评另计等待时间。此工厂不注册到默认策略，也不提供圆、孔、多板、非零间距或任意旋转的扫描实现。

可选 `MakeCircleRelocationStage()` 提供 `circle.relocate` 后处理：尝试把一板中的同规格圆件改成板边单列，同时将该板其他原件整体下移，再尝试从另一板移动原有零件组并压紧源板。每个候选保留真实零件身份与方向，以实际圆和多边形检查板界、间距、碰撞，并对完整原问题重新验证；流水线仍以公共评价决定是否接受。它是有限候选而非一般的异形局部最优搜索，不参与默认策略。当前只处理正间距、同兼容材料、2–4 张已用板、最多 200 件与 16000 个已放原件顶点，迁移组最多 8 件；还限制规格数、库存数、尝试次数和共享时间/取消，未成功保留初解。实际测量和最终验评的等待时间另计。

`SheetNestingLocalRepair.h` 的可选 `MakeEvictionRepairStage()` 能接收已验证的单板 Partial 结果：以真实外轮廓的有限接触候选试放未排原件，暂时撤出至多两个直接阻挡件，尝试恢复它们并在必要时继续移动少量其他原件；每次输出重新核对全部原件身份、允许方向、板界和碰撞，Pipeline 只接受公共评分更好的候选。当前限零间距、无孔多边形、最多 128 已排件、128 规格、每外环最多 128 点和 1–2 件未排；单次链最多移动 5 个阻挡原件、每轮至多 30000 候选姿态，且有共享时间/尝试/取消边界。失败保留原解，不表示不可行。它不自动注册默认 job；在 Albano、Jakobs1、Marques 和 Shirts 现有四个初解的固定预算回放中尚未补齐，不能将此可选阶段称为已解决这些公开问题。

`SheetNestingSeparationRepair.h` 的可选 `MakeTriangleSeparationRepairStage()` 对单板、恰缺一件的有效 Partial 初解，按允许角度构造有限初始位置，用原轮廓重叠面积选种子，将简单无孔多边形分解为三角形，再对三角分离半空间和原板边界做有界 Dykstra 投影；全部原件可平移，原角度和身份保留。求解内的分离约束有物理容差余量；最终输出仍须通过原件碰撞、角度、板界和数量校验，由 Pipeline 按公共评价接受，不接纳仅有投影残差的近似解。当前限制零间距、最多 64 个已排实例、128 规格、每环 64 点、2048 三角形、12000 个半空间、24 个种子、16 个角度，以及最多 2000000 次投影／种子工作；调用者更小的时间和尝试预算优先，失败保留初解。此阶段未注册默认 job。

一条显式配置的真实 C++ job 使用不含预置布局的公开 Dighe1 原问题，以 0.5 秒上限的 `rules.contact-large` 构造部分解，再调用分离修补：固定 100.20741924741924×100 的目标板上从 15/16 补到 16/16，独立 GEOS 与公共 C++ 校验均通过且 0 条告警；本机单次含验评墙钟约 0.116→0.766 秒，合计约 201285 次工作，需给该 job 留足预算。它不是性能保证，也不代表已解决全部公开案例：Albano、Jakobs1 和 Marques 的相应初解在当前有限预算下未补齐。复现实验、范围与实际图见[分离修补结果](../../../../output/research/plane-nesting/20261029/public-irregular-02/repair-native/dighe1-live-v2.html)。

基于固定实际初解的两次 Pipeline 回放中，该阶段使两组 80 件、3 板自造混排结果的可保留规整余料分别从 5.6943 增至 7.74336 m²、从 5.07936 增至 7.12842 m²；其余受支持初解未改善。零间距、超范围输入不运行该搜索。13 个初解及候选均经独立圆/多边形与余料证书核验，不能据此推广到所有订单或商业软件。复现实验和前后图见[可选后处理证据](../../../../output/research/plane-nesting/20261029/irregular-mixed-analysis-01/native/relocate-index.html)。

流水线共享剩余时间/尝试预算，并锁存取消；后处理抛错保留已有合法解并终止剩余后处理链。`Options.Ranking` 决定当前 job 的后处理接受口径，portfolio 显式传入 `PortfolioOptions.Ranking`，避免两级评价不一致。后处理返回的统计只报告新增工作，接受候选不丢失构造阶段统计，验证/测量成本累计，后处理执行时间单列 `PostProcessingSeconds`。接口本身不自动启用算法；默认表中的顺序矩形分支显式使用确定性排序，压紧和拆板仍须显式配置。

可选 `MakeRectangleRefillStage()` 返回 `rect.refill` 后处理阶段。它尝试将一整张板上的轴向矩形原件搬入其他已用板的空位，目标原件的位置保持不变；全部搬完并通过原问题校验才删除源板。只移动原件，保留原 ID/实例和存量板编号，允许库存编号留洞；搬运件清除旧规划组。`Group` 不是刚体约束，组合/圆阵列/补隙计数保留所选解的构造来源，不从分组大小猜类型。

该阶段只接受经流水线验评的完整初解；自身不重复测量余料，最终沿用统一评价。当前私有范围为最多32张已用板、512个已排实例、2048种输入零件、64种板材；每个源板最多64件矩形，单个可搬件外环最多128点，总世界多边形顶点最多32768；候选自由区、方向、尝试数另有硬上限，超限保留原解并报告原因。非矩形目标用保守包围盒占用，不代表通用异形插入。时间限制是协作式边界，不强行中断几何原语。

使用方式：在已有 `StrategyPipeline` 上执行 `pipeline.PostProcessors.push_back(MakeRectangleRefillStage())`，再将整条流水线注册为一个 job。`rect.refill` 是阶段 ID，不是默认排样策略；该阶段没有改变当时的34个默认策略。235个固定初解与控制的工厂回放、470个原件结果及1416个正面积余料证书经独立核验，未发现错误；222个捕获初解中10例各少用一板。该收益相对于这些初解，尚未证明超过完整策略池。证据见[可选阶段报告](../../../../output/research/plane-nesting/20261027/exploration-02/pipeline-components/sheet-reduction/direct-refill/integration/README.txt)。

正式库导出工厂另行完成相同235例回放并独立核验，收益与控制均保持。该次17个CTest程序全部通过，`RectangleRefillTests`含24项组件与真实流水线检查；证据在研究目录`formal14/`。阶段自身的候选校验与最终公共验评可能在计时分项中重叠，以完整调用墙钟为等待依据，不简单相加所有统计字段。

| `rules.strip-width` / `rules.strip-height` | 先构造完整布局，再用多个更窄/更短的工作区域尝试重排一张已用板；只接受更大的安全余料矩形证书 |
| `parallelograms.pattern-row` | 对允许方向中可归成水平底边的平行四边形/矩形，按高度和剪切量分行，行内用有界背包混合不同底宽 |
| `circles.square-voids` | 先排同半径方阵，再用局部方孔候选混排较小圆；原半径、圆心、身份与间距逐件复核 |
| `circles.cell-rows` | 用圆的外接方形复用异规格矩形行模式，再映回真实圆；作为安全、快速的保守候选，与真实圆接触策略独立比较 |
| `rules.hole-rectangles` | 真实矩形孔内增量维护局部 MaxRects，混排允许方向的矩形小件；其他空隙继续有限接触补隙 |

拼缝策略的 MaxAssemblyMembers 默认12，允许1–12；它与旧组合器的 MaxPatternMembers（1–4）分别限制不同搜索。该策略遵守 EnableCombinations，不通过镜像组装。拼缝只生成候选，最终在世界坐标检查原始零件碰撞、允许方向和板界。不适用时保留未排需求，由其他独立 job 提供候选。

组合单元混排内部保留至多四路待验骨架候选，优先维护已验证的最好缺件/板数前缀，构造结束再用公共原件校验、余料测量和 `Options.Ranking` 比较同前缀结果。完整且板数已达安全下界后，所有后续骨架共享剩余构造资源的10%，不再无条件在第一份最少板完整解处停止。该配额是私有资源启发式；最终验评另计，实际等待成本仍须实测。

同规格圆的阵列是快速子策略；不同半径并不按互不混排的规格分批占板。混半径策略先在已开板上联合尝试所有剩余规格，计算目标圆与任意已排圆的真实相切距离及两约束圆交点，再重新核对板边和全部圆间距；基本混排不依赖 `EnableGapFill`。每轮候选总数最多 4096，先在线去重，并为两圆接触保留容量，避免板边候选占满列表。

大规格优先策略在新板上对重复半径先比较方阵/错列种子的可放数量，数量相同时再比较占用面积，避免局部三圆紧排挡住第四件的可行位置；随后所有剩余半径继续真实接触混排。几何半径相同但 PartID 不同的需求可共用种子位置模板，实例身份、原始圆心、允许角度和数量仍分别保留。另两种混排 job 保留直接接触构造，各 job 输出独立比较。

平行四边形专用策略对不同规格、不同允许角度共同生成合法接触候选，基本混排不依赖组合或补隙。圆专用策略和此策略对不属于自身处理范围的原件保留明确余量；调度器仍按完整问题的需求校验与比较结果，不能把局部完成当整个订单完成。

各策略可启用补隙：从已放零件真实外环、孔洞顶点和圆相切关系提出候选，逐件检查材料碰撞、间距与板界。组合内部孔洞保留，封闭孔内放小件归补隙阶段。补隙是有限接触候选搜索，未找到不表示不可放。

三角形和梯形保留输入识别及专门的配对/组合生成规则，当前不分别注册整套排样策略。允许相应旋转时，两件全等三角形或梯形可组成平行四边形；直角三角形还可组成矩形。基础铺排能力优先收敛到矩形、平行四边形与圆，并保留类规则组合。数量余单、禁用所需旋转或配对不合算时，原件仍参与单件排放与补隙，不强制全部配对。

形状识别、组合生成与完整排样策略分别管理。job 仍独立：例如组合优先和单件优先可以分别运行比较，但不必为每种输入形状复制一套库存、补隙和多板逻辑。零件间距大于零时，组合保留真实成员与间距，不能将中间缝隙误当作材料或零间隙拼接。

矩形空闲区采用 MaxRects 的全部相交区分裂与包含剪枝。组合保留原始成员、相对姿态和数量消耗，不将几件永久合并为一个新零件。当前包络布局是保守规划，补隙阶段允许真实材料不相交的包络重叠。

默认选优只使用重新验证的合法结果：未排数量 → 板数 → 最终板可保留的规整余料矩形面积（越大越好）→ 占用高度 → 占用右边界。完整结果优先于任何漏排结果；不使用成本抵消多用一张板。面积和长度按输入容差比较，消除浮点尾数造成的虚假胜负；相同分数按注册顺序稳定选择。失败、非法或伪造“已验证”的结果不能胜出；取消后合法的部分结果保留，其状态仍为 Cancelled。

`PortfolioOptions.Ranking` 可选择 `RegularRemnant`（默认）、`LowThenLeft`、`CompactArea`，用于明确的同输入对照。后两者仍先比较未排数量和板数；占用包络面积及低左位置不代替实际余料测量。

## 规整余料的评估

当前可执行的基准是：在真实剩余材料中，寻找一个能完整保留的轴向矩形。先扣除原件真实材料及所需间距，并遵守当前板边距，再测量矩形；零件孔洞按真实材料语义保留。不能把多个碎缝面积相加，也不能把空白区域的外包矩形当成可用余料。

`FindRegularRemnant` 返回明确的矩形坐标、已验证面积下界、乐观面积上界和测量分辨率。下界来自安全网格种子和真实几何边界扩张，上界由确定被材料占据的网格及剩余材料面积限制。默认分辨率 64，调用者可提高至 256。它是有限搜索；不宣称已求出连续几何上的最大矩形，较细网格也不保证找到的下界逐次增大。需要比较接近结果时，应保留已取得的较大安全矩形，再针对重叠的估计区间加密测量。

网格种子从四个方向提出并合并，避免直角旋转改变评分；保持原安全种子，总数最多 64。纯圆大板若没有安全种子，再用有硬上限的近邻圆心中点和解析净空提出少量安全正方形，然后按真实几何扩张。下界为零仍只表示本轮没有找到正面积证书，不能据此断定没有可用余料。所有返回矩形均明确检查实际板界，修正仅一 ULP 的端点相消，不借用几何容差越过板边。

同兼容材料组的板允许调整逻辑加工次序，因此从实际已用板中选择规整余料最大的一张作为该组最终板；不同材料组分别选一张再汇总。数组末项不自动代表最终板，未使用的空板不得获得余料分数。当前 `Material` 字符串是完整兼容键；厚度等宿主条件须一并编码，模块不自行猜测兼容性。

面积相同的长条与方块能承接不同的后续需求，当前不凭空设置长宽比惩罚或最小短边。输出保留长宽，供业务定义可回库尺寸及后续订单适配。旋转矩形余料已在独立研究中发现收益，但当前公共 `Rect` 余料测量仍限轴向，不将研究值冒充已实现的默认评分。

`TimeLimitSeconds` 限制构造/重排工作，最终验证和余料测量另行计时；实际用户等待时间必须包含这两部分。`Statistics` 的准备、放置、验证、评估分项为负值时表示尚未采集，报告中写空值，不填假零。

## 输入与边界

`SheetNestingNfp.h` 提供可显式共享的 `NfpCache`。它只保存不可变几何，不保存库存、实例、布局或搜索状态；各独立 job 可注入同一个有界缓存。当前范围是零件零间距、无孔简单多边形，圆和孔明确返回 Unsupported。NFP 是相对平移的禁放区候选来源，最终合法性仍由真实原件碰撞和公共 Validate 决定。

实现先缓存原轮廓的耳切分解及相邻凸块的精确合并，再对凸块进行线性边序列 Minkowski 求和；单个凸块对直接返回，不做无用并集，多个凸块对只做一次 ClipperD 并集。缓存还复用旋转后的凸分解与 A/B 互换的中心反对称关系。统一旋转和平移通过 `NfpLookup.Transform` 表达，调用者必须应用该变换，不能直接把共享 Region 的坐标当作世界坐标。

键由规范化真实轮廓内容和相对角组成，不使用 PartID 或仅包围盒，不按几何容差量化；原点消去时的浮点余项也进入键，避免相消导致不同轮廓误命中。键在清理共线点前保存完整原始有序环，非法短边/重复点不能借合法简化轮廓的热缓存绕过校验。建议每个不可变原件先 `Prepare` 一次，再用预处理句柄反复查角度对；冷查询也直接使用已规范化、已校验快照，编辑几何后应生成新句柄。

同向或反向的同一几何对并发冷请求合并计算，计算本身不持总锁，等待者独立遵守自身取消/时间预算。LRU 限制条目与驻留载荷：按实际容器容量和保守条目/共享对象记账；固定缓存/哈希桶元数据、正在计算的临时对象和调用者持有的结果不计入 `MaxBytes`。`Clear` 释放条目及空容器桶。凸块对和总并集顶点有界；时间为协作式软限时，不能中断一次同步 Clipper 并集，超时不缓存半成品。

最终版 990 个公开源 NFP 查询、990 个任意角度几何控制和另外64个大跨度/大坐标控制均通过独立 GEOS 对照，阈值1e-7，最大边界差约1.74e-8。7个相关CTest通过，包括同向/反向并发只构建一次、等待取消/超时隔离及非法冷热输入。三轮微基准中位：990次首轮86.88ms；9900次普通热查询15.02ms、预处理热查询5.77ms。8线程同键冷启动的72轮只构建72次，关闭合并的同版控制构建576次。这些证据不代表整板速度或完整率提升。复现、源码/程序哈希和几何核验见 `output/research/plane-nesting/20261029/public-irregular-03/nfp-native/final-runs/`，图示见其上级 `index.html`。

- 单位为 mm，角度为度，绕局部原点逆时针旋转后平移；不自动镜像。
- 多边形由一个简单外环和若干严格内部、不交叠、不嵌套的孔组成，环绕向不限；也支持解析圆。圆和多边形表达互斥。
- 规则分类包括矩形、类矩形、三角形、平行四边形、梯形与圆。类矩形是材料面积/最小方向矩形包络面积至少 0.85 的启发式标签；碰撞始终使用真实材料。
- `FreeRotation=false` 时只允许 `AllowedAnglesDegrees`；列表为空表示固定 0 度。`true` 时采用直角和主要边方向等规则角，不进行连续角度全局搜索。
- 材料键必须相同；板材为有限数量矩形，边距与零件间距分别计算。当前不含异形板、缺陷区、固定件、共边工艺或 CAD 文件导入适配。
- 坐标绝对值/圆范围、板材尺寸至多 `1e7 mm`；容差为 `[1e-7, 0.01] mm`。多边形相交使用 ClipperD 精度 8，圆距离使用解析计算；合法性在给定容差内判断，不声明机器加工精度证书。
- 当前规模上限为总需求 100000 件；实际完成量受每 job 时间、候选、组合深度和放置尝试预算约束。候选耗尽返回 Partial 和明确余量，不证明不可排。
- 所有活跃规格及其基础方向候选均生成，受任务时间/取消约束；`MaxPatterns` 只限制额外组合候选，不能让排列在后的规格或必要 90 度方向消失。`MaxPatternMembers` 为 1–4；补隙每个方向最多保留 4096 个位置候选。`Seed` 供自定义随机策略使用，当前内置规则策略为确定性构造。

`GeometryValidated` 不被调度器信任，`Validate` 会重新检查需求守恒、原始实例唯一性、库存、材质、角度、实际材料碰撞/间距和板界。检查路径不依赖 MaxRects 或组合候选缓存，但与求解器共用底层几何谓词；当前证据不等于独立几何内核的认证。

## 使用

```cpp
#include "SheetNesting.h"
using namespace iCAX::SheetNesting;
Problem problem;
Part part;
part.ID = "rectangle";
part.Geometry.Outer = {{0,0}, {80,0}, {80,40}, {0,40}};
part.Quantity = 12;
problem.Parts.push_back(part);
problem.Stocks.push_back({"sheet", 300, 200, 1, 1.0, ""});
PortfolioOptions options;
options.Workers = 4;
options.PerJob.TimeLimitSeconds = 5;
auto portfolio = RunPortfolio(problem, options);
if (portfolio.BestJob != static_cast<std::size_t>(-1))
{
    const auto& best = portfolio.Jobs[portfolio.BestJob];
    // best.Output contains placements and explicit remaining demand.
}
```

独立运行某一策略：构造 `Job{ID, StrategyID, Problem, Options}` 后调用 `RunJob`。扩展策略只需实现 `IStrategy` 并注册新工厂，不改其他策略或比较器。后续扫描线、NFP 左底贪心和通用搜索沿此接口加入。

## 组合单元批量构造与可选即时补隙

`SheetNestingRuleStrategies.h` 提供 `MakeBatchRuleFactory(BatchFillTiming)`。它复用原组合生成器、原件恢复、MaxRects、几何谓词和中心验评，不增加另一套调度或库存接口。`OnStall` 已以 `rules.batch-on-stall` 追加到默认表；`AfterBatch`保留可选。批次材料面积优先策略以独立默认 job 追加，不改变已有 job 的顺序和评分。

```cpp
#include "SheetNestingRuleStrategies.h"
auto registry = DefaultStrategies();
registry.Register("rules.batch-after-batch", MakeBatchRuleFactory(BatchFillTiming::AfterBatch));
```

同一真实单元按库存消耗向量计算可重复次数，再比较满宽与满高的两种行列安排；仅占用实际提交的单元格，末行余空保留。每次重新选择时，不同规格的单件和组合共同参加；当前不是多步前瞻，也没有连续角、斜周期或矩形绕圈阵列。

局部选择先比较类基础组合节省的规划包络面积，再比较批次材料面积、单元密度及空位适配。节省量为各成员独立包络（含一次间距）的面积和减去组合包络面积；仅矩形、平行四边形或现有类矩形标签的多成员组合参与这一优先项，数值不确定量内视为相同。该值不是实际材料或可回收余料，不能替换公共的完整性／板数／规整余料评分。固定L形与补块反例用于防止大批原件提前用完互补库存。

`OnStall` 在主候选放不下时补隙，再回主循环；`AfterBatch` 还在每次模式批量提交后，仅在本批实际物理包络内立即补隙。两者保留相同圆阵列起始路径，圆起始阵列后没有新增立即补隙。关闭 `EnableGapFill` 时两种节奏使用相同构造规则；短墙钟截断仍可能导致不同候选池，不能把不同截断结果当成纯时机收益。

每个重复单元按真实世界姿态检查后整组提交，停止时只保留已完成原件。批量分支使用作业局部AABB前缀索引与尾部全查，累计64件未索引原件后重建，仍调用原 `ShapesConflict`。默认分支保持原碰撞遍历；这不是精度放宽或硬实时保证。每个job的数量、布局、索引与停止状态独立。

批量分支还缓存一次完整失败的全板补隙搜索：只在本板布局序列未变、剩余需求只减少时复用；局部失败和预算／取消截断不写入缓存。布局追加使原计数失效。局部立即补隙从本批包络生成起点和相关锚点，再按真实材料验收，避免远处锚点耗尽候选额度。局部候选池有变化，不能宣称新旧构造结果逐位等价。调用数、失败复用次数和补隙耗时写入本策略诊断，不改变公共统计布局。

局部与全板补隙共享一次可选工作额度：总构造时间的15%以及放置尝试上限的1/8（至少一次尝试），不是每块板／每次调用重发。额度用尽仅结束补隙，主体批量和新板构造继续使用job剩余总预算；该次中断不记为完整搜索失败。15%／1/8是独立试验中的资源启发式，不是几何条件或最优配额。完整状态由原需求决定，补隙子预算耗尽不自动将已完整结果改为Partial。

主候选的完整失败也按本板PlacementCount复用，减少多板任务中反复扫描已失败的板。它只适用于当前固定pattern池、固定free.X/Y首单元验证及需求递减：批次数量变化会改评分，不会救活此前失败的首单元；新布局追加后重新搜索。预算／取消中断不入缓存。以后若增加动态候选、整批联合验证、移动／回溯或单独调整主Packing，必须重新证明或改用完整状态版本，不能直接复用这个Count键。

## 凹口翻转扣合

组合生成对双方含凹角的接触先作有界收集，按相向接触及包络排序，再沿用原尝试配额验收真实几何；其他配对保留原接触顺序。有限池保留少量不同重复凹件及非支配宽高方案。低于类矩形密度阈值的不同方向扣合也可按真实规划节省参与批量预留，但仍为不规则组合，不将空白当成材料。该改进没有新增job框架或改变默认35个策略的顺序。
