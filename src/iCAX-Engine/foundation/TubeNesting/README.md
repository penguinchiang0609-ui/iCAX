# TubeNesting

`TubeNesting` 是不依赖 CAD 内核和外部整数规划器的管材排样算法核心，可同时被
TubeDesigner 的生产排样与 TubeOne 的 CAM 编译使用。

算法把制造几何压缩为三类信息：兼容键、允许姿态、端部共边签名。几何识别、机床
可达性和碰撞判断留在上游；求解器只负责库存选择、零件顺序、姿态选择、间距、余料
以及多目标优化。

所有长度均为调用方定义的整数离散单位。当前建议使用 `0.01 mm`，以便让 UI、几何
容差和求解边界保持一致。

默认目标为严格字典序：材料成本、标准料根数、不可回收损耗、开料根数、可回收余料
段数、切割次数、订单切换次数。调用方可以调整目标次序，成本字段也可以表达余料的
机会成本。

求解分为两级：

1. 多起点最佳插入 + 姿态/顺序局部搜索 + 大邻域拆解重排，快速给出可用方案；
2. 对小规模兼容组做完整分支搜索，并在未触达节点上限时给出最优性标记。

首版按锯切建模。端面只有在相邻两端均允许且规范化签名完全相同时才能共用一刀，
此时轴向损耗为一条 `Kerf`；不共刀时损耗为“两条 `Kerf` + `PartGap` + 两端
`SeparationAllowance`”。最后一个零件也预留一次锯切的锯缝。没有显式姿态的普通
直切零件会自动获得 `saw.square` 姿态，因此默认就能连续共刀。冲孔等加工特征随零件
走，不进入首版库存组合模型。求解结果在进入 TubeOne 后仍需按真实排样位姿执行几何、
装夹、可达性和碰撞复核。

对不能严格表达为平面截断的端部，上游几何层可以生成一个“保料”的等效斜截面：在
截面局部坐标中拟合 `x = a*y + b*z + c`，再沿零件外侧平移拟合面，直到原制造几何
完全位于保留侧，并叠加加工余量。拟合斜率、截面绕轴姿态和进刀方向量化后形成
`Signature`；包络平移量和拟合残差折算为 `AxialLength` 或
`SeparationAllowance`。只有签名相同且误差在工艺阈值内的两端允许共刀，超阈值端面
退化为不共刀并给出人工复核诊断。这样得到的锯切毛坯可能多留料，但不会少料。

## 展开端部特征码

对于带孔、相贯或曲线端口的管材，几何层可把外表面沿周向展开为一条周期曲线，
再用 `EncodeCutLineFeature` 生成 `icax.tube-cutline.v1` 特征码。编码包含截面展开
周期、最小/最大/平均偏移、总变差、常值/线性参数或受限数量的均匀采样点，并生成
`ClassKey` 与 `Fingerprint` 供上层做候选分组；原始 BRep/DXF 仍由几何层保留，
不会被特征码替代。

相邻零件只在求解需要判断时调用 `EvaluateCutLineMatch`，按给定周向相位计算两条
端曲线的最大轴向差，结果就是该相邻关系的最小安全间距（负值表示允许套切）。
`FindBestCutLineMatch` 只在有限相位网格上搜索最佳相位。排样器不建立全量零件两两
成本矩阵：大订单沿当前开放母材和候选姿态即时计算，特征码仅用于快速分组与筛选；
没有特征码的零件继续走原有共刀/梯形保守算法。
