# 三维绘制零件：对标与实现范围

核对日期：2026-09-08。公开说明能确认功能存在，不能据此声称已覆盖所有竞品、版本或加工工艺。

## 对标依据

- [柏楚：绘制零件](https://www.bochu.com/tubest_help/tubest-绘制零件/)：先建立主管，再通过支管、V 槽和切割工具加工，保留特征供修改。
- [柏楚：主管](https://www.bochu.com/tubest_help/tubest-绘制零件-主管/)及官方特征树、支管定位配图：已实际查看图片，确认工具入口、资源树、分组参数与三维刀具定位的工作方式。维宏仅核对官方产品说明，未将未观看的视频作为交互验收依据。
- [柏楚：支管](https://www.bochu.com/tubest_help/tubest-绘制零件-支管/)：截面、姿态、位置、阵列和拉伸范围是核心；截面可来自 DXF 或绘图。
- [柏楚：V 槽](https://www.bochu.com/tubest_help/tubest-绘制零件-v槽/)：除了尖角，还区分圆角、左右 90° 与底部处理。不能将一个三角形裁剪等同于所有折弯槽工艺。
- [柏楚：智能绘图](https://www.bochu.com/tubest_help/tubest-绘制零件-智能绘图/)：主管、支管共享截面绘制思路。
- [维宏：WiseCAM Tube](https://www.weihong.com.cn/products/detail/35)：公开产品功能涵盖三维绘图、截面编辑等；不能据产品总览推定每一种支管/槽口细节。

## 本次实现

| 项目 | 本次范围 |
| --- | --- |
| 入口 | 下料 → 零件 → 三维绘制零件；已保存零件右侧“三维编辑” |
| 工作区 | 独立建模窗口；顶部工具栏、左侧特征树、中央三维视图、右侧参数；窄窗口保持三栏，参数区独立滚动 |
| 主管 | 进入页面即建立主管；可直接使用系统内置、模板自带、我的管型，或本地 DXF，截面参数实时更新，沿 X 轴拉伸 |
| 支管 | 新增默认选中可用圆管；与主管共用截面来源；轴夹角 0–180°、绕主管方位、截面自转、Y/Z 偏移 |
| 拉伸 | 自动贯穿主管，或给定长度的正向、反向、双向对称 |
| 相贯方式 | 填实外轮廓开相贯孔；也可用原截面实体裁剪（有内孔时会保留内孔） |
| 阵列 | X 向数量/间距 × Y、Z 或绕 X 轴圆周多排；两组独立设置正反方向，间距填正数，圆周使用角度；改变定位基准不改变所选 X 向方向。旧图纸有符号间距原位保留；每个零件最多 1000 个展开刀具，不等于排样数量上限 |
| V 槽 | 尖角、非对称、圆角、左侧圆弧、右侧圆弧、平底、释放孔七类；精确圆弧、独立左右角度、底部切除；参数按类型显示，附加槽底处理独立折叠 |
| 端部 | 斜切、凸/凹圆柱面等端形；页面不提供独立冲孔入口，相贯通过支管定义 |
| 编辑 | 进入页面即有主管；添加支管、V 槽或端部以及参数修改均实时写入当前图纸，特征树支持编辑、复制、删除、停用；撤销/重做负责回退，顶部“确定”仅在最后生成或保存零件 |
| 预览 | 仅显示主管和刀具，不切除主管、不判定断裂；合并连续修改、丢弃过期响应；只更新改变的资源，保留画布、相机和其他特征；局部进度条不遮挡整页 |
| 默认视图 | 正侧视、正交投影，主管横向占画布约 90%；短粗管兼顾纵向完整显示；后续编辑不覆盖用户调整的视角 |
| 保存 | 最后“确定”由 C++ 统一布尔计算并保存独立下料零件；保存主管、特征参数、固化刀具、毛坯与最终 BRep，支持继续三维编辑、排样和导出 |

## 几何与数据约定

- 模板位于产品安装级 `templates/_shared/punch-tools/`，新增刀具通过目录和描述文件接入。
- C++ 共用实体构造与布尔能力；三维绘制独立使用 `GetPartDrawingTools`、`PreviewPartDrawing`、`AddPartDrawing`、`ApplyPartDrawing`，不转发到冲孔业务消息。前端模型、参数、控制、预览与局部更新各有专用模块。
- 新记录保存在 `tubeDesigner.partDrawing`；读取兼容旧 `tubeDesigner.punchWizard.drawing`，显式保存后迁移，不自动改写用户工程。
- 三维刀具声明 `target: part`，由 Python 输出 `coordinateSpace: part` 的自包含中性实体。几何任务使用现有 Task 调度；资源提交仍在宿主线程。
- 主管轴为 +X；主管截面原 X/Y 分别映射到零件 Y/Z。DXF 导入沿用现有精确轮廓解析及毫米归一化。
- 支管轴夹角从 +X 计量；方位 0° 指向 +Z、90° 指向 +Y。定位距原始主管起点、终点或中心，不随端部裁剪漂移。
- 编辑预览只构造并摆放刀具，主管外的刀具同样显示，不作材料相交检查。最终确定时才做布尔运算；接受合法非空多实体，不因切断而禁止建模，空结果或无效实体才拒绝保存。
- 填实外轮廓与保留内孔的支管截面按用户所选参与切除，不自动猜测保留哪一段实体。
- 截面快照随图纸保存，本地 DXF 不强制进入“我的管型”，没有对源文件或管型库的写入。
- 缺少主管/支管源管型仍可使用图纸快照。缺少准确版本刀具时，节点退化为定式且只允许删除；保留这些节点时锁定主管截面及长度，重放保存的实际裁剪体。
- 数字 JSON 表达由 `1.0` 变为 `1` 不算主管修改；跨语言 JSON 精确解析浮点数，避免旋转系数变化导致固化表达校验误报。

## 尚不能宣称已经覆盖的行业功能

- 柏楚特定的左/右 90° 折弯槽，涉及外侧圆角/内侧直角和折弯补偿，不能以旋转通用 V 槽冒充。
- 折弯展开补偿、材料/模具回弹、复杂根部工艺释放形状与微连接，需要真实样件与加工验证。
- 直接在该三维窗内画截面、拾取面/两点定位、拖拽支管操纵柄：本次未实现。当前复用管型库截面编辑，再从库选择，或直接导入 DXF。
- 这里保存一个主管经特征加工得到的零件（可包含多个有效实体），不是多零件焊接装配设计器。

这些属于后续能力缺口，不计作本次已完成项；本次交付的是主管/支管/模板刀具共用的可编辑建模链路。

## 回归入口

- `TubeDesignerPartDrawingTest.mjs`：默认主管与默认选中、截面来源、取消导入、实时创建/编辑、相邻节点选中、主管不可删除、撤销/重做、缺失刀具锁定、异步预览旧结果抑制。
- `TubeDesignerPartDrawing.browser.mjs`：1600、1024、780 宽度的独立浏览器布局；真实 Three 视口加载测试网格，验证稳定画布、相机、未修改主管/支管资源和七种 V 槽参数。界面夹具几何不冒充原生布尔结果。
- `TubeDesignerPartDrawingModelTest.mjs`、`TubeDesignerPartDrawingPreviewTest.mjs`、`TubeDesignerPartDrawingParametersTest.mjs`：独立数据模型、资源复用与过期响应、局部错误重试、条件参数及数值约束。
- `TubeDesignerPartDrawingNative.browser.mjs`：生产界面连真实原生接口及资源，验证默认支管、只改当前刀具、最终生成、`.ictd` 保存重开再编辑；GPU 投影坐标验证初始和重开均为正侧视、横向占宽 90%。
- `PunchToolRuntimeTests.py`：模板注册、固化/降级、只读保护、V 槽精确圆弧。
- `TubeDesignerTest` 的三维绘制相关用例：原生只摆放预览、最终布尔、多实体保存、管型库与 DXF、中性表达和 `.ictd` 保存重放；冲孔的连通性限制独立测试，不用于三维绘制。
- 扩展回归覆盖中性模型编解码、变换、枚举整数精度与原有防盗窗模板生成；同时修复测量凸包排序将容差混入比较器导致的 `invalid comparator`，容差仍用于几何去重及凸包判定。
