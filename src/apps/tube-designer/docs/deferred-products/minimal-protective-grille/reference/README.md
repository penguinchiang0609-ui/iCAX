# 极简防护网当前模板格式

版本 1.2.1，保留 66 个宿主物理参数。此次更新只整理声明和显示布局，未调整内横杆、边框、接头或安装孔的几何规则。

`template.json` 保留默认值、枚举、约束、显示条件和资源角色；`display.json` 单独规定右栏的边框、内横杆、把手禁区、安装分组，以及字段顺序、宽度和现有轴尺寸标注的外观。条件统一由 `parameterConditions.mjs` 解释。

结构入口映射到原字段：边框结构对应 `frameType`，内杆排布对应 `barLayoutMode`，把手禁区对应 `handleEnabled`。边框连接做法对应 `frameCornerJoint`，仍只在封闭边框且使用内置规则时出现。组合控件属于显示声明，不写入产品参数；关闭把手禁区或切换排布模式保留不适用子字段的草稿值。

场景绑定使用生成器实际的 `frame.*` 和 `inner.bar.*` 成员键；两种管材的角色包含各自圆角字段。成品宽高沿用既有 X/Z 轴尺寸声明，没有增加未提供的几何锚点。资源中的示意图仍是结构参考图，不能把它当作每个参数实时重绘的几何证据。

生成器仍要求中空矩形管，并使用实际管壁及内横杆接头尺寸校验。模板没有新增其他管型选择或承载认定。原生预览、产品拆单及真实浏览器交互需要分别验收，静态声明检查不能代替它们。

原生验收另修正了封闭框上边毛坯与设计来源区间的轴向对应：加工上边和已有设计上边均从右向左声明，参数、实际边框范围及已认可的斜拼／平口几何保持不变。
