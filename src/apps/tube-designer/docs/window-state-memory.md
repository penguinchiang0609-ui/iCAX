# 窗体输入记忆

窗体采用固定的窗口标识、字段标识和作用域保存最近一次编辑值，打开时再通过原有表单逻辑恢复。共享实现位于 `iCAX-UI/SDK/Forms/windowStateMemory.mjs`，不保存整段 DOM，也不依赖控件位置或列表下标。

记忆范围由每个页面自己声明，公共层不自动保存全部控件。页面在窗体或表单区域用 `data-window-state-controls` 指定 CSS 选择器，或给单个控件声明 `data-window-state-field`。例如 `data-window-state-controls="[data-directory],[data-scan-interval]"` 只记目录和扫描间隔。空选择器关闭该区域的记忆；适配器也可用 `controlSelector:false` 关闭整个窗体。未声明的控件保留页面原有默认值。

已选择的输入框、数字、开关、单选和下拉选择由委托事件统一记录；取消或关闭也保留最近输入。存储使用宿主的持久化浏览器数据目录中的 localStorage，重启后仍可读取。SDK 的 Bridge 单独按打开文件、保存文件、选择目录操作记录最近目录；明确指定的实体文件路径仍由调用方决定。调用方可用 `memoryKey` 指定操作身份，传 `memoryKey:false` 则关闭这次选择器的目录记忆，不读取或写入记忆值。

TubeDesigner 在 `webpage/windowStateMemory.mjs` 接入页面声明的窗口和侧栏控件。模板、管型、项目、产品、零件和特征使用各自的作用域。产品添加、Excel 列配置和新建配件使用各页面的字段投影保存草稿；不复制资源目录或生成几何。STEP 浏览窗口只记目录和仍存在的选中文件，只启动预览。资源库的卡片、来源和筛选通过 `libraryNavigationMemory.mjs` 的导航字段白名单恢复。新项目窗体在 AppShell 层只记名称和路径。

新增普通窗体应声明 `data-window-state-key`，再声明需要记忆的控件范围。已有语义 ID、name 和数据绑定标识用于已选控件的稳定字段身份，本身不代表同意记忆。需要区分对象时提供 `scope`，异步加载期间返回 `ready:false`，模型替换时改变 `owner`。模型拥有的复杂窗体使用共享存储 API，只投影页面明确选择的字段，在渲染前交换草稿，并通过 `data-window-state-ignore` 排除重复的 DOM 恢复。

恢复值只同步当前表单与预览，不自动执行生成、导入、导出、保存或删除。无效下拉选项、不可编辑控件、密码和文件输入不会恢复。联动选择保存最终叶项状态，主复选框从子项计算；普通刷新不会再次套用旧值，异步响应也不能覆盖用户后续输入、焦点、选区和滚动位置。

验收覆盖公共 SDK、AppShell、生产设置窗体、STEP 浏览、产品添加和 Excel 草稿以及资源库导航。浏览器测试使用实际渲染器和操作处理器，原生数据传输使用明确的受控夹具；磁盘持久化测试关闭浏览器进程后，以同一实际用户数据目录重新启动，不通过注入 storageState 模拟重启。
