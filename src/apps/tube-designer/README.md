# TubeDesigner

TubeDesigner 是 iCAX 上的管材产品参数化设计与制造拆单产品。

它负责回答“产品是什么、由哪些装配构件组成、最终拆成哪些制造零件”；TubeOne 负责回答“制造零件如何排样、编程和加工”。两者共享 iCAX 的 Project、Scene、Entity-Component、Resource、View 和 OpenCascade 能力，但保持独立产品边界。

## 当前范围

- 产品 ID：`icax.tube-designer`
- 工程扩展名：`.tubedesigner`
- 模板注册：正式 Python 模板包括 `single-face-security-window@2.5.0`、`two-face-security-window@1.6.0`、`three-face-security-window@1.5.0` 和 `five-face-security-window@2.5.0`；原 `security-window-1/2/3@1.0.0` 继续保留兼容
- 多面结构：两面为 L 形，三面由左侧、正面和右侧组成，五面在三面基础上增加上面和下面，形成背面敞开的箱式结构；相邻面共享转角立柱
- 装配开孔：多面模板按真实杆件相交关系给外框立柱、上下横梁及五面后梁生成减料孔，内部圆管穿过矩形横杆
- 截面：外框和横杆为矩形空心管，竖杆为圆形空心管
- 输入：界面手工参数
- 流程：添加产品实例并设置参数 → 生成装配预览 → 选择一个或多个实例拆单 → 在母子表格中逐件选择 → 选择导出总目录 → 按产品子目录导出选中 STEP
- 输出：装配预览、显式连接意图、分层制造零件清单、选中零件 STEP 与 Excel 零件清单
- 默认 1 号案例：两根外框、一根中间竖管、四根横管，共七个预览构件/制造零件
- 默认 3 号案例：一根连续折弯外框、一根中间竖管、四根横管，共六个构件/制造零件；预览显示折弯后的闭合框，拆单输出带四处 90° V 槽的展开直管

3 号兼容模板同时支持尖角、圆角、左圆弧、右圆弧 V 槽，以及斜切公母、底部切除、释放孔、壁厚过切附加工艺；也可切换为四根外框的 45° 斜拼或 90° 直拼。Excel 批量订单解析、安装孔、吊装孔和直接送入 TubeOne 属于后续阶段。

“生成预览”和“拆单”是两个独立数据库命令。预览只创建装配构件与渲染资源，并通过装配 Transform 将二维设计平面竖立到世界 XZ 平面；拆单根据已提交的模板版本和参数快照创建制造实体、制造 BRep 及缩略图 Mesh。撤销拆单不触发三维 View 等待，只有预览资源引用、版本或姿态变化才同步新的 View revision。

拆单结果会作为制造领域数据保存在工程中，但不维护独立的“是否已拆单”布尔状态。界面只在产品实例当前 `GenerationRunID` 下存在数量完整的制造零件集时显示“已拆单”；修改参数并确认重新生成后，实例切换到新生成批次，因此自然回到“未拆单”。拆单表按“产品 → 零件种类 → 具体零件”分层折叠；点击具体零件名称会打开仅包含该零件的三维复尺窗口，可通过表面两点拾取查看空间距离和 X/Y/Z 分量。

## 领域边界

- `CProductInstanceComponent`：模板实例与参数快照。
- `CAssemblyMemberComponent`：装配语义、位置和预览几何。
- `CManufacturingPartComponent`：实际下料对象与制造几何。
- `CJointIntentComponent`：目标构件、插入构件、连接模式和间隙。
- `CGenerationRunComponent`：一次可追踪的模板求值结果。

装配构件和制造零件使用不同实体与不同几何资源，避免在 V 槽折弯、拼焊、合并下料等场景中错误假设两者始终一一对应。
