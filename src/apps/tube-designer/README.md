# TubeDesigner

TubeDesigner 是 iCAX 上的管材产品参数化设计、制造拆单与排样准备产品。

它按使用频率组织为“产品 → 下料 → 管型 → 配件库 → 草图 → 关于”。产品完成设计后点击“导入下料”，软件自动完成拆单、复制独立下料零件并切换到下料页；下料页左侧提供独立零件清单，中间显示真实三维几何，右侧说明当前选择，下方承载原材排样结果，并可导出零件清单，未来也支持直接导入 STEP 零件。配件库用于管理可复用的真实三维配件和自制/外购信息。草图模块目前只负责管型截面轮廓的绘制和修改，截面草图保存为“我的管型”；零件侧面包覆图形留待零件页实现。TubeOne 继续负责加工编程与机床执行准备。

## 产品分类、独立模板与板件（新增能力）

当前保留 9 个独立产品模板，其中 6 个供产品目录使用、3 个保留为装配验证模板；另外有 21 个管型模板、24 个模具模板和 22 个装配模板。只有成功加载且声明公开的产品模板才显示。产品按模板声明的分类组织：

| 一级分类 | 目录入口 | 当前构成 |
| --- | ---: | --- |
| 窗 | 1 | 防盗窗 |
| 护栏 | 4 | 竖杆、X 形、菱形、挡板护栏 |
| 楼梯 | 1 | 钢楼梯，梯段布置由同一模板参数控制 |
| 验证用框架 | 不公开 | L＋T 框架、十字贯穿、三向直角验证件，共 3 个 |

百叶窗、普通铝合金窗、雕花装饰门和极简防护网已退出活动模板目录及运行包，当前规格、实现限制、181 项参数和源码快照见 [暂缓产品实现档案](docs/deferred-products/index.md)。归档快照只供参考，不参与模板发现或部署。

四款护栏各有自己的模板目录、模板 ID、版本和 `.itpt` 导出单元；直式、L 形、U 形等布置由对应模板的参数控制。目录卡片直接对应真实模板，选择后可继续修改尺寸，重复点击当前卡片不清空输入，编辑已有实例也不会重新套用另一款。防盗窗按各管材角色限制矩形管或圆管，四款护栏只接受矩形管和圆管；管型库中的其他截面不会因此自动适用于这些产品。缩略图由本项目代码生成。

所有产品的管型选择只提供“系统内置”和“我的”，下拉框仅列出该构件声明支持的截面，不另列支持类型说明。管型库的完整参数用于资源管理；产品只显示自身声明的有限尺寸，通过 `resourceRoles.profiles` 中的 `parameterBindingsBySectionKind` 映射到管型求值输入。`managedParameters` 指定由该编辑器承载的产品字段，避免重复显示；`defaultResourcesBySectionKind` 指定初始系统资源。选用管型后保存真实求值截面快照，修改产品内的截面尺寸时先重新求值，再写入实例。产品尺寸不提供管型示意图入口或浮窗。简短字段标签由各构件的 `parameterLabelsBySectionKind` 声明，部件名由分组表达，毫米单位在截面尺寸标题集中显示；完整管型参数和示意图留在管型库中管理。产品不提供模板自带管型来源、自由填写的金属材质牌号或管型库的偏心、独立圆角等管理字段。

护栏扶手端部从端柱外侧计算起止延伸量，默认各伸出 30 mm；设置为 0 时齐柱外侧。结构在创建时指定，创建后固定；产品尺寸与布局数值（分跨数量、首末偏移等）通过场景标注修改。安装板尺寸也由场景标注编辑，右侧保留用料和装配方式；修改用料、管型或截面参数会使场景模型过期，重新生成后才能拆单，只有装配工艺修改仅使零件清单过期。楼梯、护栏和窗共用上述产品参数与资源绑定机制，部件支持范围和有限尺寸由各模板声明。钢楼梯的添加示意图由模板声明的条件图层绘制，随梯梁、踏步支撑等结构选择联动。

四款护栏的“立柱底部安装”在添加对话框的“立柱”组中指定，创建后固定。直接落地、底板与侧装板会改变结构构件和立柱位置，不能作为创建后的装配选项；底板与侧装板的尺寸、偏移仍通过场景标注修改。该边界由模板 `creationOnly` 声明，前端和原生更新／重新生成接口共同校验，装配常用方案也不包含安装结构选择。

花格是实际直管零件：每跨 X 形采用一根主斜杆和两根分段斜杆，菱形采用四根切角斜杆，生产图保留真实裁切和斜切元数据；不是把两根未加工的管子直接互穿。围墙款竖杆穿出扶手，制造图在扶手/上横档生成对应型孔，显示请求省略内部型孔。主防护框架高度不包含向上伸出的竖杆、枪尖或柱帽。X 形、菱形、围墙枪尖等装饰做法不自动满足阳台或儿童场所的防攀爬、开口和结构要求。

板件是具有厚度的真实实体，不是显示贴图或伪装成管材。单面防盗窗可配置封板净宽、净高、板厚及相对可用区中心的水平/垂直偏移；启用开启口时封板位于窗扇内，否则位于主格栅内。封板带独立管框，相交格栅杆件分段。组合护栏支持板填充及可选带孔安装底板；板尺寸、厚度、材料等属性随制造零件保留。

板件随产品进入装配预览和拆单，纳入零件清单及 STEP / Excel 导出，并按板件显示宽、高、厚等信息。玻璃栏板是单独的 `glass` 外购项，与金属板区分；厚度和材质说明只是采购/几何参数，不等于夹层构造或安全认证。玻璃夹、柱帽、枪尖等以真实配件模型参与装配和清单。前后端均将板件、玻璃和普通配件排除在管材排样之外；**当前不包含板材二维排样、玻璃排版或配件自动 CAM**。

组合护栏在生成几何前限制管材、板件及配件合计不超过 2000 件；密集或很长的护栏应分段建模。U 型回转距离会检查截面和底板占用；内置固定尺寸配件会检查部分已知安装冲突。导入模型仍需人工核对实际连接面和尺寸，系统不会通过非均匀缩放伪造适配。

钢楼梯模板的护栏竖杆按柱间净空布置，按截面实际朝向计算净间距；手动竖杆总数分配到各跨，实际最大净间距超过设定值时给出提示。这是几何布置能力，不代表完成全部连接工艺或结构安全认证。

以上为当前类型与流程，不代表覆盖参考网站的全部产品、参数和制造工艺；也不包含板材二维套料或完整第三方 CAM 功能。

## 配件库与模板资源

产品模板通过“资源库 → 产品模板”菜单管理。每个 `.itpt` 只代表一个产品模板，文件本质是使用产品 magic number（`ICAX_TUBE_DESIGNER`）固定密码保护的 ZIP 压缩包，至少包含 `template.json`（模板描述）和 `template.py`（参数化生成脚本），也可以携带该模板自己的图片、模型或其他资源文件。不同款式必须分别导出为不同的 `.itpt`，不能在一个包里再嵌套多款。内置模板只读；个人模板可以新增、导入、导出和删除。导入时会校验扩展名、密码、压缩包路径、成员数量及大小，并拒绝带目录穿越路径或缺少必要文件的包。导入成功后立即将包解开到 `%LOCALAPPDATA%/iCAX/icax.tube-designer/template/product/<id>`，用户数据记录只保存索引和描述信息；程序启动时直接枚举已解开的模板目录，不重复解压 `.itpt`。

管型程式模板使用同一规则的 `.ittt` 加密 ZIP（一个包对应一个 `profile.json` + `profile.py`，可带该管型自己的资源），程式模具使用 `.itmt` 加密 ZIP（一个包对应一个 `tool.json` + `tool.py`，可带该模具自己的资源）；两者都由产品固定 magic number 自动校验密码。定式管型和定式模具保留为本地 DXF/截面定义，不伪装成可变参数程式。三类资源的脚本和描述都在资源库之外统一校验，业务入口只保存资源引用。

“我的配件库”支持直接绘制 CSG 配件，也支持导入 `.step`、`.stp`、`.brep` 实体文件，并保存名称、分类、材料、说明以及 `made`（自制）/`purchased`（外购）。绘制时配件库页面切换为独立零件编辑模式：左侧是由基础体叶子和并集、差集、交集运算节点组成的 CSG 结构树，中间是真实三维视口，右侧编辑当前节点参数。拉伸体的截面可以选“程式截面”或“定式截面”：程式截面包含实心矩形、实心圆、圆环、L 形等基础实体，也可直接使用管型库里的矩形管、圆管、角钢、槽钢等参数包，尺寸参数改变后重新求值；定式截面可来自 DXF 或内置二维草图，原始直线、圆弧和样条轮廓随拉伸节点嵌入 CSG。添加、移动、截面修改和布尔操作只修改当前零件会话，不会逐步创建“我的配件”记录；只有点击“完成并保存零件”才写入或更新一条记录。尺寸、位置、旋转、缩放或布尔类型变化后会由 OpenCascade 重新计算实体，并叠加显示当前基础体。记录保留经过校验的 `icax.component-csg@1` 操作树作为可二次编辑的源数据，同时生成冻结 BRep 供预览、装配和 STEP 导出。导入模型按模型包络将 XY 中心移到原点、Z 底面移到 0，保留原朝向；以毫米参与装配，BREP 原文件的单位和源尺寸应由用户确认。引用的是库内冻结的真实 BRep，不持续依赖原文件路径。

模板可引用四个来源：`system:<模型ID>`、`user:<模型ID>`、`library:<记录ID>`、`template:<资源名>`。当前系统示例包含 80/40 方柱平盖、20 管枪尖、8 mm 玻璃夹和双孔连接块。模板可以携带 STEP/BREP，或像内置示例一样携带完整 `.icaxmodel.json` 几何表达；普通用户导入入口只接受 STEP/STP/BREP。

资源文件解析和快照冻结属于 TubeDesigner 产品层；通用几何求解器只收到已解析的 BRep，不读取模板中的任意文件路径。生成产品时保存使用的配件快照；以后修改或删除库记录，不应悄悄改变该产品拆单所用的旧配件。声明格式、刚体放置、制造元数据及模型目录规范见 [配件模型契约](templates/accessory/README.md)。

标记为自制不表示能自动管材下料或自动编程。只有有明确管型、直管毛坯及实际加工几何的管件进入管材排样；导入的装饰弯花、铸件或其他复杂 STEP 仍是配件。软件不会仅根据外形猜测弯管工艺、展开长度、模具或机床可加工性。

## 当前范围

- 产品 ID：`icax.tube-designer`
- 工程扩展名：`.ictd`
- 模板发现：运行时自动发现 `templates/product/<id>/template.json + template.py`，每个目录就是一个独立 `.itpt` 模板资源；管型、模具、配件分别位于 `templates/profile/<id>`、`templates/mold/<id>`、`templates/accessory/<id>`，新增资源不再修改 C++ 注册表
- 模板来源分为两层但结构完全一致：安装目录中的 `apps/tube-designer/templates/{product,profile,mold,accessory}` 是系统内置只读资源；用户资源位于 `%LOCALAPPDATA%/iCAX/icax.tube-designer/template/{product,profile,mold,accessory}`。用户资源跟随系统用户数据目录，重装程序不会删除。
- 管型边界：产品的 `template.json` 选择管型；`templates/profile/<id>/profile.json` 描述管型参数，`profile.py` 校验参数并一次生成 `[外轮廓, 内轮廓…]`。C++ 只按轮廓数组构造带孔二维截面并执行一次标准拉伸，把 `tubeDesigner.profile` 作为不透明模板数据传递
- 内置管型包：`rect` 与 `round` 已从各产品脚本迁移为独立管型包；新增标准等截面管型时，增加同结构目录并在目标产品 `template.json` 的选项中引用其 ID，无需修改 C++
- 活动 Python 产品模板共有 9 个，其中公开产品 6 个、装配验证模板 3 个；每个模板都有自己的 ID、版本和 `.itpt` 导出单元。防盗窗面数与钢楼梯梯段布置采用各自模板的参数。
- 四款护栏（竖杆、X 形、菱形、玻璃）使用独立 `display.json` 声明右栏布局，按实际构件组织“用料／装配”。扶手连续方式、大立柱布置、横档数量及竖杆款的填充方向在添加时选择，创建后固定；尺寸和布局数值通过场景标注修改。组合控件仅映射现有物理参数，不写入项目参数。管材圆角与对应构件的场景联动保持一致，固定填充款保留各自声明的构造。
- 钢楼梯也使用独立 `display.json`，结构在添加时选择，创建后右栏按实际构件组织“用料／装配”，尺寸和布局通过场景标注修改。三个装配验证模板采用同样的构件布局，保留固定拓扑和隐藏目录属性；不添加商业产品入口或不存在的结构选项。各款具体参数与场景角色见其模板目录 README。极简防护网已从当前目录移除。
- 防盗窗尺寸、开启口、装配规则、公开资料与尚未验证的连续折弯构造，见 [防盗窗模板依据](templates/SECURITY_WINDOWS.md)。默认样例及几何测试通过不构成安装安全认证。
- 楼梯行业：钢楼梯模板统一声明直跑、L 形双跑和 U 形双跑布置，生成梯段边梁、逐级踏步横梁、休息平台骨架、扶手和立柱，并进入统一拆单与 STEP/Excel 导出流程
- 楼梯常用默认值：层高 3000mm、总级数 18、踏步宽度 260mm、梯段净宽 1100mm、休息平台长度 1200mm、护栏高度 950mm；模板会对踏步高度大于 175mm 或踏步宽度小于 260mm 的住宅常用尺寸给出提示
- 多面结构：两面为 L 形，三面由左侧、正面和右侧组成，五面在三面基础上增加上面和下面，形成背面敞开的箱式结构；相邻面共享转角立柱
- 制造开孔：多面模板按真实杆件相交关系给外框立柱、上下横梁及五面后梁生成减料孔，内部圆管穿过矩形横杆；这些布尔加工仅属于生产输出，装配显示不做布尔运算
- 截面：外框和横杆为矩形空心管，竖杆为圆形空心管
- 输入：界面手工参数，或软件导出的 `.xlsx` 产品批量模板
- 草图：仅绘制和修改管型截面轮廓；截面未形成闭合轮廓时不生成三维预览，零件侧面切割图由后续零件页承载
- 用户常用参数：产品 manifest 以 `template/parameter-preset/template-definition` 声明这种用户记录；具体模板 ID 作为 Subject，客户通过 `customer` 显式关系关联，不藏在 Payload 中。模板内置方案与“我的常用方案”在同一选择框中使用；保存时排除产品编号、主宽高等实例专属数据，模板升级后只应用当前版本仍存在的参数
- 基础版流程：定义管型 → 添加产品实例并生成装配预览 → 导入下料 → 在下料页零件清单中复尺 → 导出零件清单给第三方 CAM
- 高阶版流程：产品导入下料 → 在下料页按截面归集零件 → 设置母材与零件间距 → 开始排样 → 导出所选或所有母材结果；“下料”使用独立商业授权 `tube-designer.production-workflow`
- 输出：装配预览、显式连接意图、分层制造零件清单、选中零件 STEP 与 Excel 零件清单；排样导出为每根母材一个真实零件装配 STEP，以及汇总的 Excel 下料清单。
任意外部订单表的自动识别、安装孔和吊装孔属于后续阶段。

### Excel 模板与文件往返

“Excel”入口可为当前公开产品导出批量模板。选择参数列、中文列名、必填项和默认值后生成 `.xlsx`，实例名称及生产数量随每行填写；枚举参数提供中文下拉选项。选择填写好的文件后直接导入，每一行创建一个独立产品实例，不再显示批量创建确认框。空白参数按模板中的默认值处理，非法数值、枚举、数量、缺列及过期模板会给出错误提示，提示行号对应 Excel 实际行号。

若创建过程中某一行失败，已成功创建的实例保留并立即显示，日志记录失败的 Excel 行号与已创建数量。在当前会话中再次选择同一路径、内容未变的工作簿，会继续创建剩余行，避免重复创建前序实例；工作簿内容改变则开始新的导入。

TubeDesigner 的普通操作结果统一写入日志栏，不在场景上叠加成功通知。模型正常时不显示常驻状态条；尺寸、布局或用料改变而确实需要重新生成时才显示重新生成入口。该通知策略通过共享工作台的 `noticePresentation` 声明，不在产品或参数分支中分别处理。

下料页导出的 Excel 零件清单与 STEP 文件对应，包含零件数量、尺寸、材料、供料方式、加工方式及文件路径。批量产品导入读取模板内置列定义，零件清单用于查看和加工交接。未完成装配配合验证的产品仍按原规则限制生产导出，明确选择草稿导出时才生成草稿文件。

母材与排样参数随项目保存，可撤销。每种零件截面初始母材长为 6000 mm，数量 -1 表示不限量，0 表示停用，正整数表示有限库存。用户可追加不同长度；有限库存先参与排样，剩余零件再使用不限量母材。当前仅提供零件间距参数，按最终制造几何的轴向包络保守锯切排样，不启用共边切割。

“生成预览”和“导入下料”是两个独立命令。预览只创建装配构件与渲染资源，并通过装配 Transform 将二维设计平面竖立到世界 XZ 平面；导入下料先根据已提交的模板版本和参数快照生成当前会话的临时制造结果，再把全部制造零件复制为独立下料零件并切换页面；其中管材参与排样，板件和配件保留在清单中供复尺与导出。产品页临时结果不写入项目实体；只有独立下料副本随项目保存。撤销生成不触发三维 View 等待，只有预览资源引用、版本或姿态变化才同步新的 View revision。

拆单结果不作为产品页的制造零件实体保存在工程中。每次导入下料都依据当前产品的生成快照重新计算，随后复制成独立下料零件并切换到下料页；下料页的零件清单支持选择、复尺、修改和导出。此后下料区与原产品实例互不关联，未来导入的 STEP 零件也使用同一独立数据结构。

## 领域边界

### 模板声明的基础拉伸体共享

防盗窗模板通过 `_shared/shared_tube_geometry.py` 在每次模板生成内部显式声明共享的基础截面及拉伸体。完整局部截面参数一致时共用 `profile2d` 节点；完整局部拉伸参数也一致时共用 `extrude` 节点。每根管子仍保留自己的稳定零件编号，并使用 `transform` 节点引用基础体、指定独立的位置和朝向。

共享仅适用于模板明确选择的裸管，孔刀具、钻孔、槽口和斜切仍按各零件独立定义。求解器不根据零件名称、材料、近似尺寸或外形自行合并；不同长度不会共用同一个完整拉伸体，非对称截面也不通过镜像冒充一致。布尔运算采用非破坏模式，不能修改其他实例所引用的基础体。

产品请求必须在 `context.geometryPurpose` 中明确显示或生产。显示脚本返回公共显示模型 v2，拥有构件与共享设计几何；生产脚本独立返回制造声明 v4，包含连接与工艺。宿主将制造声明和已保存的设计一起交给当前制造执行器，得到只供内部求解的单用途中性模型。防盗窗显示请求不构造孔刀具、布尔或展开槽口节点，制造执行才构造完整加工操作。原生求解器执行收到的节点，不凭显示用途跳过布尔。

防盗窗默认、连接工艺和证据边界见 [模板说明](templates/SECURITY_WINDOWS.md)。单面默认四边框分料拼焊，多面可选择通长立柱直拼或上下框45°拼角，并分别设置正面/侧面格栅。横杆固定采用插入边框后焊接，入榫深度会改变真实杆长与开孔。显示仍为原管装配近似，斜切毛坯转角可能重叠；生产图才是含实际切角的零件，不把预览或模板校验标为安装合格证明。

生成产品时保存显示设计与宿主拥有的模板身份、规范化参数快照；导入下料时，用该快照请求制造声明并生成临时 BRep。若磁盘模板版本或包摘要已经变化，必须重新生成。导入下料会把临时 BRep 复制成独立持久化资源。`tubeDesigner.manufacturingPartCount` 由当前制造执行结果确定，预览不提前生成生产几何。产品脚本不返回模板身份或输入参数；公共显示模型和制造声明分别遵守当前 v2 与 v4 协议。

共享范围是一次求解内，不引入显示与生产之间、不同产品之间或不同生成批次之间的几何结果缓存。同一次求解中多个实例引用的基础节点只计算一次。临时拆单资源只在当前会话使用；独立下料副本拥有自己的资源和生命周期，不会回写产品实例。更新模板和原生求解器必须配套部署。

### 领域组件

- `CProductInstanceComponent`：模板实例与参数快照。
- `CAssemblyMemberComponent`：装配语义、位置、预览几何及不透明模板属性，不定义具体管型字段。
- `CManufacturingPartComponent`：实际下料对象、制造几何及不透明模板属性，不解释具体管型。
- `CJointIntentComponent`：目标构件、插入构件、连接模式和间隙。
- `CGenerationRunComponent`：一次可追踪的模板求值结果；保存生成时的显示设计和宿主输入快照，制造声明按需请求，不把拆单零件写入该组件。

装配构件和制造零件使用不同实体与不同几何资源，避免在 V 槽折弯、拼焊、合并下料等场景中错误假设两者始终一一对应。

### 排样分组与导出

排样适配层按规格键独立求解，各组使用 foundation Task 的专用线程池，默认按硬件限制最多 8 路并发；
单组内的有限库存优先、补充不限量母材、斜切姿态及搜索预算不变。输入校验在启动任务前完成，
工作任务不访问场景或资源池，所有任务结束后按原规格顺序汇总方案、编号、未排原因和统计。
四参数 `SolveManufacturingNesting(..., maximumConcurrency)` 可设为 1 作串行对照，原三参数入口默认启用分组并行。

排样数量上限与原生求解器一致为 1000000 件；2000 仅限制一次请求中的零件规格行数，1000 仍限制母材规格行数，不是生产件数量额度。

下料结果按规格折叠分组，支持组内全选及“导出本组”。分组依据 `profileKey`，不会把显示名称相同的不同规格混在一起。
每次导出新建独立目录，内含总清单 `nesting-list.xlsx`；每个规格子目录包含该组 STEP 和组内清单。
总清单的 STEP 列记录相对子目录路径；目录名称清理非法字符并加序号，避免同名冲突或路径越界，已有输出不覆盖。

回归：`TubeDesignerNesting.*`、`TubeDesignerNestingExport.*`、`NestingExportTest.mjs`。
按需性能对照：`TubeDesignerTest.exe --gtest_filter=TubeDesignerNesting.DISABLED_ProfileGroupParallelBenchmark --gtest_also_run_disabled_tests`。
并行度不等于加速比，小分组的调度和内存分配开销可能抵消收益，应以实际输入和构建模式测量。

### 图纸保存边界

实例具有独立的生产数量（默认 1，正整数，最多 1000000）。制造零件保留单套数量，产品清单及 STEP 配套清单中的数量为单套数量乘实例数量，不通过复制显示模型实现。实例导出子目录采用 `实例名称--XX--数量`；同名实例在该保留后缀前追加标识以避免重名。

“导入下料”是显式复制生产快照：创建独立零件实体、独立加工 BRep 资源和批次标识，并冻结当时的生产数量及规格。原实例的修改、数量调整、重新生成或删除均不影响已有下料副本；下料区“删除所选”只删除副本，支持撤销。再次导入下料会追加新的生产批次，不覆盖已有零件。下料与产品分别保存勾选状态。

下料 → 零件 → “添加标准零件”支持从系统和我的管型中选取截面（不列出模板自带管型），或直接导入本地 DXF 截面。程式管型可以修改本次截面参数并预览，定式管型保留原始轮廓；输入长度后生成数量为 1 的独立直管零件，数量可在清单中调整。参数修改和 DXF 导入只保留在弹窗草稿内，确认时才调用 `TubeDesigner.AddNestingStandardPart` 创建真实拉伸 BRep、保存截面与参数快照、更新下料任务并清除旧排样结果；不修改管型库，也不要求创建产品实例。创建支持撤销，零件随项目保存。

程式管型在管型库、添加标准零件、CSG 拉伸截面和三维绘制主管/支管中提供参数示意图；冲孔向导的主管、支管和端面示意图使用共享浮窗。尺寸线、引线编号和中文影响说明与输入框双向定位：聚焦/悬停参数高亮对应标注，点击图中编号或说明定位输入框。示意图使用同一份已求值真实截面与参数快照，修改后随截面更新；未成功求值时不会把新数值标在旧几何上。10 种内置程式管型已提供全部参数标注，CSG 的实心矩形、圆、圆环、L 形也提供标注。自定义复杂管型可在包内声明专属锚点与说明，见 [参数示意图协议](templates/profile/PARAMETER-DIAGRAM.md)；包内未声明标注时保留轮廓和参数说明并明确提示缺少位置标注，不依据参数名称猜测几何含义。示意数据随截面快照保存，定式 DXF 不伪装为可编辑程式参数。

### 冲孔向导：布孔、端切与复查

进入向导先显示完整主管；可以零侧孔创建直管或只加工两端。主管的显示中心固定在原点，场景保留 ViewCube。编辑期间仅显示主管与刀具体，`PreviewPunchWizard` 默认不对主管进行布尔、相交或分段检查；不存在中间“切割结果”模式。只有最终创建或应用时进行实体切除，若冲孔结果为多段则报告实际段数并保留草稿供修改。

- 表单在上、三维场景在下，主管、端面、冲孔和场景分别占独立区域。三个分隔条支持鼠标拖拽与键盘调整，限制最小高度；区域内容溢出时各自滚动。主管尺寸按管型模板的分组、顺序、整行声明和控件宽度呈现，宽窗口可将五个基本尺寸放在同一行。参数示意图使用共享可拖动、可缩放浮窗。
- 每种支管 / 刀具 / DXF 冲孔一条记录，位置姿态和阵列使用两层表头，直接逐格编辑；点击组标题可收起为摘要，点击摘要即可重新展开全部列。不同类型只提供适用字段，不适用处显示空位；同一记录的多组阵列按顺序在相同参数列中对齐。列数超出窗口时只在冲孔区横向滚动，行号、启用和形状列固定。点击形状或端面参数单元格，在母行下方整行展开模板参数，不弹出参数编辑窗；展开部分与母行颜色一致，记录行交替背景色。直接改格仍可逐次撤销，形状编辑保持一次可撤销事务。
- 参数修改只替换该记录的刀具体，保留主管、其他刀具、画布、镜头、输入焦点、文本选区与各区域滚动位置。截面求值和刀具生成按顺序等待，不积压或并发发送后端请求。区域大小、列展开与示意图位置属于界面状态，不进入原生配方。编辑中布局位置及刀具数量不冒充加工孔数；底部保留文字“取消”和“确定”。
- 轴向统一求解九种排布：定步距与数量、两端留距均分、固定步距整体居中、两端定位孔加中间定步距、中心向两端扩散、固定步距自动填满、最大步距均分、步距序列、指定位置列表。中心扩散明确区分中心有孔 / 中心留空，自动填充可选余量靠首 / 居中 / 靠尾；不静默更改奇偶意图。
- 每条孔记录用“无 / 一维阵列 / 二维阵列”选择阵列维度，不再显示单独的阵列启用列或阵列组管理按钮。一维在后面的参数列显示一行，二维显示对齐的两行，两行按顺序组合。各行可选择沿 X/Y/Z 的直线阵列或绕 X/Y/Z 的圆周阵列，再填写各自的数量、步距或角度；例如沿长度排孔再绕管身均分，可生成多圈密集孔。切换为无或一维只停用不适用行，保留参数与组合跳过设置，切回二维恢复。圆周支持定角间隔、整周等分、角度区间及旋转中心。刀具自身位置、切入面和姿态单独编辑。组合跳过按各行一基索引填写，例如 `2:4`；`*` 表示该行任意实例，底层按稳定组 ID 保存，越界会提示。
- 距离目前明确采用孔中心基准，不宣称已经支持任意刀具轮廓的净边距。普通孔按步距、数量生成后，只要刀具与主管相交就按实际实体切除，切到端面也正常形成缺口；不提供“允许开口”开关。端外实例与相交实例分开处理，不因阵列部分超出主管而拒绝整个有效切割。

端部采用刀具减料，不引入坡口工艺概念。端面切割用角度统一表达平切与斜切（0° 为平切）。插舌 / 插槽统一采用“直线段 + 半圆端”的腰形配合轮廓，半圆直径等于名义宽度；直线段深度设为 0 时即为纯半圆端，配合间隙只扩大母口。Z 口是明确的单台阶搭接轮廓，可翻转后退侧，不把它宣称为所有行业的 Z 口。真实管型相贯端切统一选用管型库主管或本地闭合 DXF 截面，调整夹角、自转、方位及偏移；端切截面刀具须实际接触目标端部，不再保留重复的圆柱端头模板。插舌 / 插槽内部固定按原端长点定位，不显示没有选择价值的尺寸基准；其余端部工艺只在确有多种定位方式时显示对应参数。

排布以不变主管为基准（`layoutDatum=base`），实体端切不会导致孔整体重新偏移。当前数量、步距布局通过 `createPunchArrayGroupsFromLayout` 转成编辑器分组；显示时只读取，不修改配方。分组保存跳过索引和展开矩阵 `arrayTransforms`，矩阵施加在已定位、已定姿的种子刀具上。布局的 `arrayOffsets` / `rowOffsets` 与编辑器分组是两种现行表示，不是版本迁移。缺失原模板的固化节点只读，必须原样传回保存配方，不追加 UI 默认字段或重新展开；可删除，不能暗换本机同名模板。

冲孔向导与三维零件编辑具有独立页面、状态、消息入口和保存属性；只共享通用的几何、布尔及渲染基础能力，不通过冲孔向导驱动三维零件编辑。

布局、参数事务、端切来源、保存重开和复查单测分别见 `TubeDesignerPunchLayoutTest.mjs`、`TubeDesignerPunchInteractionTest.mjs`、`TubeDesignerPunchEndsTest.mjs`。`TubeDesignerPunchLayout.browser.mjs` 验证实际页面绑定、键盘与鼠标连续编辑和三种窗口尺寸，但使用隔离预览服务，不替代真实几何检查；实体切除、端口互补和持久化由 `PunchGeometryTests.cpp` / `NestingStandardPartSDOTests.cpp` 验证。

图纸不打包整套管型库或配件库。实例参数、实际引用的定义/配件快照和中性构造表达属于图纸，用于保持已生成产品的形状，不随公共库修改而悄悄变化。

- 显示 BRep、显示网格和生成材质为运行时资源，不写入图纸；重开时按已保存的显示表达重建。
- 产品页拆单清单、临时实体标识、加工 BRep 和运行时生产表达都不写入图纸；重新打开项目后必须再次拆单。若需要重新请求生产表达而模板版本/摘要已改变，明确报错，要求重新生成。
- 明确“导入下料”后，所有下料副本的加工 BRep 均嵌入图纸（即使暂时未勾选排样）。`NestingTask` 保存独立副本的选择、排样请求和结果，不再依赖原实例或其生产表达；未来直接导入 STEP 也直接创建独立下料副本。
- 重开后直接用独立资源恢复下料任务，无需重建原实例加工几何。下料新增/删除零件会清除旧排样；母材或间距变化时旧结果仅供查看，必须重新排样。导出校验不改写已保存任务。

产品拆单的生产表达和 BRep 都是运行时数据；项目只保留下料区独立副本及其 `NestingTask`。`geometry.brep` 使用有版本头和边界检查的二进制编解码，保留实体标识和几何数据，不经 STEP 往返。

回归测试：`src/tests/BRepPersistence` 包括编解码异常输入、真实资源插件/图纸文件往返，以及实际防盗窗模板生成、保存重开、拆单、加入下料后保存重开。
