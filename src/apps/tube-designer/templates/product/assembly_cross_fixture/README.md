# 十字贯穿验证包当前模板格式

版本 1.0.1，保留 15 个宿主物理参数和 `catalog.listed=false`。该包验证两根连续原管的 X 节点，仍是隐藏验证包。

`display.json` 独立按主管和贯穿管组织右栏、字段顺序与宽度。添加界面使用既有 `hostLength`、`throughLength`；固定拓扑不增加结构选择器，也不增加成品宽高字段。两种管材复用既有资源角色，显示编辑入口没有扩大原来的矩形管约束。

场景绑定分别使用实际 `cross.host.*`、`cross.through.*`，各自包含外圆角和内圆角参数。模型没有提供产品尺寸锚点，此次也没有虚构标注锚点。贯穿管宽度必须小于主管实际内宽，两类原管必须中空。

显示原管、装配关系与制造处理保持分离。格式整理不改变几何或物理参数协议；验证结果不能解释为通用产品选型或承载认证。
