# 三向直角验证包当前模板格式

版本 1.0.1，保留 22 个宿主物理参数和 `catalog.listed=false`，继续作为隐藏的三向直角原管验证包。

`display.json` 独立按 A、B、C 三边组织字段。添加界面沿用 `aLength`、`bLength`、`cLength`；三向拓扑固定，没有虚构结构选择或成品宽高。各边管型资源、壁厚、外圆角、内圆角保持原来的适用范围。

场景绑定使用生成器实际的 `corner.a.*`、`corner.b.*`、`corner.c.*`。原管定位在公共节点，A/B 的原料余量按对方实际截面计算；C 边保持现有原料规则。没有新增模型尚未提供的产品尺寸锚点。

生成器要求三类中空原管，长度沿用 100～2000 mm 的约束。显示、制造声明及后续装配工艺继续使用现有合同；此次只修改显示声明和版本，不改变节点几何。
