# L/T 装配框当前模板格式

版本 1.0.1，保留 19 个宿主物理参数和隐藏目录登记 `catalog.listed=false`。模板用于四个 L 角和两个 T 节点的原管及装配合同验证，没有改为商业产品入口。

`display.json` 独立组织框架定位、外框原管、中横档原管；`template.json` 保留原尺寸、材料、资源角色和约束。拓扑固定，未虚构结构切换控件。添加界面只提供已有宽高、中横档中心高及轴线角度字段；管材继续通过实际资源角色编辑。

场景角色分别绑定生成器的 `frame.left/right/top/bottom.*` 和 `frame.middle.*`。圆角、内圆角与材料仍属于实际外框或中横档。宽、高、中横档中心高沿用既有轴尺寸声明，没有新增原生锚点。

生成器输出未切原管及独立节点关系，不替用户指定斜切、包角或槽口。两类管材须中空；中横档两端须落在边框内侧，倾斜时按实际右端高度验证。声明整理不改变这些几何规则，也不新增旧格式兼容。
