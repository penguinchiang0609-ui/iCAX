# 钢楼梯 2.1

一个模板承载直跑、同向双跑平台、L 型、U 型；保留内部模板 ID straight-steel-staircase，界面名称统一为“钢楼梯”。原 L/U 独立模板已撤下，不做旧工程迁移。

## 实现

- 路线生成独立 Flight / Landing；承重结构为单中梁、双中梁或两侧梁，双梁间距单独配置。
- 梯梁的落地端按水平面截切；上层梯跑起端和各跑终端按竖直连接面截切。毛坯长度按截切包络沿管轴投影取得，不用两定位点的距离冒充成品长度。
- 踏步横撑和管框各自独立；立支架下端匹配实际梯梁轮廓，上端支撑水平踏步骨架。
- 级数按级高总数计，每级均带一个踏步位置，最高一级作为上层收口踏板；水平长度为本跑级数乘踏步进深。
- 平台独立管材规格、横撑间距、四根支撑柱；立柱避开转角梯梁及端板包络。平台框用端面对接，不互相穿插。
- 带孔落地底板、梯段端板、平台柱底板为真实独立板件；板厚、孔径、边距生效。L 型长度不足导致两跑端板冲突时明确报错。
- 钢踏板为板件；木、玻璃、石材踏板为外购件，只进预览和采购信息，不当成切管零件。玻璃沿用半透明材质。
- 梯跑立柱按踏步级数定位，首末必设柱，落在延伸钢支撑上；平台立柱按间距布置。支持横杆或竖杆填充，竖杆包含下横杆。
- 平台铺板按立柱位置实际避让；管件、板件和外购件分别标记。相同规格、材质、尺寸与加工条件的零件记录数量归并。

## 范围与边界

梯梁制造方式独立于单梁/双梁/侧梁布置：型材梁支持方矩管、槽钢、圆管、椭圆管；锯齿钢板梁按独立板厚和竖向带宽生成完整阶梯板轮廓，齿根必须连通。锯齿梁直接承托踏步骨架，不重复生成悬空立支架，也不读取已隐藏的管梁参数。

型材梁的立支架可选管材或钢板。板支架按独立板件拆单；底部按实际接收截面的材料外边界相贯修切。开放型材可能切出余料，布尔节点的 `keepConnectedTo` 用明确的材料内部点选择成品，找不到或命中多个实体则报错，不以最大体积猜测。槽钢可选冷弯等边、热轧平行翼缘、热轧斜腿、板焊构造，翼缘厚度、圆角、斜度、焊脚等随构造联动；默认冷弯等边 U 截面，名义尺寸不冒充某个国标热轧规格。

扶手、立柱和填充支持方矩管、圆管、椭圆管、腰型管。节点使用真实截面外轮廓切除接收体包络，不用包围盒替代圆弧或椭圆曲面。平台骨架和踏步横撑仍使用方矩管。

扶手可选独立梯段或连续斜切焊接转接。连续模式把梯跑、平台、平面转角及上跑处升降转接拆成独立直管件，在公共端点按角平分面实际截切，并输出焊接关系。非圆截面保持各平面转折的截面朝向，不用一根空间斜管掩盖扭转。它是分段焊接式连续扶手，不是滚弯/弯管圆弧弯头；柱头还按完整转接节点避让。

U 型井道间距按当前端板、横撑外伸和内侧栏杆包络校验，不满足时提示所需最小值。几何上可行但没有独立平台内侧扶手的布置，使用两跑扶手直接回转连接。

尚未扩展多跑、扇形转角、悬挑、螺旋、滚弯，以及挡板、X/菱形或钢索填充。

端板与安装孔是制造几何；螺栓、焊缝、建筑接收梁/墙体/楼板、锚固设计不由模板虚构。截面、支承、焊缝、连接和外购踏板承载必须另做项目结构设计。程序几何检查不代表承载、安全规范或施工许可审核。
