# 雕花装饰门

依据《门雕花行业款式调研分析及产品建议》实现的参数化门面模块。

- 单开、双开、子母、多扇；独立重复、交替镜像、全宽连续构图。
- 六类模块：平底／V形铣线、菱形花格、八角花格、几何圆景、直壁池板／独立扣线、玻璃门花。
- 整面、上下分区、上下双块、居中／偏置带；按数量或间距排线、二维单元阵列。
- 真正从板实体减去凹槽／镂空，不用表面贴图；保留边框、锁区与三处铰链区；双面深度累计检查剩余板厚。
- 镂空单元碰到五金区时整单元跳过，避免保护区成为悬空孤岛；扣线越过装饰边界时整单元跳过。
- 门扇、扣线为独立板件；背衬玻璃列为外购件，只参与预览，不当成自制加工零件输出。

## 资源与扩展

`template.json` 定义参数及显隐条件；`patterns.json` 定义图案资源（生成器、归一化轮廓／路径、适配方式和最小特征）；`template.py` 统一执行版式、分扇、避让与实体加工。

新增现有生成器能表达的图案只需增加资源数据和对应参数选项，不应在前端按款式写专用分支。全宽连续构图先生成统一图案，再按各扇安全区域裁切；不是逐扇拉伸假装连续。

## 明确边界

这是门面几何与板件清单，**不是完整门窗结构系统或雕刻CAM**。门框、锁具、铰链安装件、复合门芯、防火结构和玻璃固定件未建模，不据此认证强度或直接投产。

直线槽为平面截断端部；圆景由解析圆环与几何折线构成，不冒充艺术山水浮雕。池板为直壁凹坑，不冒充斜面清根。实际刀具半径、扫掠、走刀、桥位、工装、粗精加工、NC与仿真必须在雕刻CAM中另行设计。参数中的表面处理仅是备注，不是纹理材质。

没有生成龙凤、人物、欧式艺术浮雕等缺少授权源模型的资产；本模板六类图案不等于报告建议的完整艺术素材库。输出始终标记 `ncReady=false`，加工特征记录的原始路径也不能作为机床轨迹。
