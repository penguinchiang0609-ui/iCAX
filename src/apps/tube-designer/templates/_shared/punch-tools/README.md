# TubeDesigner 模具模板

模具库属于 **产品级安装数据**；实际加工使用的固化模具实例属于图纸。
不需要在向导或 C++ 中注册每一种模具：
在此目录新增一个模具文件夹，重新打开冲孔向导即可自动发现。

## 精确截面分析协议（槽口 2.0）

公共入口从主管 BRep 提取截面，传入 targetSection；不调用管型 fitting，不传管型 ID 或能力标签。
截面采用居中的 YZ 坐标，含内外环、闭合标记、边的方向与参数区间，并保留直线、圆弧、椭圆和样条原始参数。

程式模具可声明 `"sectionAnalysis":{"schemaVersion":1}` 并实现：
`analyze(parameters, section, context)`，返回 `{applicable, reason, data, derivedParameters}`。
运行时先分析，再将 data 放入 context.analysis 调用 generate。分析失败禁止生成。
derivedParameters 只能填写声明 derived:true 的参数，不能覆盖普通用户参数。
未声明分析的简单孔模具继续按原方式生成。

共享 section_geometry 仅提供坐标变换、精确包围范围、平面边查找和壁间距查询。
两个槽口模具各自负责选择基准壁、判断适用性和提取壁厚；不按名称或类型识别管型。
当前槽口要求单腔闭合截面，在加工方向具有可确定的上下平直内外壁且对应壁厚一致。
圆弧保持精确；不能可靠查询的曲线明确拒绝，不采样冒充精确判断。加工方向改变必须重新分析。
前端只展示本次预览返回的测量结果，过期结果不作为适用性结论。

已有 K 因子补偿保留并使用实测壁厚。折弯成形预览、闭合及过程干涉尚未实现。

## 图纸携带什么

- 原始毛坯 BRep、已加工零件 BRep。
- 加工实例：刀具 ID、版本、内容摘要、名称，以及参数、定位、阵列、启用状态和端部设置。
- 每个节点的 `frozenTool`：当次生成的自包含中性几何、原程式号与参数、生成上下文及几何摘要。
- 每个已计算节点的 `frozenCut`：实际用于布尔减的刀具体 BRep 资源引用，资源内嵌进 `.ictd`。
  使用毛坯坐标，已包含放置、实际深度和阵列；一条阵列作为一个复合刀具节点保存。
- `operations`：有序的 subtract 链，依次引用起点端部、终点端部、侧面特征节点。
- **不携带**产品模具库、模具脚本或可执行参数定义，也不向目标电脑安装任何模具。

工具运行时返回的 `toolSnapshot` 是当次解析结果，不直接持久化。
图纸保存的是代码无关的固化表达与实际刀具体，不是脚本副本。旧版没有固化数据的节点不能凭空恢复。

## 系统内置模具分类

模具库按“孔型、槽口、支管、端面”分类，界面以类别页签展示；卡片仅显示名称和示意图，具体参数在选中后查看。
系统内置孔型包括圆孔、方孔、矩形/圆角孔、长圆孔、椭圆孔、菱形孔、六角孔、三角孔、单 D 孔和双 D 孔；
V 槽归入槽口，支管相贯归入支管，平切、斜切、凹口、凸口、插舌/插槽和 Z 形搭接口归入端面。
系统内置槽口模具只保留 `V槽` 和 `边弧槽` 两个独立包，资源库只按目录扫描，不在前端按样式拆分。V槽的底部平口、圆角、释放孔和公母配合属于它自己的附加工艺参数；`边弧槽` 内部只用 `leftArc` 选择左侧或右侧圆弧。边弧槽按实际加工实体用基体减圆柱生成，圆弧沿单侧槽壁从槽口连续过渡到槽底，另一侧保持按夹角定义的直壁，定位和阵列由外部调用者处理。

| 目标电脑状态 | 表现 |
| --- | --- |
| 缺少模具，有固化数据 | 退化为定式节点，用保存的实际模具体继续重放；只读、仅可删除 |
| 同名但版本或内容不同 | 同样退化，不自动换用本机版本 |
| 安装完全匹配的模具 | 可以修改参数并重新计算 |
| 退化节点 | 不允许修改参数、位置、阵列、复制、停用或直接替换；前后端同时限制 |
| 删除退化节点 | 从毛坯重放剩余节点；其他退化刀具保持原世界位置，不重新求定位或深度 |
| 旧图纸缺少刀具且没有固化数据 | 已有结果仍可查看、排样和导出；删除此节点或安装原版刀具后才能重算 |

仅打开、查看或导出图纸不运行刀具脚本。无法重算时，不覆盖已有实体。
图纸通过独立下料零件的资源持久化机制保存毛坯、结果与固化模具体，不依赖模具库或原产品实例。
删除节点时不需要保存各步中间零件；原始毛坯加剩余刀具体足以重放。

## 最小程式刀具

目录名与 `id` 必须一致，例如 `my-round/`：

```json
{
  "schema": "icax.punch-tool",
  "schemaVersion": 1,
  "id": "my-round",
  "version": "1.0.0",
  "displayName": "自定义圆孔",
  "kind": "programmatic",
  "target": "side",
  "parameters": [
    {"key": "diameter", "displayName": "直径", "valueType": "number",
     "defaultValue": 10, "min": 0.1, "max": 1000, "step": 0.1}
  ]
}
```

`tool.py`：

```python
def generate(parameters, context):
    return {
        "mode": "profile",
        "contours": [{"kind": "circle", "radius": parameters["diameter"] / 2}]
    }
```

参数支持 number、integer、string、boolean，以及带 `value` / `label` 的
`options`。参数面板由声明生成，不为某个刀具 ID 写专用前端分支。
Python 可返回自包含的中性几何图，实现新的轮廓或布尔组合；仅增加一类几何算子时才需要扩展中性几何内核。
脚本须为单文件、不可依赖旁边未纳入摘要的脚本。安装的 Python 是受信代码，不是沙箱；
只安装经过审核的产品刀具，不执行来自图纸的代码。

## 定式刀具

`kind` 为 `fixed`，`parameters` 必须为空。提供 `geometry.json`，不提供 Python。
例如 `diamond-12`。几何尺寸固定，仍可调整位置、方向、阵列、对面和贯穿设置。

支持两种输出：

- `mode: profile`：闭合二维 `contours`，位于局部 XY 平面；后台按实际管壁延伸刀具。
  圆、椭圆、圆弧路径保持解析曲线，不用显示网格代替裁剪几何。
- `mode: solid`：`model` 为 `icax.neutral-model`，`outputKey` 指定实体输出节点。
  允许 profile2d / extrude / boolean / transform / compound；
  不允许外部资源或脚本引用。侧面实体刀具的 Z=0 为接触基准，正 Z 为切入方向，深度不缩放。

侧面局部 X 为管材长度方向，Y 为面内横向；定位和旋转由向导统一处理。

对于需要自带完整三维刀具体的 `target: part` 模具，返回
`coordinateSpace: part-local`：模型只描述以主管截面中心为原点的一把模具，
不读取 `station`、`reference` 或其它实例定位字段；统一放置层负责沿管长、截面中心、
阵列和姿态变换。返回 `coordinateSpace: part` 才表示模板自己已经输出毛坯坐标中的完整实体。

## 端部刀具

`target: end`。上下文提供：

- `end`：start / end。
- `bounds.min`、`bounds.max`：原始毛坯在 +X 长度坐标系中的范围。
- `placement`：trim、rotation、datum（long / center / short）。
- `section`：可选的已保存管型库或本地 DXF 截面，结构与支管实例的 section 相同；`requiresSection: true` 的端切模板使用它。
- `lengthUnit`：mm。

端部刀具返回实体：

- `coordinateSpace: part`：程式刀具已按上下文构造在原始毛坯坐标中。
- `coordinateSpace: end-local`：在端部局部坐标中，X 向管内，Y/Z 为截面；
  后台统一放到所选端部并应用修剪量、旋转。定式端部刀具必须用这个坐标系。
- 可选 `datumCenter` 表示平面端头中心坐标；曲面端头不声明此值，孔位使用长点/包络基准。
- 可选 `requireEndContact: true` 要求刀具体与选定定位端面内侧的实际材料相交；完全无接触或仅在远处形成侧孔会明确拒绝。
- 可选描述字段 `processCode` 用于零件清单中的工艺名称。

内置端面平切、斜切、圆柱凹口和圆柱凸头也使用这套协议。
凸头的刀具体是“端部区域减去圆柱”；统一引擎仍执行原始管体减刀具体，无专用凸头布尔分支。

新增的具体端切样式（两端分别选择，均使用长点/包络定位）：

- `end-key-joint`：矩形插舌/插槽配合口。公口保留中央宽度为 width、深度为 depth 的插舌；母口切除对应插槽。将母口原端面与公口肩部对齐，零间隙时两件材料互补、无体积干涉。sideClearance 是母口每侧扩大量，axialClearance 是母口根部加深量；不是刀缝补偿或任意圆弧凹凸头。
- `end-step-z`：明确定义为侧视方向的**单台阶 Z 形搭接口**。横向分界 splitOffset 两侧的端线相差 depth，hand 选择后退侧；不是所有行业所谓 Z 口的统称。
- `end-profile`：从 `ends.start/end.section.profile` 读取库截面或本地 DXF，构造真正端内坐标的拉伸切除体。+X 朝所选端的内部，angle 为与 +X 的夹角，azimuth=0 朝局部 +Z，roll 自转；轴向与横向偏移均是刀具体位置。自动贯穿毛坯，扣除截面拉伸体并保留外部主管材料；端切始终使用截面的外轮廓。必须接触定位端面，不允许伪装成远处普通侧孔。

普通孔的阵列按真实实体相交裁剪：越过管端的刀具仍切除接触部分，完全管外实例略过；整条无材料接触时明确失败。旧 allowOpen 字段仅保留配方兼容，不再限制裁剪。预览同时返回候选、主动跳过、未接触略过、实际刀具和端切刀具数量，固化刀具保存实际实例数；旧固化配方缺少数量时标记统计非精确。

三维显示只绘制母材附近的局部刀具体：母材包围盒外扩 max(10 mm, 截面对角线/2) 后求交。`toolDisplayClipped=true` 表示该显示裁剪；加工与固化保存仍使用完整刀具体，不能将显示体用作加工输入。

## 计算与限制

### 槽口尺寸约定（V槽 1.1 / 边弧槽 1.3）

- 两个槽口均在主管截面中心局部坐标生成，定位、旋转、阵列仍由公共层处理。
- `bottomReference=outer` 从外底面量留底；`inner` 从内底面量，实际高度为留底加 `wallThickness`。壁厚必须显式填写，不能从包围盒或支管截面猜测；0 表示未提供，不是零壁厚管。
- V 槽 `flatReference=apex` 保留旧版虚拟尖底解释；`actual` 则把留底直接作为实际平底高度。`roundRadius` 是刀口根部圆角，不是折弯后的内半径。
- 公母尺寸从主管真实顶面向下量，不包含刀具的 1 mm 外伸。0 表示采用已填写壁厚；已提供壁厚时，公母尺寸不得小于它，也不得达到斜边可用高度。未填写壁厚的手动尺寸保留兼容，但不代表已完成壁厚适配验证。
- `reliefDepth=0` 贯穿；正值从所选局部 `+Y/-Y` 外壁向内量，范围不超过主管宽度。刀具在入口外伸 1 mm，该外伸不计入切深。此选项只限制附加释放孔，主槽仍贯穿；加工过切量需由用户计入切深。
- 释放孔圆角不能超过短边的一半；等于一半时移除零长度直线，保留完整圆弧。非法尺寸明确报错，不再静默缩小圆角。
- 边弧槽释放孔不得意外越过外底面；需要切穿时必须明确开启“切断底部桥接”。该开关意味着不再保证留底桥接。孔高不得超出顶面。
- 旧版 `rootRadius` 迁移为圆角策略，避免只复制半径却仍生成尖底。前后端同步保留新增参数；已固化的旧版刀具仍按版本/摘要走原有只读回放，不自动改写历史实体。

### K 因子展开补偿（V槽 1.2 / 边弧槽 1.4）

依据小步 [圆角V槽教程](https://docs.asteptech.com/user_manual/圆角V槽/detail.html)：
`L = 2l + 2πKTθ/360`；默认 K 为 0.62，建议调试范围 0.6～1。
这里 θ 是实际折弯转角，不是折弯后的内夹角（转角 45° 对应内夹角 135°）。

- `bendCompensation` 开启后必须填写 `wallThickness=T`，不得由截面外形猜测。
- `useDefaultKFactor=true` 使用 0.62；关闭后使用 `kFactor`，支持 0～1。K=0 可用于无补偿对照。
- 本项目单槽的几何落地约定：在原切槽展开轮廓上加入 `ΔL=K*T*θ(rad)`，以槽定位中心向左右各分配一半。边弧侧圆柱整体平移，直边向另一侧移动；圆角 V 的两侧切边与相切圆弧分别整体平移。只增加展开宽度，不缩放圆弧半径，不改变槽角与留底。这是本项目的局部轮廓实现约定，不宣称复现小步未公开的全部几何算法。
- V 槽当前仅在圆角策略、正刀口圆角下允许启用；非对称时 θ 为左右角之和。边弧槽使用 angle。
- 例如 T=2 mm、θ=90°、K=0.62，展开补偿量为 1.947787445 mm；K=1 为 3.141592654 mm。
- 为兼容历史尺寸，缺失开关时仍为关闭；旧版固化实体不自动重算。启用后参数随配方和固化快照保存，几何摘要随补偿变化。
- 单槽工具只切除已有毛坯，不自动延长主管，不改定位或阵列间距。不能在不知道成形各段长度和折弯顺序时用此增量替代整件展开；产品级整件展开也不得再次把同一补偿叠加到单槽宽度。

当前范围是含局部 K 因子补偿的切槽刀具体。独立成形半径、整件毛坯展开、折弯成形预览、闭合干涉验证和圆管专项槽型尚未实现，不应将当前预览当作完整折弯工艺验证。

原始毛坯不修改；每次确认重放启用的刀具实例。先处理端部，新 layoutDatum=base 按母材基准定位；未声明该字段的旧侧孔仍按原加工端部基准定位。
退化节点不重新放置，直接使用固化 BRep。内核可批量执行多个布尔减，但持久化仍保留逐节点的有序表达。
真实 BRep 检查壁面、穿透深度、旋转包络、空切和断开实体；未通过时不写回零件。
几何及中性数据转换使用 iCAX Task 调度，资源入池与数据库提交在后端调用线程完成。

每件最多 256 条配置、1000 个展开侧面刀具，超限明确报错，不截断。这是单件加工复杂度保护，
不限制下料零件的生产数量。程序包与单刀几何各限 4 MB，图纸刀具表达请求限 16 MB。
