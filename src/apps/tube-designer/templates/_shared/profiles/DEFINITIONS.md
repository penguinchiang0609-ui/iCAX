# 管型定义协议 v3

管型定义使用 icax.tube-profile-descriptor / schemaVersion:3，必须明确 profileForm：
parametric（程式）或 fixed（定式）。来源独立为 system / user，管理页不展示产品内部资源。

程式提供 parameters 和 profile.py；定式提供 parameters:[] 和 section，不执行脚本。
两者共用 evaluate_section。截面快照包含明确形式和实际 contours，长度由使用方提供。

profile-package 表示定义包，不表示程式；fixed-section 表示直接保存的截面记录，不表示 DXF 来源。
导入格式由 sourceFormat 表达。不得从来源、参数数量、旧 kind 或可编辑标志推断新定义形式。

运行时拒绝旧版定义及缺失形式的截面。旧字段兼容推断只允许存在于离线迁移工具。
migrations/profile_v3.py 只升级独立 profile.json；默认只打印，--output 只能写新文件，原件保留。
工具不处理 .ictd、加密包、数据库记录和带摘要的引用，不应对这些文件作文本替换。
历史图纸与用户数据库尚需单独的事务迁移；本次未执行任何历史数据迁移。

现有中性轮廓表达和原生拉伸校验继续使用；完整拓扑升级与一键另存定式是独立的后续工作。

## 公共材料区域规则

原生 `profile2d` 是所有程式、定式和导入截面构面的统一入口，不读取管型 ID 或行列等生成参数。
一份截面表示一个连续材料区域：一个外边界、零个或多个严格位于其中的孔边界。
轮廓顺序、顺逆时针均不决定内外角色；公共入口用精确曲线边界距离和面内分类确定包含关系。
边界自交、重复、相交、接触或无法可靠分类时拒绝构面；最终材料面再次做有效性检查。
分离外边界、孔内材料孤岛属于多个材料区域，当前协议不支持，需拆为独立截面；不得悄悄当孔处理。
在此单材料区域约束下，多个轮廓才意味着 hollow；Python 返回的轮廓数量及 hollow 是待原生校验的描述，不是拓扑有效性证明。
多腔的比例、筋厚、圆角只是某个程式生成轮廓的参数，不是公共几何机制的规则。

## 系统截面扩充边界

系统目录目前提供 23 种程式截面；这些是自由尺寸几何定义，不是国标规格库，也不代表已覆盖竞品全部截面。

模板以具体用途组织，不要求一个模板囊括所有变体。增加模板只需提供描述和轮廓生成脚本；底层不添加管型分支。
新增独立模板：开口矩形管（顶部居中槽）、外翻边槽型材（两侧外翻）、十字型材（独立横竖板厚）、双圆孔矩形型材（独立孔径与中心距）。前三者为直角截面；双圆孔保留精确圆弧。

- 卷边 C、卷边 Z、帽形：bendRadius 是内弯半径，外弯半径为内弯半径加壁厚。内弯半径为零时，外弯仍保留壁厚半径；自由切边不倒圆。相邻圆角无法容纳时拒绝生成，不自动缩小半径。
- 多腔矩形管：columns / rows 为横纵腔数（各 1～16）；columnRatios / rowRatios 为从左到右、从下到上的内腔净尺寸比例，逗号分隔，留空等分，数量必须与腔数一致。总尺寸先扣除外壁及隔板，再按比例分配；比例必须有限且为正，不自动截断或补项。
- 多腔内腔支持统一 innerRadius 精确圆角，必须小于每个内腔短边的一半。外围保持直角；wallThickness / ribThickness 为直边间壁厚和筋厚，圆角处材料加厚，不宣称全截面等壁厚。尚不支持局部中断、错位、斜向隔板及独立每腔圆角。
- 带筋双腔圆管：圆环加贯通直径的单隔板，两个内腔保留精确圆弧；wallThickness 是圆环壁厚，ribThickness 是隔板厚度。
- 新增截面沿用统一截面获取入口，无管型识别或模具专用分支。尚未实现的非零 clearance 偏置会明确报错。

回归验证覆盖参数示意标注、非法尺寸、内外弯同心及半径差、内腔数量与尺寸，以及全部系统截面的原生拉伸、单实体有效性和 BRep 往返。
