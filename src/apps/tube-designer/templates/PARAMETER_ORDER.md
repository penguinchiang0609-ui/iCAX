# 组内参数显示顺序

在 `template.json` 的 `parameters` 元素中配置可选整数 `order`，例如：

```json
{"key":"width","displayName":"宽度","valueType":"number","defaultValue":1000,"group":"overall","order":10}
```

- 同组参数按 `order` 从小到大排列，建议按 10、20、30 留出插入空间。
- 未配置的参数排在有配置的参数之后。`0` 是有效顺序，不等同于未配置。
- 相同顺序及均未配置的参数保持 JSON 数组声明顺序。
- 添加页和实例编辑页共用规则；条件隐藏后再显示仍回到原有相对位置。
- 此规则只排序组内参数，不改变现有分组方式或组的顺序。
- 原生描述转换保留 `order` 的缺省状态，不补成 `0`。
