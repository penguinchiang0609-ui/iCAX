# TubeDesigner 0.1.1

发布日期：2026-10-24。Windows x64 Release。
对比版本：0.1.0。配套 iCAX 授权签发器版本：0.1.1。

## Fix（修复）

- 修复部分电脑在 Windows 已确认 TPM 就绪后，仍因 TPM 内部时钟连续性标记而报 `Unsafe TPM clock`、无法正常导出授权申请的问题。
- 同步修复签发端对该标记的误判，避免客户端能生成申请但签发工具仍拒绝处理。
- 统一程序“关于”、EXE 文件属性、安装包名称、安装欢迎页和 Windows 卸载记录中的产品版本为 0.1.1；Windows 文件版本为 0.1.1.0。

## Add（新增）

- 签发工具增加可见版本号及 Windows 文件版本信息，方便确认是否使用了新工具。
- 每个发行版本附带 README，分别说明 Fix、Add、升级方法和验证范围；没有新增功能时明确写“无”。
- 打包时检查版本一致性及对应版本 README；缺少说明或版本不一致时停止打包。README 随安装包提供，并安装到程序目录。
- 本次没有新增建模、拆单或加工功能。

## 升级与授权

1. 保存工作并退出 TubeDesigner，运行 `TubeDesigner-0.1.1-20261024-x64-Setup.exe` 覆盖安装。
2. 签发端也更新为本版 `iCAX-License-Issuer.exe`，打开原有签发库。签发工具仅供授权管理人员使用，不用发给客户。
3. 遇到上述 TPM 错误的客户，升级后重新导出授权申请，再按原流程签发、激活；无需清除 TPM 或修改系统时间。
4. 同一台电脑、同一 Windows 环境下，覆盖安装保留 `C:\ProgramData\TubeDesigner\Licensing\` 中的现有授权文件；本次不改变授权主版本、签发密钥或许可证格式。
5. 客户端继续强制授权，仅公开“产品、资源库、关于”三个入口，下料与加工页保持隐藏。设备绑定、验签、防重放、试用到期和计数回退检查继续生效。

## 验证范围

- TPM 修复已通过原生 7 组测试（核心 2180 项检查、签发器 347 项检查）及 Python 42 项测试；合法时钟标记 0/1 均接受，非法标记及篡改、重放继续拒绝。
- 同一修复代码已在本机真实 TPM 及安装后的 Release 程序验证授权申请、正式权限；真实模型 11 类、40 件，重复拆单、保存和冷启动重开通过。
- 本机真实 TPM 的时钟标记为 1；标记为 0 的情况使用正确签名的软件样本验证。客户电脑仍需安装后复测，不能据此认定客户现场已激活成功。
- 0.1.1 发布时另核对版本、README 安装及 0.1.0 覆盖升级结果；本次验收记录随发行目录提供。正式管理员安装界面与客户现场结果不属于隔离安装测试的覆盖范围。
