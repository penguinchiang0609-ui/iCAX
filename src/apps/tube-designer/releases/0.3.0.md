# TubeDesigner 0.3.0

发布日期：2026-10-26。Windows x64 Release。对比版本：0.2.0。
产品版本为 0.3.0，文件版本为 0.3.0.0。

## Add（新增）

- 新增独立“极简防护网”产品模板，与防盗窗并列。支持两竖管、四边框、下横管，以及无把手、左侧、右侧、中间双把手和封闭/开槽把手位。
- 添加窗口的结构示意随当前款式更新，并显示所选款式文字。示意区尺寸与其他产品统一。
- 视口使用灰色中文视图立方体、方向环和 XYZ；透视/正交切换放在立方体下方，主视口及独立三维预览统一。

## Fix（修复）

- 极简防护网单侧把手口上下横杆保持整根，只有实际开槽才断开对应边框。
- 添加窗口只选择款式。把手位置、净宽净高、偏移、排杆间距和根数由创建后的场景标注修改；只有主体框架类型创建后固定。
- 首杆中心离顶、末杆中心离底使用实际横杆中心作为尺寸端点，并按主体框架显示适用标注。
- 修正混合插接款的生产导出检查：逐连接核对对应参与件及已执行工艺，平口构件可正常下料；未分配、缺少关联或错误关联的工艺继续阻止生产导出。
- 修复项目另存后旧编辑日志残留引起的资源版本恢复错误。成功另存保留原文件内容，失败保留原路径和恢复日志。
- 参数局部更新保留现有焦点、输入选区和侧栏滚动位置。

## 安装与授权

1. 保存并退出 TubeDesigner，运行 `TubeDesigner-0.3.0-20261026-x64-Setup.exe`。安装后在“关于”确认版本为 0.3.0。
2. 程序为正式 Release 构建，强制原生授权，继续使用正式签发公钥、设备绑定、权限、有效期及防回退校验。
3. 未激活时，从“关于 → 授权”检查环境、导出申请并导入供应商签发的授权文件。修复授权环境不等于激活。
4. 授权主版本仍为 0，许可证格式和签发密钥保持现有契约。本次次版本升级不要求重新签发仍然有效的现有授权。
5. 安装包仅包含程序、依赖、内置资源和本说明，不包含客户授权、签发私钥、工程文件或本机用户数据。

## 使用范围说明

- 极简防护网把手位是局部避让口；中间双把手开槽款的局部接法依据客户小图推定，生产前应核对实际要求。
- 本版未增加安装孔规则或第三方 HTB 文件格式支持。
- 发布验收记录随发行目录提供，分别记录安装器文件校验、程序实操和授权测试覆盖范围。
