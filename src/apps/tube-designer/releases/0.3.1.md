# TubeDesigner 0.3.1

发布日期：2026-10-27。Windows x64 Release，保留原生授权限制。

## Fix

- 安装大小孔分别切穿自身一层管壁，保留小孔侧承压壁料；孔位落在开槽缺口、端部余料不足或接头遮挡时给出明确原因。
- 安装孔位置按实际竖管及分段起点计算，不增加实物分段，拆单数量和料长保持正确。

## Add

- 极简防护网安装孔支持侧装与正装：侧装朝网内大孔、朝侧墙小孔；正装正面大孔、背面小孔，默认直径 6 / 4 mm。
- 每侧安装孔组数支持 2、3、4、5 四档，创建后可通过场景标注修改开关、组数及上下端距。
- 内杆与边框新增“双边对穿公母”：母管两侧开口，公头长度按母管实际宽度计算，插入后与对侧外表面齐平，便于外侧焊接。原单边开孔、公头长度调整及平焊工艺保留。

安装孔与公母接头均检查真实管壁平直区域和最小余料。修改布局后须重新生成，修改工艺后须重新拆单。
