# TubeDesigner 0.3.2

发布日期：2026-10-28。Windows x64 Release，保留原生授权限制。

## Fix

- 公头与母口按实际构件姿态匹配，支持方管、圆管混用时的周向加工。
- 母口跨圆角、侧缘或端部时，按加工后真实实体是否连通判断；不再仅凭平面区域或余料估算误拒，确实断管时仍拒绝拆单。

## Add

- 极简防护网支持方管与圆管的四种配对，公母连接提供窄插舌、整管端头，以及单边和对穿方式。
- 公母加工支持两个相对方位、四个相隔 90° 的方位，并可调整周向角；现有 T 形公母插接与长短包接入口同步支持。
- 客户端支持 TDREI001 再次授权资料，与更新后的授权签发流程配套；原有 TDLIC003 授权校验及功能权限限制保持生效。

本版整合已完成产品及导出验证的模板和界面资源。产品导出验证覆盖方矩管和圆管；其他截面、实际切割、焊接强度及整机验收不在此次发布验证范围内。
