# TubeDesigner 0.3.4

发布日期：2026-11-10。Windows x64 Release，保留原生授权限制。

## Fix

- 极简防护网按实际用料和连接方式生成零件：实心单 C、双 C 支撑处的横杆在接触面截断焊接，保留支撑实体；双 C 中间净空不自动补杆。
- 双 C 之间的短杆独立设置数量和位置，不再借用普通横杆数量；未启用时不生成多余零件。
- 产品示意图随结构、尺寸和用料更新，场景尺寸标注与右侧用料编辑按参数归属显示，编辑时保留输入焦点、选区和滚动位置。

## Add

- 极简防护网默认采用 5 mm 厚实心扁钢：边框与横杆为 10×5 mm，支撑为 20×5 mm；普通横杆默认中心距为 115 mm。
- 飘面结构的竖向、横向构件可分别选择用料，默认分别为 15×15 mm、12×12 mm 方管；支持五面飘窗及阳台封闭结构的实际尺寸与拆单。
- 新增可选晾衣杆及配套吊杆，可调整位置和下落尺寸，并生成独立制造零件。
- 新增与极简防护网并列的“隐形防护网”单面模板：采用通长实心圆线、上下及可调中间正背双片压条，支持线径、中心距、夹条数量及位置编辑和拆单；不含飘面结构。

本版保留已有公母插接、安装孔及再次授权支持。隐形防护网当前描述圆线与普通矩形压条的真实几何和接触关系，未代替供应商专用槽型、端部锚固、紧固方案或承载能力验证。
