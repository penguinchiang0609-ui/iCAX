# TubeDesigner 0.3.3

发布日期：2026-10-28。Windows x64 Release，保留原生授权限制。

## Fix

- 切换产品用料管型时，更新选择值并保留原选择框节点与监听器，避免异步刷新打断正在进行的输入。

## Add

- 极简防护网的公母装配参数分为“连接方式”“公头尺寸”“母孔尺寸”。
- 新增单个公头和母孔的局部特写，伸出长度、宽度、倒角和圆角随参数更新；图中尺寸可定位对应输入。
- 母孔直接显示单孔宽向、厚向或完整开口尺寸，并与配合余量联动；派生读数不写入产品参数。
- 圆管按实际截面显示，对穿端头展示与母管对侧外表面齐平的关系。

本版保留已有圆方管公母插接、周向加工与再次授权支持。此前已完成16组真实原生预览、Release独立程序实操，以及24次专项浏览器编辑和管型选择回归；本次发布另做安装包成品核对。
