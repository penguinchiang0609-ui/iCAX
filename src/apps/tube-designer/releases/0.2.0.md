# TubeDesigner 0.2.0

发布日期：2026-10-24。Windows x64 Release。对比版本：0.1.1。
本次新增授权环境修复入口，产品版本升至 0.2.0，文件版本为 0.2.0.0。

## Add（新增）

- “关于 → 授权”增加“检查并修复授权环境”。先检查本机 TPM 及现有厂商证书；缺少证书的 Intel TPM 尝试从 Intel 官方证书服务获取。
- 明确提示申请材料已就绪、证书已获取、网络超时、连接失败、厂商未提供证书或设备不匹配等结果，便于客户下一步处理。
- 成功取得的公开证书保存在当前用户 `%LOCALAPPDATA%\TubeDesigner\Licensing\Endorsement\`，下次导出申请会重新验证证书与本机 TPM 的匹配关系。

## Fix（修复）

- 针对“TPM 已就绪，但 Windows 及 TPM 中均没有厂商证书”的情况，新增联网补齐途径，并在导出失败时指向修复入口，避免只提示重试或重启。
- 没有授权文件时显示明确的申请、激活指引。
- 授权操作的进度和结果只更新授权面板内容，保留现有输入节点、焦点、选区及侧栏滚动位置；重复点击不会同时启动多次操作。
- 延续 0.1.1 对合法 TPM 时钟标记的修复，以及程序、安装包、关于页、文件属性和卸载记录的版本一致性检查。

## 使用方法

1. 保存并退出程序，运行 `TubeDesigner-0.2.0-20261024-x64-Setup.exe` 覆盖安装，打开“关于”确认版本为 0.2.0。
2. 遇到厂商证书缺失时，点击“检查并修复授权环境”。缺少 Intel 证书时需要能访问 `https://ekop.intel.com/ekcertservice/` 的网络；请求只发送 TPM 公钥摘要，不发送私钥、授权文件或模型。
3. 显示“申请材料已就绪”或“已获取并保存”后，导出授权申请，交给供应商签发，再导入激活文件。
4. 若提示 Intel 暂未提供证书，请联系电脑或主板厂商确认；本功能不能制造厂商未签发的证书。若网络失败，检查网络、代理及系统时间后重试。只有 Windows 提示需要重启时再按其提示处理，重启不保证补齐证书。

## 授权与升级

- 修复环境不等于激活，仍须供应商签发。现有授权校验、设备绑定、签名验证、试用期限和防回退规则继续生效。
- 下载结果只作为申请材料；签发端继续独立验证厂商证书的签名和完整信任链。证书缓存不会成为新的信任根。
- 不清除或重置 TPM，不写入系统证书库，不改变固件，不修改现有授权文件。
- 同一电脑和 Windows 环境下，覆盖安装保留 `C:\ProgramData\TubeDesigner\Licensing\license.tdlic`。公开证书缓存与授权文件是不同文件。
- 授权主版本保持 0，许可证格式和签发密钥不变。配套签发器仍使用 0.1.1，不必因本次客户端升级重新签发已有授权。
- 客户端继续强制授权，仅公开“产品、资源库、关于”，下料、加工页继续隐藏。

## 验证范围与限制

- 原生授权 7 组测试通过，签发器及新增修复流程共 374 项检查；新增检查覆盖成功缓存、重新读取、错误设备、损坏证书、网络失败，以及缓存证书仍不能绕过签发验证。
- 前端授权测试及真实浏览器交互测试通过，覆盖重复点击、异步结果、左右侧栏及嵌套滚动、输入选区、字段移除和切换项目。
- 实际访问 Intel 服务已验证“厂商未提供证书”的错误分支。缺失证书后下载成功的分支使用软件证书样本验证；未将此等同于客户机器获取成功。
- 客户电脑的 TPM 证书是否能从厂商获取，仍需在客户机器执行一次本入口确认。完整安装包与真实模型验收详情见发行目录的发布验收记录。
