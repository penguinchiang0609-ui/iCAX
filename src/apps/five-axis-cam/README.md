# 三维五轴 CAM

基于 `doc/3DCAm` 的产品规格与技术方案，复用 iCAX AppShell、共享 `camWorkbench`、场景 SDO、View/Resources 和真实 SDK 三维视口。

## 2026-10-29 同名内置切割头

CAM 轨迹仿真旁的“切割头 → 内置切割头”列出产品清单中全部内置机床，名称与机床定义一致。选择时直接读取对应 URDF/SDF 的工具端全部显示网格、附件位姿、单位与缩放、TCP 和光束方向；将完整几何与标定作为嵌入快照保存到当前工程，不另维护一套示意外形。切换使用原生历史与自动保存，保留切割定义、已有空移几何及手动路径；此前针对另一刀头的检查结果须重新验证。旧版示意头仅保留已有工程兼容，不再作为新列表选项。

这一阶段同步模型来源及选择入口。CAM 检查仍使用由所选模型生成的保守分层包络，机床规划保留实际网格与整机轴运动检查；同名选择不会自动替换旧工程已经保存的机床实例。

## 2026-10-25 刀路工程数据与局部更新

刀路使用 `CEditableDocumentComponent`、`CEditablePlanComponent` 和 `CEditableOperationComponent` 保存唯一编辑定义，精确结果保存在 `CEditableDerivedComponent`。刀轴、补偿、裁剪、引线和分段属于同一操作图；执行投影直接消费已处理的精确结果。装夹的 `GeneratedToolpaths` 保存执行投影，空移记录与依赖指纹保存在 `GeneratedRapidPaths`。不提供旧刀路组件、旧业务资源或旧空移缓存的兼容迁移。原生接口以 `geometryRevision` 校验当前数据快照，显示采样与完整报告通过有版本的资源通道传送，避免大消息占满 SDO。

切割生成按单条实际输入复用已有结果与精确曲线。空移只依赖连接两端的位置、方向、工件、工装、切割头、策略与安全参数，不依赖整套切割的资源版本或工程修改序号。姿态编辑保留未受影响连接；内部姿态更新后若两端不变，可复用全部空移。自动排序改变时按最终实际连接复用，不能承诺任何修改都固定只重算两段。旧生成结果尚未更新时，只将相邻连接标为待更新，不恢复旧证书为有效。

分段后的局部工艺通过 `fiveaxis.branch.process` 从精确来源映射取得保留区间，再调用已注册的补偿、裁剪和引线算法；不把已补偿曲线再次补偿，也不从显示采样重建权威几何。刀轴区间表达式与来源锚点保存在同一操作图中。`CamPlan.Generate`、工艺编译及夹具刀路避让只把当前精确结果投影为执行数据，不再另走一套工艺计算。

操作的 `EvaluationRevision` 独立于可编辑定义的 schema/algorithm 版本；实现修正使旧计算结果失效并重新求值，不修改编辑定义，也不接纳缺少求值版本的 Current 缓存。复制工件或装夹复制完整可编辑图并重算，撤销/重做使运行时投影缓存失效。初始化统一文档不增加或清空用户撤销历史。

下方按日期保留的条目及报告记录当时的实现和验收范围。涉及旧组件权威、旧生成入口或旧资源字段的描述，以本节的统一模型为准；历史报告不能代替本次产品工作流和界面验收。

## 最终页面设计

主流程为“工件与装夹准备 → CAM 编程 → 实机仿真 → 加工交付”。顶部为 **工件、CAM、孪生、帮助**，CAM 和孪生页始终可见，实际条件决定各菜单项是否可用。工件页按“工件、几何、装夹姿态、夹具”分组，左侧保留工件、装夹姿态、夹具单元三级列表。“放置”统一进入平移和旋转操作；参数按 Enter、离开输入框或结束拖动后保存，不再要求确认装夹完成。几何分组仅保留已接入的缩放、自身坐标系重置。工程新建、打开、保存及另存为复用 iCAX 文件入口，产品不再提供文件页。内部 `toolpath` 标识不改变，用户标题为 CAM。

| 页面 | 用户任务 | 功能分组 |
| --- | --- | --- |
| 工件 | 管理共享几何、装夹姿态及夹具单元 | 新增、删除、复制；等比缩放、自身坐标系重置；装夹放置、姿态锁、三点定位；夹具库、静态间隙检查、支撑夹具设计和制造导出 |
| CAM | 保留可编辑的加工定义，生成并调整完整计划 | 自动提取/手动选面/草图投影、工艺与方向、生成与调整、轨迹仿真/输出、设备与规划设置 |
| 孪生 | 按真实机型检查完整机床和装夹 | 实机配置、整机仿真、问题与报告 |
| 帮助 | 操作指引与排查 | 说明、诊断、日志、关于、重置布局 |

装夹姿态和夹具单元的放置默认吸附当前网格（2000 mm / 40 格，即 50 mm）与世界原点；旋转在距离 15° 倍数不超过 3° 时吸附。平移吸附距离为 8 CSS 像素，局部坐标仍保持所选轴或平面的运动约束。按住 Alt 临时自由拖动，手工输入的精确位置和角度不量化。

工件启用开关由原生 Scene 持久化，支持撤销重做和保存重开。禁用工件只在工件页保留管理入口；装夹、CAM 与孪生页的场景、工件选择器和关联内容均排除禁用工件。仍有已启用工件时自动切换；全部禁用时显示空状态。装夹与各条刀路自身的启用设置保留，不能生成切割/空移或运行轨迹碰撞检查。重新启用恢复原设置和仍匹配的刀路缓存；启用开关与姿态锁相互独立。

工件定位按 FACAM 手册图 3-1、3-2、3-3、3-6 使用左侧紧凑浮窗，其余空间为三维视口。删除重复的产品说明条和工件底部流程按钮。其他页面保留现有操作区；不宣称其已按 FACAM 完整复刻。

## 关键功能边界

- 工件加载后保持激活，点击空白不取消，也不对整件着选中色。工件页的缩放修改共享 BRep；自身坐标系重置写入共享几何，其他装夹补偿变换以保持原场景位置。存在锁定装夹时禁止修改共享几何或删除工件。
- 装夹姿态的放置提供平移和旋转，工件几何可单独缩放；操作按钮不显示未实现的快捷键提示，没有装夹缩放。每个装夹引用同一工件，独立保存姿态、锁、工装、刀路和三点资料。新增装夹从当前姿态开始，不复制工装和刀路；删除装夹可撤销，保留至少一个装夹。
- 选中工件后提供可拖动的 XYZ 平移轴和旋转圆环。点击手柄选择操作轴，旁边只显示该轴的一个数值框（mm 或 °），没有轴下拉、旋转中心或确定/取消按钮。旋转以工件包围盒中心为中心；顶部世界/局部切换决定操作轴。拖动时只预览，松开使用 `CamPlacement.SetTransform` 提交一次事务；输入只在 Enter 时提交，失焦不提交。松开后数值保留，修改并 Enter 替换这次操作的数值，不额外叠加。下一次拾取手柄从最近提交的位置开始；换轴/坐标模式放弃未按 Enter 的输入。拖动中 Esc/窗口失焦撤回当前手势，切换工具/页面或工程版本变化清理未提交预览。撤销/重做与工程保存由原生负责；回执不明时输入框只读，Enter 重试同一命令。
- 视口左上角为着色/着色+线框/线框显示模式。右上角使用带窄倒角、方向光照和柔和渐变的灰白视图立方体；中文视图名贴合各自面平面，边缘侧视时隐藏文字。保留 26 个面/边/角点击方向，窄倒角配较大的透明命中区域，悬停或键盘焦点只高亮对应表面。立方体底部带灰色方向圆环，左键拖动绕世界 Z 轴旋转视野，保留俯仰、缩放和当前投影，围绕按下时捕获的固定中心旋转；侧视保留最小厚度方便拾取，顶视呈圆形。拖动支持连续整圈，Esc/指针取消恢复起始视角；方向键左右微调 5°，Shift 为 15°。圆环不改变工件和变换草稿，数值框节点、焦点与选区保持。透视/正交切换紧贴圆环下方，底部不再放置独立切换框。这些视图偏好不改写工程。
- 世界坐标系是固定的场景基准：原点 `(0,0,0)` 和 XYZ 单位方向不随工件、选择、镜头或显示模式改变。物体坐标系来自导入模型，其局部原点/方向经工件 Placement 映射到世界；平移、旋转仅修改这份对象变换。世界/局部按钮选择操作方向。显示在工件中心的手柄是编辑支点，不是世界原点，也不重定义物体原点；右上立方体旁的方向标始终表示世界方向，屏幕投影只随镜头变化。
- 三维视口使用 `constrainOrbit: false`，中键拖动可以连续越过俯视、仰视方向，Ctrl＋中键拖动平移视野；镜头旋转不改变工件摆放。
- 中键按下时，以鼠标周围 6 CSS px 范围内九条射线的最近模型命中点中心作为固定旋转中心；未命中则使用当前工件的世界坐标包围盒中心，排除夹具对回退中心的影响。按下不跳动、不重新取景，一次拖动中不再检测或更换中心。视图立方体和方向圆环拖动在按下时采样画布中央，沿用相同的固定中心规则。
- 工件平移、旋转、缩放工具保持中键旋转、Ctrl＋中键平移和滚轮缩放可用；手柄仍由左键编辑。视野操作保留当前操作轴、数值与未提交预览，等待原生保存响应时也可调整视野。
- 操纵器使用紧凑单向细轴、小箭头、完整旋转环和缩放方块，透视与正交的屏幕尺寸一致。平移轴根部的三个方块分别约束 XOY、XOZ、YOZ 平面；支持世界和局部坐标系，第三个方向保持不变。选中平面后显示两个方向的位移输入，Enter 一次提交，修改数值替换本次位移；鼠标松开提交，Esc 取消当前拖动。世界参考轴缩小淡化，与操作手柄区分。
- 旋转操纵器以前亮后淡的三轴圆环表达空间层次，当前轴保持黄色。灰白外圈绕当前视线旋转，数值框标为“视图”；工件和刀轴关键点共用这一交互。视图旋转轴在选环时固定，随后漫游不改变本次角度的含义；新拖动重新捕获视线。继续通过原有原生命令保存，支持取消、撤销和工程重开。
- 一个工程可导入多个工件，每件可建立多个装夹。工件页按几何去重显示；装夹/CAM 页提供当前工件与装夹选择。切割定义始终归属于具体装夹 Placement。

- 装夹设置：导入现有 STEP/IGES 工装，编辑装夹坐标系中的刚体位置；隐藏与参与检查分别控制。检查工件/工装及工装之间的精确静态距离，接触/相交由用户核对支撑用途，不形成刀路或整机碰撞验证资格。先前推测的夹具自动生成、拆单、导出入口与占位编辑器已移除。
- CAD 编辑是可选辅助。CSG 开孔修改实体；CAM 草图投影创建加工定义，保留工作平面、草图尺寸、目标面、投影方向与设计轴向，不修改实体。
- 自动提取、手动选面、草图投影在 CAM 直接启动。标准孔设置、起点各有一个入口；标准孔/轮廓是切割类型，圆/矩形/腰型是几何类别。
- CAM 轨迹仿真显示工件、切割头与切割/空移路径。独立孪生页要求真实机型、完整机床几何、运动链、行程、工具标定和当前装夹；缺少配置时显示待配置，不能产生整机通过结论。
- 三点定位归装夹页，直接消费现有吸附特征服务的端点、圆心、球心、辅助中心和面上点。原生提交重新解析特征，拒绝重合/共线点；以当前装夹坐标系和 mm 导出标准 JSON，附点序、来源几何和摆放矩阵。只表示资料已准备，机床测量后自行求变换；不设置加工零点或录入实测坐标。几何或摆放改变使资料过期并阻止导出。
- 工件页“几何”提供“自身坐标系重置”，不再提供选点/选直线/选面定位及实测校准菜单。工件坐标系对齐按“基准面 → Z 正方向 → X 正方向 → 原点”执行；每步即时预览，完成前三步后才选择原点。Z／X 均可反向，X 候选方向投影到基准面内，垂直于基准面的方向明确拒绝。
- 基准面可以来自已有平面、圆／椭圆所在平面、经精确 BRep 检验的共面轮廓，或三个吸附点。没有直边时，X 可由两个吸附点确定，或由用户明确采用基准面的 U／V 方向；不替用户猜测对称模型的唯一 X 方向。原点可以选端点、圆心、球心、轮廓／平面面积中心或面上点，也可以采用基准中心。取消／Esc 恢复，最终确定一次提交并立即恢复平移手柄；场景修订使对齐失效时同样恢复操作状态。
- “对齐后重设物坐标系”为明确选项：先求对齐，再以中性 `ICadBRepTransformService` 将刚性变换写入精确 BRep 和显示几何，Placement 归单位矩阵，场景位置保持对齐预览结果。事务由 FiveAxisCAM 管理，已有刀路标记 `Stale` 需重新提取；几何、显示、工件引用和定位报告共同支持一次撤销／重做及独立源文件的保存重开。
- 对齐与吸附分层：`ICadSnapFeatureService::Analyze(BRep)` 返回端点、中点、圆心、椭圆中心、球心、直边、曲边、平面、共面轮廓基准面及面积中心，以及圆柱／圆锥／圆环／回转轴、圆锥顶点。特征包含标签、是否派生、方向／平面基向量及稳定拓扑来源。`Construct` 以已解析的精确特征建立两点方向、三点平面、平面 U／V 方向和基准中心，重合／共线点明确拒绝。非共面轮廓不拟合成假平面。边采样只用于拾取初筛；service 不依赖 Scene、相机、像素、对齐、资源版本和持久化。
- Scene 适配器按固定 BRep 资源版本复用特征目录，视口按 12 CSS 像素筛选并缓存投影；鼠标移动不重新解析 BRep。对齐消费已有吸附结果，确认时按特征 ID 重新校验，右栏参数只读，镜头操作可用。独立的几何拾取控制条不属于对齐参数。保存回执不明时保留原命令核对，避免重复移动。
- 吸附交互参考 [SketchUp 推断](https://help.sketchup.com/en/sketchup/introducing-drawing-basics-and-concepts)：候选类型提示、悬停建立中心参考、方向／平面锁定是吸附层的能力。当前已实现特征目录与基本拾取；尚未实现完整的关系推断、候选切换与锁定，不能宣称已复刻 SketchUp。
- 关键点修正局部姿态，刀路调整修正整体方向，空移调整修正工序连接；手动排序的前移/后移为草稿重做/撤回。引线、阴阳切、过切、补偿与清除分别维护自身语义。

## 框架与当前实现

- 产品 ID 为 `icax.five-axis-cam`，入口为 `webpage/entry.mjs`。没有独立 HTML 产品入口或其他产品业务代码依赖。
- 正式 FiveAxisCAM 领域模块接管模型导入、Placement、候选、切割定义、工艺、后台任务、撤销与工程持久化。场景通道为 `CamScene/CamWorkpiece/CamPlacement/CamCut/CamProcess/CamPlan`；不使用 CamRuntime 的旧产品状态。
- STEP/IGES 导入保存原文、毫米制精确 BRep 与显示资源。未知单位拒绝；任务幂等、取消、编辑后撤销的旧任务拒绝、事务失败回滚、关闭场景与删除源文件后的重开均有原生验证。
- 工件坐标系支持点/直线/平面基准；实测校准界面按手册使用 3 组配对点；底层通用求解最多 10000 组。使用带权 SVD 正刚体解，检查点组分布、残差、反射与缩放；预览只读，应用保存固定版本定位证据并使下游过期。工件坐标系从模型拾取基准，实测校准输入实测坐标；拾取支持精确曲面点、拓扑端点、弧长中点、圆心、直线方向和平面法向。拾取参照在应用前按当前固定几何重算。
- 定位编辑器通过 `CamPlacement.ReadRegistration` 读取工程中已保存的输入和完整残差；重开工程与撤销重做后可恢复。工件坐标系方法切换会清空含义不同的点/方向输入；改变捕捉方式会切换当前基准的捕捉类型。异步读取、求解、拾取和应用均保留后续编辑，应用回执丢失时查询原命令，结果未确认时保留原 commandId 安全核对。实测校准直接从原始模型坐标映射到实测坐标，替换摆放而不叠加工件坐标系。
- 中性几何服务已验证单面/面片边界、周期接缝抵消、封头和弯管端口；解析圆/矩形/腰型保留精确来源区间及解析偏差上界。直孔、直槽和单锥通道检查完整侧壁、终端面域以及整个扫掠体与实体的交，不使用中心射线代替贯通证明。盲腔、凸台、沉孔、交叉孔和偏心残料有反例验证。
- 独立 `cam/CutRecognition` 服务返回纯值和证据：形状、边界角色、通道类型、确认资格与工艺资格分开；盲腔阻止贯穿切割，锥形通道要求测量截面选择，曲面声明厚度模式不声称实体贯通。当前仅支持显式选择的通用实体/单层曲面组合；弯管局部壁配对、复杂坡口链、样条有界识别仍待接入。

## 2026-10-14 CAM 空移规划与逐段调整

左侧刀路区分为“切割”和“空移”两个页签。切割页保留刀路树和排序工具；空移页仅保留空移策略参数、更新刀路与空移两个 SVG 图标（原生悬停提示），以及当前默认策略选择。策略参数对话框在场景左上；右侧是选中段的持久属性区，没有关闭叉号和窗口取消按钮。右侧预览、保存只作用于该段，列表和视口选择联动。“检测碰撞”只检查当前段的固定曲线或折线，使用独立的 CamRapid.CheckPath 接口；不重算路径、不搜索绕行、不保存工程、不进入自动排序。进度使用 PDO，结束后读取一次任务回执，右侧显示通过状态、原因及障碍物。同一输入版本内切换空移段保留各段检测结果，路径或环境变化后不沿用旧结果。参数语义及与 FACAM 的已知差异见《空移参数与FACAM对照》。

`ISurfaceTravelService` 是中性几何服务，仅接收不可变 BRep、刚体变换、端点姿态及数值参数。快速规划、蛙跳、飞切分别请求 `Retract`、`Arch`、`Follow`，实际空移仍执行完整刀头包络的连续间隙检查。缓存键使用 `SelectableSurfaceTravelV1`，只有当前输入的检查结果可以复用。排序估算与实际空移计算独立，估算耗时不代表机床时间。

## 2026-10-14 轨迹碰撞检测

轨迹仿真播放条提供碰撞检测、取消、进度及前后碰撞位置跳转；未有当前结果时，播放先执行检查。切割、引入、引出和有效空移统一转换为装夹坐标的喷嘴 TCP 与连续四元数姿态。碰撞段与当前碰撞姿态标红，未能确认的连续区间标为未验证；缺少空移不生成虚构连接。切割头弹窗复用空移设置中的碰撞阈值，空移段另加其自身冗余距离。

`IRigidMotionCollisionService` 是框架中性几何服务，接受 BRep/解析实体、刚体标定、障碍物和姿态区间，不访问场景或加工对象。OCC 实现用精确 BRep 距离、双向实体包含、保守空间覆盖和刚体运动位移上界检查线性 TCP／四元数插值区间。无法确认的区间保持 Unchecked。导入模型使用实际 BRep；内置头按当前示意外形检查，结果明确注明示意头。

高阶曲面采用面 BVH 和正权 NURBS 控制点凸包投影作保守距离下界；修剪面上的点只能用于证明碰撞，不能用于证明无碰撞。精确求解设置每段 500 ms 协作预算，取消传入 OCC 进度回调；超限、求解失败或运动区间无法收敛的结果一律为未验证，并保留原因。该预算不是内核单次调用的硬实时保证。`ICAX_COLLISION_PROFILE=1` 可输出开发诊断。

## 2026-10-15 三维刀补接入生成刀路

`CamPlan.Generate` 已调用独立 `ICurveOffset3DService`，由产品把切缝宽度的一半、保留侧、源共边朝向和刀轴方向转换成每段的有符号偏置。反向只改遍历，不翻转物理补偿侧。支持尖角、圆角、斜角连接及去环；原定义保持不变，生成结果保存可重新求值的 offset law、原生参数、连接段和删除环。精确曲线二进制格式为 2，JSON 清单格式仍为 1，`exactCurveVersion=2`；生成输入键含算法版本，算法更新使旧结果过期。

## 2026-10-18 支撑板的榫卯插接

新建支撑默认选择“榫卯插接”，也可明确选择“定位拼焊”。井字插接采用整块 X／Y 板：X 板从下侧开槽，Y 板从上侧开槽，每个交叉位置按照两块板在全槽宽内的最低轮廓共用搭接高度，并留出总配合间隙。先将 Y 板插入底座，再向下装入 X 板。梅花与平行板只需要向下插入相应底座榫孔。支撑底部出榫，底座开真正的贯穿矩形孔，榫长等于底座厚度，装配后底面齐平。

界面提供总配合间隙、底部榫宽、底部榫间距和榫卯最小保留板带。间隙是孔与榫的成品尺寸差，槽宽为配合板厚加总间隙，不在此处重复进行切割割缝补偿。榫孔之间、榫孔与底座边缘、搭接槽与板边均校验保留板带；开槽导致板件断开、没有足够底边布榫或失去承托接触时拒绝生成，原已采用装配保持不变。梅花边界的接触面裁窄时，低位连接板带保留设定支脚宽度用于布榫，上端仍按真实接触面裁切；该板带始终低于工件最低点。被生成区域边界裁得不足以保留插榫和板带的单元不生成，并按最终实际接触重新评估承托分布。

中性几何服务返回外轮廓、内孔、成对连接的几何索引及方向；Scene SDO 映射板件 ID、连接对编号、资源和持久化状态。实际 CAD 实体、候选三维预览、板件缩略图、1:1 DXF 的 CUT_OUTER／CUT_INNER、SVG、PDF 和导出清单共用同一组轮廓。底座定位标注使用独立的板身范围，不从出榫后的首两个顶点猜测；装配图编号避开榫孔，支撑页标明 X／Y 装配组。

原生报告 `output/tests/fixture-joinery-regression-final.json` 包含 22 项回归；`output/tests/fixture-joinery-final-native.json` 专项核对独立 CAD 实体的体积、插榫与榫孔的材料状态、上下搭接空隙、装配中间高度、梅花边缘的低位支脚、DXF 内孔回读以及保存重开。圆盖完整界面流程见 `output/tests/fixture-joinery-package-browser-verified`；新榫宽控件的异步焦点、选区、节点、画布、双侧栏与夹具列表内部滚动检查见 `output/tests/fixture-joinery-controls-browser`。最终两套下料包见 `output/tests/fixture-joinery-delivery-grid-final` 和 `output/tests/fixture-joinery-delivery-staggered-final`，汇总见 `output/tests/fixture-joinery-acceptance.json`。验证包为 `output/releases/FiveAxisCAM-Fixture-Debug-20261018-joinery`；仍是几何装配验收，不包含强度、夹紧、焊接与实机加工资格确认。

## 2026-10-18 刀轴姿态的影响范围与曲线

在“编辑关键点”中先选择主姿态，再点击“选择受影响姿态”。同一刀路的参考姿态可在三维点选、Shift 连选或“连续选择”模式中加入跟随范围；右侧列表也可选择、全选和清空。黄色为主姿态，橙色为跟随姿态，灰色参考姿态保持原方向。影响曲线的横轴为相对主姿态的沿刀路距离，纵轴为跟随比例；可上下拖动曲线点、用方向键微调，或通过“当前曲线点”选择密集点并输入 0～100%。提供等量跟随、线性衰减和平滑衰减，点间过渡可单独选择线性或平滑。旋转环、IJK、欧拉角、工件／装夹坐标、反向、恢复和删除沿用已有编辑入口。

Scene 命令以精确曲线来源位置保存影响目标、原始方向、权重和过渡形式；前端不提交可信基准方向。重复修改基于保存的原始方向计算，不累积旋转；一次 Apply 是一个事务，支持撤销、重做与工程保存重开。不同主姿态的显式目标不允许重叠；可先在原主姿态中取消该目标。闭合轮廓的起终点别名不会锁定自己的跟随点。打断刀路时将物理姿态控制保留到各自片段，避免跨片段的悬空影响关系。平滑区间在生成时按姿态误差细分，保留精确源参数与几何曲线，不仅改变显示箭头。

矢量直接旋转、数值调角等交互参考 [SprutCAM X 自定义矢量](https://kb.sprutcam.com/docs/SprutCAM/17/en/10134.html)；显式跟随范围与影响曲线按本次产品要求实现。验证记录在 `output/tests/axis-influence`：原生姿态／影响回归、打包页面的真实三维点击和曲线拖拽、ICPS 生成采样核对、保存重开、撤销重做，以及输入节点／监听器／焦点／选区和左右及嵌套滚动保持。独立 CEF 仅验证启动响应，完整编辑流程由 Edge 页面与生产 Scene/SDO 联调覆盖，不代表实机加工验收。

## 2026-10-18 全部刀路方向与圆盖姿态显示

启用的刀路默认显示切割行进方向：普通刀路为蓝色，选中为黄色；名义轮廓、生成后的切割路径和补偿路径共用固定屏幕尺寸箭头。刀轴姿态仍使用紫色，与切割行进方向区分。

原始 `多槽圆盖-3-7b202.igs` 的 125 条刀路中，原先有 116 条因 `CURVE_MEASURE_UNRESOLVED` 无法读取姿态。中性曲线服务现按全部样条节点分段，对转角积分按区间总误差分配细分，避免局部极小误差预算导致失败；初始分面避免对称曲线的误差抵消，节点转角使用稳定的 atan2。保留计算精度与预算限制，不以默认方向替代失败的姿态。

`output/tests/cut-directions/acceptance.json` 汇总验收：原始模型 125 条姿态全部读取、375 个切割方向箭头、选中着色、25 倍缩放与两种投影、反向与撤销、125 条生成路径及保存重开；18 项原生回归包含 534 条非退化边的完整／截取长度和转角一致性以及原有姿态影响编辑。浏览器加载 `FiveAxisCAM-Debug-20261018-directions` 包内页面并连接生产 Scene/SDO，独立 CEF 仅验证启动响应。
# 独立装夹工作页

顶部工作页按“工件、装夹、CAM、孪生、帮助”排列。工件页提供工件管理、“几何”分组、摆放和自身坐标系重置；装夹页集中提供当前装夹的工装管理、导入、支撑夹具设计、装夹静态干涉检查、制造导出与实测校准。锁定工件不阻止工装操作，但实测校准仍需先解锁工件。

装夹页使用当前原生 Setup 和场景资源，切页不复制工件、不重建视口、不变更加工输入。工装选择自动进入装夹页；工装草稿、夹具候选与报告继续归属原装夹。尚未导入工件时提供返回工件页入口。加工区域及同一工件的多次装夹管理属于后续功能，本次拆页不新增对应数据或验收结论。

## 机床实例的轴心与安装位置

在“孪生 → 实例参数”中选中机床部件，右栏直接提供 X、Y、Z 三个位置输入。旋转关节显示“轴心位置”，其他部件显示“安装位置”；单位为 mm，数值表示相对父部件的零位位置。调整这些位置可设置轴间距离和部件安装偏移，FK/IK 仍用于改变关节运动状态。

`Machine.SetElementPosition({entityId,position:[x,y,z]})` 只修改当前实例 `RestPose` 的前三项，拒绝轴方向、旋转、关节类型和父子关系等额外输入，保持 AC/BC/AB 等机型机构不变。固定部件和可动部件共用该入口，不修改内置 SDF/URDF。修改直接提交原生事务并随工程保存，支持撤销、重做和关闭重开。

位置改变使已有机床运动计划过期；旧计划和旧模型键均不能导出。重新规划使用当前轴心和安装位置，重新执行运动与碰撞检查，再由后置输出各轴指令。工件上的切割轮廓和工艺数据保持不变。



### 2026-10-31 CAM 刀路入口与容差浮层

新增和删除位于顶部 CAM 的“刀路管理”组，左侧仅保留刀路列表。新增采用分裂按钮，默认进入批量；下拉提供批量、选边、选加工面。批量选择保留材料上的非加工面集合提取边界，并在操作区的小箭头中设置工件坐标下的加工观察方向（观察者指向工件）；展开时显示三维方向箭头，原生创建根据选中 CAD 面的定向法向确定加工侧。相切而无法确定加工侧的方向会被拒绝，方向修改使候选失效。
