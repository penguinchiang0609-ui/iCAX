iCAX RC-1000 4+1 转盘五轴激光加工中心（自建展示资产）

用途
展示类旋转件由三爪卡盘装夹、工件 C 轴回转与 XYZ+B 刀头支链共同运动的五轴机床。
“4+1”在本资产中表示四个物理轴在刀头侧、一个物理轴在工件侧，五轴均可联动。
这是自主设计的工业布局与几何，不是某品牌的原厂机床、参数或数控控制器。
前面和顶部外罩剖开以观察关节、卡盘和加工空间；不代表实机防护状态。

结构与外表面
11 个部件节点，56 份分材质 STL，共 23,824 个三角面。
包括焊接床身、调平脚、双侧直线导轨与滑块、移动龙门、Y 滑鞍、Z 长滑枕、
B 摆头叉架、实体铜喷嘴、C 轴轴承座、三爪回转卡盘、后罩、电气柜、操作台及三色灯。
每个刚体先将自身全部实体求并集，再保留外表面的材质分区输出。
单份分色 STL 可能是开放的表面片，全部分色表面合起来才构成刚体的闭合外壳。
不同关节的部件保持独立；未将可动结构合并为静态整机网格。

导入
孪生页中选取 RC-1000 4+1 转盘五轴机床定义并创建实例。
也可直接导入本目录 RC-1000.urdf；须保留同目录 meshes 子文件夹。
URDF、STL 使用米；程序内部将直线尺寸换算为 mm，旋转角使用弧度。

两条真实运动支链
刀具侧：床身 -> X 移动龙门 -> Y 滑鞍 -> Z 滑枕与摆头叉架 -> B 摆动激光切割头。
工件侧：床身 -> C 轴轴承座（固定） -> C 三爪回转卡盘 -> 中央装夹承托盘（固定）。
C 不是刀头上的第二根旋转轴。工件装夹在卡盘上，随 C 围绕竖直 Z 轴旋转。
B 绕刀头局部 Y 轴摆动。工作支承与刀具部件分别由显式标签声明，不按名称猜测。

轴限位与装料初始位
X：-600..600 mm；Y：-400..400 mm；Z：-400..120 mm；
B：-120..120 度；C：-180..180 度。
速度上限：X/Y 800 mm/s，Z 500 mm/s，B/C 1.2 rad/s。
icax_home 显式声明 X=0、Y=0、Z=+120 mm、B=0、C=0。
该初始位的物理喷嘴位于 (0,0,550) mm，卡盘中心顶面为 (0,0,0) mm。
源生成器在输出时统一重定部件局部原点；关节原点、网格、碰撞盒、喷嘴与子节点同步补偿。
原先 X 支链 -320 mm 与 Z 滑枕 +320 mm 的布置关系保留，最终局部坐标以 URDF 为准。
X 两根导轨端点为 ±1200 mm；最不利的移动龙门底座仍留有约 60 mm 导轨余量。
Y 导轨端点 ±705 mm；滑鞍最不利位置有 155 mm 余量。
以床身世界坐标核对：Z 主杆在最低位覆盖 Z=380..1430 mm，在最高位覆盖 Z=900..1950 mm；
两端都覆盖滑鞍导向范围 Z=960..1380 mm，最不利端部余量为 50 mm。
上述余量属于展示几何，不是机床精度承诺。

装夹与物理 TCP
工作支承部件：中央装夹承托盘；局部原点位于该盘几何中心。
该盘由半径 100 mm 的中央盘和半径 100..260 mm 的钢环求并集组成，整体半径 260 mm、厚 8 mm，
通过固定关节随 C 卡盘运动，是唯一的 icax_work_support。
该盘局部顶面 Z 约为 +4 mm；承托顶面的床身世界高度仍为 Z=0 mm。
中央盘和钢环的真实顶面均为世界 Z=0 mm，完整平承面直径 520 mm。
钢环已从 C 主体移到工作支承，源网格只保留一份，没有重叠的顶面。
卡盘外径 540 mm；三爪固定径向占用约 130..280 mm，比承托面最高高出 66 mm。
三只夹爪整体相对旧位置径向外移 30 mm，固定开口内径为 260 mm；对应碰撞盒同步外移。
直径 202 mm 的圆柱工装与每爪内面留出约 29 mm 径向空间，便于 CAM 仿真放入。
自动摆放读取中央承托盘的局部顶面，再随真实支承 frame 转入世界坐标，工件落在世界 Z=0。
夹爪属于 C 刚体，旋转卡盘时同步运动；演示工件须按自身底部/夹持尺寸摆放，
不提供开合或液压控制；初始机床资产没有装载工件。
刀具部件：B 摆动激光切割头；icax_tool tcp_mm="0 0 -220"，beam="0 0 -1"。
TCP 对应铜喷嘴的真实端面中心。跟随高度由作业 followHeightMm 另加，不并入物理 TCP。

源局部原点
平移关节和固定子部件的原点置于自身全部可视网格包围盒中心；根床身原点保持不动。
旋转部件只沿真实旋转轴平移原点，将几何中心投影到轴线上，完整物理转轴线保持不变。
C 卡盘原点原距几何中心约 36.500 mm，现在位于几何中心。
B 刀头几何中心距真实 Y 转轴线约 59.003 mm，沿轴无法消除的垂直距离保留。
平移部件原点到自身几何中心的距离，重定前 -> 重定后：
  X 移动龙门：904.500 -> 0 mm
  Y 滑鞍：1274.823 -> 0 mm
  Z 滑枕与摆头叉架：561.500 -> 0 mm
固定子部件 C 轴轴承座、中央承托盘、外罩、电气柜、操作台均已居中。
重定是局部 frame 的纯平移，轴型、轴方向、关节顺序、行程、初始位及速度都保持原值。
网格顶点和碰撞盒中心减去本部件平移量 c；子关节采用 T(-c_parent) O T(c_child)。
旋转部件的 c 与轴平行，平移部件的 c 与其平移运动可交换，因此任意关节位置下物理外形保持。
重建脚本每次都执行同一重定步骤，不会重新输出偏离自身几何中心的平移部件原点。
独立审查覆盖 128 组随机轴位置及零位、初始位和各轴两端，共 140 组；每组核对全部 72,066 个
STL 面顶点，世界位置最大变化 0.000060 mm，来自 STL float32 重写量化；碰撞盒角点、物理
TCP 与真实旋转轴线最大差均小于 0.000000001 mm。该精度说明不作为原厂机械精度承诺。

碰撞包络
碰撞盒独立于显示表面。空心龙门、叉架、外罩分成多个盒体，保留加工空间。
卡盘基体、三只夹爪、台面螺栓分别声明包络；夹爪使用与其朝向一致的旋转盒。
切割头采用多个保守盒体覆盖头身、铜喷嘴、物理接头和上部软管。
喷嘴锥段与末端薄层在局部 Z=-214 mm 处分开；每侧预留 0.001 mm 浮点覆盖余量。
当前初始位为装料位；关节限位内的任意组合仍须由作业规划做碰撞与超程检查。
这些盒体不构成原厂安全包络；加速度、夹紧力、防护联锁与实机 NC 标定不包含在本资产中。

生成与独立审查
安装 ../requirements-build.txt 后用 Python 3 执行 build_model.py。
生成依赖 manifold3d 与 NumPy，仅用于离线制备，不进入应用运行环境。
脚本写回本目录 STL 与 URDF；输出确定，不需要网络或下载模型。
IndustrialMachineSurface.py 可独立审查重复面、退化面、共面重叠与非流形边。
SplitChainMachineAssets.py 另审查两条支链、显式角色、物理喷嘴端点及碰撞盒包络。
上述静态审查不等同于真实机床加工、实际切割工艺或控制器上机验收。
