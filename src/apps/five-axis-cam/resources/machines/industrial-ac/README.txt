iCAX LC-3015 工业五轴激光加工中心（展示模型）

用途
在 FiveAxisCAM 孪生页展示 URDF 机床实例、工件装夹与 X/Y/Z/C/A 关节运动。
这是按工业设备布局自行制作的展示资产，不是某品牌机床的原厂数字样机。
前方和顶部外罩剖开，以便观察内部运动；不代表实际设备的防护状态。

结构
10 个部件节点，54 份分材质 STL，39,966 个三角面。
生成前安装 ../requirements-build.txt；同一部件先求实体并集，再按表面材质输出。
分色网格合起来构成闭合外表面，不保留实体内部重面和接触面。
包括焊接床身、调平脚、双侧直线导轨及滑块、龙门横梁、Y 滑鞍、Z 滑枕、
C 回转叉架、A 摆动切割头、铜喷嘴、台面夹具槽、电气柜、操作台和三色灯。
各部件分别挂接到实际运动链，非整体外形贴图。

导入
孪生页 -> 机床定义列表 -> LC-3015 工业五轴激光机床 -> 机床实例区“创建实例”。
亦可将本目录整体保留，直接导入 LC-3015.urdf，不能单独移走 URDF 文件。
URDF 与 STL 均以米表达；程序内部采用 mm，旋转轴采用弧度。

装夹标定
工作台/装夹部件：工作台
刀具部件：A 激光切割头
TCP 局部坐标：0, 0, -220 mm
光束局部方向：0, 0, -1
以上由 URDF icax_work_support / icax_tool 明确声明，TCP 是物理喷嘴端点。
作业点击“放到工作台”后，工件与所有启用夹具作为整体居中落在台面（Z = 5 mm）。
喷嘴离板距离另由作业的空移设置 followHeightMm 提供，不能把离板距离算入物理 TCP。
摆放、刀头碰撞模型及 TCP 参数随装夹保存，模板参数仍需实机标定。
原 Z = 30 mm 的侧切摆放作为碰撞反例保留，不可用于加工演示。

运动链
床身 -> X 龙门 -> Y 滑鞍 -> Z 滑枕 -> C 回转叉架 -> A 激光切割头。
工作台固定于床身。C 到 A 中心偏置 220 mm；A 中心到喷嘴尖端 220 mm。
X: -1500..1500 mm; Y: -750..750 mm; Z: -450..150 mm;
C: -180..180 度; A: -120..120 度。
X 关节原点为 -430 mm，补偿滑枕的 +430 mm 刀头偏置。
X 导轨长 3900 mm，极限位置滑块余量约 232.5 mm；Y 余量 130 mm。
Z 滑枕长 1600 mm，最不利位置仍覆盖全部滑鞍导向区并保留 120 mm 余量。
Z 的声明初始装料位置为 +150 mm，其他轴为 0；此时物理喷嘴高度为 360 mm。
“回到初始位”采用上述声明位置并检查移动，不把 Z = +150 mm 称作轴零位。
这些是本展示模型的参数，不是原厂性能承诺。

验证范围
轴限位、逆运动学、工件随工作台摆放、保存并在新程序进程中重新打开。
仿真检查起始接近段和逐段关节线性插补，以当前有效的原生计划驱动整机各轴。
未完成检测、碰撞或超程的候选不能执行或导出；可静态查看被拒绝候选的干涉位置。
刀头碰撞模型由装夹配置 toolCollisionRepresentation 明确选择：
  OwnMesh（真实刀头网格）：完整切割头的六份可视 STL、6,278 个三角面参与精确检测；
    六份分色表面在刀头坐标系中共同组成一个经闭合验证的实体；
    刀头碰撞盒只用于快速筛选。内置“放到工作台”采用此模式。
  Boxes（自定义碰撞盒）：刀头按实例中编辑的盒体检测，调整位置、角度、尺寸会改变检测范围。
    新手动配置默认此模式；已有配置必须明确保存所选模式，不做隐式回退。
两种模式下其他机床部件仍使用各自的碰撞盒，工件与启用夹具均采用自身网格。
空心结构用多个盒子留出空间；盒体检测结论不宣称精确 CAD 穿透。
切割头六个保守包络盒完整覆盖头体、喷嘴、接头和回转软管；喷嘴在 Z = -214 mm 分为
末端薄层与上部锥段，边界每侧增加 0.001 mm 以覆盖 STL 浮点坐标与接缝。
实际报告 collisionRepresentation 记录本次采用的检测模型，不能把示意切割头的检测替代整机报告。
同一刚体组、直接关节连接的机械接触副不作为自碰撞对；检测对及排除对写入结果。
播放时长受 URDF 各轴速度上限约束。加速度、控制器插补及实际 NC 验收未包含。

复现模型
使用 Python 3 运行 build_model.py；仅依赖标准库，输出确定的 STL 和 URDF。
生成声明同时保留六个头部碰撞盒的名称、完整包络、工作台/物理喷嘴端点及 Z 装料初始位。
生成脚本会写回本目录的 STL 和 URDF；只读审查使用语法树与现有 URDF 对照，不执行生成脚本。

孪生页工作流
机床定义：导入 URDF、启用/禁用、删除定义、创建实例。
机床实例：独立调整轴行程、按步长点动和回到初始位、设置本实例后置。
作业：选择工件装夹和机床实例，放到工作台，明确刀头碰撞模型，采用后置配置，规划轴运动并仿真。
后置随实例保存，作业直接继承。修改实例或后置后须重新检查。
工程保存包含关节零位、当前轴位置、嵌入网格、后置和装夹绑定。

可配置后置
轴运动 JSON：包含真实关节位置、轴字、正负方向/零位偏置、段时间与加工开关状态。
逆时间 NC：各轴绝对坐标，角轴为度、直线轴为 mm；F = 60 / 段秒数。
运动行可配置 {axes}、{feed}、{line}，程序头尾和加工启停由实例后置指定。
NC 初始轴位置作为起始条件写入程序注释，不额外插入未经验证的定位运动。
规划使用实例轴链、转轴中心、TCP、行程、速度上限和后置加工/空移进给。
导出读取已保存且当前有效的原生计划，不重新选择另一条关节分支，也不接受前端伪造的通过报告。
完整轴帧与运动指令经固定版本资源传输，不截帧或降低关节坐标、时间精度。
当前未提供原厂已标定后置，不代表实机控制器、加速度、激光工艺与上机验收通过。
逆时间语义参考：https://www.linuxcnc.org/docs/html/gcode/g-code.html#gcode:g93-g94-g95
