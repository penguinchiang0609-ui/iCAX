# 龙门切割头与轴分配

五种定义共用 LC-3015 的龙门、X/Y/Z 滑动支链与行程。每个目录均为可独立导入的完整 URDF 和 STL；未修改旧项目使用的四种定义。

| 定义 | 刀头支链（由外至内） | 工件支链 | 轴方向 |
| --- | --- | --- | --- |
| GAC-3015 | C → A | 固定台面 | C 绕 Z，A 绕 X |
| GAB-3015 | B → A | 固定台面 | B 绕 Y，A 绕 X |
| GBC-3015 | C → B | 固定台面 | C 绕 Z，B 绕 Y |
| GA-3015 · 4+1 | 固定叉架 → A | C 转盘 | A 绕 X，C 绕 Z |
| GF-3015 · 3+2 | 固定喷嘴，无回转关节 | A 摇篮 → C 转台 | A 绕 X，C 绕 Z |

这里的 3+2 / 4+1 表示刀具、工件两侧的结构分配，不表示分度加工或联动轴数的软件模式。固定头不伪装成自由转向的双回转头；单摆头也没有第二个刀头回转轴。

在“切割头设置”的“龙门刀头”中选型，可显示机构和喷嘴的分体姿态。在机床仿真中选择并绑定实际机床，再执行机床运动规划。整机规划沿真实两条支链求解，使用各部件碰撞盒与工件、夹具网格作连续检查，检查通过后才允许播放和输出。

CAM 分体显示属于姿态预览，不替代机床可达性证明。未绑定机床时，新的刀头不允许用旧的喷嘴刚体检查冒充完整机构通过。绑定后，CAM 独立碰撞视图仍明确检查喷嘴部件；完整叉架、刀头、工作台和其他部件由机床仿真检查。机床实例编辑的原点、网格、标定会用于绑定后的显示。

`build_models.py` 仅使用 Python 标准库，读取仓库已有自主设计资产，确定性地生成这五种定义，不在应用运行时执行。AB 头采用沿 Y 的后置电机和沿 X 的侧置电机；BC 的叉架、喷嘴、标定与碰撞盒同步转向；3+2 采用固定喷嘴，并将双回转工作台安装到龙门床身的独立支承上。每个头部三角面完整覆盖在一个凸碰撞盒内，支架外侧不以大盒封堵空白。

`catalog.json` 声明头部装配边界和轴分配；产品清单登记同一套源定义。目录版本 2 只向旧安装加入本次新机型，不恢复此前删除的旧定义，也不覆盖已有实例、用户名称或禁用状态。

验证入口：`GantryHeadAssets.py`（独立轴向、支链、TCP 和头部表面覆盖审查）、`FiveAxisGantryHeads` / `FiveAxisGantryHeadPlans` / `FiveAxisBuiltinHead`（原生导入、求解、连续碰撞、完整规划、输出和保存重开）、`FiveAxisGantryHeads.native.browser.mjs`（真实原生资源与 WebGL、五种切换、分体姿态、两侧及嵌套滚动、焦点、选区和节点保留）。

完整规划回归采用 A/B=0.15 rad、C=0.25 rad 的非奇异初始姿态和明确的速度、加速度、加加速度边界；关节与连续碰撞回归从默认初始位开始。某些直立奇异姿态或时序配置仍可能被现有求解器判为未验证，保持禁止播放和输出。本次没有修改时序求解器。

这些资产是自主设计的通用机构，不包含原厂机械标定、控制器后置验收或实机加工资格。

AB 头的三个刚体分别为固定安装座、B 摆轴壳体和 A 激光切割头。B 的实体轴承与转轴沿 Y；A 的侧置电机和轴承沿 X，安装在 B 携带的圆角壳体上。B 运动携带 A 机构，A 单独运动只带动刀体；固定安装座保持不动。零位 A/X、B/Y、C/Z 与机床坐标方向一致，串联关节由父机构携带。内部 link 名称沿用定义中的“B 回转叉架”，不参与轴向推断。

AB 外形参考柏楚官网公开的 [TKF420 AB 机构手册](https://www.bochu.com/pro_mix/平面坡口切割/)，使用圆形安装法兰、封闭圆角摆轴壳体、侧置电机和刀头固定板，撤去原先的大方框。通用模型默认 A=-46°～50°、B=-50°～50°；刀体前置 140 mm 留出实际间隙，喷嘴局部 TCP 保持由刀体声明。模型是自主创建的参考结构，未标为原厂 CAD 或原厂标定。机床、独立刀头预览与碰撞体读取同一份资源。已有工程实例保存嵌入快照，重新选择内置 AB 头读取新版资源。

“切割头模型”的“预览转角”按真实关节轴及限位旋转，各轴标明 A/绕 X、B/绕 Y、C/绕 Z。这里的转角只用于观察结构，不修改保存的机床位置、刀头标定或加工姿态。导入机构尚未标定时，不显示臆造的 TCP 或光束标记。
