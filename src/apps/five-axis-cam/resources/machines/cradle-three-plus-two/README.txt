iCAX TC-800 3+2 摇篮式五轴激光机床（自主设计展示资产）

用途与结构
这是按工业设备布局自主设计的示意模型，没有对应品牌或原厂数字样机。
3+2 表示三个直线轴在刀头分支、两个回转轴在工件分支的结构分配，
五个物理轴均可联动，不把 A/C 限制为仅定位加工。
刀头分支：床身 → X 悬臂横滑座 → Y 滑鞍 → Z 滑枕 → 固定激光切割头。
工件分支：床身 → A 摇篮（绕 X）→ C 回转工作台（绕摇篮局部 Z）。
工件和夹具装夹到 C 回转工作台后随 A/C 联动，刀头保持竖直光束。
X/Y/Z 是直线运动，A 的正向服从绕 X 右手定则，C 的正向服从局部 Z 右手定则。

外观包括焊接床身、调平脚、双侧耳轴支承和轴承盖、U 形摇篮、
直径 800 mm 圆转盘、上置横梁、侧置 Y 悬臂导轨和跨接滑鞍、Z 长滑枕、
真实铜喷嘴、电气柜、操作台、三色灯和剖开前方/顶部的防护罩。
剖视是展示方式，不代表实际机床的防护状态。
10 个刚体节点，50 份分材质 STL，22,274 个三角面。
同一刚体先用实体并集合并，再按保留的外表面材质输出，去除内部面与接触重面。
分材质网格要合起来看作该刚体的闭合外表面。

导入和单位
FiveAxisCAM 孪生页导入本目录 TC-800.urdf；保留相邻 meshes 目录。
URDF/STL 使用米，程序内部换算为 mm；回转角度使用弧度。
界面显示名称与资产中的工作台/刀头标记一致，不依赖名称猜测用途。

部件原点与源坐标
导出时把各部件 frame 平移到自己的可视包围中心附近，原点由源数据声明。
直线轴与固定节点可自由平移；A/C 回转节点只沿本身轴向平移，保留真实轴线。
床身根节点保留原世界基准。所有轴向、关节类型、父子关系、角度、行程、速度和初始位均不改变。
下列为相对于生成脚本原工程坐标的 frame 平移量（mm）：
  X 悬臂横滑座：-254.5, 51.75, 2155
  Y 滑鞍：-112.5, 0, 1918.75
  Z 滑枕：0, 1.5, 500
  固定激光切割头：0, -3, -102.5
  A 摇篮：0, 0, 0（可视中心的轴向投影）
  C 回转工作台：0, 0, -80
  外罩：0, 151, 1425；电气柜：1810, 653.5, 890；操作台：1580, -850, 825
各 STL 保留原工程坐标和原始字节，visual.origin 用 -c 补偿，避免再次量化网格坐标。
碰撞附件和 TCP 同样减去 c，子关节原点使用 T(-c_parent) O T(c_child) 补偿。
因此全部轴位置下的实体外形、碰撞体、喷嘴端点与光束方向都保持原世界位置。
生成器确定性输出这些变换，不依靠界面或操纵器的位置补丁。

运动轴、限位与初始位（本展示资产参数，不是厂商性能承诺）
X：-650..650 mm；Y：-380..380 mm；Z：-550..250 mm。
A：-110..110 度；C：-180..180 度。
X/Y 最大速度 800 mm/s，Z 最大速度 600 mm/s；A 1.2 rad/s，C 1.5 rad/s。
初始装料位 X=0、Y=0、Z=250 mm、A=0、C=0；由各关节 icax_home 明确声明。
Z 零位时滑枕 frame 的床身坐标为 (0,1.5,2100) mm。
初始刀头 frame 在床身坐标 (0,-3,1747.5) mm，实际喷嘴尖端仍为 (0,0,1600) mm。
初始转盘顶面中心 (0,0,1000) mm；喷嘴与空台面净空 600 mm。
直立台面中心上方 10 mm 的接近位置对应 X=0、Y=0、Z=-340 mm，位于轴行程内。
具体工件、夹具和联动轨迹仍须使用当前实例的原生规划/碰撞检查。

摇篮与装夹基准
A 轴线为床身中的 (x,0,1000)；C 轴线在 A 零位时为 (0,0,z)。
两个旋转轴相交于 (0,0,1000) mm。
C 回转工作台的 frame 在转盘包围中心，沿真实 C 轴位于床身 Z=920 mm。
转盘顶面中心的局部坐标为 (0,0,80) mm，物理台面中心仍在床身 Z=1000 mm。
icax_work_support 标记位于 C 回转工作台，不在固定床身或 A 摇篮上。
自动装夹使用本部件碰撞包络顶面 Z=80 mm，不把居中 frame 误认为台面。
台面半径 400 mm；转盘主体位于局部 Z=10..80，传动鼓向下到 -80 mm。
A 摇篮横梁位于旋转中心下 280 mm，保留加工空腔。

工具标定
icax_tool 标记属于固定激光切割头。
TCP 局部坐标 (0,3,-147.5) mm，精确落在物理铜喷嘴底面中心。
光束方向 (0,0,-1)。CAM 离板高度由作业 followHeightMm 单独控制；
不把 10 mm 焦点/接近距离写入物理 TCP。
喷嘴末端薄层盒与上部锥体盒分别声明，避免用整个头体替代端点包络。

导轨与碰撞包络（未特别注明的尺寸沿用床身工程基准）
X 轨道范围 -1090..1090 mm，滑座中心在刀头左侧 250 mm，半宽 170 mm；
X 全行程的最小滑座端部余量 20 mm。
Y 轨道范围 -535..665 mm，导块中心在 Y±85 mm、半长 47.5 mm；
Y 全行程的最小端部余量 22.5 mm。
Z 导轨在重定后的滑枕局部 -590..590 mm，床身中的静态导向区 1800..2000 mm；
Z 全行程最小覆盖余量 40 mm，另一端最不利余量 140 mm。
Y 悬臂放在刀头左侧，右缘 X=-110 mm，Z 滑枕外缘 X=-103.5 mm，
两者留出 6.5 mm 横向间隙，避免滑枕穿过上方悬臂。
固定门架中心位于 Y=900 mm，给 Y=380 mm 端部的滑鞍与长滑枕留出空间；
上方伺服罩保持在侧置悬臂轮廓内，避免 Y 后端滑枕碰到伺服罩。
Y 滑鞍为前后跨接、侧面导向的 U 形架，中央头部通道贯通，
装料高度下的切割头从通道穿过；左右导向块覆盖滑枕导轨接触区。
通道保守盒边界为 X±105 mm、Y±130 mm；滑枕/导轨最大 X±103.5 mm，
底法兰最大 X±100 mm，因此整个 Z 行程都保留至少 1.5 mm 横向净空。
各刚体使用独立碰撞盒；床身、耳轴和空心摇篮分盒包络，不封死加工空间。
全部 62 个盒体覆盖可视 STL 外表面，包括轴承盖螺钉、导轨螺钉、灯柱和面板。
圆台面采用八条保守分片包络，避免用一个方盒的空角在 C 回转时扫进耳轴支承。
每侧额外保留 0.001 mm 包络余量，以覆盖 STL 的 float32 存储误差。
连接机械副按运行时规则处理；盒体是保守检测包络，不替代精确 CAD 实体。
侧栏主动进入指定碰撞盒的编辑时才调整包络，不改变对应的可视几何。

重建
安装 ../requirements-build.txt 后使用 Python 3 运行本目录 build_model.py。
脚本只生成本目录 STL/URDF，输出稳定可复现，不修改运行时代码或共享模型。
当前资产不含原厂后置、控制器验收、加速度标定与真实激光加工工艺认证。
