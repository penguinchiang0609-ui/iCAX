# 独立切割头

AC、AB、BC、A 单摆和固定头的喷嘴细端均在原模型基础上加长 80 mm。
细端沿长锥形收至 1 mm 外径，主体、关节、回转轴及限位保持原定义。
锥形碰撞体使用长度不超过 2 mm 的分段盒，末端不使用主体宽度的大方盒。

TCP 是非接触加工的虚拟切割点：实体喷嘴端面中心沿末端激光方向向外
0.2 mm。碰撞盒只覆盖实体模型，不把这段光束间隙当作实体。
正常切割的额外跟随高度为 0，避免重复叠加喷嘴间隙。

`build_heads.py` 从 `../machines/gantry-heads` 生成这些独立资源，不修改
孪生机床资源。运行后用 `src/tests/icax-plugins/cam/LongNozzleHeadAssets.py`
检查模型闭合、碰撞覆盖、关节和 TCP 偏移。

已保存工程与“我的”中的刀头是嵌入快照，不随系统资源自动替换；已保存的
跟随高度也保留原值。更新这些已有数据须明确选择相应目标。
