# 装夹工序、整任务仿真与输出

CAM 内的当前装夹独立保存刀路、刀轴姿态、空移、切割头与局部检查。选择其他装夹会清理上一装夹的临时编辑、预览和播放状态，读取该装夹自己的数据。

三点定位资料保存在装夹的 `RegistrationPlan`，不写入共享工件。定位窗口显示所属装夹，切换时读取该装夹自己的 P1/P2/P3；新增装夹不继承上一装夹的定位资料。定位资料导出包含 `setupId`、装夹名称与当前装夹坐标，摆放或工件几何改变后须重新保存。

每个模型点可填写对应的机床实测 X/Y/Z（mm）。Scene 从真实几何重新求装夹三点，调用中性刚体配准服务拟合 `Setup -> Machine`，同时保存原始实测点、允许误差、拟合误差及刚体矩阵；不修改工件几何、摆放或本地刀路。重合、共线、非有限坐标、配对误差超限不能保存机床定位。仅选模型点也可保存为未测量状态，但未完成或过期的机床定位会阻止统一输出。

CAM 和孪生页的“整个加工任务”入口管理全工程装夹的执行顺序。顺序由 Scene 的装夹 `Sequence` 持久化，`CamSetup.SetSequence` 一次提交完整排列，拒绝遗漏、重复与未知装夹；支持撤销、重做和命令回执。顺序修改不改写装夹内的刀路顺序与几何。

整任务预览按保存顺序逐装夹运行既有轨迹播放器。装夹结束时暂停，显示 `M00` 换装夹边界；用户确认重新装夹和定位后才切换到下一装夹。边界两侧不插值、不生成空移。禁用工件的装夹不执行；启用工件存在过期刀路或缺失空移时不能开始。输入变化后需重新开始整任务预览。预览不等于整机验证通过。

`CamSetup.ExportProgram` 从当前 Scene 数据生成 **ICAX-CL 1** 刀位文件（`.cl`），与总仿真使用相同的装夹顺序。切割和空移的每个刀位均由当前装夹定位矩阵转换到机床系：点为 `R*P+T`、方向为 `R*D`，刀轴不加平移。文件在全部工序验证完后原子写入并回读。失败不覆盖已有文件。编辑及轨迹预览仍在装夹坐标系内，保持原有模型、工装和刀路的相对关系。

- `UNITS/MM`：长度单位。
- `FRAME/MACHINE`：后续刀位属于实测定位后的机床坐标系。
- `FROM/x,y,z,i,j,k`：当前装夹初始刀位声明，不是上一装夹到此处的运动。
- `GOTO/x,y,z,i,j,k`：喷嘴 TCP 和单位刀轴向量。切割目标按跟随高度转换，空移已有 TCP 不重复偏置。
- `PROCESS/ON`、`PROCESS/OFF`：加工开关意图；`RAPID` 表示本装夹内已生成的空移段。
- `M00`：停止，重新装夹并建立下一装夹坐标；下一工序重新以 `FROM` 开始。
- `FINI`：任务结束。

这是采样刀位中间格式，保留五轴刀位与刀轴意图，`machineReady=false`。它不是特定控制系统的 NC 程序；真实机床的运动学、轴角、开光指令、进给与后处理仍须单独接入。文件内同时明确标识此边界。
