# TubeOne

TubeOne 是基于 iCAX 的管材 CAM 产品，首版只覆盖从管件模型到 NC 输出的编程主链路，不包含订单、管理和拆单模块。

当前范围：

- `管件`：导入 STEP/STP/IGS/IGES 管件，从平移不变的侧壁识别二维材料区域、轴向和拉伸范围；截面允许任意曲线边界和任意数量内腔，不按管型硬编码。
- `编程`：识别一个管件上的多个孔、切口和闭合轮廓，生成并组织刀路，配置工艺事件，执行轨迹规划、碰撞检查和运动仿真。
- `机床`：导入 SDF/URDF 机床定义，实例化机床，维护运动轴、TCP、光束方向和约束。
- `输出`：选择后处理器，预览并导出 NC。

数据边界：

- 产品与项目隔离由 iCAX 的 Product Channel 和 Scene Channel 完成，SDO 名称不重复携带产品名。
- Workpiece Entity 只引用 `tube.neutral_geometry` 资源；标准截面拉伸体、参数化减材、半参数化复合体和最终 residual BRep 统一由一棵 CSG 图表达。
- 中性 CSG v5 包含等截面拉伸、相似截面渐缩体、半空间、布尔、变换、稳定 Side Atlas 上的 UV 法向体和开口剖面扫掠。每个可编辑特征还可保存对母材的构造依赖、参数可观测性以及编辑后的动态范围规则。
- “贯穿”不是固定长度标签。`ThroughAllHostMaterial` 和 `ThroughSelectedHostBoundaries` 在母材截面或尺寸变化后重新解析有限求值范围；`BlindFromHostBoundary` 保持指定开口与内部终止关系。当前有限 First/Last 只是求值快照。
- BRep 反推同时使用毛坯 `B`、最终零件 `P` 和缺失材料 `R=B-P`：`B` 区分母体继承边界与造型生成边界，`P` 保存可回指的碎面证据，`R` 负责候选覆盖和组合验证。连通 Solid 只用于求值，不直接充当特征单位。
- 生成侧壁不依赖 OCC 的 Cylinder/Cone 类型作识别门槛。采样切平面 `π=(n,c)` 后求共同射影中心：中心位于无穷远得到拉伸方向，有限中心得到锥心；解析面类型只作为参数提取加速器。圆柱、方管、工字钢和 NURBS 碎面不进入管型分支。
- 差集的连通 Solid 不等于特征。同一个支管生成体可以覆盖多腔管上的多个不连续 `MaterialSpan`；反过来，同一组面也可以同时进入“一个跨材料生成体”和“多个独立同轴切割”的 optional 候选。
- 等截面拉伸和圆锥/锥台均已接入切平面共识识别；识别出方向后用垂直虚拟截面恢复任意二维 Region，NURBS 截面保留次数、控制点、权重、节点和重数。多材料跨度仍保留为同一生成体的多个 `MaterialSpan`。
- 相交的截断、孔和坡口允许分别作为完整缺失体的子集，最终通过候选并集验证，不再要求每个特征单独等于整个连通缺失体。
- 自动拆解失败时只把未识别局部保存成 `CompositeVolume`。它保留精确 BRep、解析曲面分类、参数和面邻接关系，可整体编辑、直接面编辑或由用户提升为参数化特征；完全不透明的 `ResidualBRep` 是最后一级保底。
- 同一局部 BRep 若有多种几何等价的构造解释，使用 `AlternativeNode` 保存全部 `optional` 候选及评价向量：拟合/误删/漏删、证据覆盖、参数可观测性、模型与场复杂度、扰动稳定性和编辑稳定性。例如同一锥面可解释为真锥体，也可解释为直孔加全深开口剖面。推荐候选不等于选定候选；人工或策略选择之前，刀路编译保持“待解释选择”状态。
- 坡口的权威表达不是角度和钝边，而是沿开口物理弧长变化的二维壁厚剖面曲线场；直线、折线、圆弧和 NURBS 可统一表达整圈变坡、局部坡及 X/K/J/U 形。角度、深度和钝边仅作为派生信息。
- “截断”是特征相对母材的 `Truncation` 关系，不是新的几何原语。它可由全局半空间、拉伸/锥形生成体或多个局部生成体实现；孔与截断相交时先分别生成子集候选，再验证候选并集，无法拆开的局部才进入 `CompositeVolume`。
- UV 法向截断不依赖某个 CAD 系统的曲面天然 UV。识别器先从毛坯截面构造以物理弧长和轴向距离为坐标的稳定 Side Atlas，再把缺失材料边界投影到该参数域，并以沿母材法向的材料射线验证体积关系。圆管周向法向连续变化、方管分片侧壁和端部阶梯截断使用同一表达。
- 对可以确定穿越关系的减材节点，只派生三种几何结果：贯穿、盲、气泡；不区分外壁、内腔壁或腔间隔板。“气泡”表示完全位于材料内部且没有入口的空腔。无法可靠分类属于识别状态，不构造第四种穿越类型。盲特征只表示“从既有边界开口并在材料内部终止”，不预先决定打标、激光半切、钻削或铣削。
- 深度为零的几何不伪造空的 CSG 减材体，而是保存为 `UVFeature`：矢量曲线、矢量区域或图片均稳定依附于 Side Atlas。UV 类型只说明“位于表面”，后续策略再决定打标、浅刻、铣削或切割。
- 截面内腔属于二维材料区域；侧壁孔、切口及坡口属于三维 CSG 减材，两者不混为“多孔”。`Toolpath.RecognizeLoops` 可一次识别多个候选加工轮廓并生成 Path Entity。
- 几何、拓扑、刀路、机床与仿真继续进入主 Scene 的 Database / Resources，不使用产品私有 Workspace 数据。

产品页面首个闭环：

- 在“管件”页选择 STEP/IGES 文件并导入，点击“识别 CAD 意图”后才展开中性 CSG 结构，避免把导入成功与意图确认混为一个动作。
- 左侧 CSG 树区分管材毛坯、支管贯切体、锥形贯切体、平面截断、UV 法向截断、坡口剖面和复合兜底；中间视口显示当前节点在 `B − R = P` 中的材料角色。
- 选择参数化节点后，右侧可以编辑拉伸范围、位置、锥度或法向偏移；修改通过 `CADIntent.SetParameters` 写回同一中性资源的新版本。存在多种解释时，可通过 `CADIntent.SelectInterpretation` 明确记录人工选择。
- 当前参数编辑已经完成中性模型的版本化写回；把修改后的 CSG 重新求值为 OCC BRep 并刷新三维网格，是下一条产品化链路。

未来的订单、拆单和管理模块可以作为新的产品模块接入，但不进入当前 CAM 首版的功能和数据模型。
