# BRep → CamPath 服务

接口：`iCAX::CAM::IBRepToCamPathService::Analyze(const BRepModel&, options)`。
返回 `CamPathAnalysis`，包含独立 `CamPath` 集合、识别提示及完整性标志；不接收项目、场景或文件路径。

## 识别顺序

1. 将 BRep 装配拆为各实体，分别识别拉伸轴。原装配位置不作为轴方向假设。
2. 在临时规范坐标系中恢复截面，识别沿轴不变且属于截面边界的侧面。内、外纵向管壁均为侧面；锥面不属于等截面拉伸侧面。
3. 排除侧面，保留端面、孔壁、槽壁、斜切等特征面。将相邻特征面按公共拓扑缝合分组。
4. 从特征面组提取外侧切入轮廓。去除组内公共边、参数接缝、退化边和内侧重复轮廓；连接仅发生在同一特征组的共享拓扑之间。
5. 将轮廓恢复到输入 BRep 的世界坐标，输出拥有自身数据的 CamPath。释放 BRep 不影响输出。

带孔的大侧面不能因为含有内环就获得高额“端面”评分，否则会把钻孔方向当作拉伸轴。平切端面也不能因边界落在截面上而被当作侧面排除。

## 数据与边界

- 当前输出为毫米单位的**独立名义刀路**，不是可以直接下发机床的加工程序。
- 编辑器使用 `CompositeCurve3` 中的单段 `Polyline3`；保留直线端点及拓扑拐角，曲线采用 OCCT 挠度采样（默认容差 0.001 mm）。不是原始解析圆弧/NURBS 的无损编辑。
- `Poses` 可为空：没有证明有效方向律时不臆造刀姿；带方向的兼容直纹特征输出也需要后续工艺校验。
- 内侧重复轮廓不作为另一条外切刀路。无法证明为外侧连续轮廓的特征给出提示；兼容直纹求解器可提供已识别部分。调用方必须显示 `Complete=false` 和诊断。
- 未识别出任何刀路时，产品适配层拒绝替换旧分析；服务本身允许返回空结果及诊断。
- 尚不保证任意自由曲面、变截面型材、多腔复杂分支、坡口复合刀姿的完整解析。应按模型检查诊断，不能把轮廓显示成功当成加工验证成功。
- 不生成引线、微连、刀补、加工排序、机床关节坐标或切割头碰撞检测。

## 接入及所有权

实现通过现有服务目录注册，目前编入 TubeDesigner 模块，由产品清单的 services 项加载；服务接口与产品界面无依赖。
`MachiningToolpaths.cpp` 仅负责服务输出与项目持久化数据之间的适配、校验。

加工项目只保存独立路径值与来源标识，路径不持有 CAD 面、边或资源指针。关联下料排样不复制持久 BRep；分析时临时建立与排样 STEP 导出一致的几何，结果生成后临时几何释放。
原 CAD/下料变化不重算刀路。只有用户主动“分析所选 / 分析全部”才能替换目标分析，必须确认此前编辑将丢失。批量分析完成后统一提交；异常不提交部分覆盖。

编辑保存检查加工任务版本和刀路分析版本。CAD 背景显示失败不影响已生成刀路的显示、编辑或保存。

## 验证

`TubeDesignerTest --gtest_filter=BRepToCamPath.*`：方管外端轮廓、圆管端部/接缝排除、任意旋转的穿孔方管、STEP/IGES 装配位置及分析、输入释放后的输出所有权、持久化校验。

`TubeDesignerMachiningTest.mjs`：复制独立性、变换、打断/合并、重分析确认/作用范围、保存版本、CAD 失效时路径保留。

`TubeDesignerMachining.browser.mjs`：使用实际编辑组件及 WebGL 视图，在独立浏览器中验证二维/三维绘制、拾取、列表/属性联动、复制变换、打断合并、撤销重做和布局。
