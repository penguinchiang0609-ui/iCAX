# ExtrusionRecognition

`ExtrusionRecognition` 是与管材、型钢等产品解耦的拉伸体基础识别插件。

- Service 输入尚未进入资源池的中立 `GeometryData::BRepModel`。
- Service 按调用方传入顺序执行外部声明式截面类型定义，首个匹配成功的定义生效。
- 成功结果包含规范化 BRep、截面类型 ID、动态参数和长度；资源发布与业务组件创建由调用方负责。
- C++ 扩展点是可复用的规则算子 `ISectionRuleOperator`，不是具体管型类。
- Service 不持有 Product、Project、Scene、资源池或匹配顺序状态。

## 管材真实文件阶段回归

识别审阅流程为 `导入 → HealWork → Align → Coutour → Classify → MachiningEdgeAnalysisWork`。`HealWork::Run` 调用中立 `ICadBRepHealService`，先规范化面，再把通过验证的中立 BRep 交给方向识别。原始缓存保持不变；洗面结果另存 `Reports/staging/Reports/<输入名>/part-1-healed.icaxbrep`。

洗面默认线性容差为 `1e-6 mm`，合并角度容差为 `1e-8 rad`，不复用加工面判断的距离容差。恢复平面时检查样条控制网；恢复一般拉伸面时检查整张有理控制网的相同权重和线性平移关系；圆柱和圆锥恢复同时重建原三维边在新曲面上的参数线。参数线最大偏差由内核曲线检查器测定，只有在配置容差或原边界容差预算内才接收。验证还覆盖裁剪线环、面有效性、实际法向、面积、实体数量、带符号体积和中立 BRep 往返。曲面表达改变导致内核积分阶数结果不一致时，用原裁剪域上的自适应边界积分复核，报告记录所用方法；不放宽面积阈值。

每张原始面都返回源类型、结果类型、处理状态、保留原因、偏差和结果面 ID。无法验证的转换保留原面，包括尚无专门参数映射的周期缝或退化边。该保留会明确记录，不冒充解析化成功。转换批次未通过整体拓扑、体积或持久化验证时，完整撤回该批次，返回已验证的原几何，并以 `conversionBatchRejected=true` 和逐面 `retained` 状态记录；转换统计归零。非法输入和输出文件回读失败仍阻断后续 Align。`Success` 表示返回几何已验证，不表示所有面都完成了解析化。

同域合并由 `SCadBRepHealOptions::MergeSameDomain` 独立控制，默认关闭；批量脚本可用 `--heal-merge` 启用。合并只在每个原有 Solid 内进行，保留完整的多对一面映射；跨实体、共享面归属不明确的实体、没有明确实体归属的散面均不合并。不缝合成实体，不做布尔并集，也不因重合且反向删除排样中的面。

`ClassifySectionFaces` 复用加工轨迹分析的截面分割与侧壁判断，返回中立的全部裁剪面、加工面、非加工面及诊断。它不生成刀路，也不发布业务资源。装配预处理入口 `OpenCascade::PrepareAssemblyForRecognition` 目前原样返回输入；不检测装配、不按连通关系拆分，多实体仍作为一个模型识别。

同一连续型材的内部界面证书可沿原支撑面的精确有限重叠域传播：仅将被证明的内部片归为非加工，外露余片仍保留加工；派生片记录父源面、接口锚点与原 coedge/曲线来源，总裁剪面积和原 CAD 保持不变。`SectionZeroAreaTrimFace.inc` 另检查严格塌缩的非周期参数域，或在浮点表示误差内反向重走同一顶点对的两条一次参数曲线；证明没有二维裁剪域的面仍保留于 `SplitGeometry`，归入非加工并记录完整证书。不能用面积大小、网格生成失败或放宽 CAD 容差替代该证明，微小正面积域仍须保留。

`MachiningEdgeAnalysisWork` 紧接加工面分类，在原边参数域上输出分析段。每段独立保存两个枚举：皮关系 `OnSkin / OffSkin / PartialOnSkin`，与相邻加工面的关系 `Concave / Convex / Coplanar / Free`，组成 3×4 的组合。普通加工边的每个分析段都有明确的两个枚举；参数接缝和退化边单列在 `excludedEdges`，保留原面、线环和 coedge 引用，不混入业务枚举统计。皮关系依据固定截面轮廓，不把非加工面一概视为毛坯皮面。邻接只在加工面集合内统计，只有一个加工面覆盖的段为自由边，非加工面不参与凹凸配对。

皮关系分段通过 `MachiningEdgeSkinSpans.inc` 完成：沿 X 将原曲线保参数投影到 YZ，用有限轮廓的实际交点、正长度支撑重合区间端点，以及原 BSpline 中支撑规律发生变化的 knot 划分参数域。同一支撑关系连续不变的 knot 不额外产生分析段。每段整体在皮上时优先归为 `OnSkin`；其余段一个或两个端点在皮上时为 `PartialOnSkin`，否则为 `OffSkin`。内部孤立相交或相切点保留为分界，不生成零宽的 Skin 段。原边只在末端接触皮时，距离容差内的近端邻域仍属于同一 Partial 段，不能沿 `distance=0.001 mm` 等值线制造 Skin 窄条。几何采样用于支撑检查和偏差记录，不能用 49 个采样点的位置冒充实际交点参数或连续误差证明。来源皮面归属证据与原曲线近似偏差分别保存。

几何重合边只在已验证的有限覆盖区间内建立分析邻接，按这些区间端点分段后重新统计邻面。已有完整的双面拓扑邻接保留，不能因别处重合又跨组件拼成多面邻接；已拒绝的同侧重合关系不能通过传递合并重新引入。分析段使用唯一 `edgeKey`，`edgeId` 始终是原边编号，同一原边可对应多个分析段。`sourceEdges` 保存原边完整参数域和 `segmentKeys`，`faces.edgeKeys` 引用分析段，`faces.edgeIds` 与线环分组仍引用原边。分析不物理裁剪或修改输入 CAD。

加工面分类使用轮廓的精确裁剪曲线计算投影点的最近距离：直线段用点到有限线段距离，圆弧、椭圆弧与样条用限定参数范围的曲线投影并检查两端点。`Samples` 仅用于显示，不作为圆角侧壁的距离基准；显示弦误差不能参与 `dSkinDistanceTolerance` 的判定。横向孔壁、斜切面仍须分类，不按面长、面积或文件名排除。

重合且朝向相反的原始面不能据此排除：输入 STEP 可能是排样结果，相邻零件的加工面可以完全重合。分类与刀路面收集均保留这些面，分别依据固定截面判断；平行于拉伸轴也不是删除加工面的条件。回归检查两个、三个腔体的未合并接触模型，验证两侧原面面积均保留。

调用方明确声明输入是同一根连续型材时，可设置 `SFeatureToolpathOptions::bSingleExtrudedStock`。此时只有同时证明以下条件的内部接合面才归入非加工：平面精确平行拉伸轴并贯穿输入的两个轴向端点；存在完整覆盖它的真实反向同面；按原 `0.002 mm` 距离向法向两侧偏移后，固定截面的拉伸材料均覆盖整张面，面积误差仍满足原 `1e-6` 门限。独立零件／排样输入不作该声明，服务不能从重合关系推断业务归属。局部接触切面、孤立槽底和缺少双侧材料证明的面保留加工分类，原始几何始终不删除。本轮真实管材测试以一文件一根固定截面型材调用该声明，并在逐件报告记录 `singleExtrudedStock=true`；两个、三个腔体分别回归未声明、已声明及局部接触三种情况。

解析化会改变圆弧的参数坐标系。内环最小性检查遇到点域分类器返回内部点时，先按原连接容差计算该点到候选有限边界曲线及端点的精确距离；落在边界容差内的点不能用作内部边证据。回归包含不同参数坐标系的半圆柱及四张轴向连接面，验证 Heal 后内环与连接加工面同时保留。

截面顶点母线经过面内且未被原边界覆盖时，用跨越该面轴向包围盒的完整母线作为分割工具，由内核与原裁剪边界求交。边界求交参数用于证明需要分割，并在真实面内区间测定新工具所需的参数一致性容差，不能同时用于截短工具；近似端点留下的微小间隙会让毛坯长侧面与局部加工区域仍连成一面。完整工具不预先向有限样条曲面域外投影；其参数线由分割内核在实际交段上生成，不扩大原面公差。回归检查平面与有限样条表达的斜边局部凸片和微小端点偏差，验证长侧面与凸片分别分类、总面积不变。

分割工具按原面隔离，仅交给证明它位于其上的那张面；不同实体、反向重合面和同一面的独立出现不共用其他面的切线。收集分割区间时，每张面上的有限裁剪参数线只提升一次，后续母线复用其三维曲线和精确包围盒求交；不再把每根完整母线投影到不包含它的 NURBS 支撑面上。实际面内区间仍检查点域与原有公差后才创建工具，既有边界的覆盖判断保持独立。

解析平面的法向若按原角度门限已证明不垂直于拉伸轴，则其任何子面都不可能成为轴向毛坯侧面，也不可能包含沿 X 的母线。此类横向／斜切加工平面整体保留，不再对整组截面顶点逐一搜索轴向分割线；曲面与可能包含毛坯／加工混合区域的轴向平面仍走完整分割流程。该排除只省去无效细分，不删除加工面、不按长宽比或面数判断。回归检查斜切平面的面数、面积、原输入字节和没有母线求交搜索。

审阅导出的有效性分析按整份准备几何执行一次，并复用分析器中各面、边的结果；不再逐面创建分析器后立即重复整体验证。截面边界与材料覆盖分析在同一次操作内复用已重建的原始 BRep，切面计算声明为非破坏操作；原始投影 SVG 也复用对齐时的同一次重建。各文件的 STEP 写出、重新读入、面数量、面积、同级展示和轮廓颜色检查仍分别执行，容差和 240 秒限制保持不变。

分类只将全部裁剪面转换为中立 BRep 一次，`MachiningFaceIds` 与 `NonMachiningFaceIds` 引用 `SplitGeometry` 中的稳定面编号；两个分区保留这些编号、实际面方向及所引用的原始曲线、曲面和拓扑记录，移除无关记录，分别返回独立可重建的模型。验证程序重建全部裁剪面一次后按编号组成分区，不再为三个重叠结果反复重建相同曲面。回归验证分区编号完整且互斥、独立分区可重建、平铺根面和面积一致。

分割结果在拓扑未再改变时复用已完成的完整有效性结论。验证程序仍独立检查中立数据重建的全部裁剪面，并以同一分析器验证直接由其原面组成的两个 Compound 分区；分区不含 Shell/Solid，不能新增壳体约束，也不能用面编号完整性代替逐面有效性。回归同时验证有效分区与无效分区共存时，各自结论不受另一分区影响。洗面输入与持久化结果重建后仍各自完整校验，去除重建入口附带的重复诊断扫描；整份模型的有效性分析启用内核并行执行，几何检查项目和门限不变。

中立 BRep 适配器每次重建时，为曲线、曲面、线环和面记录建立只读编号索引，避免逐边、逐面反复线性扫描全部记录。索引只在当前调用内存活，引用原始记录，查找保持原先相同编号的首次匹配规则；不重新编号，不修改曲线、参数域、容差或输入模型。

`ReconstructOpenCascadeShape` 只报告重建是否完成，`bOK` 不代表几何有效。识别及阶段验证流程在原有明确的输入、分割结果、审阅准备和 STEP 读回检查处验证几何，不再在每次中立重建时重复执行未参与通过判据的诊断扫描。需要独立重建诊断的调用仍使用 `BuildOpenCascadeShape`。回归核对两种入口产生相同的精确中立几何，并验证故意破坏的输入不能把“重建成功”当作几何校验通过。

单件计算使用已有 `Task::Run`、`ThreadPoolTaskScheduler` 和 CAD 几何任务池，统一通过 `OpenCascadeTaskExecution::ForGeometryIndices` 分配独立面任务。洗面候选验证、原面材料投影、候选区域与源面的交集、分割前的面准备及外皮判定均在该任务池执行；默认最多 8 个几何任务，选项 `MaximumConcurrency`／`nMaximumConcurrency` 设为 1 时用相同计算路径串行执行。线程不共享可变 OCC 拓扑、曲面或参数曲线，输入副本在调度前建立，结果按原始面顺序提交。外皮结论只计算一次，凹槽、内部接缝和最终分组共用它。材料交集按原顺序归约并延迟重抛任务异常，保留原来的早期接受语义。取消检查显式传入工作线程；已经在同一有限任务池执行的同步嵌套操作内联完成，避免全部 worker 等待子任务。回归核对串行与并行的精确中立几何、轮廓参数域、面编号和分区一致，并覆盖嵌套调用。

`--compute-benchmark <输入中立 BRep> <目录> <几何任务数>` 单独记录 Heal／Align／Coutour／Classify 的实际计算时间，同时保存各阶段精确几何和轮廓参数域以供逐字节比较。该时间不包含审阅 STEP 导出；完整 `--part` 报告另有每阶段 `computeSeconds` 与总 `seconds`，继续覆盖每份 STEP 的独立读回与验收。性能测量不以批量文件吞吐量替代单件延迟，也不修改几何公差或超时。

材料覆盖先尝试一张源面；已有完整覆盖证明时立即返回，不再为其余重复截面准备几何副本或计算布尔交集。尚未确定的候选区域按任务数上限分批处理，仍按原始源面顺序归约和重抛异常。投影前先用同一支撑面判据排除轴向侧壁，仅为真正参与材料投影的面建立任务私有副本；没有改动材料判据或容差。MSVC `_ITERATOR_DEBUG_LEVEL=2` 使用全局锁维护迭代器，分配密集的布尔交集阶段单独采用一个任务，洗面、逐面投影、分割准备和外皮判定继续并行；Release 的布尔交集仍分批并行。性能报告分别记录 Debug／Release，不混算两个配置的加速比。

浅槽底与切口侧壁分开处理：平行于 X 的平面位于固定截面材料内部，且两端各存在完整连接到底面与同一毛坯表面的横向侧壁时，可将底面归入非加工面，连接侧壁保留为加工面。证明过程中合并同一直线上的连续截面段，不修改截面；槽深不得超过底面的两个面内跨度，避免把窄侧壁误配到远处毛坯平面。缺少双侧连接或材料覆盖证据时保留加工分类。线性、毛坯距离和角度容差仍分别为 `0.001 mm`、`0.002 mm`、`0.001 rad`，不通过放宽容差吸收浅槽或刻字。非加工面不再等同于毛坯面，其中也包含保留的槽底几何。

中立 BRep 重建遇到不一致的平面参数线时，仅在原三维曲线确实共面、端点对应原顶点、每条线环完整且闭合的情况下，由原曲线生成精确平面参数线。原三维曲线、参数范围、顶点、拓扑和面朝向保持不变。刻字回归同时检查线环与边数，以及 STEP 导出重读后的双向边界采样偏差；面积通过不能代替字形检查。

裁剪前判断轴向线段是否已是原面的边界，必须包含 NURBS 表达的直线。对真实裁剪参数区间截取样条后，利用正权重有理样条的凸包性质证明全部控制点位于已有直线的公差管内，再登记端点覆盖区间；不能只检查 `GeomAbs_Line`，也不能仅采样几个点就认定整条曲线是直线。遗漏此判断会重复添加边界，触发分割异常或原面丢失，继而把包含局部加工区域的整张长侧壁误分为加工面。面积守恒与 STEP 往返检查使用自适应曲面积分，防止固定阶积分在样条裁剪前后产生假偏差。

每个拉伸体只对应一套固定基准截面；外环与全部内环属于同一套截面，并共同用于侧壁和加工面的分类。孔、坡口、端部台阶等局部变化不能各自提供一部分边来拼成基准截面。原始截面确有变化时，需要先区分基准截面与局部加工特征；没有足够依据确定唯一基准截面时，应报告不确定。当前投影路径尚未完成这项唯一性判定，因此闭环、颜色及面积检查通过不能证明基准截面正确，也不能仅凭原始面存在就认定它是加工面。`--classification-diagnostic` 可输出原始面与分类面的精确/折线距离、法向、边界框，以及可复查的原始截面 STEP/SVG。

拉伸方向的平行证据簇以加权角距离的 medoid 选择实际观测方向，避免近似平行的斜切边把平均方向拉偏后，在长零件上累积超过分类公差的位置误差。高阶样条面如果在连接公差内可证明为平面，按平面法向判断是否沿轴向延伸，不要求它的 UV 参数恰好是一阶轴向母线。

截面投影在删除悬空边之前，会检查原始横向平面的裁剪边界。只有能连接两个悬空端点、不与现有投影相交或重合、且连接选择唯一的真实 BRep 边，才可补入投影图；不会按距离制造连接线。已连接部分仍保留侧面的曲线表达，避免将导入数据中端面与侧面的近似重复圆角混入同一张图。新增的斜切端部解析样本检查完整投影面积，防止闭环虽有效但端部被截短。

圆弧所在平面包含拉伸轴时，其投影可能是有限直线段；按圆锥曲线参数区间的端点和驻点求完整覆盖范围，不能当作退化点删除。轴向圆柱面（含 IGES 直线旋转面）的边界优先采用原面上的参数曲线 U 区间生成精确圆弧，避免独立近似的三维样条在重合区间产生伪交点。圆柱面的方向证据与直线旋转面的方向证据采用相同的裁剪后轴向跨度。

圆柱形加工端部可能在投影极值处没有拓扑边。满足 `n·X=0` 的轮廓线由原始裁剪面与通过圆柱轴的轮廓平面求交得到；仍只允许它唯一地连接两个已有悬空端点，且必须通过相交检查。此类边记录 `SourceFaceId`，不伪造原始边编号。外环必须包含剪枝前的投影边界证据，不能通过删去断开的主体边界把局部小框判作外环。

内腔排除保留原面裁剪区域：平面通过可逆坐标变换做二维区域相交；曲面则与内环沿轴向拉伸的检验棱柱求交。轴向侧面本身只投影为线，不作填充区域。局部材料投影与候选内环相交不代表整个候选都是材料；只有覆盖下界证明候选区域被完全填充，才据此排除该内环。曲面面积按法向的轴向分量投影，并按解析曲面与轴向直线相交的最大重数约束重复覆盖；无法证明覆盖关系时报告歧义，不把曲面面积直接当作二维覆盖面积。检验棱柱仅用于判断原面是否覆盖候选区域，不缝合、不合并输入实体。轴向 NURBS 圆柱使用原面的横向等参曲线及原始参数边界恢复统一圆支撑，避免独立近似的边界曲线生成伪小环。

轴向抽线未得到包含全部源边的有效外环时，截面提取会尝试原始裁剪面的有限材料投影。可证明单值的曲面片保留支撑和参数线，圆柱及直母线回转圆柱在原参数域的精确轮廓处划分；一般非有理样条采用裁剪后控制网的导数符号与行列式界证明单值，不能证明的面不冒充单值。独立三维边的宽松轴向误差不能传递为二维连接精度：临时分析拓扑按原参数线端点的实际投影误差构造，仍须满足调用方原有门限，源面和源边不变。只合并派生二维材料区域，不合并输入面、实体或反向重合面。

恢复出的外环仍按原连接精度检查每条原始边的 65 个支撑采样点。内腔与全部源边的精确投影相交、分割后，沿用接受环后消耗边、剪除悬边和桥边的规则；无效自交候选不消耗边，已经由接受内腔在同一连接精度下表示的候选不重复输出。没有按文件名、面边编号、面积大小或模型类型跳过验收。该恢复仅用于确定轴后的截面工作，不作为候选轴的额外评分证据。

- `Classify/<原文件名>.step`：输出灰色加工面，并在对齐本体的最小 X 端叠加截面轮廓，外轮廓绿色、内轮廓红色。重新读回 STEP 检查加工面面数、面积、轮廓颜色与端部位置。非加工面、全部裁剪面的面数、面积守恒、拓扑有效性和分割警告仍在报告中检查，不另存辅助 STEP。`--classify-overlay <加工面 STEP> <Coutour STEP> <输出 STEP> <验证 JSON>` 可复用已生成的精确轮廓更新展示，重复执行不累加轮廓。
- `EdgeAnalysis/<原文件名>.step/.json/.brep`：STEP 中加工面保留整体，分析段颜色分别为青色在皮上、橙色不在皮上、紫色部分在皮上；线型分别为凸边实线、凹边虚线、共面边点划线、自由边点线。JSON 保存两个枚举、原面原边编号、完整参数域与分析子区间、匹配分析段、采样证据和排除原因。接缝和退化边通过 `excludedEdges` 单独检查。BREP 每个原模型只有一份，包含整件加工面，不按分析段或边拆成文件。STEP 线型附着于实际 styled item，并回读验证覆盖数；网页按屏幕像素渲染线型。另有 `.html` 时一起发布。BREP 本身不保存颜色和线型，不能把无样式的 BREP 当作可视化验收。
- 中间缓存、日志和逐件报告放在 `Reports`。五个审阅目录内平铺文件，无 `part-1` 子目录。同名不同扩展名的输入追加 `__step`、`__igs` 等后缀区分。

Heal、Align、Coutour、Classify 的审阅几何只输出 STEP，不再并行输出同名 BREP；EdgeAnalysis 按整件审查需要额外输出一份完整加工面 BREP。导出边界统一平铺拓扑：所有 face 直接加入同一个 Compound，保留累积坐标、朝向和几何，不保留 Solid/Shell/嵌套 Compound，也不移动或展开曲面。独立轮廓边和孤立顶点保留。STEP 编码会为独立面添加格式所需的单面 Shell，不重新缝合为实体或多面壳，颜色与逐面显示层级均保留。JSON 诊断和内部 `.icaxbrep` 计算缓存保持独立，计算模型仍保留原拓扑，避免影响识别和体积验证。`--flat-artifact-test <输出目录>` 检查原四阶段内存中的平铺拓扑往返，以及 STEP 的嵌套实体、变换、朝向、游离边/顶点和回读层级；同时确认这些阶段不生成重复 BREP 文件。

审阅导出不能让源模型的宽松顶点重新裁剪精确参数线：某些输入的参数线闭合，但顶点或独立三维边偏离面上端点，STEP 回读会在允许的源拓扑公差内截短边界。`ExactTrimPresentationFace` 仅对存在这种不一致的面建立独立导出拓扑：保留原支撑曲面、全部参数线、裁剪范围、线环、孔和朝向，按参数线端点建立顶点及对应三维边。原线环必须已在现有 `1e-6 mm` 导出预算内闭合；不能借此填补实际开口或放宽容差。计算模型与源文件不受修改。回归同时检查曲面参数线的双向空间偏差、面数、线环、面积以及源 BRep 字节不变。

另一类输入由原有宽松顶点连接不重合的有限裁剪端点。导出副本通过 `ExplicitTrimJunctionFace` 显式表示这段原连接，预算不超过相邻原顶点容差之和；超出预算的真实开口拒绝修复。相邻裁剪线发生回折重叠时，仅在原曲线的精确交点裁去重复连接，不移动支撑曲面或原曲线。修复前以原有限裁剪线与原端点显式连接的闭合域作独立积分参考，修复后检查有效拓扑、面数和 STEP 回读；面积相对阈值始终为 `1e-6`。不再把参数原点相关的开口边界积分当作闭合区域面积，也不使用导出副本自身的面积作为参考。已知面积矩形回归核对面积、STEP 往返和源 BRep 字节不变。

可选的导出准备若使某张原本有效的面无效，只撤回该面的替换，并记录 `presentationPreparationDiagnostics`；保留的原面仍须通过 STEP 回读、面积与逐面层级检查。展示顶点的数值重定心只在现有顶点预算内同时包含全部相邻曲线端点时执行，不增大公差。轮廓展示的灰色透明样式直接绑定每个 face，回读核对全部面的不透明度为 `0.35`，避免只在装配根节点设置样式而未传入 STEP。

独立积分会在曲面及裁剪曲线的全部样条节点、以及参数线穿越曲面节点的位置分段。数值舍入范围内的平面直接对物理边界作 Green 积分，避免非均匀样条参数引起嵌套积分不收敛；带符号体积仍按散度定理计算。回归包含高度集中在两个微小参数区间的已知面积平面，防止两种 Gauss 阶数同时漏采后虚假收敛。积分精度与几何验收容差分别保持原值。

`--heal-face-audit <中立 BRep> <面序号列表> <目录>` 分别保存原面、导出准备面、STEP 回读面及逐面诊断；面序号采用原始拓扑遍历顺序，与平铺 STEP 的 Face 标签对应。`--compare-face-breps <原面 BREP> <回读面 BREP> <JSON>` 可对保留的失败快照重新计算独立面积、线环闭合、顶点偏差和双向裁剪边界偏差。边界偏差诊断按每条面上参数线构造三维曲线并采样比较，报告保留采样精度含义，不将面数或包围盒相同当作几何未变的证明。

STEP 的 XCAF 显示结构也必须逐面展开：本体作为一个装配根节点，每个 face 是直接子节点并标为 `Face 1`、`Face 2` 等。不能只平铺 TopoDS 后用 `AddShape(..., false)` 包装成单个不可展开的显示对象。彩色 STEP 读回同时验证装配子节点与面一一对应；几何面数检查不能代替查看器层级检查。

`TubeStageProbe.exe --self-test <输出目录>` 包含已知尺寸、旋转方向、孔壁/端面分类、彩色 STEP 往返和多实体原样返回的解析样本。真实文件尚无人工标注，报告的 passed 表示自动几何约束通过，不等于识别语义已经人工验收；未通过或超时的输出仅供定位问题。

`TubeStageProbe.exe --heal-work-test <输出目录>` 单独验证规范化、反向面、交换 UV 方向、内孔、自由曲面保留、重复执行不变、接触实体边界、可选合并及完整面映射。

`--edge-analysis-test <输出目录>` 检查两枚举、原边参数覆盖、连续逻辑组、邻接和输入不变；`--partial-internal-interface-test <输出目录> [真实对齐中立模型]` 检查内部域精确分区及外露余片保留；`--zero-trim-test <输出目录> <真实零域诊断缓存根目录>` 检查零域面完整保留于 Split、仅归 NonMachining，并回归微小正面积矩形、非线性两边透镜及完整周期圆柱不被排除。
